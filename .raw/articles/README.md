# .raw/articles/ · 网页文章

> **用Obsidian Web Clipper 一键剪藏的目标目录。**

---

## 怎么存

1. 浏览器装 **Obsidian Web Clipper** 扩展
2. 打开任意网页 → 点扩展图标
3. **目标目录选 `.raw/articles/`** ⚠️
4. 勾选「保存原文链接与出处」

剪藏后的文件自带：正文、原文链接、标题作者、剪藏时间。

> ⚠️ **务必确认目标目录是这里。**
> 存错到 `wiki/` 会污染成品层，存到别处 AI 编译时会漏掉。

---

## 什么样的文章值得存

| ✅ 收 | ❌ 不收 |
|---|---|
| 有完整论证的深度长文 | 营销软文、无观点的资讯 |
| 讲清一个方法论的教程 | 标题党、碎片化观点 |
| 一手经验总结 | 纯转述的二手内容 |
| 有数据支撑的分析 | 没有论据的情绪化判断 |

> **宁缺勿滥。** 垃圾进必然垃圾出。
> 判断标准：半年后还会回来看这一页吗？

**交易库特别注意**：只收**方法论层面**的内容（体系辨析、风险认知、执行纪律），
不收行情预测、荐股、涨跌判断。

---

## 编译时会怎么处理

按 `CLAUDE.md`：

1. **保留原文链接与时间元信息** —— 这是溯源依据
2. 判断是**新知识**还是**已有知识的补充**：
   - 是补充 → **更新已有页面**，不另建
   - 是全新且长期有用 → 建新页
3. **单篇文章不构成 `syntheses/` 依据**（综合理解需跨体系或 2 份以上资料）
4. 案例需**匿名化**，不写具体标的推荐
