# .raw/distilled/ · 编译中间产物

> **AI 自动写入，你不用管。**

---

## 放什么

编译过程中产生的中间文件：

| 内容 | 说明 |
|---|---|
| 逐页提取片段 | 从 PDF 抽出的原文段落 |
| 章节摘要 | 编译时的临时整理 |
| 待核实参数列表 | 存疑的数值，等人工确认 |
| 素材 hash 记录 | 增量编译用 |

---

## 重要特性

| 特性 | 说明 |
|---|---|
| **可以随时删** | 内容是重建的，不是原始资料 |
| **不是知识层** | 不参与检索、不参与双链 |
| **不保证完整** | 可能只编了一部分 |

> 📌 与 `.raw/` 其他三个目录的区别：
> `articles/` `clips/` `academic/` 是**你存的原始资料，不可变**；
> `distilled/` 是**AI 生成的中间产物，可重建**。

---

## 为什么单独隔开

不隔开的话，中间产物会混进原始资料，
既污染素材层（违反「原始资料不可变」），又让编译逻辑变复杂。
