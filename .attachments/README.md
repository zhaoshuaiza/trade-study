# .attachments/ · 附件目录

> Obsidian 的**默认附件存放位置**。

---

## 用途

存放图片、PDF 等附件文件。

| 情况 | 说明 |
|---|---|
| Web Clipper 剪藏带图 | 图片可能存这 |
| 缠论 PDF 的插图 | 186MB  book's 图解 |
| 案例截图 | 黑马王子的形态图 |

---

## 重要说明

⚠️ **这里不参与知识层，不参与检索。**

附件只是文件的存放位置，**真正的知识必须在 `wiki/` 的 md 文件里**。
一张图本身不构成知识，要配上文字说明才有意义。

---

## 与素材层的关系

`.attachments/` 是**存放位置**，不是素材层：
- 内容可以是原始资料的一部分（图片）
- 但它**受 `.raw/` 的规则约束** —— 原始图片不可修改

---

## 建议

如果图片与某个页面强相关（如缠论中枢示意图），
**在页面里用 `![[图片名]]` 嵌入**，并在页面正文里解释这张图说明了什么——
而不是只把图扔在这里。
