## 五套体系

```
道氏理论 ──→ 波浪理论 ──→ 缠论
（趋势源头）（结构细化）（国产改造）

海龟法则          黑马王子
（机械系统）      （量价短线）
```

**关键认知**：道氏 → 波浪 → 缠论是**同一件事的三个阶段**，不是三套并行方法。
缠论不是波浪的改良，是**因为波浪主观而另起一路**。

| 体系 | 一句话本质 |
|---|---|
| 道氏理论 | 趋势是可观测的，不是可预测的 |
| 波浪理论 | 价值是**排除**不可能的数法，不是预测下一浪 |
| 缠论 | 不预测方向，只定义「走势完成的判据」 |
| 海龟法则 | 90% 是风险控制，赚钱是自动的副产品 |
| 黑马王子 | 短线爆发力来自量价关系，与趋势无关 |

**详细对比** → [[wiki/comparisons/五套体系总览对比.md]]

## 日常三件事

**① 编译**
```
读 CLAUDE.md，编译《XXX》
```
AI 会读PDF → 提取概念/体系/来源 → 建页→ 建双链 → 更新索引。

**② 提问**
```
根据库里已有内容，回答：xxx
```
AI 先查库再回答，**库里没有就说没有**。

**③ 体检**
```
读 CLAUDE.md，对全库做一次健康检查
```
只生成报告不直接改，等你确认。
