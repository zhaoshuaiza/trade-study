# 陈浩《筹码分布》· 来源页

> 作者陈浩，与杨新宇博士合作，1996–1997 年发明**筹码分布（CYQ）**、**成本均线**等数十种指标，
> 并据此开发"指南针"证券分析软件。本书是 A 股**庄股时代（2000 年前后）**筹码分析的代表作，
> 核心是用"市场成本"视角替代传统 K 线视角，把博弈对象锁定为**庄家与散户**。

## 一、本书在讲什么

用**成本分布（谁在哪个价位买了、现在亏还是赚）**重新描述一只股票，
把"K 线形态"翻译成"筹码迁移"，以此识别庄家吸筹、控盘、派发的全过程。

- 给谁看：A 股**中长线持仓者**、想识别庄股与主力意图的人
- 解决什么：传统技术面看不到"持仓成本结构"，本书用 CYQ 把成本画出来
- 核心工具：**CYQ 筹码分布**（代号）、**成本均线**、**博弈 K 线**、**活筹指数**、**短线盈亏**

## 三、可落成动作的判据（看盘用）

1. **看支撑/压力**：打开 CYQ，找当前价格附近的**最厚筹码峰** → 那是天然支撑/压力，
   价格触及后观察"无量上穿"（突破）还是"放量滞涨"（遇阻）。
2. **判吸筹完成**：低位出现**单峰密集 + 筹码锁定（不随上涨发散）** → 主力吸筹尾声，
   结合"低位无量上穿密集区"确认。
3. **判出货**：高位出现**密集 + 横盘** → 警惕派发；若"次高位横盘后向下破位" → 出货确认。
4. **选受伤庄股**：前期中高控盘 → 因大盘暴跌被套 → 大盘企稳时优先自救（L268–280）。

## 四、⚠️ 适用边界与坑

- **适用对象**：A 股**中长线持仓**、想识别主力成本结构的人。
- **时效性极强（务必标注）**：本书方法论建立在**2000 年前后庄股时代**——
  当时庄家控盘普遍、散户被动。如今 A 股机构化、量化化，**纯庄股模式已大幅弱化**，
  CYQ 的"高控盘庄股"信号需打折使用。
- **参数是否可核实**：CYQ/成本均线为陈浩自研指标，原书给的是**原理与形态定义**，
  非可调参数（如 N 日）。现代软件（同花顺/东方财富）自带"筹码分布"功能，算法细节可能与原书不同。
- **与用户约束的关系**：用户只做 A 股单边 + 可转债，本书**完全合规可用**；
  但其"跟庄"思路偏中长线，与可转债 T+0 波段、游资超短是不同时间框架，勿混用。
