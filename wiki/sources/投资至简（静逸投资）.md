## ⭐⭐「原点 → 体系」推导链条（本页核心）

作者原话（前言 / 第一章开头）：

> 「投资就是**放弃一种资产，获得另一种资产更多的未来现金流的折现值**。」
> 这就是投资的"第一性原理"，投资的"原点"。
> 资产配置、标的选择、估值方法、买入标准、持有的原因、卖出时机、投资原则、资产观、
> 风险观、企业分析方法……**都可以而且应该从投资的第一性原理推导出来**。

### 完整链条

```
【原点】投资 = 放弃一种资产，获得另一种资产更多的未来现金流的折现值
   │
   ├─(1)─→ 内在价值 ≡ 未来现金流折现值（唯一标准，非账面/历史成本/清算/公允价值）
   │
   ├─(2)─→ 按「未来现金流特征」把一切资产分三类：
   │        ① 现金类（现金/存款/债/货基）→ 长期确定缩水，只留流动性
   │        ② 交易类（黄金/原油/比特币/艺术品）→ 只有一次性现金流
   │        ③ 股权类（企业/商铺/农场）→ 持续产出，不需要他人接盘
   │        ⇒ 股权长期收益最高（三因：蛋糕做大 / 股权分蛋糕分得多 / 利润再投资复利）
   │
   ├─(3)─→ 【第一决策】资产配置 > 标的选择 > 市场择时（择价）
   │        ⇒ 长期大比例配置股权类资产
   │
   ├─(4)─→ 股票内在价值 = 企业未来现金流折现值 × 持股比例
   │        ⇒ 推出股票投资「四大基石」（均由原点导出）：
   │           企业思维 / 安全边际 / 市场先生 / 能力圈
   │
   ├─(5)─→ 分子：未来现金流由 6 个因子决定
   │        确定性 · 盈利性(ROE) · 自由性 · 成长性(g) · 寿命(n) · 管理质量与企业文化
   │        ⇒ 折叠为定性四问：商业模式 / 发展空间 / 竞争壁垒 / 管理质量与企业文化
   │        ⇒ 这就是第二章的全部内容（商业洞察 = 对这 6 因子的展开）
   │
   ├─(6)─→ 分母：折现率 r = f(无风险利率, 生意确定性)
   │
   ├─(7)─→ 估值：P = EPS × PE，且 PE = Normal PE + e
   │        Normal PE = 内在价值 ÷ EPS  ← 由现金流折现推导出来
   │        e = 情绪扰动项（不可计算，属行为金融学）
   │        ⇒ PE / PB 只是现金流折现的「特例表达」，不是独立方法
   │
   ├─(8)─→ 股票市场三条公理（模仿欧氏几何演绎）
   │        公理一：一股 = 一个基本单位所有权，优秀企业内在价值长期增长
   │        公理二：股价长期回归内在价值（价值规律 + 套利原理）
   │        公理三：主观定价 + 边际定价 ⇒ 短期与给定时点价格完全随机、不可预测
   │        ⇒ 七条推论（见下）
   │
   ├─(9)─→ 时间尺度：股价回归内在价值一般需 3~5 年
   │        且股价只反映「可见未来」（3~5 年或 5~10 年），随新信息贝叶斯式动态调整
   │
   ├─(10)→ 安全边际 = 价格相对 DCF 的折扣；分静态（低PE/PB/高股息）与动态（成长带来）
   │        ⇒ 价格 vs 质量的天平 → 加入「时间」变量后**质量为先**
   │        ⇒ 安全边际不是第一原则，**企业思维（买对）才是**
   │
   ├─(11)→ 「安全边际要多安全？」由**机会成本**决定，不存在绝对定量标准
   │
   ├─(12)→ 买入标准：股价相对未来自由现金流折现有合理折扣
   │                ≈ 预期收益达到机会成本导出的目标
   │
   ├─(13)→ 卖出四标准（详见概念页）
   │
   ├─(14)→ 买入与卖出**非对称**：估值区间内 = 持有，既不符合买入也不符合卖出
   │
   ├─(15)→ 集中度 = f(确定性, 弹性)（凯利公式思想）→ 主要持仓 10 只左右
   │
   ├─(16)→ 能力圈 ≡ 能判断现金流折现的范围；「懂」≡ 有大把握判断 5~10 年未来
   │
   └─(17)→ 【终点】一句话投资体系（见下）
```

### 三条公理的七条推论（第一章第二节）

| # | 推论 | 可执行动作 |
|---|---|---|
| 一 | 股票其实是**流动性很差**的资产 | 只用**闲钱**（未来五年以上不动用的钱）入市，杜绝期限错配 |
| 二 | 任一时刻的股价/市值/净值都是**精确的错误** | 不把账户市值等同于活期存款余额 |
| 三 | 只有**长期持有**才能确保股价与价值的高度相关性 | 对全部时间"傻傻全覆盖"，保证"闪电时刻"在场；反对做T、反对板块轮动 |
| 四 | **止损、止盈等任何基于买入成本价的决策都是逻辑错误的** | ⚔️ 建议把成本价改成 0 元并忘掉它；只有"止错"，没有"止损" |
| 五 | 任何隐含短期/给定时点预测的决策都是逻辑错误的 | 决策前逐条自查是否隐含预测 |
| 六 | 投资策略与资金量**无相关性** | 小资金也不该激进、不该单押、不该上杠杆 |
| 七 | 股价有反身性，极端价格永远可能出现，非理性可维持数年 | **不使用任何程度的杠杆，不做空** |

### 终点：一句话投资体系（第一章第三节第八小节，原文照录）

> 「**不预测市场，但利用市场已经给出的机会，不断将自有资产转换为少数价格合理，
> 且我们可以深刻理解的优质股权尽量多的份额，逐步构建一个稳健均衡的优质股权资产组合，
> 耐心持有这些公司，伴随其尽可能长的经营时间。**」

八个要点：**优质股权组合 / 不预测市场但利用机会 / 自有资产（无杠杆无做空）/ 少数 /
价格合理 / 深刻理解 / 尽量多 / 尽可能长的经营时间。**

## ⭐ 编译中挖到的核心干货（参数原样保留 + 出处章节）

### A. 估值与折现

1. **折现率取值**（第一章第一节·五·5）：巴菲特 1994 年股东大会原话——
   「至于折现率，在**长期债券的利息 7% 的情况下，我们至少会用 10% 以上的折现率**。
   当然，折现率也取决于我们对生意本身的确定性的看法……生意的确定性越高，
   我们愿意付出的价格越接近其自由现金流折现值。」
   → **动作**：先取长期国债利率作基准，再按生意确定性上调；或只用无风险利率折现、把确定性差异放到「价格折扣」上（作者说两种做法等价）。

2. **茅台 DCF 演示**（第一章第一节·三）：2018 年净利 340 亿元≈自由现金流；
   假设 2019—2028 年每年增长 **15%**、2029 年后每年 **5%**、折现率 **10%**
   → 2019-01-01 内在价值 **15,514 亿元**；当时股价约 **600 元/股 × 12.56 亿股 ≈ 7,500 亿元**，
   约为内在价值**五折**。
   **参数敏感性**（原书表 1-3 结论，逐项保留）：
   | 假设 | 折现值 |
   |---|---|
   | 前 10 年 +15%，之后 +5%，r=10% | **15,514 亿元** |
   | 前 10 年 +20%，之后 +5%，r=10% | **22,704 亿元** |
   | 前 10 年 +10%，之后 0，r=10% | **6,800 亿元** |
   | 前 10 年 +15%，之后 +5%，**r=7%** | **41,873 亿元** |
   | 永续零增长，r=10% | **3,400 亿元** |

3. **内在价值随时间自增**（同节）：上述基准假设下，2021—2028 年内在价值分别比上年增长
   **7.30% / 7.11% / 6.90% / 6.66% / 6.40% / 6.11% / 5.78% / 5.42%**，2029 年后每年 **5%**。
   → **动作**：这就是「以合理价格买优秀公司」的数学依据——不动也能赚到内在价值自增的钱。

4. **企业寿命的权重**（同节）：基准假设下 2029 年之后的折现值 **11,137 亿元，占比近 70%**；
   若只活 10 年 / 20 年，内在价值只剩永续假设的 **30% / 55%**。
   → **动作**：把「这门生意还能活多久」当成独立评分项，而不是附属项。

5. **股价回归内在价值的期限 = 3~5 年**（第一章第二节·三）：
   巴菲特「至少持有五年」；费雪「三年守则」；邓普顿「未来五年的盈利预期」（其组合平均持有期也是五年）；
   斯文森「三年、四年乃至五年」。作者结论：**市场价格反映内在价值期限一般在 3~5 年**。
   → **动作**：给自己定「三年守则 / 五年守则」——既要有耐心，又要防错：
   合理价格买入后 **三年甚至五年仍浮亏或收益一般 → 反省是否看错**。

6. **股价只反映「可见未来」**（第一章第二节·四）：反映的通常只有**三五年的可见未来**，
   随新信息**贝叶斯式动态调整**（例：乔布斯 1985 年离开、1996 年回归、2001 iPod、2007 iPhone，
   股价每一步都只反映当时可见的信息，不会提前反映 10 年后）。
   → **动作**：只需看清 **3~5 年或 5~10 年**，不必也不可能有穿越 30 年的能力；但要**定期动态重估**。

7. **P = EPS × PE，PE = Normal PE + e**（第一章第一节·四）：
   Normal PE 由 DCF 决定；e 是情绪项。
   → **动作**：判断高估/低估的参照系是**企业自身的 Normal PE**，不是市场平均 PE、不是历史 PE 分位。

8. **业绩 vs 估值的时间权重**（同节，《沃伦·巴菲特的投资组合》研究数据）：
   持股 **3 年**股价与业绩相关性 **0.131~0.360**；**5 年** **0.374~0.599**；
   **10 年** **0.563~0.695**；**18 年** **0.688**。
   → **动作**：持有期越短，赚的越是估值波动的钱（只有一次、无复利）；业绩增长才有复利。

9. **收益率两种口算法**（第一章第一节·四·6）：
   ① DCF 法——简单算 DCF 区间，假定 **5 年**回归内在价值，若现价相对区间最小值仍打**五折**，
   预期收益约 **15%**；
   ② PE 法——估未来 5 年利润年化增速（如 20%），若预期 5 年后估值不变，则预期年化 ≈ 20%。

### B. 买入 / 卖出 / 持有

10. **买入标准**（第一章第三节·三）：「股价相对于未来自由现金流折现有合理的折扣」，
    等价于「预期收益达到我们的目标」，目标由**机会成本**导出。

11. **巴菲特的 10% 不是教条**（第一章第三节·二）：2002 年致股东信——
    「除非我们发现有很高的概率可以让我们获得**至少税前 10%**（也可视为公司税后的 **6.5%~7%**）的回报，
    否则我们宁可坐在一旁观望。」作者明确指出：这 10% 是**根据当时机会成本定下来的**，
    「一些投资者因此将预期收益 10% 作为合理价格，其实是教条主义的理解」。

12. **四个卖出标准**（第一章第三节·三）——详见 [[concepts/投资至简·四个卖出标准与非对称买卖]]。
    ① 发现当初**看错了**（价值投资者没有"止损"一说，但应坚决"**止错**"）；
    ② 企业基本面发生**长期的**恶化（不是短期）；
    ③ 企业价值被"**极度高估**"（不是"一般高估"）；
    ④ 发现"**明显更好**"的机会（作者给的尺度：**好上 100%、200%** 才值得换股；好 20%~30% 无法判断，不必换）。

13. **买入/持有/卖出三区**（第一章第三节·四）：设估值区间 100 亿~200 亿元——
    **低于 100 亿（最好 50 亿）才买**；**显著高于 200 亿可卖**；**100~200 亿之间 = 持有，不买也不卖**。
    书中对"持有"的逻辑拆解：持有 = 「卖出 + 买入」两个动作，**与"买入"不可比较**（违反逻辑同一律）。

### C. 仓位与集中度

14. **主要持仓 10 只左右**（第一章第三节·八·4）：「我们的主要持仓标的在 **10 只左右**，且有相对侧重」；
    第一章第三节·五则说「选择 **5~10 家**具有长期竞争力而且价格合适的公司」；
    容错机制第 6 条说「如果拥有 **5~10 只**，每只股票都看错的概率就会大幅度减小」。
    → 三个数字同出于本书，**均原样保留**（10 只左右 / 5~10 家 / 5~10 只）。

15. **集中度由"确定性 × 弹性"决定**（第一章第三节·五）：确定性优先于弹性；
    弹性大但确定性有瑕疵 → 要么不投，要么**小仓位**。
    → 详见 [[concepts/投资至简·确定性与弹性定仓位]]。

16. **行业内部不确定时的分散法**（同节）：能判断行业好但判断不出哪家胜出时，
    「可以考虑同时分散买入这几家企业」（例：巴菲特 2016 年同时买入美国四大航空公司）。

### D. 风险与容错

17. **风险的正确定义**（第一章第二节·六）：「**本金永久性损失或回报不足**」才是风险，
    **股价波动不是风险**。推论：**股票投资中风险越低、收益越高**，不是"富贵险中求"。

18. **风险控制要在买入之前**（同节）：「**胜而后求战**，而不是战而后求胜」。
    书中点名批评私募「净值跌破 **70%** 的清盘线」式止损：「连续止损 10 次，本金还剩下多少?」

19. **容错机制七条**（同节）：① 世界观（必然性/偶然性/多重性）② 投资观（资产形态转化）
    ③ 纪律（只买能力圈内）④ 公司（买确定性高的好公司）⑤ 价格（足够安全边际）
    ⑥ 组合（适度分散）⑦ 行为（**不加任何幅度的杠杆、不做空**）。

20. **回撤五分类**（第一章第二节·七）：
    ① 股价随机游走 → **不可避免**；② 个股短期高涨情绪回落 → **不可避免**；
    ③ 公司业绩回落 → 分长期/短期；④ 黑天鹅 → 事前不可知，事后持续评估；
    ⑤ **牛市崩塌 → 可能可避免，应提前准备**。
    → **动作**：先看是哪一类，只防"可能可以避免的回撤"；避免不了的，不动或伺机加仓。

### E. 能力圈

21. **「懂」= 有大把握判断公司 5~10 年的未来**（第一章第三节·六），
    且是判断**未来"经济特征"**，不是懂产品。
22. **不以行业划分能力圈**（同节）：「落脚点还是放在能否看懂一家企业的商业模式、
    发展前景、护城河、管理质量等几个重要的问题上。企业处在什么行业并不重要。」
23. **研究深度抓大放小**（同节）：「研究茅台，需要对白酒发酵的微生物机理研究很深吗?……
    把企业的商业模式、发展前景、护城河、管理质量等几个大的问题弄明白就完全足够了。」

### F. 思维与心法（第一章第一节·二，19 条"破除偏见"）

24. 由原点直接推出的**反直觉结论**（可作"决策前偏见自查表"）：
    - 「价值投资」的"价值"二字是多余的（芒格：所有聪明的投资都是价值投资）
    - 投资必须建立在**高度确定性**之上
    - 投资必须面向未来，**财务与股价历史数据是结果不是原因**（反线性外推）
    - 投资价值与**短期是否盈利无关**（亚马逊长期亏损但内在价值提高）
    - **安全边际与 PE、PB 高低没有必然关系**
    - 投资价值与过去涨了多少跌了多少**无关**（反锚定效应）
    - **股价越涨，公司反而可能越便宜**
    - **区分左侧/右侧交易毫无意义**；**区分成长股/价值股毫无意义**（成长只是 DCF 的一个参数）
    - 投资价值与**市值大小、板块风格、新兴/传统、行业、现金流稳定性与周期性**均无必然关系
    - 投资价值与**是否逆向无关**；与**巴菲特是否投资无关**；与**股息率高低无太大关系**
    - 格雷厄姆体系只是 DCF「忽略掉某些重要因素的一个特例」
