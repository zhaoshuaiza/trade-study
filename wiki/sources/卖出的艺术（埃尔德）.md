# 卖出的艺术（埃尔德）

> 埃尔德把"卖出"拆成止盈、保护性止损、因交易噪音卖出三类，主张所有出场价在买入前就定好，并用 2%/6% 铁律与多种追踪止损把"离场"落成可执行的数值规则——这是离场判据总纲。

---

## 一、本书在讲什么

1. 本书是埃尔德"以交易为生"系列的离场专册，核心信条是**"卖出的所有决定必须在买入前做出"**：开仓前必须写下入场价、止损价、止盈价，并据此算出损益比（经验值 ≥3:1，作者很不情愿做 <2:1 的交易）。
2. 全书把卖出分为三类：**止盈卖出、保护性止损卖出、因市场状况变化（交易噪音）卖出**；前两类人人可用，第三类需要大量经验，新手可跳过。
3. 资金管理有两条铁律：**2% 规则**（单次交易总风险 ≤ 账户总资产 2%）与 **6% 规则**（当月累计亏损含浮亏达 6% 即停手）；止损是一条单行道，只能收紧不能放松（多单只上移、空单只下移）。
4. 指标层面提供 **MACD 柱背离、强力指数（FI）背离、NH−NL 新高新低背离** 等"提前落袋"信号，并与三重滤网的时间框架对接——短线看日线噪音、长线等周线更大信号。

## 二、核心参数与判据（原书原值，未改动）

| 判据 | 具体规则（原书原值） | 原文出处 |
|---|---|---|
| **2% 规则（铁三角）** | 单次交易总风险（含佣金滑点）≤ 账户总资产 2%；头寸公式：单次最大风险 ÷ 每股风险 = 最大股数（止损越宽股数越少）。原书例：10 万账户 → 2000 美元上限 | 资金管理铁律（2%规则专节） |
| **6% 规则** | 当月账户累计亏损（含浮亏）达到 6%，当月剩余时间停止交易、场外等待 | 资金管理铁律（6%规则专节） |
| **安全区（SafeZone）止损** | 用 22 日 EMA 定义趋势；涨势中噪音=今日低于前一日低点的部分，取回测期（约 1 个月日线）噪音均值 × 系数（**2~3**），止损 = 昨日最低价 − 该值；跌势相反（昨日最高价 + 该值）；止损只单向移动 | 安全区止损（原书专节） |
| **抛物线止损 SAR** | 今日 SAR = 前日 SAR + AF ×（EP − 前日 SAR）；AF 初始 **0.02**，每创新高/新低加 0.02，上限 **0.2**；适合无回调加速行情，震荡市失灵 | 抛物线止损（原书专节） |
| **MACD 柱 / 价格 顶背离** | 不必等价格到上轨，看到背离即出场，落袋后在场外重新评估；背离后价格常跌回价值区，是再入场时机 | 第6章 因交易噪音卖出 |
| **强力指数 FI 背离** | FI =（今收 − 昨收）× 成交量；FI 深幅尖角下跌 = 多头洗盘见底信号；FI 顶背离 = 卖出信号；价格上轨附近 + MACD 柱超买 + FI 顶背离 → 减仓 | 第6章 强力指标信号 |
| **NH−NL 新高新低背离** | NH−NL = 创 52 周新高家数 − 创 52 周新低家数；周值 = 近 5 日之和；与价格背离 = 趋势转折预警，是最好的大盘领先指标，周线背离为主卖出信号 | 第6章 NH−NL 指标 |
| **时间止损** | 日内交易：股价在 **10~15 分钟** 内明显未按预期变化即了结；波段交易：预计持续数日，若**一周过去仍横盘**说明市场没确认判断，直接出局 | 时间止损（原书专节） |

## 三、可落成动作的判据（看盘用）

1. **开仓前先定三价**：写下入场价、止损价、止盈价，并核验损益比 ≥3:1（至少 ≥2:1）；三价未写、损益比不达标，交易就不算完成计划。
2. **止损用市价/MIT，不讨价还价**：入场和止盈可用限价，但止损一律用 MIT（到价即市价成交）；多单止损只上移、空单只下移，绝不上调多单止损来放松防线。被止损后再次入场完全没问题。
3. **安全区止损落地**：22 日 EMA 判趋势方向；算回测约 1 个月日线的"噪音均值"× 系数 2~3，涨势止损 = 昨日最低价 − 该值，次日刷新只下移、不回头。
4. **顶背离即减仓/离场**：日线 MACD 柱与价格顶背离，或 FI 出现顶背离，不非要等触上轨，先落袋、去场外重新评估；背离后跌回价值区往往是再买点。
5. **上轨/价值区止盈**：价格升到通道上轨之上按计划减仓；一旦出现**长上影 + 收在最低价 + 巨量**这类转弱信号，不执着原目标价，主动了结，避免利润回吐。
6. **反弹疲态卖出**：持仓未到初始目标却显疲态，等价格"创新高失败"当天以收盘价卖出，或次日开盘不久卖出——早卖胜晚卖（雅虎案例：三日不创新高即跌回价值区）。
7. **业绩/公告前出局**：若无法确认公司保密良好，无论多空都在业绩报告前出局（原文：业绩很少带来惊喜，价格已反映预期 + 信息泄露普遍）。
8. **时间止损执行**：日内 10~15 分钟未按预期、波段一周仍横盘，说明市场没有确认你的判断，直接出局，时间也是成本。
9. **大盘见顶信号**：NH−NL 周值与指数背离，或市场出现"门外汉持续赚大钱"（空乘炒股收入超工资、擦鞋工荐股）类心理警钟，清仓。
10. **当月回撤到 6% 即停**：一旦当月累计亏损含浮亏达 6%，立即停止所有新交易，到场外等待到月底。

## 四、⚠️ 适用边界与坑

**适用对象**：股票 / 期货 / 期权通用的技术交易者。用户只做 **A 股单边 + 可转债，不能做期货、不能做空**。

**A 股可直接用的部分（与能否做空无关的价格行为判据）**：
- 2% / 6% 资金管理铁律（按本币账户直接换算）；
- 安全区 / 尼克 / SAR 止损、MACD 柱与 FI 背离、通道上轨止盈、时间止损、业绩前出局；
- 三重滤网的时间框架思路（周线定方向、日线找逆势）同样适用于 A 股与可转债择时。

**需转换 / 注意的部分**：
- 原书用 MIT 市价止损 + 做 T+0；A 股为限价/市价委托且 **T+1**，当日买入不能当日止损，须以前一日持仓为前提来挂止损。
- 全部**做空、期权卖方**条款不可用（与用户约束一致）。
- 尼克止损的"整数价位规避"等短线手法，对可转债的流动性、涨跌幅（±20%/±30%）需重新适配。
- **NH−NL 需改用 A 股全市场或转债样本池**重新定义"52 周新高 / 新低"，原书样本为美股全市场。

**参数可核实性**：2%/6%、22 日 EMA、系数 2~3、SAR 的 AF 0.02→0.2、时间止损 10~15 分 / 1 周 均来自原书专节，可机械核对；但"回测期长度""噪音系数""通道标准差倍数"需按 A 股 / 转债自身数据重新校准——原书明言直接套用别人参数，逆境中无法对工具保持信心。

**坑（原书自陈的局限）**：
- 追踪止损（SAR / 安全区）**只在强趋势中好用**，震荡市左右挨耳光，且必须准备回吐一部分利润（作者自认约一半时间追踪止损带来更多利润）。
- 滑点与跳空（利空直接跳穿止损位）无法避免，止损是"仅有的、最好的工具"，不是完美工具。
- "因噪音卖出"需要大量经验积累，新手不要模仿；市场警钟（心理信号）无法量化，机会极少、常事后才听懂。
