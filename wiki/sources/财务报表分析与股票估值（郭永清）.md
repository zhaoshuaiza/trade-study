## ⭐ 编译中挖到的核心干货

### A. 口径类（本书独有，最值钱）

1. **⭐ 营运资本口径被本书改写了** —— 通用教材「流动资产 − 流动负债」；本书「**营运资产 − 营运负债**」，剔除未投入循环的金融资产与短期债务。**书中原话**：「本书中的营运资本定义与一般教材中的营运资本定义之间存在差异」。→ 详见 [[concepts/资产资本表与营运资本口径（郭永清）]]
2. **⭐ 资产负债表重构为「资产资本表」** —— 等式由「资产 = 负债 + 股东权益」改为「**资产 = 资本**」；资产分金融资产 / 经营资产（营运资本 + 长期经营资产）/ 长期股权投资三类；资本分短期债务 / 长期债务 / 股东权益。**理由**：标准表的流动性分类「武断主观」，且无法与现金流量表建立清晰联系（8.1.1）。
3. **⭐ 利润表重构为「股权价值增加表」** —— 把收益按资产归类（金融资产收益 / 长期股权投资收益 / 经营利润），并**补上股权资金成本**；标准利润表的三大缺陷：无法与资产负债表建立逻辑联系、只扣债务资本成本不扣股权资金成本、内部递延所得税处理混乱（9.1.1）。
4. **⭐ 资本支出拆成保全性 vs 扩张性，自由现金流只扣保全性**（15.2.2）—— 这是本书对科普兰公式的改造，理由见下文第 9 条。

### B. 判据类（可落成动作）

5. **审计意见一票否决**：读到「带强调事项段的无保留意见 / 保留意见 / 无法表示意见 / 否定意见」四类之一，**直接剔除出候选池**；书中原话「惹不起，但是躲得起」（1.1）。→ 动作：下载年报先看第 1 页，非标准无保留即跳过。
6. **营运资本为负要分两种**：正常经营下为负 = 上下游谈判能力强（**是优势不是危机**）；因资产资本结构错配、付不出应付账款而被动为负 = **支付危机**。区分动作：看长期融资净值是否同时为负（8.4.4，乐视网为反面例）。
7. **流动比率 / 速动比率被本书判定为不可用**：原话「在工业 4.0 时代，传统的流动比率和速动比率已经不能说明任何问题」。理由：「流动」是动态概念，却用静态时点数据算；提高这两个比率的操作（晚收钱、多存货、早付款）**恰好全部损害公司价值**。→ 用 **营运资本长期化率** 替代（8.4.1 / 8.5）。这条与本库已有的 [[claims/流动比率阈值的两种相反主张]] 构成**第三方立场**，见下文差异表。
8. **经营现金流五态分级**：只有第 5 态（>0 且补偿全部非付现成本后仍有剩余）算健康；前 4 态长期持续都会陷入经营困境（11.4）。→ 动作：把「经营活动现金流量净额 ÷ 折旧摊销」拉 5~10 年看。
9. **⭐「苹果树公司」论证：扩张性资本支出不该从自由现金流里扣**（15.2.2）。书中算例：一家成长期公司连续 20 年把每年 200 万经营现金流全部再投入，按「全部资本性支出」口径自由现金流 20 年全为 0，但股东权益从 1,000 万涨到 4,000 万 —— 作者原话「这是非常荒谬的」。**原口径 → 本书口径**：
   `自由现金流量 =（税后净营业利润 + 折旧及摊销）−（资本支出 + 营运资本增加）`（科普兰）
   → `经营资产自由现金流 = 经营活动现金流量净额 − 保全性资本支出`（本书，15.2.2）
   **保全性资本支出在财报中取不到，通常用长期资产折旧摊销近似替代。**
10. **股权价值增加值替代净利润**（9.9.1）：`股权价值增加值 = 净利润 − 股权资本 × 股东预期回报率`。书中简化取 **8%** 作为股东预期回报；并注明国资委 EVA 用 **5.5%** 加权平均资本成本率，作者认为「从股东角度看 5.5% 略微偏低」。含义：**净利润为正但增加值为负 = 在损毁股东价值**。
11. **ROE 五因素分解定位病因**（10.2）：
    `股东权益回报率 = 息税前经营利润率 × 资产总额周转率 × 财务成本效应比率 × 财务杠杆倍数 × 企业所得税效应比率 × 100%`
    五个因素分别对应：前两个 = 投资经营活动效率，中间两个 = 筹资活动效率，最后一个 = 税负。→ 动作：ROE 下滑时逐项比对，定位是哪一段塌的。
12. **财务杠杆倍数的硬阈值**：「对投资者而言，公司的财务杠杆倍数最好控制在 **2 倍以内**」（8.3.1）。`财务杠杆倍数 = 资产总额 ÷ 股东权益 = 资本总额 ÷ 股东权益`。
13. **营业收入现金含量**（11.3.1）：**平稳经营阶段、剔除增值税后应在 1 左右**；明显低于 1 = 放宽信用政策、收入掺水。（书中原话：「营业收入规模差不多，而应收账款大幅增加，则意味着公司放宽了信用政策」。）
14. **历史证据的窗口长度**：「历史证据的期限必须跨越**不少于 5 年**的时期，最好达到 **7~10 年**，甚至可以更长」（12.3）；安全性的考核期「**五年以上，一般来说七年可能更合适些**」（12.5）。→ 动作：任何财报判据至少拉 5 年再下结论。
15. **安全边际 + 成组购买双原则**（12.5 / 12.6）：因为估值是艺术（三大理由：数据不足或不准确、未来的不确定性、市场的非理性行为），所以必须打折买入 + **组合持有**。原话：「仅仅购买一只股票不能被称为投资，购买一个多家公司组成的股票组合才有可能是一种投资。」

### C. 估值模型类（参数原样保留）

16. **⭐ 股权资本成本率不用 CAPM，用简化法**（15.3.4）：以**我国 5 年期国债利率**为基准，加 **4%~5% 风险溢价**，得 **8%~10%**，按个人风险偏好取值；**本书演示统一取 9%**。书中明确否定贝塔系数：原话「用一个反映过去价格波动的数字就能完全描述一种证券风险的想法真是太荒谬了」「过去的波动性是一个糟糕的衡量风险的指标」。
    > [!warning] 待复核（2017 年口径）
    > 书中锚定的是「**2016 年我国 5 年期国债的利率为 4.2% 左右**」。该利率已变化，8%~10% 区间需按当期国债利率重算，**不得直接沿用**。
17. **⭐ WACC 用账面价值口径，不用市场价值口径**（15.3.4）—— 这是本书与主流教材的**显式分歧**，作者点名了《股票估值实用指南》（加里·格雷）和达摩达兰《估值》都用市场价值。本书三条理由：① 分子经营资产用账面价值，分母须同口径；② 不能资产用账面、资本用市场；③ 市场价值每天变 → WACC 每天变 → 每股内在价值每天变 → 估值失去意义。
    `WACC = kd × [D/(D+E)] × (1 − t) + ke × [E/(D+E)]`
    （D 债务资本，E 股权资本，kd 税前债务成本率，t 实际所得税税率，ke 股权资本成本率）
    - 万华化学：`WACC = 4.52% × 50% × (1 − 22.72%) + 9% × 50% = 6.16%`
    - 中国石化：`WACC = 3.24% × 24.56% × (1 − 19.95%) + 9% × 75.44% = 7.42%`
18. **风险调整走分子，不走分母**（15.3.4）：本书主张不用高贴现率惩罚高风险公司，而是**在估算自由现金流时取保守值**。原话：「第二种方法更加接近价值投资的本质」「公司的风险不是取决于公司价格相对于市场的波动性，而是取决于公司经济基本面的变化」。
19. **⭐ 经营资产自由现金流的完整算例**（15.2.2，可复算）：
    - 万华化学 2015：`460,239.37 − 147,283.57(折旧) − 7,317.79(摊销) − 16,002.01(长期资产处置损失) = 289,636.00 万元`
    - 中国石化 2015：`16,581,800.00 − 8,706,900.00 − 929,900.00 − 72,100.00 = 6,945,000.00 万元`
    - `股权经营资产自由现金流 = 经营资产自由现金流 − 利息支出`（万华：289,636.00 − 107,545.53 = 182,090.47 万元）
20. **公司价值 → 每股内在价值闭环**（15.1 / 15.4）：
    `公司价值 = 金融资产账面价值 + 长期股权投资价值 + 经营资产自由现金流现值`
    `股权价值 = 公司价值 − 公司债务`（债务取账面价值）
    `上市公司股票价值 = 股权资本价值 ×（1 − 少数股东权益比例）`
    - 万华化学：`公司价值 = 208,636.18 + 18,612.81 + 21,346,317.06 = 21,626,068.16 万元`；减债务 2,313,423.57 → 股权价值 19,312,644.59 万元
    - 中国石化：`公司价值 = 7,888,300.00 + 8,297,000.00 + 93,598,382.75 = 112,363,182.75 万元`
21. **两阶段 / 零增长两个算例的参数**（15.3.5，原样保留）：
    - 万华化学（两阶段）：`FCF0 = 289,836.00 万元，g1 = 15%，WACC = 6.16%，g2 = 4%，n = 5` → 经营资产自由现金流现值 **21,346,317.06 万元**
    - 中国石化（零增长）：`6,945,000.00 ÷ 7.42% = 93,598,382.75 万元`
    - g 的约束：「一般情况下，投资者的预期回报 WACC 至少要高于总体的经济增长率，因此不变增长率 g 通常小于 WACC」（14.3）
22. **相对估值四个公式 + 各自的「死穴」**（13.2-13.5）：
    - `市盈率 = 每股价格 / 每股收益 = 股票市值 / 净利润`；死穴：收益为负时不可用；**不能区分经营资产创造的利润和非经营资产创造的收益**。
    - `市净率 = 每股价格 / 每股净资产 = 股票市值 / 净资产`；死穴：忽略资产创收能力差异。书中特别指出 PB **对银行业更有意义**（资本充足率约束规模扩张、资产负债多为金融工具已按市值计量）。
    - `市销率 = 每股价格 / 每股营业收入 = 股票市值 / 营业收入`；优点：任何公司都能用；死穴：**直接忽视成本费用控制能力**。
    - `市盈增长比率 PEG = 市盈率 / 每股收益的年度增长率`（吉姆·斯莱特发明）；书中给出的读法：**PEG = 1 表示定价充分反映成长性**；>1 可能高估；<1 要么低估要么市场认为成长更差。**实践中一般用未来 3~5 年复合增长率**。
23. **相对估值法解决不了终极问题**（13.6）：作者对 A 用 B、C 作可比，对 B 又用 A、C 作可比 → **循环估值**。原话：「我们可以用相对估值法寻找看起来比较廉价的投资标的，但是必须用绝对估值法来最终解决是否值得投资」。
24. **波特五力用于增长率预测的输入**（15.3.3）：现有企业间竞争 / 进入壁垒 / 替代品威胁 / 买方议价能力 / 卖方议价能力，逐项落到「未来 g 该怎么给」。→ 动作：给 g 之前先过一遍五力，而不是拍脑袋。
25. **知识性条目，非动作**：「公司创造价值的过程就是公司财报的生成过程」（3.3）——顺向是「商业环境 → 公司战略 → 经济活动 → 数字结果」，逆向是「数字结果 → 会计质量 → 经济活动 → 战略 → 商业环境」。作者比喻为「类似于福尔摩斯探案，案件是顺时发生，而探案则是逆时还原」。

## 与已有 4 本估值书 / 3 本财报书的差异（本页最大价值）

本库在本书之前已有：估值类 [[sources/价值评估（科勒）]]、[[sources/学会估值轻松投资（达摩达兰）]]、[[sources/故事与估值（达摩达兰）]]、[[concepts/慢慢变富·八不投负面清单与5性九刀估值模型]]；财报类 [[sources/一本书读懂财报（全新修订版）]]、[[sources/财报掘金（王洪张晓曦）]]、[[sources/手把手教你读财报2（唐朝）]]。

### 一、与估值书的差异

| 维度 | 已有估值书 | **本书（郭永清）** |
|---|---|---|
| **起点** | 从市场/倍数/DCF 直接起手（科勒从 ROIC×增长×WACC 三因子起手；达摩达兰从「现金流/增长率/融资成本/期末价值」四输入项起手） | ⭐ **从重构后的财报起手**——先把标准资产负债表改成资产资本表、利润表改成股权价值增加表，估值用的每一个数都从重构后的报表里取 |
| **自由现金流口径** | 科勒：NOPLAT 路径；达摩达兰：`FCFF = 税后运营收入 −（净资本支出 + 非现金营运资本变化）` | ⭐ **只扣保全性资本支出**，`经营资产自由现金流 = 经营活动现金流量净额 − 保全性资本支出`。**扩张性资本支出不扣**（苹果树论证，见干货第 9 条） |
| **WACC 权重口径** | 科勒/达摩达兰/加里·格雷：**市场价值**口径 | ⭐ **账面价值**口径，且作者点名反对上述三家，给出三条理由（干货第 17 条） |
| **股权成本怎么定** | 达摩达兰：CAPM，`无风险利率 + β × ERP`，β 有明确取值规则（单业务用行业平均 β、多业务用分部加权 β） | ⭐ **否定 CAPM 与 β**，用「5 年期国债 + 4%~5% 溢价 = 8%~10%」简化法；**且主张所有公司用同一个股权成本**，差异只体现在分子端的现金流保守度上 |
| **风险放在哪** | 主流：放分母（风险高 → 贴现率高） | ⭐ **放分子**（风险高 → 自由现金流取保守值） |
| **现金/金融资产处理** | 达摩达兰：大额现金通常被市场打折，返还股东更有利 | 一致方向，但本书更进一步给出**动作**：非金融公司金融资产占比过高 → 应加大分红或回购（8.2.1） |
| **少数股东权益** | 已有页未涉及 | ⭐ 本书给出简化扣减式：`上市公司股票价值 = 股权资本价值 ×（1 − 少数股东权益比例）`，并点明**存在巨额亏损子公司时会低估**，需谨慎（15.4.2） |
| **不重叠的部分** | 科勒的 ROIC/经济利润/连续价值公式、达摩达兰的受困概率两段式调整、研发资本化、周期股正常化 —— **本书完全没有** | 本书的报表重构 + 保全性资本支出 + 账面价值 WACC —— **已有估值书也完全没有** |

> 📌 一句话：**已有估值书解决「用什么公式估」，本书解决「公式里的每一个数从财报的哪一格取、取之前要不要改口径」。**
