## 核心论点

### 经验层面（Found in the Middle）

**诊断公式**：`Attn ≈ rel + bias`

**关键判断**：模型**确实**注意到中间的相关信息，
但被首尾的注意力尖峰**淹没了**。这把问题从「看不到」重新定义为
「看到了但被淹没」——两者解法完全不同。

**校准方法**：训练无关的推理时干预，减去位置偏置。
Recall@3 从 20.52% → 68.32%（K=20，gold 在中间）。

### 理论层面（at Birth）

**数学链条**：
```
M[i,j] = 1/i(j ≤ i)        Cesàro 矩阵
N = (1−α)I + αM            残差矩阵
→ 连续极限下的影响密度闭式解
```

**三个结构**：
- **Primacy Tail**——对数发散
- **Recency Delta**——O(1) 孤立锚点
- **阶乘死区** O(1/(H−1)!)——H 为网络深度

**验证**：随机初始化的 Qwen2 与 GPT-2 在 **Step 0 即U 型**，
**有无 RoPE 结果一致**，训练未克服拓扑谷。

## 对既有内容的修正

**一处需要更精确表述**：先前 [[中间遗忘]] 记述的经验现象是
「上下文越长，退化越严重」。理论提供了机制解释，但两者**不能直接等同**：

- 阶乘死区随**网络深度** H 扩张——这是静态结构性质
- 经验上「越长越差」还叠加了 RoPE 类外推衰减

**更准确的说法**：不是「上下文越长越错」，而是
「无论多长，落在中间的那部分始终处于劣势；
越长则中间段占比越大、落入死区的 token 越多」。

这个区分很重要——它意味着**加大上下文并不能改善位置鲁棒性，
只是把同样的劣势摊薄到更多 token 上**。

## 可验证性

- **事实**：两篇论文的作者、编号、会议 —— 全部可核实
- **数据**：Recall@3 20.52%→68.32%、Spearman 0.88–0.98、
  阶乘死区阶数 —— 均来自原论文
- **重要限定**：at Birth 是**单作者预印本**，
  2026-03 发布，**尚未见同行评审**。其结论应视为**待验证的理论主张**
- **时效性**：Found in the Middle 测的是 Vicuna-7b / Tulu-2-7b（2023 年代），
  校准方法在当前前沿模型上是否仍有效**未知**

## 遗留问题

- at Birth 的推广场景（MoE、混合架构）未讨论
- 「偏置可能有用」这一 Found in the Middle 承认但未研究的问题
- 无需 O(K) 额外前向的偏置估计方法是否存在
