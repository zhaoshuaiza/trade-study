## ⭐ 谷底线：比黄金线更简单的第 7 条线

> **「就是画水平线」**——取各阶段最低点即可，
> 但有一条硬要求：**尽量找能与左侧重要点位形成「精准线」的最低点**。

**三个功能**（可直接判断后续走势）：
```
谷底线逐步抬高 → 持股成本抬高 → 后期上涨
谷底线逐步降低 → 套牢盘增多   → 后期下跌
谷底线 + 低量柱 → 休克到位     → 支撑成立
```

**⭐ 与 [[concepts/黄金道]] 的关键差异**：
谷底线**取点可机械复核**（找精准线），黄金道需目测「三个最低点」——
所以黄金道标记 draft，**谷底线可以放心用**。

详见 → [[concepts/谷底线]]

## ⭐ 双阴出货：全库最机械的离场技法

```
① 连续两根阴线
② 第二根跌破（或持平于）第一根的收盘价
   → 立即盘中出货
```

**⚠️ 易漏的关键细节**：
「应包括'**低开高走的假阳线**'」——
**只看有没有跌破前收盘价（中轴线），不看K 线颜色。**

**辅助判据**：全天所有高点都在中轴线下方 → 弱势确认 → 出货。

详见 → [[concepts/双阴出货]]

## ⭐ 谷底线捉涨停四要素（本次新增最实操的一组判据）

| # | 要素 |
|---|---|
| 1 | 谷底线之前有「**长阴短柱**」（缩量假跌）→ ⭐ **假跌必然对应真涨** |
| 2 | 谷底线之底现「**百日低量**」 |
| 3 | 触底后 **3~5 天**内突破第一阻力位（**重在时效**）|
| 4 | 阻力线之前应「**蓄势突破**」（一天触线一天过线）|

**⭐ 反面教材（原文给出失败案例）**：
一次性冲过多个阻力位 = 帮套牢盘解套 =
「连续 10 天受制于第二阻力线，上攻乏力，无功而返」。
