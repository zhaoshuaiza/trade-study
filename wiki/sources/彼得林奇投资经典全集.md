# 彼得林奇投资经典全集（共 3 册）

## 一、⚠️⚠️ 两条任务书前提需更正

### 1. 原文**没有**「15 倍市盈率是买入门槛」这种说法

「15 倍」全文 7 处命中，逐一核对后 **0 处是门槛**：
- 第 11017 行恰是 **PEG 公式的举例**：「可口可乐市盈率 15 倍 → 你应预期增长率约 15%」
- ⭐ 「15 倍」在原文指的是**股价上涨 15 倍的股票**（fifteenbagger），是**结果，不是门槛**

### 2. ⭐ 原文真正的估值判据是 PEG

```
P/E = 增长率              → 合理
P/E = 增长率的一半         → 赚钱可能性相当大
P/E = 增长率的两倍         → 亏钱可能非常大
含股息修正式：(增长率 + 股息率) ÷ P/E ≥ 2  → 才算棒
```
⚠️ **全部无样本量、无统计口径、无回测区间。**

### 3. ⛔ 不是「四大分类」，原文是 **6 类**

缓慢增长型、稳定增长型、快速增长型、**周期型**、**隐蔽资产型**、**困境反转型**。
⛔ **原文没有「收益股」这一类。**

### 4. ⛔「十亿美元俱乐部」在本源文件中查无实据

检索「俱乐部」11 处**全部指投资俱乐部（NAIC）**。已登记，未编造。
