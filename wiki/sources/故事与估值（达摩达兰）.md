# 故事与估值（阿斯沃斯·达摩达兰）

> 达摩达兰把"叙事（故事）"与"数字（估值）"打通的方法论：好故事必须能翻译成市场总额、增长率、利润率、风险与再投资这几个估值输入，并经"价值铁三角"与终值上限自检，否则只是情绪化的炒作话术。

## 一、本书在讲什么

达摩达兰认为估值世界里长期分裂成"故事讲述者"和"数字处理者"两类人，而缺了故事支撑的估值"既无灵魂也不可信"，故事比数据表更易于记忆（尾声，p.1666）。他给出一套可复用的流程：先给公司讲一个**简单、可信、鼓舞人心**的商业故事，再用**三级可能性测试**筛掉不成立的故事，最后把故事逐条翻译成 DCF 的估值输入（收入、利润率、再投资、贴现率）。书的后半部分讲反向操作（从估值数字反推故事）、如何用反馈修正故事、以及现实事件（财报、收购、丑闻、宏观变动）如何改写故事与估值。贯穿全书的核心约束是**价值铁三角**——增长、风险、再投资三者的平衡关系，任何自相矛盾的故事都会在估值里露馅。

## 二、核心参数与判据（原书原值，未改动）

| 概念 / 判据 | 具体规则 | 原文出处 |
|---|---|---|
| 好故事的要素 | 成功商业故事必备四要素：**简单**（简单且言之有理比复杂更难忘）、**可信**（可疑处终将损害故事）、**鼓舞人心**、**促使听众采取行动**。基本原则是多着眼全局与愿景，少抠细枝末节 | 第 4 章"成功故事的精髓"，p.520-523 |
| 三级可能性测试 | 故事须经三关：①**可能发生**；②**很可能发生**（须举证已有类似公司实现过、或公司自身历史佐证）；③**极有可能发生**。通不过第一关的是"商业童话" | 第 7 章，p.655-656 |
| 价值铁三角（不可自相矛盾） | 增长↑→价值↑；风险↑或再投资↑→价值↓。高增长公司通常需**高再投资 + 高风险**，"高增长 + 低风险 + 低再投资"组合自相矛盾、通常不成立。铁三角是发现故事内部矛盾的最简工具 | 第 7-8 章，p.746（图 7-8 价值铁三角） |
| 故事 → 数字 映射链 | 目标市场总额 × 预计市场份额 = 收入；收入 × 税前营业利润率 = 营业收入；− 税金 = 税后营业收入；− 再投资额 = 自由现金流；按风险调整贴现率贴现 = 预期价值。各类型故事对应输入：大市场→市场总额；份额→市占率；护城河→高利润率；低资本集约→低再投资（高营收资本比）；低风险→低贴现率 | 第 8 章，p.784-785 |
| 终值增长率上限 | 终值中的增长率必须 **≤ 公司运营经济体（国内/国际）的名义增长率**；达摩达兰建议**用无风险收益率替代**以收紧约束（高通胀货币下无风险收益率与预期增长率同升，已把货币选择纳入增长估算） | 第 9 章，p.890 |
| 稳定期再投资率 | **最终再投资率 = 稳定增长率 ÷ 投资资本回报率(ROC)**。原书例：若希望在新项目上实现 **12% 的 ROC**，需持续将税后营业收入的 **25%** 用于再投资，方可维持 **3%** 的年增长率 | 第 9 章，p.890-899 |
| 内部一致性检验 | **投资边际收益 = 高增长阶段营业收入变化值总额 ÷ 同期再投资金额**；与资本成本 / 历史资本回报率 / 行业均值比较，过高或过低皆警示需重审增长与再投资假设 | 第 9 章"估值诊断法"，p.917-921 |
| 估值 ≠ 市价 的四种解释 | 当估值与现价大幅背离，只有四种可能：①你对了市场错了；②你错了市场对了；③你和市场都错了（内在价值不可知）；④**定价过程与估值过程偏差**（市场给"类似"公司定价，你做 DCF）。差异大处恰恰是需补研究的地方，而非直接认定市场错 | 第 10 章，p.1018 |

## 三、可落成动作的判据（看盘用）

1. **先写一句话故事，按四要素自检**：能用"简单、可信、鼓舞人心"讲清、且能促使你行动的才进下一步；讲不清或只能靠"赛道好""有想象空间"撑着的，不碰（p.520）。
2. **三级测试打分**：故事是否①可能发生 ②有类似成功先例/公司自身历史佐证（很可能） ③极可能？只投通过二级以上的；对"高增长 + 低风险 + 低再投"的自相矛盾叙事直接打回（铁三角，p.746）。
3. **把故事拆成 5 个可填数字**：市场总额(TAM)、市占率、营业利润率、再投资率、贴现率。任一填不出具体数的叙事 = 翻译未完成，不能当估值依据（p.784-785）。
4. **终值增长率 ≤ 无风险收益率**（A股用十年国债收益率作代理）；高于此的"永续高增长"是童话，直接戳破（p.890）。
5. **算投资边际收益 = 营收变化 ÷ 再投资**；若显著偏离行业均值或公司历史 ROC，说明故事与数字脱节，回到第 3 步重填（p.917）。
6. **跟踪"故事变化"三态**：中断（事件令情节失效）、改变（根本改写）、略微修改（微调）。财报、收购、融资/分红、丑闻、激进投资者入局都是改故事的信号——每次都重估，不死守原故事（p.195，第 11-12 章）。
7. **估值与现价背离先走四种解释**：别默认自己对了、市场错；差异最大处是你研究最薄弱处（p.1018）。
8. **转债视角**：正股叙事质量决定转股价重估空间与强赎/下修博弈；"低 PE 正股 + 高增长故事"若再投资率撑不起增长，是童话而非便宜（铁三角 + 再投资率联动）。周期/宏观叙事用**宏观中立估值**先剥离宏观、再看个股（p.1288）。

## 四、⚠️ 适用边界与坑

- **适用对象**：做个股内在估值 / DCF、或判断"研报故事是否自洽"的投资者。本书**不谈择时、不谈买卖点、不覆盖技术面**，纯短线博弈者用不上。
- **易误用（故事被当炒作借口）**：达摩达兰明确警告，故事会让听众**放下戒备、忽略矛盾**（第 2 章，p.65-73），骗子正是利用这点编"轻松暴富"故事。好故事必须能翻译成数字并自检，止于"故事好听"本身就是书中点名的风险。
- **参数可核实性**：书给的是框架 + 案例数字（如优步：城市汽车服务市场 **1000 亿美元**、稳态市占率 **10%**、稳态营业利润率 **40%**、营收资本比 **5.0**，而美国公司中值约 **1.5**、超 **90%** 公司低于此，p.794-802）。这些案例数字**不可直接套用 A 股**，只能当"如何把故事落成数字"的范本，具体数值须用财报与行业数据自己填。
- **对"用户只做 A股单边 + 可转债"的直接可用部分**：
  - ✅ **A股个股**：用铁三角 + 三级测试筛掉"童话 / 自相矛盾"叙事；用映射链把研报故事翻译成可验算的 DCF 输入；用终值上限与内部一致性检验戳破永续高增长与"增收不增利"陷阱。
  - ✅ **可转债（正股叙事）**：框架用于判断**正股故事质量**——正股叙事决定转债期权价值与下修/强赎空间；周期股、宏观敏感正股用宏观中立估值分离"宏观叙事 vs 个股叙事"；书里"成人礼时刻"（市场关注点从一变量突跳到另一变量，p.868）对转债正股尤其致命，需跟踪变量切换。
  - ⚠️ **不适用本书**：转债的债底 / 纯债价值、溢价率套利、下修博弈等纯条款与定价动作，本书完全不覆盖，需结合本库可转债页（如 [[可转债投资魔法书]]）。
  - ⚠️ **A股单边注意**：本书估值基于有效市场 / 可卖空 / 美股语境；A股散户结构、壳价值、政策扰动会使"故事→价格"传导变形，结论用于**仓位与标的筛选判断**，而非抄底信号。
