# 涨停密码（黑马王子）

> ⭐⭐⭐ **黑马王子体系里唯一讲「多因子组合」的一本。**
> 核心命题只有一句：**单个基因不足以促成涨停，
> 只有多个基因排列组合成「密码」才行。**
>
> ⭐ **它与《伏击涨停》的分工**：
> 《伏击涨停》看**单根/单组量柱**（该买还是该卖），
> **《涨停密码》看多基因组合**（什么时候爆）。

## 核心论点

1. ⭐⭐ **单基因无效，多基因才有效。**
   「单个的『助涨基因』只含有涨停因子，⭐ **并非一定能『促使涨停』**」。

2. ⭐⭐ **密码的磨损顺序可机械判断。**
   ⭐ **自右向左，各个击破** → 离信号越近的那个基因最先坏；
   新密码 ⭐ **自左向右，逐个生成**。
   📌 这是本库在全书里见到的**最简洁、最可执行的一条诊断顺序**。

3. ⭐⭐ **极阴次阳有完整的「形态 → 幅度」量化表。**
   「有底极阴 + 次阳过全阴」→ **30% 以上**；
   「有底 + 过半」→ **约 20%**；
   「无底 + 过半」→ **约 10%**；
   「无底 + 未过半」→ ⭐ **「涨幅不够理想」（原文未给数）**。
   次阳高度三档：**未到左阴 1/3 → 反弹低于 10%；
   未及 1/2 → 低于 15%；超过 1/2 → 可达 20% 以上。**

4. ⭐ **涨停板有三重身份**（试探 / 进攻 / 防御），
   且 ⭐ **「涨停后再涨停的概率通常是 1/20」**——
   📌 本书因此建议「**从 20 多只股票里找机会，肯定比从 2000 多只里容易**」。

5. ⭐ **庄家性格可从形态反推。**
   「实底接实底的接力，就是**狡庄**；实底踩实顶的接力，就是**强庄**」；
   牛股三绝中「踩顶的是强庄、踩腰的是精庄、踩脚的是狡庄」。
