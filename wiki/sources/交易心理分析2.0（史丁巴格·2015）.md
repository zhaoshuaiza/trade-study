### 1.2 中心主张（原书原文口径，非二手转述）

作者把成功交易拆成**四个基本过程**（ABCD 框架）：

- **A — 持续适应变化的市场环境**（Adapt）：市场 regime 会变，旧优势会失效；纪律问题有时不是执行问题，而是「你在纪律地执行一个已经死掉的优势」。
- **B — 识别并打造自己独特的交易风格/优势**（Build on strengths）：放大你的「签名天赋」，而不是死补弱点——这是相对前作最大的转向。
- **C — 打造创造性过程、形成独到市场观点**（Cultivate creativity）：用企业家精神、类比思维、模式切换产生 alpha 想法。
- **D — 把最佳实践固化成最优流程**（Design processes）：从 best practices 到 best processes——流程会自我复利，且内建「优势衰减检测」。

**原书结论段（0049 片段，原文照录）**：

> 「不要只专注于缺点，优点也很重要。如果这本书只有一个最重要的主题，那就是**成功取决于你如何识别并利用自己的优势**。一些最佳实践的确可以弥补你的弱点，帮你规避失误，而**最好的实践能够发挥你的优势**。」

**原书第 3 章末的新原则定性（0027 片段，原文照录）**：

> 「传统的交易心理学认为……原则与自律将是交易成功的关键。然而，新时代的交易心理学认为，我们在交易中的优势并不是单一且一成不变的。**原则、自律依然是成功的必要条件，但仅有这些还不够。在如今的市场中，创造力变成了一个新的原则。**」

### A · 适应变化（第 1 章）

| 判据 | 动作化表述 | 证据 |
|---|---|---|
| 优势衰减自检 | 每周末问一次：我这周赚钱的理由，和上个月还是同一条吗？若同一理由连续失效 N 次，标记为「优势待重建」，进入第 3 章创造力流程 | [纲] |
| 环境-优势匹配 | 记录自己连续 3 个最佳状态日的环境变量（噪音/独处/音乐/社交），把交易时段固定在该环境下；环境被迫改变时，主动重构（原书案例：查尔斯雇助手重启信息处理优势） | [原] |
| 优势不用即消退 | 每季度检查被搁置的优势（原书案例：交易员只顾工作冷落家庭 → 分心 → 工作质量下降），搁置超过 1 个季度的优势安排一次「复健」 | [原] |
| 过度自信之误 | 盈利后强制一次「理由重述」：用一句话写下本笔盈利来自市场还是来自自己，防止把 beta 当 alpha | [纲] |
| 识别机会/威胁两栏 | 盘后各写 3 条：本周错过的机会（机会栏）、本周差点犯的错（威胁栏），只写可观察事实不写情绪 | [纲] |

### B · 从优势出发（第 2 章，本库覆盖最好的一章）

| 判据 | 动作化表述 | 证据 |
|---|---|---|
| 优势与环境匹配（原书核心句） | 「当外界环境与我们的优势相协调的时候，会催生我们的最佳表现」→ 写出自己的「优势-环境」对照表：什么条件下我注意力最集中、什么条件下我只会厌倦 | [原] |
| 优势清单法 | 列 3 类：①我做得比多数人省力的 ②我做时有心流体验的 ③别人常来求助我的；交叉项即为签名优势 | [纲] |
| 优势组合（乘数效应） | 把上表的交叉项两两配对，写出「A+B 让我能做到什么单人做不到的事」（原书：信息汇集型 + 音乐刺激型 = 出点子效率） | [原] |
| 优势也会变弱点 | 每个优势写一条「过度使用时的失效形态」（如：专注 → 视野狭隘；谨慎 → 不敢下手），失效形态出现即降档 | [纲] |
| 主观幸福感四维自评 | 按原书情绪日记：幸福感/满足感/活力/关爱 四维，各设「很少→十分频繁」五档，**每天一次、连记 7 天**；任一维长期低位即视为影响交易的独立问题 | [原] |
| 正负情绪独立（关键结论） | 原书结论：积极情绪减少≠消极情绪增加，两者来源不同——「积极的感受往往来源于新策略及实践，消极的感受来源于对风险的忧虑」；**风险忧虑是风控的必要成本，不必强行消除** | [原] |
| 情绪多变性是性情 | 先判定自己是「稳定型」还是「情绪起伏型」，再定交易节奏：稳定型可持续小仓、起伏型需设定强制停手线 | [原] |

### C · 培养创造力（第 3 章）

| 判据 | 动作化表述 | 证据 |
|---|---|---|
| 模式切换（原书给出 5 条） | ① 不同时间框架追踪同一标的；② 追踪相关联标的是否同步；③ 写下支持头寸的理论依据；④ 与知识渊博的同事讨论反方证据；⑤ 把交易计划录音，开盘前听几遍 | [原] |
| 心智图法（mind-mapping） | 以中心想法为圆心画派生圈（例：加息预期 → 央行政策/经济实力/通胀/固收价格/其他货币），每个派生圈再挂「声明、数据发布、就业」；**画图本身就是头脑风暴**，用于暴露自己依赖的假设 | [原] |

### D · 探索与整合（第 4 章）

| 判据 | 动作化表述 | 证据 |
|---|---|---|
| 交易是知识型业务，不是制造型业务 | 原书明确：交易「对市场的解读和交易的执行更像是咨询而不是制造」→ **流程化的对象是「决策步骤」，不是「交易动作本身」**；不要追求制造业式的动作标准化 | [原] |
| 交易流程化的三大障碍（原书列出） | ①缺乏优劣评判（策略不同无法横向比）→ 对策：只跟**自己的历史高低期**比；②缺乏结果数据（多数人只有盈亏总数）→ 对策：按策略/按研究/按头寸管理分别记账；③抗拒约束 → 对策：把流程写成规则而非限制 | [原] |
| 最佳实践→最佳流程 | 清单只是培训计划的起点；把多项实践编织进「盘前准备→盘中执行→盘后回顾」三段流程，每段有明确输入输出 | [原] |
| 质量控制的核心是减少变化 | 引自制造业：影响质量的罪魁祸首是变化 → 交易侧对应：**同一套入场条件、同一套仓位算法、同一套复盘格式，长期不变** | [原] |
