## 体系特征

**核心哲学**：把风险控制放在第一位，把赚钱交给趋势，把人性关在门外。

```
先确定能亏多少（仓位）→ 再考虑怎么赚（信号）→ 最后保证活到赚的那天（组合规则）
```

**六层逻辑链**：
```
生存层 → 度量层（N/ATR）→ 仓位层 → 信号层（通道）→ 错误层（止损）→ 放大层（加仓）→ 系统层（限仓/降档）
```

胜率仅约 40%，**靠 1:3~1:6 的盈亏比**赚不对称的钱。

### ⭐ 疑点一：「1% 与 2%」是什么关系

```
1% = 仓位刻度（1 单位 = 净值 1% ÷ (N × 每点价值)）
2% = 单笔最大亏损（初始止损 2N）
```

原文的算术：初始止损 2N = 100 点 → 20 手 × 100 点 × 10 = **2 万 = 账户 2%** ✅

> 原文点透：「**波动大 → N 大 → 手数自动变小 → 每笔亏损恒定 2%。
> 这一条就是'永不爆仓'的数学原因。**」

> 📌 **这是海龟体系的本质** —— 不预测方向，只保证「输的时候输得一样多」。

### ⭐ 疑点二：4/6/10/12 各对应哪一层

| 层级 | 上限 | 含义 |
|---|---|---|
| 单一市场 | **4** | 不能把宝押在一个品种 |
| **高度相关组** | **6** | **黄金 + 白银 = 一个赌注** |
| 松散相关组 | **10** | 美债 + 欧债 ≈ 相关 |
| 单一方向 | **12** | 可同时持 12 多 + 12 空 |

⭐ **第二行最有价值** —— 「黄金+白银算一个赌注」是**相关性限额**的核心逻辑。
