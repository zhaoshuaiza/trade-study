### 一、估值判据（第 7 章）

1. **算不增长公司的合理 PB**：当公司利润不增长时，用 `PB = ROE / r`，**r 取 10%** 代入。
   例：ROE 13% → 合理 PB 1.3 倍；ROE 16% → 合理 PB 1.6 倍；ROE 18% → 1.8 倍以上。
   （出处 7.4「ROE 与 PB 组合」，原书以中国交建 13%、中国建筑 16%、大秦铁路 18% 为例）

2. **算增长公司的合理 PB**：用五要素简化模型
   `合理市净率 = (1 + 净利润增幅)³ × (期初ROE / 贴现率)`，
   其中 **贴现率取 9%～11%，风险大的取大值**；
   **期末 ROE 须换算为期初 ROE：期初ROE = 期末ROE / (1 − 期末ROE)**。
   （出处 7.6 简化模型）

3. **给模型加两层溢价**：若判断「存在显著增长空间」→ 估值结果 **上调 10%～20%**；
   若「经营性现金流优异 且 投资性现金流较低」→ 再 **上调 10%～20%**。
   （出处 7.6；原书茅台案例用 9% 贴现率 + 现金流上调 20%，算出 11 倍 PB）

4. **用 PE 经验倍数分档**：正常盈利公司利润不变 → **10 倍 PE 左右**；
   净利增速单位数至 30% → **10～20 多倍 PE**；
   **30 倍 PE 以上尽量别买**；**60 倍 PE 以上为「死亡市盈率」**。
   （出处 7.3「正常盈利下市盈率经验倍数」）

5. **用指数 PE 判市场位置**：美股长期 PE 波动 **10～20 倍，均值 14、15 倍**；
   恒指同样 **10～20 倍**；**上证综指 PE 波动区间 10～60 倍**，2000 与 2007 年均达 60 倍后各开启 5～6 年熊市。
   → 判据：**上证 PE 到 60 倍区间视为泡沫区；10 倍出头视为播种区**。
   （出处 7.3；⚠️ 数据截至 2015-04，见「待复核」）

6. **用指数 PB 判底部**：**上证综指从未跌破 1 倍 PB，最低为 2013 年的 1.34 倍**；
   邓普顿 1970s 末进美股时道指 PB 跌破 1 倍（史上仅 2 次，前一次 1932 年大萧条），
   通胀调整后仅相当于重置净资产的 **0.59 倍**。
   （出处 7.4）

7. **按 PB 分四层定「需要多少研究深度」**：
   - **第 1 层 PB < 1**：ROE 维持 **5%～10%** 且 PB 约 **0.5 倍** → 最易把握，不需深度研究；
   - **第 2 层 PB 1～3**：ROE **10%～20% 多** → 需确定更高增长与更广空间；
   - **第 3 层 PB > 3**：成长占价值绝大部分 → **超出一般专业散户能力范围**，需行业专业背景 + 运气；
   - **第 4 层**：ROE **远超 30%** + 超高增长（原书仅举白酒、澳门赌场股、腾讯三类）。
   （出处 7.7；⚠️ 原书明确说第 3 层「超出一般专业散户能力范围」）

8. **用 PE×ROE=PB 做四象限筛选**：
   - 高 PB 高 PE → 需**同时**有超高增长 + 超高 ROE，否则是泡沫；
   - 高 PB 低 PE → ROE 高位但增速低，**ROE 能否维持是唯一变量**；
   - 低 PB 高 PE → 微利/亏损，**ROE 若回升即困境反转**；
   - **低 PB 低 PE + 高 ROE + 增长** → 原书称「难得的机会」。
   （出处 7.5）

9. **用现金流双比率验增长质量**：
   **经营性现金流净额 / 净利润 > 1**（越高越好，验利润真伪）；
   **投资性现金流净额 / 净利润 越小越好**（验增长效率）。
   并用 `净利润增长率 = 投资率 × 投入资本回报率` 反推资本支出回报率。
   （出处 7.2；原书茅台投资率 45% → 资本支出回报率 80%；乐视网投资率 440% → 仅 12%）

10. **避开 PE 的 8 种误用**（可当检查清单逐条打勾）：
    ①周期股误用（须改用 PB）；②前景变差业绩下滑；③现金流差；
    ④风险过高（贴现率被低估）；⑤忽略增长与空间；⑥忽视可持续经营利润（须扣非经常损益）；
    ⑦假账风险；⑧**用别人更贵来证明自己便宜**。
    （出处 7.3「避免市盈率误用」）

11. **避开 PB 的 3 种误用**：
    ①PB 低不代表有价值（**ROE < 10% 的公司只配低 PB**）；
    ②资产重估/虚增导致 PB 假低（**港股地产股 PB 低至 0.1、0.2 倍也不代表有价值**）；
    ③风险过高可令净资产全部损失。
    （出处 7.4）

12. **估未来股息收益率**：`未来股息收益率 = 1/PE × 历史现金分红比例`。
    （出处 7.8）

13. **估股息再投后的资产增速**：
    `资产增速 = [1 + ROE×(1−分红率)] × [1 + (ROE×分红率)/PB] − 1`。
    → 判据：**PB 越低，股息再投积累股份越快**；原书由此得出「小散户资产增速可长期超过大股东」。
    （出处 7.8）

14. **烟蒂股三条件（可逐条核对）**：①继续经营光收股息收益率尚可；
    ②经营恶化向下空间有限（净资产/重置价值托底）；③可能碰上三种上涨因素
    （**碰概念 / ROE 提升 / 行业复苏**）。
    （出处 7.8「现金分红股价上涨奥秘与烟蒂股投资策略」）

15. **DCF 参数区间（原书给的通行取值，非作者独创）**：
    贴现率 **8%～12%**，永续增长 **2%～4%**。
    → 但作者立场：**DCF 的价值在过程不在结果**，「模型中大部分价值来源于永续阶段，
    永续阶段增长率变动一点点，模型输出的结果变动很大」。
    （出处 7.2）

### 二、风险量化（7.6 五要素之「风险」）

16. **算财务风险**：`有息负债率 = (短期借款 + 一年内到期的非流动负债 + 长期借款 + 长期债券) / 所有者权益`，
    **该指标 > 1 时风险偏大**。
    → 注意：预收款、应付账款**不算**风险（「多多益善」），**只有有息负债算**。

17. **算经营风险（经营杠杆）**：用 `固定资产比例 = (固定资产 + 在建工程) / 总资产` 侧面衡量；
    比例越高，成本刚性越大，收入小幅下滑即引发利润大幅下滑。

18. **判市场风险（周期性）**：看**产品的供给时间 + 使用寿命**——两者都长 = 强周期。
    原书例：造船业，2007 年订单排到 2011 年，造出的船可用一二十年 → 强周期。

### 三、安全边际与卖出（2.5 / 2.7）

19. **按折价定仓位**：价格 = 价值的 **七折（70%～80%）→ 可买入**；**五折 → 值得重仓**；
    「如果一个股票没有 **50%～100% 的盈利空间**，购买意义不大」。（出处 2.5、8.2）

20. **卖出只有三个理由**（可逐条核对，答「否」就不卖）：
    ① 市场发疯，**股价透支未来好多年业绩**；
    ② 存在**更好基本面 + 更低估值**的替代品种（换股）；
    ③ **基本面恶化大幅超出预期**，且非短期能改善、属长期价值减损。
    → 其他时间：**「如果没有看错公司，低估区间还是拿着别动」**。（出处 2.7）

21. **不做波段的量化依据**（转引，非作者原创）：
    1982–1990 标普 500 年均 **18%**，去掉涨幅最好的 **10 天**（占交易期间 <0.5%）→ **12%**；
    去掉最好的 **30 天**（占 1.5%）→ **5%**。
    1926–1996 共 70 年，几乎全部回报由最好的 **60 个月**缔造（占 862 个月的 **7%**）。
    （出处 2.6）

22. **不追活跃股**：申万活跃股指数（2000 年起 1000 点，每周换手率最高前 100 家）→
    **2015-07 跌至 37.52 点，年化 −18%**。（出处 2.6；⚠️ 数据已失效）

23. **忘记初始成本**：任何时点都**假设自己手上全是现金**，问「现在该如何配置」。（出处 9.7）

### 四、组合与仓位（第 9 章）

24. **设三条分散上限**：**单一证券 ≤ 总资产 15%**；**单一行业 ≤ 总资产 25%**；
    组合**只数**：资金量大 → **十多到二十多只**，资金量小 → **五、六只**；
    原书依据：**20～30 只足以分散掉个股风险，剩下的只有系统风险**。（出处 9.2、9.5、2.8）

25. **按相关性排雷**：**煤炭、有色、石油、航运**属强周期正相关，放一起**不减少风险**；
    **煤炭 vs 火电**属负相关。（出处 9.5）

26. **⭐ 按指数 PE 定股票比例（估值化再平衡）**：
    **PE ≤ 10 → 股票 90%**；**PE 20～25 → 定投一半股一半债**；
    **PE > 30 → 定投绝大部分债券/现金**；**PE 60 → 股票降到 0～10%**。
    （出处 9.4；格雷厄姆原始版：股债比率恒在 **25%～75%** 之间，通常各 **50%**）

27. **用凯利公式定个股仓位**：`f = (bp − cq) / (bc)`；
    **p < 0.5 就不参与**；原书算例 p=0.6 → **f = 20%**。
    股票口径：**b** = 回到合理估值能赚百分之几；**c** = 跌到历史最低估值 / 净资产 / 破产全亏。
    （出处 9.6；⚠️ 原书承认「录入参数无法准确假设」是最大局限）

28. **加仓/清仓路径**：确信基本面无误 → **越跌越买至仓位上限**；
    过程中发现看错 → **停止买入**；回归价值后仍涨 → 保守者**清仓**；
    **严重高估 → 全部清仓**。（出处 9.6）

### 五、买卖触发与趋势（第 8 章）

29. **只认均线，否定其余技术分析**：`MA(P,N)`，**P 取收盘价**，
    **N 取 5/10/20/30/60/120/250 日**；**60 日、120 日 = 牛熊分界线**；
    **上穿买入 / 下穿卖出**；双均线组合用 **20 日 × 60 日** 或 **20 日 × 120 日**。
    （出处 8.1 三）

30. **作者自述回测（沪深 300，2003–2009-04）**：
    **60 日均线** 21 个信号、正确率 **52%**、策略收益 **601.6%**（持有 130%）；
    **120 日均线** 9 个信号、正确率 **77.7%**、收益 **559.7%**（持有 113.9%）；
    **250 日均线** 4 个信号、正确率 **100%**、收益 **345.5%**（持有 115%）。
    ⚠️ **作者自述回测，非第三方研究**。（出处 8.1 五）

31. **⭐ 价值趋势仓位矩阵**：基本面优质 + 低估值 + 中长期均线向上 = **最大获胜概率**；
    高估值 + 均线向下 = **大概率大幅下挫**；**模糊区间** → 向上轻仓买 / 向下减仓 / 震荡反复交易；
    ⚠️ **基本面好 + 估值低 + 下降趋势** = 原书自认最难受一档，作者选择「**坚持慢慢熬**」。
    （出处 8.2 四）

32. **止损/止盈用均线**：卖点 = **股价向下突破中长期均线**，且**随均线抬升而抬升**。（出处 8.1 八）

### 六、分策略入场触发（第 10 章）

33. **可转债**（⭐ 与用户实盘直接相关）：**价格跌破 100 元时，持有可转债比持有正股更划算**；
    **下修触发**：正股连续一定数量交易日低于当期转股价 **85% 或 90%** → 可提出下修；
    **套利**：可转债价格 < 转股价值 → 买入转债 + 转股 + 融券卖出正股。
    （出处 10.8；⚠️ 融券受 A 股券源限制）

34. **周期股**：**用 PB 不用 PE**，**严重跌破净资产才具吸引力**；
    **全行业亏损**才可能是底；**必须等股价向上突破长期均线才介入**；
    顶部 = 全行业效益好 + 纷纷加大资本支出 + **股价是净资产几倍** + **长期均线跌破** → 快抛。
    （出处 10.5）

35. **困境反转**：六条必要条件 + 时机上「**10 日均线走稳是买入信号**，保守点等中长期均线走稳」；
    见底 K 线特征 = **开盘急跌 20%～30% 后快速回升、留长下影线**。
    ⭐ 关键排除项：**事件须不具备反身性**——「靠融资而活的公司和金融类公司存在反身性」。
    （出处 10.2）

36. **A 股「大烂臭」筛选条件**（2014-01-07 公布）：**2012 年 ROE > 10%** +
    **2013 年三季度 ROE > 8%** + **PE < 10 倍** + 按股息收益率从高到低排名。（出处 10.1）

37. **业绩提升型黑马股五层逻辑链**：**股东 → 资产 → 员工 → 客户 → 财务**逐级验证，
    「脱离财务数据的印证，上述几个方面说得再好也都是空中楼阁」。（出处 10.4）

### 七、财务排雷（6.3）

38. **不碰上市未满 3 年的公司**（原书：「先看三年」；造假公司一般上市后 **3～5 年**内露馅）。

39. **⭐ 造假「三者不可兼得」**：若利润夸大 1 倍以上且不筹资，则
    **分红率 > 25%** + **所得税率正常 25%** + **利润继续增长** 三者不可兼得 → 三者齐备即列嫌疑。

40. **九大事件信号**：生活奢靡 / **高层频繁变动（尤指财务总监、董秘离职）** / 高层大股东套现 /
    股权质押 / 过分关心股价 / 频繁变更会计师事务所 / 频繁股权融资 / 频繁收购重组剥离 / 股权关系错综复杂。

41. **现金流排雷**：造假公司「不是**经营性现金流糟糕**，就是**投资性现金流巨额流出**，
    又或者两者兼有」。
