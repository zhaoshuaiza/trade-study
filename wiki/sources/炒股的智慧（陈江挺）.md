# 炒股的智慧（陈江挺）

> 写给A股散户的实战心法：把"止损、趋势、保本"当三根支柱，炒股是概率 + 人性的双修，而非公式。

## 一、本书在讲什么

- 这不是技术公式书，而是讲"炒股是艺术，不是科学"——股票运动反映投资大众的集体心理，人性不变所以规律可循，但没有保证赚钱的公式和电脑指示。
- 全书可拆成三条看得见的动作线：**保本**（快速止损 + 分层下注）、**只在胜率大于50%的临界点入场**、**让利润奔跑**（截断亏损，让利润奔跑）。
- 作者认为一般股民败多胜少是人性使然（"好贪小便宜、吃不得小亏的心态使一般股民几乎必然地成了输家"），炒股是头脑与人性的双修，最终要从有招迈向无招。
- 方法上只用四张图（走势及走势线、支撑线与阻力线、双肩图和头肩图、平均线），作者断言"三角、隧道、旗子"及MACD等电脑指标"见光死"、没有实用价值。
- 它偏A股/散户实战语境，门槛极高（作者称"没有三年的全职经验连门都入不了"、悟性好也要五至六年），更像忠告与筛选，而非可复制的教程。

## 二、核心参数与判据（原书原值，未改动）

| 判据 | 具体规则 | 原文出处 |
|---|---|---|
| 止损硬上限 | 止损点不应超出投资额的20%；把止损点定在10%或更小，任何情况下都不要超出20%，"只要条件允许，越小越好！" | 第三章 资金管理 |
| 作者自选止损 | 把止损点定在"入市当天的最低点"——"如果我的入场点选的正确，股票开始上升，它不应跌回我当天入场的最低点" | 第三章 资金管理 |
| 利润保护止损 | 10元进、升到12元，止损定在10.5或11元，给股票约10%喘息空间（别让利润变成亏损） | 第三章 资金管理 |
| 均线判势 | 不买200天线下的股票（200天线看长期、50天线看中期；短线例外） | 第二章 技术分析 |
| 正常升势判据 | 正常升势=一浪高过一浪、回调缩量、升势在200天线上；突破阻力线/支撑线后应继续，否则是危险信号，须离场 | 第二章 正常运动 |
| 入场临界点 | 最好在升势或突破阻力线时买；绝不在跌势入市；不以"已跌很低/好消息/专家推荐"为买入理由 | 第四章 寻找临界点 |
| 移动止损 | 用移动止损点，把卖点放在每个波浪的浪谷，随势上移（遇暴利"拿了再说"） | 第四章 卖点方法 |
| 选股顺序 | 先看大市走向（大市不好什么都别买）→ 找"牛劲"最足的类别股 → 选龙头股；选蓄劲期久、上升阻力小的股票 | 第四章 选股三步骤 |

## 三、可落成动作的判据（看盘用）

1. **先看大市再动手**：每天追踪指数、留意交易总量异常、龙头股疲软、垃圾股活跃等见顶信号；任一项出现，当天不买任何股票。
2. **入场前先定止损点**：绝对不超过本金的20%，尽量压到10%或更小；把止损价写在"入市当天最低点"上。
3. **只在临界点买**：升势中突破前高、或突破阻力线才动手；跌势中一律不动手。
4. **不买200天线下的股票**（短线例外）；用50天线判断中期、200天线判断长期方向。
5. **持仓盯"正常运动"**：一浪高过一浪且回调缩量就持有；一旦突破后不继续、或暴升无利好且量增价不升，立即离场。
6. **有利润就抬止损**：10元进、12元时把止损抬到10.5/11元；之后用移动止损随每个浪谷上移锁利。
7. **见疑即走**：出现危险信号、有疑问、或"担忧到睡不着"，执行"有疑问的时候，离场！"——几天后可重新入场，不恋战。
8. **分层下注、绝不摊平**：新手把本金分6-8份每次只下一份；胜算60%下小注、80%胜算才加注；亏钱不加码摊低成本（"不要向下摊平，在这行是破产的捷径"）。
9. **截断亏损、让利润奔跑**：小亏果断走，正常回调不吓出场；遇暴利"拿了再说"，让大利润自己跑。

## 四、⚠️ 适用边界与坑

- **适用对象**：本书偏A股散户实战，多数判据可直接用。**对散户特别对症的几条**：①止损纪律（散户最常死在不止损/向下摊平）；②"大市不好不买任何股票"；③分层下注控制单笔下注；④不接下落的刀子、不靠消息买。这几条正好打在散户最致命的坑上。
- **结合你的约束（只做A股单边 + 可转债，不能做期货）**：本书的"趋势、止损、仓位、心理"四大块对A股单边完全适用；对**可转债**可借鉴「止损 / 不向下摊平 / 分层下注 / 见疑即走」，但本书的「均线、选股三步骤、临界点」都是**股票语境**——可转债另有转股价、溢价率、债底、到期收益率等特有判据，本书未覆盖，不能照搬到转债。尤其"不买200天线下的股票"对转债要慎套：很多低溢价转债因债底保护长期在均线下方，硬套会错过机会。期货维度本书未涉及，你本就不做，无影响。
- **易误用点**：①把经验百分比当死规矩——作者明言"没有死定的百分比"，全凭个人摸索；②只学止损不学"让利润奔跑"，结果仍是赚小亏大；③神化"临界点"——作者自承"只可意会，难以言传"，需自己复盘积累；④频繁交易、买太多票会冲散冷静观察力，违背"集中三至五只"的原则。
- **参数可核实性**：全书无任何理论公式与数据验证，案例（微软、王安、上海石化）有时代局限，成书于1990年代末、基于美股经验；作者自述"每年回报率超过100%"也承认日后能否持续"我不知道"。A股制度、交易规则与其华尔街经验有实质差异，判据需读者自行验证与调整后再用。
