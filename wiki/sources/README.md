# sources/ · 来源页

> **一本原始资料一页。** 记录它是什么、在哪、编译到什么程度了。
> 这是整个库的**溯源入口**。

---

## 放什么

| 类型 | 说明 |
|---|---|
| **书籍** | 一本书一页，记录作者、年份、路径 |
| **系列** | 多本成套的（如黑马王子7 本）合并为一页 |
| **文章合集** | Web Clipper 剪藏的一批同类文章 |

## 命名

用**资料名**命名，不用类型前缀：
```
道氏理论.md
缠论108课.md
黑马王子系列.md
```

---

## 每页必须记录

| 字段 | 作用 |
|---|---|
| `source_file` / `source_dir` | **精确路径**（用正斜杠） |
| 出处 | 作者、年份、版本 |
| 定位 | 这套方法解决什么问题 |
| 与其他体系的关系 | 上下游、并行、批评对象 |
| **编译状态** | 未开始 / 进行中（第几章）/ 已完成 |
| 抽取出的页面 | 指向 concepts/entities/claims |

## 编译流程

```
读 PDF（按章节分批，不要一次全量）
  → 提取 concepts / entities / claims
  → 建页 + 建双链
  → 回本页更新「编译状态」和「抽取出的页面」
  → 在 .manifest.json 记录已读章节
```

**增量编译**：已编译过的书不重复编译，部分完成的从上次章节继续。
