## 三、六态状态机（`build_progress.py` 自动判定）

```
待OCR → 待提取 → 待编译 → 已编译
                ↓
             提取失败 / 待编译(字少)
```

| 状态 | 判定依据 |
|---|---|
| 待OCR | `_meta.verdict == 需OCR` 且无 `book.txt` |
| 待提取 | 有零 OCR 格式但尚未提取 |
| 提取失败 | `_meta.extract_status == fail` |
| 待编译 | 有 `book.txt` 且中文字数 > 2000 |
| 待编译(字少) | 有 `book.txt` 但字数少（公版/目录型，需人工判断） |
| 已编译 | 库内 `wiki/` 已有对应来源页或概念页 |
