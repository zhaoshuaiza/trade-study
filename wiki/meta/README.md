| 内容 | 说明 |

## 健康检查（lint）

**建议每两周一次** —— 交易知识更新快，比技术库更频繁。

### 检查项

| 问题 | 判定方式 |
|---|---|
| 孤立页面 | 无任何入链且无出链 |
| 死链接 | 方括号双链指向的页面不存在 |
| 索引漂移 | 页面已建但未登记进 `index.md` |
| 元信息缺失 | 缺 frontmatter 必填字段 |
| **结论冲突未处理** | 两页矛盾但无 `comparisons/` 页承接 |
| **参数被擅自改动** | 与原书数值不一致且无「原值→建议值」标注 |
| 来源可溯源性 | `sources/` 页是否记录了原书页码/章节 |

> 📌 后两项是**交易库特有的检查**——
> 参数被「优化」过是技术分析里最隐蔽的错误。

### 报告格式

写入 `lint/<日期>.md`，分三档：

```
需要处理  ← 影响知识可靠性
建议优化  ← 能提升可读性
暂时观察  ← 先记着，不急
```

> ⚠️ **体检只生成报告，不直接改。**
> 等用户确认后再执行修改。
