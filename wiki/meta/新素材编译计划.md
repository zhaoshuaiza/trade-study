## 四、⭐⭐⭐ 每轮的固定检查动作（建议流程）

```
① 跑进度     progress_new.py            → 看清当前百分比与待办
② 挑本做     从当前批次头部取 1~3 本    →⭐ 不跳批
③ 编译       出概念页/来源页/综合页
④ ⭐ 更新台账  progress_new.py --set N done --note "..."
⑤ ⭐ 跑体检   lint_vault.py              → 死链/孤立/占位必须全绿
⑥ ⭐ 同步索引  sync_index.py
⑦ git commit
⑧ ⭐ 再跑一次进度，把新百分比报给用户
```

> ⭐⭐⭐ **第 ④ 步是本计划的核心机制**：
> 📌 **每编完一本就改台账 → 进度是累计出来的，不会漂移。**
> ⛔ 不允许「编完一批再一次性改台账」。
