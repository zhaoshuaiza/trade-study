# 知识库使用方法 · 笔记模板

> **一条模板，两种用法**：收件箱阶段只填前 6 行 frontmatter + 标题 + 一句话结论；知识页阶段填全。
> 配套：[[方法卡]] · [[常见问题处理]]

---

## 模板正文（直接抄）

```markdown
---
type: inbox
status: draft
created: 2026-10-21
updated: 2026-10-21
source:
sources: []
tags: []
---

# 标题：说清「这是什么」，不用文艺标题

## 一句话结论

## 可执行动作
- 动词 + 可验证的触发条件

## 出处
- 页码 / 章节 / 链接 / 检索日期

## 关联
- [[双链]]

## 待办
- [ ] 
```

---

## 字段说明

| 字段 | 必填 | 填什么 |
|---|---|---|
| `type` | ✅ | `inbox`=收件箱；知识页用八类之一：`concept` / `entity` / `source` / `claim` / `comparison` / `synthesis` / `question` |
| `status` | ✅ | `draft` 未核实 / `verified` 已核实 / `uncertain` 不确定——**不确定就标 uncertain，别硬写确定答案** |
| `created` / `updated` | ✅ | 建页日期 / 最后修改日期 |
| `source` | ✅ | 单一来源：书名 / URL / 「IMA库名 + 条目标题」。**没有来源的笔记不收** |
| `sources` | 知识页 | 双链数组，指向 `wiki/sources/` 页 |
| `tags` | 选填 | 2~4 个，优先用库内已有词（可转债、强赎、止损……），不造新词 |
| 标题 | ✅ | 说清这是什么。判断：「这是什么」→ concept；「这是谁/哪本书」→ entity |
| 一句话结论 | ✅ | 不许绕弯。**写不出这句话 = 还没读懂，退回素材层** |
| 可执行动作 | 知识页 | **动词 + 可验证的触发条件**。「严格止损」不合格；「单笔亏损达净值 2% 时无条件平仓」才合格 |
| 出处 | ✅ | 页码 / 章节 / 链接 / 检索日期——参数必须原样保留 |
| 关联 | ✅ | 至少一条双链；**孤立页面视为不合格产物** |
| 待办 | 选填 | 还差什么、要核实什么 |

## 收件箱简化版（`raw/` 用，30 秒填完）

只保留：frontmatter 前 6 行 + 标题 + 一句话结论 + 出处。

每周清收件箱时补 `type` 判定去留：

| 判定 | 动作 |
|---|---|
| 蒸馏 | `type` 改成八类之一，移进 `wiki/` 对应目录 |
| 留源 | 保持 `inbox`，留在 `raw/` |
| 分流 | 登记「已分流」后转 `hedge` 库（非交易内容） |
| 丢弃 | 删 |

## IMA 指针登记行（收集第 ④ 步用）

```
- [ ] 【长安投研】关键词「液冷」｜《060_液冷行业更新》｜2026-10-21｜用途：补 AI 散热产业链认知
```

格式：`【库名】关键词｜条目标题｜日期｜打算用来干什么`

**为什么只登记指针不搬运**：五个 IMA 库共 9 万多条，全是只读订阅库，本地库只放「用得上」的蒸馏结论，原文现查。

```markdown
# 强赎条款：与走势无关的外生离场信号

## 一句话结论
连续 30 个交易日中 15 日收盘价 ≥ 转股价的 130%，发行人有权按面值加利息赎回——这部分亏损与量价无关，是转债最大的亏损来源。

## 可执行动作
- 买入前：查该转债强赎触发进度，已在触发边缘的不买
- 持仓中：每周末核对「30 日中 15 日 ≥ 130%」计数，进入观察名单
- 公告强赎时：对比赎回价与市价再决策——红相转债市价 179.36 元、赎回价 102.19 元，只有转股或卖出两条路，被动持有到手亏超 40%

## 出处
- 《可转债投资魔法书》强赎条款章节；2025 年 71 只退市中 51 只为强赎（71.83%）

## 关联
- [[concepts/可转债复合资产特性]]
- [[syntheses/可转债体系总览]]
- [[questions/问答与纠错机制]]

## 待办
- [ ] 建一张持仓转债的强赎进度核对表
```
