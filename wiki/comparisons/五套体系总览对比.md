# 原内容：五套交易体系总览与对比

> 本库的**核心参照页**。回答一个根本问题：
> **这五套方法是什么关系，各自解决什么问题，我该学哪个？**

---

## 一、先看清五套体系的真实关系

它们**不是五套并行方法**，而是**两条脉络 + 一个变体**：

```
第一条脉络（趋势结构的细化演进）
道氏理论（源头：定义什么是趋势）
   ↓
波浪理论（细化：趋势由五浪三浪构成）
   ↓  被批评：浪的级别无严格定义，数浪主观
缠论（国产改造：用中枢和级别给出可机械判定的结构）

第二条脉络（把趋势变成可执行系统）
海龟法则（把趋势思想转成机械触发 + 风险等分）

独立一支（换赛道：走量价短线）
黑马王子（周期最短，看量价关系，专攻涨停板）
```

> ⚠️ **最关键的认知**：
> 道氏 → 波浪 → 缠论是**同一件事的三个阶段**，不是三套并行方法。
> 缠论不是在波浪上打补丁，是**因为波浪的主观性而另起一路**。
>
> 海龟和黑马王子则**换了问题域**：一个问「怎么控制风险」，一个问「怎么抓短线爆发」。

| 维度 | 道氏理论 | 波浪理论 | 缠论 | 海龟法则 | 黑马王子 |
|---|---|---|---|---|---|

## 三、方法论的根本分野

这是全表最重要的一列——**主观 vs 客观**：

```
主观画线派：道氏 → 波浪
             「我觉得这是第3 浪」→ 事后都能解释 → 无法机械执行

判据化派：  缠论 → 海龟
             「中枢已形成且走势完成」→ 可预先定义 → 可机械执行
```

**缠论与海龟虽然一个画线、一个不画线，但在方法论上是同一类**：
都试图把「凭感觉」变成「按判据」。

> 📌 这条线索是理解五套体系的关键。
> 缠论的原话是：波浪之所以主观，是因为**没有严格定义级别**。
> 缠论用「中枢 + 级别」解决了这个问题。
> 海龟用「通道 + ATR」解决了同一个问题，路径不同，方向一致。

### ⚠️⚠️ 但缠论对量化的态度需要分清说话人（2026-10-09 修订）

第 33 课**扫地僧点评**原话：

> **「如果有人说开发了缠论的量化交易系统，请远离他，
> 因为艺术是不可能量化的。」**

> ⚠️ **更正（2026-10-09）**：这句话是**评注者扫地僧**说的，**不是缠中说禅本人**。
> **缠师本人明确主张理论完全量化**，并给出了机械化操作程式（第 38 课）：
> 「本ID的理论完全是数量化的，因此是精确化的，里面不存在任何含糊的地方」
> ——含第 236 页可编码的完整买卖规则。
> 详见 [[claims/缠论能否量化]]。

| | 缠论（**缠师本人**） | 海龟 |
|---|---|---|
| 主张 | **理论完全量化、精确化**，可给机械化程式 | **把规则写死，照做** |
| 反对的是 | **丢掉多义性的简化版「缠论指标」** | 优化参数 |
| 终点 | 熟练后「形成市场直觉」 | 「照规则执行」就完成 |

**两者的分歧比原先描述的小得多**——缠师本人并不排斥机械化，
排斥的是**把缠论当指标公式交易的简化做法**。

```
缠论的隐忧：买点识别需要「看清结构」，
这一步仍带主观性 —— 原文也承认「与操作的熟练度有关」
```

**所以「判据化派」这个说法需要修正**：

| 更准确的说法 | 体系 |
|---|---|
| **完全判据化**（机械可执行） | 只有海龟 |
| **半判据化**（框架判据 + 人工识别） | 缠论 |

> 📌 这条结论是编译后新增的，不是原有框架。
> 详见 [[concepts/走势的多义性]]。

## 三之二、⭐ 三套体系都承认自己错（本库最有价值的资产）

编译完道氏与缠论后发现，**它们都主动记录了自己的失败**，而且都是原文原话：

| 体系 | 承认的错误 | 出处 |
|---|---|---|
| **道氏** | 1926 年汉密尔顿把牛市次级回调看成熊市显现 | 第 5 章 |
| **缠论** | 2007-02-27「无中枢最强单边走势」实为**骗线** | 第 46 课 |
| **缠论** | 承认缠论**无法量化** | 第 33 课 |
| **海龟** | 费思遵守规则仍最终破产 | 海龟全书 |

| | 这些承认带来的结论 |
|---|---|
| **道氏** | 胜率 70% 有严格限定（一年 4~5 次、只做主要运动） |
| **缠论** | 「无中枢单边走势」在大中枢内部大概率是骗线 |
| **海龟** | 规则有效，**执行失败也会破产** |

> 📌 **一个不敢记录自己错误的理论不值得学。**
> 详见 [[concepts/道氏理论的适用边界]]、[[concepts/背驰与力度比较]]。

## 四、各体系的一句话本质

| 体系 | 一句话本质 |
|---|---|
| **道氏理论** | 趋势是可观测的，不是可预测的 |
| **波浪理论** | 波浪的价值是**排除**不可能的数法，不是预测下一浪 |
| **缠论** | 不预测方向，只定义「走势完成的判据」 |
| **海龟法则** | 90% 的工作是风险控制，赚钱是自动的副产品 |
| **黑马王子** | 短线的爆发力来自**量价关系**，与趋势无关 |

## 五、你该先学哪个

### 按目标的推荐路径

| 你的目标 | 路径 | 理由 |
|---|---|---|
| **想看懂走势** | 道氏 → 波浪 → 缠论 | 顺脉演进，前一个是后一个的前提 |
| **想控制风险** | 海龟优先 | 仓位和止损是所有体系里最硬的收获 |
| **想做短线** | 先海龟（纪律）→ 再黑马王子（技法） | **没有纪律的技法是赌博** |
| **想系统化交易** | 缠论 + 海龟并读 | 一个给结构判据，一个给风险框架 |

### ⚠️ 一个反直觉的建议

**不要从缠论开始。**

缠论 186MB，体量最大，且它明确批评波浪的主观性——
**如果还没理解道氏和波浪在解决什么问题，学缠论会变成记术语。**

正确的顺序：
```
道氏（建立趋势概念）→ 波浪（看结构如何细化）→ 缠论（看如何让结构可判定）
```

### 如果只学一套

**海龟。** 理由：

1. **唯一完全机械化**的，不需要主观判断
2. 核心收获是**仓位管理和止损纪律**，这套东西**跨体系通用**
3. 有反面教材（费思最终破产），说明纪律比技巧重要
4. hedge 库已有完整蒸馏成果，可直接用

> 📌 止损纪律在五套体系里都成立。
> 缠论止损、波浪止损，最终都回到「我错了就离场」——海龟只是把它量化成了 2N。
