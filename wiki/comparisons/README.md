## 对比页的写法

必备内容：

1. **一句话区分** —— 让人一眼看懂核心差异
2. **多维对比表** —— 覆盖所有关键维度，不要只比一两个
3. **关键差异** —— 差异的**根本原因**，不只是现象
4. **共同点** —— 往往比差异更有价值
5. **何时用哪个** —— 这是最有决策价值的一节

> 📌 **第 5 条是本页的落点**。
> 对比不是为了「知道有区别」，是为了**知道什么时候该用哪个**。

## 维度的选择

按需选择，不必凑齐。交易体系常用维度：

| 维度 | 问什么 |
|---|---|
| 核心问题 | 这套方法试图回答什么 |
| 观察对象 | 看价格结构？量价关系？还是波动率？ |
| 画线/触发 | 主观画线还是机械触发 |
| 持仓周期 | 日内？周？月？ |
| 主战场 | 期货？A 股？美股？ |
| 止损方式 | 判据式还是数字式 |
| 仓位方法 | 固定比例还是风险等分 |
| 胜率/盈亏比 | **必须标明回测/模拟/实盘** |
