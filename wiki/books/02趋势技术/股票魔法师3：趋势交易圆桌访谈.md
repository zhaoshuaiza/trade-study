## 二、精读总结

### 这本书在讲什么

四位美股短线交易冠军（Minervini、Zanger、Ryan、Ritchie II）的**圆桌问答**，11 个部分：介绍 / 选股 / 买入标准 / 头寸 / 技术分析 / 基本面 / 市场 / 风险控制 / 交易管理 / 心理学 / 最后的思考。

它的价值不在于提供新方法（方法都在第 1、2 册），而在于**让四个立场不同的人在同一个问题上给出不同答案**——比如止损设置：米勒维尼按形态与波动定，Ryan 按支撑位定，Zanger 看 10/21 日均线被破，Ritchie II 用自己的"交易矩阵"算出**买入点下方 3%~10% 的中位数**。**同一问题多答案，正是它比前两册更有用之处：它让你看到哪些是共识、哪些是个人偏好。**

四个人的共识也很清楚，可以直接当结论用：① **只做个股，不做指数**；② **让股票自己告诉你该卖哪只，而不是听市场的**；③ **单笔交易对组合的风险贡献必须封顶**；④ **亏钱就自动减小头寸**；⑤ **学徒期以年计**。

它还是三册里唯一敢讲失败的部分——Zanger 讲自己 44 万→22 万→欠债 225 美元、卖车重新开始的完整过程，四个人都交代了自己从盈到亏的年份。**这比任何"我 33 年从未亏损"的宣传都有价值。**

### ⭐ 核心判据（可落成看盘动作的）

| 判据 | 具体规则 | 原文出处 |
|---|---|---|
| ⭐ **单笔风险贡献上限（四人共识，可直接取最严的）** | **Minervini：单笔不超过 2.5%，平均 0.75%~1.25%**（算例：25% 仓位 × 10% 止损 = 2.5% 组合风险；5% 止损 = 1.25%）。**Ryan：单笔最高 1%**（10% 仓位 × 10% 止损）。**Zanger：单股 1%~3%，整个组合最大风险 20%**。**Ritchie II：亏损期 ≤100BP，顺境 200~300BP，极佳时 500BP** | S8-2（第292–320行） |
| ⭐ **按自身盈亏记录调整风险敞口（动态降档）** | Ritchie II："**这取决于好多因素，最重要的因素就是我目前的业绩怎么样**。如果我正处于亏损状态或者情况不太乐观，那么一般风险比例不会超过 100BP……当情况好的时候……提高到 200~300BP……但**一定是在好业绩的基础上**才能这样做" | S8-2 |
| ⭐ **风险随连亏自动收缩** | **Minervini："我亏得越多，我的交易额越小。如果我连续遭受损失，则通常意味着整体市场条件不佳。"** **Ryan："我不想失去本金，所以当我开始连续亏损时，我的投资金额会越来越小。"** Zanger：连亏则"退后一步，等待市场恢复正常……这可能需要几周、几个月或更长时间，几年都有可能" | S8-2、S10-1、S10-4 |
| ⭐ **止损设置的四种口径（都可用，选一个）** | Minervini：形态未坏就持有，**对高波动股设比例止损或固定风险金额+头寸**。Ryan：**设亏损比例，或用买入价下方的强支撑线**。Zanger：**趋势线 + 日线最低点，再叠加 10 日与 21 日均线，任一被破即止损或减仓**。Ritchie II：用"交易矩阵"算出加权平均盈亏比，**止损失效点通常在买入点下方 3%~10%** | S8-1 |
| ⭐ **10% 是硬天花板（可直接当上限用）** | Minervini："**10% 是我最高的止损比例了，我基本上没有哪一笔交易的亏损超过 10%。请记住，止损越严格，择时就需要越准确，但是损失越大，交易就会越困难。我宁愿把更多的精力和成本放在择时上，也不愿意面临大幅的亏损**" | S8-4 |
| **分两次止损 vs 一次止损** | 面对"一次 10% 还是两次 5%"的问题，Minervini 选**后者（给股票两次机会）** | S8-4 |
| ⭐ **"枕头因素"（头寸过大的自检）** | Minervini 的助理称之为"**枕头因素**"："**如果你连觉都睡不好，那么说明你的头寸太大了**"（他说要在"睡眠点"卖出）。Ryan 同义："**如果你为某个头寸焦虑到夜不能寐，那么你可能需要找别人帮你管理资产了**" | S8-3 |
| **隔夜跳空的应对** | Minervini：跳空风险无法消除，只能靠**限制头寸**降低；买入前要查这股票**过去 3~6 个月是否大幅向下跳过空**（David Ryan 称之为"连续的跳空"）。Zanger：**隔夜风险从来不是问题**，"我有很多超额收益都来自隔夜持有或者隔周末持有"，事前在 **FOMC 会议前/重大新闻发布前**警觉。Ritchie II：**市场好时处在收集阶段的股票极少跳空低开，市场差时高波动股才会**（芝加哥天气类比） | S8-3 |
| ⭐ **卖出由股票决定，不由市场决定** | **Minervini："我让我的股票告诉我应该卖哪一只……我通常不会根据自己对市场的'看法'去卖。我做的仅仅是加强止损，根据价格的变化一个一个地卖出我的头寸。我经常会长期持有几只股票，经历一轮市场的回撤也没有卖出。"** **Ritchie II："如果一只股票进入了我的卖出范围，我就卖掉它。"** 反例是 Zanger 的极端做法："**当房子下陷时，我得撬开墙保住厨房。为什么要等一只股票跌到更低再卖掉它呢？**" | S6-3 |
| **先卖亏损股（Ritchie/Ryan 的次序）** | Ryan："**我会先卖掉出现亏损的股票**。如果在我买了之后它们的表现就不好，那么大概率在市场变坏的情况下它们的表现也不会好。" 然后**把股票按从最差到最好排序，优先卖最差的**；"我会尽可能久地持有好的股票，因为**在市场下行时它们最抗跌，然后在下一轮趋势来的时候它们会涨得更高**" | S6-3 |
| ⭐ **"不要把婴儿连同洗澡水一起倒掉"（市场指标的正确用法）** | Ryan："**你可能会从市场指标那里得出一个卖出信号，但是如果你的股票正拿得非常好，那么你不应该卖掉它们**……**你要观察市场，但不能市场指标一显示出下跌趋势，你就卖掉所有的股票**。" Zanger 更极端："除了技术形态和龙头股，**没有其他有价值的指标了**"。Ritchie II：A/D 线、新高新低、总量、情绪**只作辅助，从不作为择时依据** | S6-2 |
| **微盘盈的处理（市场恶化时）** | Minervini："如果市场真的恶化了，那么**对于有微小浮盈的股票，我通常会把止损的位置改成盈亏平衡点**；对于涨了很多的股票，我也会相应地提高止损点，我会**让我的股票度过第一次'自然反应'（市场回调）**" | S6-4 |
| ⭐ **"分析麻痹"的两种类型与解法** | Zanger 的分类：**第一类 = 不能下投资决定**（多因害怕失败，解法是**交易小头寸**，用一点真金白银换信心）；**第二类 = 在本该退出的交易里，因为情绪问题而"分析麻痹"**（认为股票优质、拒绝面对明显的不健康下跌），**解法是入场前就设定交易准则并坚持** | S10-2 |
| **"不用动脑"的选股条件** | Ritchie II："**每个交易者某些时候都必须设定一套'不用动脑'的选股条件**。即自己制定一个交易计划，在股票满足 x、y、z 标准时就进行交易。" Ryan 同义："**如果股票符合你设定的所有标准，就持有它，如果没有，就什么都不要做。**" | S10-2 |
| **头寸随信心增长（幅度要克制）** | Ryan："如果你用 **5% 的头寸**投资时表现良好，那么现在可以将比例提升至 **7%~8%**……我希望**每个头寸只占整体投资组合的 15%~25%**。" Minervini："**从小心寸开始**……如果你过于自信，那么你可能会做一些非常冒险的事情，然后在遭受巨额损失时失去所有信心" | S10-3 |
| **方法稳定性（米勒维尼的原话）** | "我稍微做了一些改进并增加了新方法，但 **95% 的内容没有改变，因为供求之美是永恒不变的**。我唯一做的就是改变交易回调设置……**我的交易方式在过去 30 多年里基本保持不变**" | S1-1 |
| ⭐ **学徒期（三人一致，可直接当预期管理）** | **Minervini："学习曲线至少需要几年，或许是 5 年"**（且他自述**花了 6 年收益不佳**，转机点是"去他的自我，我的目标是赚钱，而不是追求正确"）。**Ryan：约 2 年**，"在你掌握它之前你通常会犯很多错误"。**Zanger：一个杰出的交易员至少全职投入 5 年，并且至少经历一个完整的市场周期**。Ritchie II 引 Tony Robbins："**大多数人都高估了2年内他们能做到的，低估了10年后能做到的**" | S1-10 |
| ⭐ **市场未被操纵的论证（散户优势）** | Minervini："**想象一下掌控游轮的大机构和驾驶快艇的小商人，你认为谁会取胜？**" 并反驳"被操纵论"："那些说'股市被操纵'的人往往是没有能力在市场中表现卓越的人……**在股市中，你可以赚钱，也可以找借口，但不能两者兼得**。" Ryan："**如果个人投资者能够训练出火眼金睛去发现机构的投资标的，那么他可以更快地行动，并利用机会抢在一些机构买入之前就布局**。" Ritchie II 的相反意见："**几乎所有的交易者，包括大机构，都没有明显的优势**" | S1-6 |
| ⭐ **只做个股的理由（含杠杆效应）** | Minervini："**我一般投资个股，因为相对于指数投资，个股能给我带来杠杆。如果纳斯达克涨 10%，那么在同样的时间内龙头股可能涨 50%~100%。**" Ritchie II 给出反面理由："相较个股，**指数的定价更有效，也有更多的噪声，所以更容易出现锯齿**，异常的波动性可能会忽悠你一把" | S6-1 |
| **工作流（米勒维尼的日程，可照搬）** | 前一晚完成大部分工作 → 8:30 到屏幕前先看**新闻 + 盘前期货** → 更新止损指令与提醒（**接近买入价与接近止损价都有声音提醒**）→ "**因为我不喜欢惊喜，所以会试着提前做计划**……我会在收盘期间做好计划以消除情绪因素" | S1-2 |
| **前 45 分钟少动手** | Ryan："**我通常在前 45 分钟内不会做过多交易**，因为股价有很多误导性的波动和由隔夜新闻引起的变化"；且"**看短期趋势曾使我多次错过交易良机**" | S1-2、S1-7 |
| **量价的即时判读（Zanger 的盘中规则）** | "**如果股价上涨但成交量小，那么它们可能会很快下跌。或者如果成交量很小伴随股价下跌，那么这种情况是买入的机会。放量上涨或下跌会告诉我它们可能会延续当前走势。**" | S1-2 |
| **趋势模板在今天的失效（重要提醒）** | Ritchie II："**最近很难在创下 52 周新高时买入或买到长期高位突破趋势线的股票，而在以往会容易许多。**" → **同一套规则在不同时期的成功率不同** | S1-1 |
| **日内交易不是他们的优势** | Ryan："**我最大的收益来自中长期持有的股票**……有时分时图上的波动看起来很可怕，但是当你退后一步，在每日甚至每周的图表内查看时，会发现这个波动是非常小的" | S1-7 |
| **期权与保证金的态度** | Minervini：**现在不用**保证金与期权（"使用期权时会遇到种种阻力"）。Ryan："**我几乎不使用期权。我不喜欢时间衰减**……我只在市场处于良好的上升趋势且没有太大波动时使用保证金"。Zanger 的名言："**新手喜欢期权，这也是他们一直是新手的原因。**" | S1-9 |

### ⚠️ 适用边界与坑

- **适用对象**：**已经在用第 1、2 册方法的成长股/强势股交易者**，以及需要一个"别人怎么做"的参照的人。**不适合入门——它没有系统，只有片段。**
- **不适用/易误用之处**：
  1. ⛔ **算法不能直接用（四处）**：① **"2.5% 单笔风险""10% 止损"全部是美国成长股 + 每日可交易的假设**；② **"FOMC 会议前减仓"是中国投资者没有的对应事件**（对应的是**财报披露、政策窗口、限售解禁**）；③ **Ryan 的"前 45 分钟不动手"是美股开盘时段（9:30）**，A 股对应的是集合竞价后前 30 分钟，且**A 股开盘经常直接跳空，实际更应推迟**；④ **"设置止损指令 + 括号订单"在 A 股 T+1 与涨跌停下不可执行**。
  2. ✅ **思想可用且本库最该抄的**：① **单笔风险贡献封顶 + 随近期表现动态升降档**（Ritchie II 的 100/200~300/500BP 三档）——这是本库 [[claims/五套体系的仓位与风控对照]] 缺的一层；② **"枕头因素"作为头寸过大的唯一自检**；③ **"让股票告诉你卖哪只"而非听市场信号**（这一条能直接减少大多数散户的最大亏损来源——恐慌卖出）；④ **连亏自动缩表**。
  3. ⚠️ **四人观点大量冲突，必须挑一套，不能混着执行**：Zanger 的"**撬开墙保住厨房**"（跌势中立即清仓）与 Minervini 的"**经历一轮市场回撤也没有卖出**"完全相反；Ryan 的"止损 10%"与 Ritchie II 的"3%~10% 区间"也不同。**这是本库做体系选择时最该警惕的一点。**
  4. ⚠️ **HFT 那段（S1-3）对中国投资者基本无效**。四人谈的是美国市场的电子化、8 位小数报价、抢跑。**A 股是 T+1 + 涨跌幅限制 + T+0 转债，市场微观结构完全不同。**唯一可迁移的是 Zanger 的建议："**通过买入确定会突破趋势线的股票并持有几个月，以避免陷入 HFT 带来的困境**"——**即用持有周期躲开高频资金的战场**。
  5. ⚠️ **"市场被操纵了吗"这一节四位没有共识**，Ritchie II 直接反对米勒维尼。→ **这一节的结论要当作"信念"而不是"事实"，不影响操作。**
  6. ⚠️ **S6-2 那句"除了技术形态和龙头股，没有其他有价值的指标了"是强观点，不是公理**。本库用**道氏/均线判断牛熊**的做法与之冲突——**但那是"降低仓位"的宏观过滤，不是"卖哪只"的微观决策，两者可以并存**（米勒维尼自己也说"如果纳斯达克涨 10%……龙头股涨 50%~100%"，即他并不否认大盘）。
- **参数是否可核实**：
  - ✅ **原书给的、具体可用的数字**：单笔风险 2.5%/0.75%~1.25%（Minervini）、1%（Ryan）、1%~3% 与组合 20%（Zanger）、100/200~300/500BP 三档（Ritchie II）、止损 3%~10% 与 10% 硬上限、"两次 5% 优于一次 10%"、头寸 5%→7%~8%→单个 15%~25%、学习期 2 年（Ryan）/5 年（Minervini、Zanger）、查底"过去 3~6 个月是否大幅向下跳空"、前 45 分钟不动手。
  - ⚠️ **原书给的、需重估的自述数据**：米勒维尼"6 年收益不佳后转正"、"基本上没有哪一笔交易的亏损超过 10%"；Ryan "投资额越来越小"；Zanger "44 万→22 万→欠债 225 美元→卖车 11000 美元"；**以及四人共同的"方法 30 年不变"**。**都是口述，无第三方验证。**
  - ⚠️ **口述转述他人**：Ritchie II 引 Tony Robbins；Ryan 引 Minervini 2014 年 60 分钟广播；Minervini 转述 William Berger 的"拥有网球，放掉鸡蛋"（这句出自第 2 册，Zanger 才是听者）。
  - ❌ **原书没有的**：任何回测数据、胜率统计、市占率。**这是一本"经验之谈"，不是研究著作。**
