## 二、精读总结

### 这本书在讲什么

技术分析界的"圣经"，第一部分讲**道氏理论**（含三种趋势、12 条信条、三个平均指数互相印证），第二部分讲**实战战术**（头肩顶/三角形/缺口/支撑阻力/趋势线 + 两类止损 + 仓位管理）。前七版作者是爱德华兹与迈吉，第 10 版由巴塞蒂修订，加了一整节编者按——**这套编者按往往比正文更诚实**（例如他直言"我认为现在看来，道氏理论已不足以作为宏观经济的晴雨表或当今市场的投资工具"）。

它的真正身份有两层：① **道氏理论的权威注释本**——本库 [[concepts/道氏的三种运动]]、[[concepts/道氏理论的适用边界]] 的规则细节以本书为准；② **一套形态教科书**——头肩顶、双顶双底、三角形、箱体、缺口、支撑阻力的定义与测算目标，是所有技术分析图表教材的共同祖先。

第二个实用价值常被忽略：**它是本库里少见的、把"止损"讲得最完整的书**（第27章区分了保护性止损、跟进性止损、基准点止损、ATR 止损、抛物线 SAR、目标止损法六种，并说明各自适用场合）。

给谁看：所有技术分析者的地基。**但必须知道它的时代局限**——所有原始图表是 1940 年代的道指/美国无线电/西屋电气，价格 5~50 美元，**没有 T+1、没有涨跌幅限制、没有 ETF**。

### ⭐ 核心判据（可落成看盘动作的）

| 判据 | 具体规则 | 原文出处 |
|---|---|---|
| ⭐ **长线趋势的判定（牛市定义）** | 牛市：每一波连续上涨都**达到新的高度**，且每一次回调的**低点都高于前一次回调的低点**。熊市反之。持续时间"一般（并非总是）一年以上" | 第792行（第3章原则3） |
| **中线趋势（次级修正）** | 逆长线趋势的重要调整，**一般持续 3 周到数月**；**一般从前一波净涨跌幅的 1/3～2/3 处回调**。⚠️ 作者明说"这个1/3～2/3调整法则并非绝对"，有完全抵消前期涨跌幅的例外 | 第796–800行 |
| **中线趋势的双重确认标准** | ① 时间**超过 3 周**；② 幅度**超过前一波行情净涨跌幅的 1/3**。两个条件都满足才能确认为中线趋势 | 第802行 |
| **短线趋势** | 持续**不到 6 天**，极少达 3 周。中期调整"一般都由 **3 个或以上**的小波段组成"。⚠️ **"仅从每日波动得出的推断往往会误导投资者"** | 第804行 |
| **长线趋势不可操纵** | "长线趋势和中线趋势无法被操纵；**哪怕美国财政部竭尽所有资源，也未必能操纵市场**"。但短线趋势**是三者中唯一可以被"操纵"的** | 第804行 |
| ⭐ **相互印证原则（道氏最核心）** | **任何预示趋势改变的有效信号都无法单独由某一个指数发出。** 两个指数不必同日印证，一个可能**滞后另一个数天、数周甚至一两个月**，此时"投资者应该耐心等待，直至市场出现明确的方向"。⚠️ 分歧时"**只能相互否定或削弱效力**"，绝不能当作看涨信号 | 第834–839行 |
| **成交量验证趋势原则（准确表述）** | 牛市：价涨量增、价跌量缩；熊市：价跌量增、价升量缩。⚠️ 作者明确说**成交量只作附加证据**——"有关市场趋势的**决定性信号最终都是通过分析价格变动得出的**" | 第846行 |
| ⭐ **只使用收盘价** | 道氏不关注盘中最高/最低，只看收盘价。书中给的判例：某波上涨上午 11 点见顶 152.45 点、收于 150.70 点，则**下一波必须收于 150.70 上方才表明长期升势不改**，盘中摸到 152.60 不算 | 第876行 |
| **突破幅度（作者的立场）** | "道氏和汉密尔顿显然认为，**收盘价只要突破了前期顶部或底部，就算只突破了0.01点，都是有效信号**"；对"起码突破1个点"的说法，作者认为"最初的观点最站得住脚" | 第882行 |
| ⭐ **趋势延续原则（第12条）** | "在明确的趋势反转信号出现前，应认为趋势将持续"。作者的论证是**概率论**：首次确认长期趋势时延续概率最大，随趋势运行时间加长，**后续再次确认信号的技术意义越来越小**。⚠️ 作者承认"这提醒投资者：在应用道氏理论时必须时刻关注市场动向" | 第888行 |
| **横盘（line）的定义** | 一个或一对指数的小幅震荡，持续**两到三周（有时数月）**，价格在 **5% 范围内**波动。**横盘持续越久、价格区间越窄，突破的技术意义越大**。突破方向无法预测 | 第856行 |
| ⭐ **头肩顶四阶段（A/B/C/D，缺一不可）** | **A 左肩**：强劲上涨+成交量显著扩大 → 短线回调+成交量缩小。**B 头部**：另一波高成交量上涨**超过左肩顶部** → 回调**低于左肩顶部**。**C 右肩**：第三波上涨但**成交量显著低于左肩和头部**，且**在达到头部顶点之前就开始回落**。**D 确认**：跌破颈线（连接左-头、头-右两低点的直线）并**继续下探约 3%** | 第1066–1074行 |
| **头肩顶的成交量分布概率** | "确认的头肩形态中，**大约有 1/3 的左肩成交量大于头部交易量，1/3 两阶段成交量差不多，剩余 1/3 头部的交易量高于左肩**" | 第1092行 |
| **头肩顶的两种失败模式** | ① **约 20% 的右肩没有有效向下突破**（在右肩区间震荡后再次回升，形态半途而废）；② 颈线突破后股价**没跌太多**（"假突破"）。作者称假突破"在绝大多数的头肩顶形态中极为罕见" | 第1100–1102行 |
| ⭐ **最小跌幅测算公式（可直接算）** | ① 从**头部顶点竖直向下量到颈线的距离**；② 从**右肩成形后最终突破颈线的位置**竖直下探**相同距离** → 所得点位即**最小下跌目标**。⚠️ **重要限制**：还有第二个最小目标＝头肩顶形成前的涨幅，**两个取较小的那个** | 第1130–1134行 |
| **最大跌幅无法计算** | "最大跌幅取决于诸多因素，如前期的涨幅、头肩顶的大小、成交量及时间跨度、**大盘的长线趋势（非常重要）**、股价离下方支撑区域的距离等"。**无法定义简单的测算规则** | 第1136行 |
| **三角形的最小目标测算** | 从第1波反弹的高点（三角形左上角）出发，**画一条平行于三角形下界线、从左往右向上倾斜的直线**，股价的最小上涨目标就是攀升到这条线 | 第1454行 |
| ⭐ **两类止损指令（本书最实用的部分）** | **保护性止损**：设在某一底部之下的安全范围，危急时才用，"救火"性质。**跟进性止损**：**在放量日撤销保护性止损，当天在收盘价以下 1/8 美元处设跟进性止损**——例：21 元买入→23 元放量新高→25 元天量收盘，**第 2 天撤销 18 元保护性止损，在 24⅞ 美元设跟进性止损** | 第4000–4036行 |
| **两类止损的适用场合** | 跟进性止损"非常有用，但是是用来应对**特殊甚至异常的市场状况**的"；**保护性止损可以保护普通投资者和交易新手**。作者认为有经验者可不用止损，"对于不确定自己交易方法的投资者来说，**过早平仓总比将股票从60美元捂至5美元好太多**" | 第4052–4056行 |
| **止损位的四种设定方式** | ① 按**基准点**设置（第28章）；② 设在**支撑/阻力区**的上方或下方；③ **百分比**（书中转述威廉·欧尼尔：**止损位应在买入价以下 8% 处**）；④ **资金总额百分比**（每笔交易风险控制在 **2%**，10 万资金即亏 2000 止损） | 第4079行 |
| **ATR 止损** | 真实波幅 = max（今日最高−今日最低，今日最高−昨日收盘，今日最低−昨日收盘）。ATR 通常取 **14 天或 20 天**；**5 天的 ATR 非常敏感**。用法：初始止损设在买入价以下 **2 个（或 x 个）ATR**；移动止损设在近期高点以下 x 个 ATR | 第4090–4094行 |
| **书中转述的海龟止损法** | "海龟交易员使用的标准是，**当股价跌破10日通道时，就抛出多头仓位**"。并注明这个标准**可修正为 3 日通道** | 第4104行 |
| **止损哲学（与海龟的关键分歧）** | "长期经验显示，**在市场小幅下行时就离场，势必导致长期利润偏低；接受市场的下行与利润的波动，则能获得较高的长线利润**" | 第4084行 |
| ⭐ **新手的资金使用纪律** | ① **绘图初期不动用任何资金**，"最初四五周内你建立的任何仓位都只是基于直觉的赌博"；② "你需要**耐心绘图 2 个月左右**，才能从技术上清楚地分析股票走势"；③ **学徒期通常要两年**，"在这两年的'学徒期'内，许多交易者逐步输光自己的资金"；④ "**你可以从 500 美元开始交易**"；⑤ "**你不能从一开始就依赖从交易中赚取的回报过活**" | 第5670–5686行（第40章） |
| **试错法（可落成动作）** | 用**过去已发生的行情**复盘你的新策略："曾有个交易员在一轮熊市中损失严重……用优化过的新策略重新审视了那段时期的 **30 笔交易**，原先的方法年损失 40%，新策略可带来 **156% 盈利**"。→ **检验新想法时不要用真钱，先用历史行情跑一遍** | 第5640–5642行（第39章） |
| **半对数坐标系（本库未收录但重要）** | 作者推荐半对数坐标：**等距纵轴 = 等距百分比**（10→20 与 20→40 距离相同）。优点是比较高价股低价股、便于下止损，且"**一些趋势线却能在半对数坐标系中得到更好的体现**" | 第736行 |
| **开盘价的技术意义≈0** | "经验表明，**开盘价对预测未来走势几乎没有意义**。但是，**收盘价却非常重要**，是多数人真正关注的信息" | 第356行 |

### ⚠️ 适用边界与坑

- **适用对象**：**所有技术分析者的地基**，尤其中长线趋势判断。**本身是美股工具**（道指/标普/纳斯达克），但形态与止损逻辑与市场无关，可移植。
- **不适用/易误用之处**：
  1. ⛔ **算法不能直接用（制度部分）**。① **道氏的"相互印证"依赖多指数/多行业指数**——A 股可用上证+深证+沪深300+创业板互相印证，**逻辑成立，标的需替换**；② **第10版编者按自己就承认道氏已过时**："我认为现在看来，道氏理论已不足以作为宏观经济的晴雨表或当今市场的投资工具。它只是在早期简单的市场环境中提出的一套简单理论"；③ **第10章"大宗商品图表技术分析"整章讲期货**——⛔ 不做期货，该章只保留一条通用思想：**期货的杠杆会放大同一形态的百分比波动**，其余不用。
  2. ⛔ **形态全部是事后确认的，作者自己承认**。第10章明说"反转形态通常在趋势改变以后才发出信号，虽然一般比道氏理论要早，但也不会正好在顶部或底部发出信号"；头肩顶"从形态刚形成就卖出，损失不超过最高点至最低点价差的一半"。
  3. ⚠️ **A 股的三处硬约束原书没处理**：**T+1**（跟进性止损"当天收盘后设置"在股票上做不到隔夜追单）、**涨跌停**（跌停时止损单挂不上，"你在出现成交放量的这天撤销保护性止损"这条无法执行）、**停牌与除权**（书中专门讲除息会人为制造跌破信号，见第37章"旧图重读"）。**可转债 T+0 反而更适配跟进性止损。**
  4. ⚠️ **半对数坐标系在今天的软件里默认关闭**。作者花了一整节推荐它，但默认的K线图是等差的。**用等差图看长周期行情会严重误导**——建议在软件里打开对数坐标或改用涨跌幅归一化。
  5. ⚠️ **不要把第27章的止损方法当成"六选一"**。作者的排序是明确的：**新手用保护性止损，成熟交易者用基准点/趋势线**，跟进性止损只应对异常。作者的结论句："**一个方法越是自然、需要的演算越少，这个方法就越好**"。
  6. ⚠️ **"技术分析对市场的影响"（第35章）意味着形态会自我消解**。当所有人都认识头肩顶时，它就不再有效。→ **形态是描述工具，不是预测工具**。
- **参数是否可核实**：
  - ✅ **原书给的、可逐条核对的规则**：长/中/短趋势的时长与幅度定义（3 周、1/3～2/3、1/3）、横盘 5%、头肩顶 A/B/C/D 四阶段、头肩顶与三角形的最小目标测算公式、2%～3% 趋势线突破标准、跟进性止损"收盘价以下 1/8 美元"、欧尼尔的 **8%** 止损、**2%** 单笔风险、ATR **14/20 天**、海龟 **10 日通道**、绘图 2 个月/学徒期 2 年/500 美元起步。
  - ⚠️ **原书给的实证数据（需重估）**：道氏理论的 **60 年（1897 起）/113 年模拟交易记录**（表4-1、表4-2，未计佣金与税、需考虑分红）；头肩顶"约 20% 的右肩没效""约 1/3 的成交量分布"——**这些是 1940 年代美股的统计，A 股没有任何对应数据**。
  - ⚠️ **书中转述他人观点（非爱德华兹原创）**：欧尼尔的 8% 止损、SAR（怀尔德 1978）、抛物线修正版（Chuck LeBeau）、比尔·司各特的"连跌5天卖一半"、日本谚语"8次新高卖一半"、克里滕登的"10 个 ATR ≈ 27%"。**引用时应标为转述。**
  - ❌ **后人加的**：把"道氏理论"等同于"三线定律""九转序列""生命线"等国内衍生品；把"均线吻"当作道氏理论内容（作者只推荐 200 日线判断牛熊，见第6章）。**注意书中明确删掉了"综合杠杆"章节（第7版第42章/第8版附录A），只在第42章保留概略。**
