## 二、精读总结

### 这本书在讲什么

亚历山大·埃尔德（Alexander Elder）医生的三重修订版（原版 1993，本书为第 4 版）。**它不是教人看盘的，而是教人活下来的**——作者明说第 1 版最薄弱的就是资金管理，这一版把那一部分**完全重写**了。

全书的骨架是三个支柱加一个黏合剂：**交易技巧 + 心理学 + 资金管理 + 交易记录（交易日志）**。三个系统（三重滤网、动力系统、通道交易系统）只是"技巧层"，而真正贯穿全书的是**风险控制的铁三角**（最大风险 ÷ 每股风险 = 最大股数）。

它还有一个容易被忽略的价值：**埃尔德是唯一一个把止损位置当成数学问题来处理的作者**。他把市场波动拆成"信号"与"噪声"两部分，然后要求**止损设在噪声之外**（安全区域法 / 尼克止损）——**这与米勒维尼"反对按波动率设止损"是本分类中最值得对照的一对矛盾。**

给谁看：**任何做短线/波段的股票交易者**。第 5 章整章讲期货，但可跳过（第 48 章"新手炒变化更慢的股票会更好一些"是作者自己的建议）。

### ⭐ 核心判据（可落成看盘动作的）

| 判据 | 具体规则 | 原文出处 |
|---|---|---|
| ⭐⭐ **三重滤网的三重过滤（核心系统）** | **第一重 = 长期周期的趋势**（用周线）："**只允许你顺着大趋势的方向进行交易**……它**仅允许你顺着大趋势的方向进行交易**"；作用像监察员——"**在上升的趋势里只允许你选择买入或者观望；在下行的趋势里只允许你卖空或观望**"。**第二重 = 中期周期的震荡指标**（用日线）："**当周趋势是上升的，三重滤网仅允许采用日线图震荡指标发出的买入信号，而不会允许采用其发出的卖空信号**"。**第三重 = 更短期的买入技术** | 第2590–2624行 |
| **时间周期的"5 倍关系"** | "**市场的每一个时间周期对其大一号或小一号的时间周期，大概是五倍的关系**"。选好中期周期后，**先看大一号的长期周期做战略决策，再回中期周期**。"如果你开始分析周线图时，**你的视角会比你的竞争者大出五倍**" | 第2582–2594行 |
| **日内交易的配对（可直接用）** | 美国股票"39 分钟线 + 8 分钟线"（39×10=390 分钟=6.5 小时）；通用版"**30 分钟线 + 5 分钟线**"。**先在长期周期定多空，再在短期周期找入场与止损** | 第2795–2810行 |
| ⭐⭐ **2% 原则（单笔风险）** | "**2% 原则会防止你的账户在单次交易中出现本金亏损 2% 以上的风险**"。例：5 万账户 → 每笔最大风险 1000 美元。⚠️ "**这不是交易规模，而是账户中本金风险的大小，基于入场点和止损点之间距离大小来计算**" | 第3723–3725行 |
| ⭐⭐ **6% 原则（当月总风险，硬上限）** | "**6% 原则给每一个账户都设定了一个当月最大回撤比例。如果你达到了限制，这个月接下来的时间就要停止交易。**6% 原则**强制你在受到食人鱼攻击前，从水里走出来**。"例：5 万账户 → 全账户风险敞口不超过 **3000 美元（6%）**，B、C、D 三笔各 2% 已用满 → **不能买 E** | 第4355、4383–4395行 |
| **2% / 6% 的比喻（记住这两个词）** | "**只需要一次致命的损失，就能毁掉一个账户……就像是鲨鱼咬了致命的一口**"（= 2%，防单笔巨亏）；"**市场也可以通过一串连续的损失毁掉账户……就像是一群食人鱼一样**"（= 6%，防连亏出局） | 第152、4353行 |
| ⭐ **2% 是浮动的（按账户净值重算）** | 月初 10 万 → 每笔最大风险 **2000**；月底涨到 10.5 万 → **2100**；跌到 9.5 万 → **1900**。"**2% 原则将你能交易的规模与你的操作表现以及账户中资金的多少联系起来了**" | 第4353 区域 |
| ⭐⭐ **风险控制的铁三角（全书最该抄的公式）** | **A. 你计划要进行的交易的最大风险额度（永远不能超过账户规模的 2%）** → **B. 你预计的进场位和止损位之间的价差（每股风险）** → **C. 将 A 除以 B，得到所能交易的最大股数**。"**你并不一定要交易这么多，但是不应该超过这个数字。**"作者的班级实例：4 万账户、按 1% = 400 元风险，买入价 16 元、止损 14.5 元（每股 1.5 元）→ **250 股**（余量留给佣金） | 第3770–3780行 |
| **仓位差异化的分配方式** | "对一般的交易是最大限额的三分之一，对比较有信心的交易使用三分之二，其他更有信心的可能就全额使用" | 第3782行 |
| **三种最致命的错误（作者点名）** | ① **从不使用止损**（"会使你暴露在无限的损失之中"）；② **持有相对账户来说过高比例的仓位**；③ **过度交易**——"**失败者的真正问题不在于资金多少，而在于过度交易和糟糕的资金管理**" | 第155–158、206行 |
| ⭐ **进场前必须写下三个数字** | "**在你进入一个交易之前，写下三个数字：买入价位、盈利目标价位和止损价位。没有定好这三个数字的交易便是赌博。**" | 第2757行 |
| **止盈止损的周期分工** | "**三重滤网交易系统要求使用长期图表来设置止盈点，使用中期图表来设置止损点。**"周+日组合 → **周线设盈利目标（日线 EMA 价值区间），日线设止损**；25 分+5 分组合 → 25 分钟设目标，5 分钟设止损 | 第2761行 |
| ⭐ **安全区域止损（用噪声设止损）** | ① 用 **22 日 EMA** 定义趋势线；② **上升趋势**：记录 10~20 天内**向下穿透 EMA 的深度**，求平均向下穿透值 = 当前平均噪声水平；③ **止损设在远离该平均值的位置**，即**平均穿透值 × 系数（通常 2 以上）**。**下降趋势**：改为向上穿透求平均，**系数可以从 3 开始**——"**在高点卖空比在低点买入需要更宽的止损空间**" | 第3066–3074行 |
| ⭐ **尼克止损（避开止损单扎堆区）** | 逻辑："**从密集的价格区间向下探出显眼的新低点，最容易吸引交易者在新低点下方设置止损位。问题是太多人在这里设止损线……市场有一个神秘的习惯，会很快地跌穿这些明显低点，引发止损后再反转。**"→ **把止损设在近期的次低点，而不是最低点附近**；做空则设在**次高点**而非最高点之上 | 第3082–3100行 |
| **止损宽度的权衡原则** | "**对短期波段交易来说，把止损设在更近的位置比较好，然而对长线交易来说，最好设定更远的止损线。记住'风险控制的铁三角'——更远的止损可以交易的规模会较小。**" | 第3078行 |
| **止损失效与失效条件（动力系统口径）** | 双重否定式：**买入**时"动力系统从蓝色变成了红色"才有效（反之无效）；**卖出**时"动力系统从红色变成了蓝色"才有效。→ **不看指标的超买超卖，只看是否转向** | 第3090行 |
| **通道交易系统的构造（可量化）** | **上通道线 = EMA + 通道系数 × EMA；下通道线 = EMA − 通道系数 × EMA**（EMA 为长期均线，如 13/26 日 EMA 的 26 日线）。**系数起始设 3% 或 5%，然后调整到"最近 100 根线柱中约 95% 的价格被包含在内"**（日线约 5 个月）。**经验值：周线图的通道宽度是日线图的两倍** | 第2800–2830行 |
| **通道的铁律（可直接执行）** | "我有一个严格的准则就是：**永远不要在上通道线之上买入，也不要在下通道线之下卖出。这个准则会导致我错过一些趋势机会，但我的安全性得到了极大的提升。**" | 第2840行 |
| ⭐ **指标季节性四阶段（可直接照搬到 MACD）** | **秋季**（指标在中线上方但下降）= **建立空头仓位的最佳时期**；**冬季**（指标降到中线之下）= **了结获利的空头仓位**；**春季**（指标自中线之下掉头向上）= **建立多头仓位的最佳时期**；**夏季**（指标自中线上方上升）= **了结获利的多头仓位** | 第32 节区域 |
| **对周期分析的证伪（重要反共识）** | "如果你用严格的数学程序来分析价格数据，比如用约翰·埃勒斯（John Ehlers）发明的最大熵谱分析法来分析，**你就会发现大约 80% 的看似周期的东西都只是市场噪音**……**用笔和尺寻找短期市场周期就好比用魔杖来找水，由于方法没有根据，偶尔成功的获利也会被许多次损失吞噬**" | 第32 节 |
| **时间意识的重要性** | "**大多数交易者只关注价格的变化，很少关心时间**，这正是被大众心智俘虏的另一个标志。" | 第32 节 |
| **分组指标组合（震荡 vs 趋势）** | "**将不同组中的不同指标结合起来是很有用的，可以抵消各个指标的缺点同时保留它们的优点。**"具体配法：**随机指标等震荡指标在趋势中会持续失效**——"在上涨趋势中，随机指标会很快到达超买位置，会持续给出卖出的信号，但市场会一直上涨" | 第2429、844行 |
| **分析市场数据的最少集** | "**当我们看图表时，我们仅需分析五种数据——开盘价、最高价、最低价、收盘价和成交量。在这五种数据之上，再堆加大量指标和图形只会徒增困扰。大道至简**" | 第665行 |
| **每日交易记录（第三支柱的黏合剂）** | "**列一个单子，记录你的每一笔交易，包括佣金和滑点。坚持记录'购买前和购买后'的表格。在交易生涯的初始阶段，你得投入足够长的时间去分析自己，时间至少得和分析市场的时间一样长。**" | 第517行 |
| **交易的三个目标（次序不能颠倒）** | "**你的第一目标是必须长期生存下去，第二目标是资本的稳定增长，第三目标才是赚取高额利润。大多数交易者……将第三目标放在了第一位，更有甚者，都不知道第一目标和第二目标的存在**" | 第480行 |
| **期货的致死性（⛔ 用户约束相关）** | "**据说不分之十的新手在最初几个月就会被洗出局**"；"**并不是期货打败了交易者，是拙劣的资金管理能力击败了期货交易者**"；作者建议："**新手炒变化更慢的股票会更好一些。一旦成为成熟的交易者，你观察期货会更加清晰。**" | 第1236、1250行 |

### ⚠️ 适用边界与坑

- **适用对象**：**所有做短线/波段的股票交易者**。三重滤网与止损方法**完全适用于 A 股股票**；通道系统同样适用。
- **不适用/易误用之处**：
  1. ⛔ **期货那两章（第 5、48 章）直接跳过**。作者的裸卖期权、每日涨跌停、保证金等论述，**与本库"不做期货"的约束完全无关**；他提到的"EMini 电子迷你期货"在中国不存在。**唯一值得留的是那句风险警告（新手存活率十分之一）——它同样适用于 A 股票的杠杆产品与可转债。**
  2. ⛔ **算法不能直接用（三处）**：① **"39 分钟 + 8 分钟"的配对是美股的开盘时长算出来的**（6.5 小时 = 390 分钟），A 股要按自己的交易时段重算；② **第三重滤网的"平均 EMA 下跌穿透"需要回测确定系数**（原书只给方法，未给系数）；③ **"强力指数、随机指标、RSI"在中国软件的默认参数与美股不同**（如 EMA 的 EMA 种子值）。
  3. ✅ **思想可用、且本库最该抄的三条**：① **风险控制的铁三角（A÷B=C）**——这是本库最清晰的一条头寸公式；② **2% 单笔 + 6% 当月总风险的双层保险**——**6% 原则是本分类里唯一一条"强制停手的硬规则"**，比"回撤降档"（海龟）更硬；③ **止损设在噪声之外（安全区域）+ 避开止损扎堆区（尼克止损）**——**"止损不要设在显眼位置"这一条，几乎所有止损体系都没提过。**
  4. ⚠️ **与米勒维尼的止损观正面冲突，本库必须做取舍**：**埃尔德主张按波动率（EMA 穿透深度）设止损；米勒维尼明确"强烈反对"按波动率设止损、主张按胜率反推。**两人都给了自洽的论证。**建议的调和（本库口径）**：① **头寸用埃尔德的铁三角，止损宽度用米勒维尼的胜率反推**——两者解决的不是同一个问题（前者是"能买多少"，后者是"该亏多少"）；② **止损位的位置用埃尔德的"避开显眼低点/设在次低点"**——这是纯技术性改进，与宽度之争无关。
  5. ⚠️ **"6% 原则 → 停手一个月"在实盘极难执行**，作者自己也承认这是"防食人鱼"的最后一道。**它更像一个心理契约而非机械规则**——真到 6% 时，人很难接受"这个月不做了"。**建议改造为：触发 6% 时把当月剩余时间的仓位上限降半，而不是完全停手。**
  6. ⚠️ **"永远不要在上通道线之上买入，也不要在下通道线之下卖出"这条铁律作者自己承认会错过趋势**。在 A 股题材股上，这条规则会让你错过大量主升浪。**它更适合作为"警戒信号"而非"禁止操作"。**
  7. ⚠️ **对周期的证伪（80% 是噪音）这一段，对本库的"时间窗与数量参数总纲"是一个反向证据**——如果真要写进本库，那一页应该标注"埃尔德对周期分析给出了 80% 为噪音的量化反驳"。
- **参数是否可核实**：
  - ✅ **原书给的、可核的规则与公式**：**三重滤网三重的分工**、时间周期 **5 倍关系**、**2% / 6% 原则**、**风险控制铁三角（A÷B=C）**、**进场前写下三个数字**、**止盈止损的周期分工**、**安全区域止损（22 日 EMA + 10~20 天回溯 + 系数 2 以上；下降趋势系数从 3 开始）**、**尼克止损（次低点/次高点）**、**通道系数 3% 或 5% 起始、覆盖 95%**、**周线通道宽度 = 日线 2 倍**、**指标季节性四阶段**、**39 分钟 + 8 分钟（美股）**。
  - ⚠️ **原书给的、需重估的实证**：埃尔德多次在《巴伦周刊》专栏披露的实盘收益（**已随时间推移而变化，不宜引用为当前业绩**）；"埃尔德盘/自动包络"等自研工具的效果。
  - ✅ **原书给的、罕见的反共识量化证据**："用最大熵谱分析法分析，**大约 80% 的看似周期的东西都只是市场噪音**"——**这是本分类中少见的、可被独立验证的证伪性陈述**（埃勒斯的方法是公开的）。
  - ❌ **原书没有的**：**胜率统计、盈亏比、任何回测序列**。全书以方法与纪律为主，无系统业绩披露。
  - ⚠️ **版本注意**：中文版是第 4 版，**较第 1 版变化很大**（作者明说"我减少了技术章节的内容……完全重写了资金管理部分"）。**国内流传的很多"埃尔德止损法"出自第 1 版，与本书有出入。**

  - **头寸上限的层次不同**：海龟是**跨市场总敞口上限**（4/6/10/12 单位），本书是**单笔 2% + 当月 6%**。**两者不冲突，是不同层级**——建议叠加使用。
  - **对周期的态度**：本库 [[syntheses/时间窗与数量参数总纲]] 假设时间窗有统计意义，**本书第 32 节给了 80% 为噪音的反驳**，这与该页的前提存在张力。
