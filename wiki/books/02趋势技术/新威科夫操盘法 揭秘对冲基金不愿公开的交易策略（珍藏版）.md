## 二、精读总结

### 这本书在讲什么

孟洪涛（Edward Meng），2016 年《威科夫操盘法》的修订版。**它是本库三本威科夫书里唯一一本把"主力资金（CM）"当成真实对手、并给出完整操作流程的**——另外两本（库林《量价分析》、库林译的《威科夫体系》）讲的是形态学，这本讲的是**博弈**。

它的核心转变是把威科夫从"形态分类学"改造成"**供求关系读数法**"。作者的表述很精确：**威科夫研究的不是形态，而是"价格背后供求关系的变化"**——而这套方法的核心动作只有一个：**每根 K 线都问一句"现在是需求大于供应，还是供应大于需求？订单一旦改变，价格就止步了。"**

作者还给出了一句比其他威科夫书都更冷的胜率观：**"即使十次交易只有五次，甚至是只有三次或四次是正确的，总的结果是我们依然能够盈利。原因就是我们通过识别供求关系把风险降为最低，这样一次盈利的交易就能把所有亏损的交易补平。"** — 这就是全部的容错逻辑。

⚠️ **副标题"揭秘对冲基金不愿公开的交易策略"是营销话术。** 作者反复强调的主角是"聪明钱"而非某家对冲基金，且书中所有"主力资金"的行为都是**从量价推断的假设**，不是内部资料。

### ⭐ 核心判据（可落成看盘动作的）

| 判据 | 具体规则 | 原文出处 |
|---|---|---|
| ⭐⭐ **聪明钱的五步看图顺序（全书唯一的操作流程）** | **① 背景** → **② 价量形态**：K 线长度、成交量高度、**变化速度** → **③ 价量形态的性质**：走势强弱、原因与后果 → **④ 结论或预测**：判断当前处于**上涨趋势的秩序**还是**下跌趋势的秩序** → **⑤ 措施和行动**：进场、离场、**收紧止损**。作者开篇即否定"等指标给信号"的做法："**如果想挖掘价格背后主力资金的真正意图，只看技术指标无法得到真正的答案**" | 第21行（第一节） |
| ⭐ **主力资金四条观察原则** | ① **趋势的动力来自供求关系的不平衡（供求关系原则）**；② **趋势形成之前需要准备过程（因果关系原则）**；③ **成交量的增长没有使价格大幅增长，这是走势停止行为（努力和效果原则）**；④ **市场要是保持一种趋势，必须遵循现有的秩序。换句话说，只要这种秩序不被打破，趋势就存在，我们就可以安心持仓** | 第26–27行（第二节） |
| ⭐ **上涨秩序的定义（可用来判断何时离场）** | "在上涨趋势中，价格上涨背后的原因是**供不应求**。市场上**在同一价格的卖单总是无法满足不断增加的购买力**，这是一种秩序。为了满足需求，买方只能去买高一点价位的股票……**在这种需求大于供应的情况下，价格走势如果要停止或者出现反转，供求关系的秩序首先要有变化**。也就是说**在同一价格情况下，当人们的购买力完全得到了满足，不需要抬高价格来满足需求的时候**，趋势就停了" | 第29行 |
| ⭐ **持仓期的唯一检查（可落成动作）** | **"上涨趋势当中，没有卖盘出现（供应），任何的低量回调都是我们的进场点。"** 反之，"上涨当中出现了**两天回落**，我们更关注成交量，**低量说明没有供应压力，价格继续上涨的秩序没有被打破**。这里是个好中最好的进场时机！" | 第41、26行 |
| ⭐ **吸收（高支撑）的识别与用途）** | "K 线７的**振幅大幅缩小，同时成交量没有缩小**，这是**停止行为**，表明**供应努力没有结果，同时新的需求在接盘**。特别是最后一根阳线，说明需求已经全部吸收了供应。**略高的支撑位说明主力资金已经全部收购了下方的股票，现在开始向上收购**" | 第25、41行 |
| **吸收的确认方式** | "如果 K 线３之后第二天没有跟随，而是**立刻反弹**，说明**一次有压力的威胁被立刻摆平（吸收）**……**如果有高支撑，就确认了吸收行为，价格会继续上涨**" | 第41行 |
| ⭐ **需求/供应扩大的位置要求（很关键）** | "在不同位置的供应或需求扩大的意义**有非常大的区别**。**在震荡区的需求扩大表现为：它必须在震荡区的右手边，必须是相对长的阳线（包括长下影线）以及扩大的成交量**。在震荡区供应扩大的表现正相反" | 第41行 |
| **垂直需求柱（VDB）** | "１号 K 线：放量，长阳，这是上涨中**垂直需求柱（VDB）**，说明**需求控制市场**" | 第41行 |
| ⭐ **二次测试的确认规则（可直接当入场条件）** | "**需要二次测试来确认秩序。而这个二次过程必须是成交量递减的，才能确认市场需求主控，从而确认上涨趋势的秩序。**"（另："**所有超卖高潮之后的成功二次测试将终止熊市**"） | 第62行 |
| **恐慌抛售（SC）的定义与硬门槛）** | "也叫作**超卖高潮**。它是**下降趋势中发生的、潮水般的恐慌抛售**……发生在下跌趋势持续了一段时间之后。它标志着**下降趋势的结束或者接近结束**。这种恐慌性的卖盘形成了**极宽的振幅和超高的成交量**，可以发生在**一天或者几天内**。**如果没有上述特征，将不是超卖高潮。不是所有的下降趋势都会有超卖高潮。**" | 目录页/第24行区域 |
| **上冲回落（UT）的用法）** | "K 线３**突破了阻力线回落**，我们叫**上冲回落**，简称 **UT**。"→ UT 是顶部预警 | 第40行 |
| ⭐ **震仓（Shakeout）的两类与目的）** | **普通震仓**：发生在**上升趋势**中，多数受不利消息影响造成临时波动，**之后价格快速恢复上涨**。**终极震仓**：发生在**吸筹过程中**，目的是"**让还在死扛的大众交易者抛掉手里股票，让主力资金控制更多筹码**" | 脚注②（第25行） |
| **死角（Dead Corner）** | "在支撑位或阻力位，**K 线的高点不断降低，低点不断升高，价格波动越走越窄**。**死角意味着价格很快有大幅波动，这是个提前进场的好时机**。" | 脚注① |
| ⭐ **断路判据（趋势反转的确认）** | **顶部的主线**："**无论有多大的需求努力，都无法克服顶部的供应压力，导致价格无法创新高。**派发的最后观察是**需求耗尽**。" → **底部对称：无论供应多大多小，都无法跌破需求支撑** | 第171行 |
| **突破幅度缩短（SOT）** | "**SOT 是一个非常实用的停止行为，特别是在区间交易的时候，如果在支撑或阻力位出现 SOT，说明当前趋势可能停止**" | 第171行 |
| ⭐ **冰线（SOW）的持仓处置）** | "**供应的持续增加导致价格破冰。这个在持仓当中要特别小心。一个光头阴线大幅度突破昨天的最低点，这是非常明显的破冰行为**，用小时图看得更清晰。**这个时候必须启动保护措施，不要在乎账户盈亏。**"——并解释为什么："在冰层之上，**套住了大量大众交易者**，这些人此时处于后悔和恐慌当中，非常盼望价格起来帮他们解套。但是从主力资金角度讲，**帮大众交易者解套等于自己要用更高的价钱吃进**（筹码）" | 第174行 |
| ⭐ **离场的供求判据（可直接照搬的检查表）** | 案例原文：在阻力区（供应区）价格恢复上涨时，**需求应该扩大并战胜供应（应该增量突破阻力创新高）**。判读："我们看 E 后面的 K 线，**没有上涨的跟随，说明需求已经耗尽**……再看累积成交量，BC 这波成交量巨大，而 DE 波的累积成交量已经稀少，这也证明了需求的耗尽，**我们应该考虑离场**" | 第164行区域 |
| **三类"不可信"的市场行为（停止行为的解读）** | ① "**巨量之后的不涨说明有卖盘增加**，这对继续上涨造成临时的威胁。第二天量增……但**价格保持高支撑，说明需求还有能力撑住价格，明显的供应努力没结果**。第三天量增，但是阳线和高支撑告诉我们**供应耗尽**"。② "**巨量 OKR 阴线（外部反转）是个麻烦**……巨量表明出货量依然很大，**上涨当中出现巨量是个预警**。如果是震仓的话，后面应该立刻反弹" | 第62行 |
| **回头看"聪明的钱"的完整定义** | "他们**不看基本面和消息，不参与群聊，不使用技术指标等表象工具**。他们的判断**基于市场自身行为，他们研究的是盘口和量价**，然后通过判断市场的供求关系进而对下一波发展方向预测，以及制定应对失败的危机管理方法" | 前言 |

### ⚠️ 适用边界与坑

- **适用对象**：**A 股日线/60 分钟级别的手工看盘者**。这本书有**大量 A 股真实案例**（鄂武商 A 等），是三本威科夫书里**本土化验证最充分**的一本。
- **不适用/易误用之处**：
  1. ⛔ **算法不能直接用（三点）**：① **"主力资金（CM）的意图"全是事后叙事**——作者的推理链条是"**如果我是有主力资金，我会怎么做**"，这是**博弈推演而非情报**；② **"聪明钱"这个术语在书中没有可测量的定义**（没有北向资金、没有龙虎榜、没有席位数据），**它是一类人，不是一个指标**；③ 目录里的"**破冰回测做空策略**"（第227页）**直接违反 A 股单边约束**——⛔ 不做期货/不做空，该节只保留"破冰后离场"这一个用法。
  2. ⚠️ **"技术指标都是垃圾"这个前提过强**。作者说"技术指标本身就是在分析过去……他们万万没想到这些依据本身就不靠谱"。**这在诊断大众交易者时成立，但作为否定规则的理由是错的**——均线/ATR 的作用是**标准化与筛选**，不是预测。**本库的做法（用 200 日线判断牛熊、用 ATR 定止损）不与本书冲突**，因为那是"风控层"，不是"信号层"。
  3. ⚠️ **"聪明钱 vs 大众"的二分自带胜者偏差**。作者明说"我自己也曾经是羊！而且当了很多年羊"——**但书里没有给出"如何在当下识别哪一笔是聪明钱"的可操作判据**，只有事后解释。这使它**很容易变成一个万能叙事**（涨了=聪明钱拉的，跌了=大众恐慌）。
  4. ⚠️ **"死扛的大众交易者"这类表述容易滑向阴谋论**。作者的"主力"统一意志假设在**有真实控盘能力的标的**上成立，在**流动性充分的大盘蓝筹**上不成立。**用它选股 = 只在高控盘、小市值、有题材的票上有意义。**
  5. ⚠️ **"不要在乎账户盈亏"这条在 A 股有制度问题**：原文语境是"破冰立刻启动保护措施"，但 **跌停时根本卖不出去**。可转债 T+0 + ±20% 反而更接近原书的执行环境。
- **参数是否可核实**：
  - ✅ **原书给的、可核的规则**：五步看图顺序（背景→价量形态→性质→结论→行动）、四条观察原则（供求/因果/努力与结果/秩序）、**二次测试必须"成交量递减"**、**需求扩大必须在震荡区右手边 + 相对长阳（含长下影）+ 扩大成交量**、恐慌抛售的三要素（潮水般/极宽振幅/超高成交量，1~几天）、死角定义（高点降低+低点升高+波动走窄）、**破冰 = 光头阴线大幅跌破昨日最低点**、**离场的两条判据（无上涨跟随 + 累积成交量对比 BC 波）**。
  - ⚠️ **原书给的、需重估的描述**：A 股案例的历史走势本身可复核（**这是三本威科夫书里唯一可以回查的**），但**作者的解读无法证伪**。
  - ❌ **原书没有的**：吸筹/派发的**时长参数**、**具体标的名称的统计胜率**、**任何百分比止损**。⚠️ 全书**几乎不写止损比例，只写"破冰就启动保护措施"**——这是本书相比股票魔法师系列的明显缺口。
  - ⚠️ **术语注意**：国内常见的 **SC/AR/Spring/ST/SOT/SOS/JOC/UT/LPS/UTAD/OKR** 这套缩写，**威科夫本人与他主要的弟子从未统一使用**——它们主要来自 Bob Evans 与 Bruce Babcock 的推广。**本书使用的也是这套，所以引用时应说"威科夫体系（孟洪涛版）"，而不是"威科夫定律"。**
