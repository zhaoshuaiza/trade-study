## 八个目录，按「这是什么东西」分类

| 目录 | 中文名 | 放什么 | 判断方法 | 交易场景举例 |
|---|---|---|---|---|
| [`entities/`](entities/) | 实体 | **具体对象** | 「这是谁/哪套方法」 | 道氏理论、缠论、海龟法则 |
| [`concepts/`](concepts/) | 概念 | **抽象概念** | 「这是什么」 | 中枢、背驰、ATR、量价背离 |
| [`sources/`](sources/) | 来源 | **一本原始资料**一页 | 一对一 | 《道氏理论》PDF 的来源页 |
| [`claims/`](claims/) | 主张 | **有争议的主张** | 「这话对不对、证据够不够」 | 「10% 止损优于 2N 止损」 |
| [`comparisons/`](comparisons/) | 对比 | **两个东西的差异** | 「A 和 B 区别」 | ⭐ 五套体系总览对比 |
| [`syntheses/`](syntheses/) | 综合 | **跨体系交叉结论** | 「综合来看怎么回事」 | 五套体系的共识与分歧 |
| [`questions/`](questions/) | 问答 | 好问答存档 | 「问了什么、答了什么」 | 「止损该设多少」 |
| [`meta/`](meta/) | 元信息 | 体检报告 | **不放知识，放运行状况** | 某次健康检查报告 |

## 三个最容易搞混的

**1. `concepts/` vs `entities/`**
- 概念是**抽象名词**：中枢、背驰、趋势结构
- 实体是**具体东西**：道氏理论、缠论、海龟法则
- 一句话判断：**能指着它说「它就是这个东西」吗？** 能 → entities

**2. `claims/` vs `concepts/`**
- 概念页是**中性解释**：「趋势是价格高点低点依次抬升」
- 观点页是**带判断的主张**：「均线多头排列胜率更高」
- 判断：**这话对错有争议吗？** 有争议、需要判断 → `claims/`

**3. `syntheses/` vs 其他**
- 必须**跨 2 套体系或 2 份以上资料**才放这
- **单篇文章不构成依据**——一篇网文建「综合页」不叫综合，叫摘要
- 价值在于发现**共识**和**分歧**

## 硬性约束（来自 CLAUDE.md）

| 规则 | 为什么 |
|---|---|
| **参数原样保留，禁止优化** | 海龟 20/55/10/20 改动就是拟合噪声 |
| **方法必须落成动作** | 写「顺势而为」没用，要写「站上 20 日最高价时进场」 |
| **冲突只暴露，取舍用户拍板** | AI 摆问题，不替用户选 |
| **回测/模拟/实盘分开标注** | 三者可信度完全不同 |
| **不给投资建议** | 不写具体标的推荐 |
| **标注时效性** | 记录出版年份 + 适用市场 |

## 新建页面的流程

1. 先读 `../CLAUDE.md`
2. **先检索**已有页面（避免重复）
3. 确认满足存放标准
4. **必须建双链**——至少 2 个（1 个同类型、1 个跨类型）
5. 更新 `index.md`
6. 追加 `log.md`

> 🚫 **孤立页面等于没写。** 只会被搜索命中一次，然后就再也不被打开。
