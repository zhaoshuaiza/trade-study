# 闭环检查清单（这个知识库到底闭环没有）

> 用户模型：**书的蒸馏是完善策略的依据，复盘日报是实战的检验报告；
> 每日统计、每周每月出报告，统计结果反哺策略。**
> 本页把这条链拆成 11 个环节逐项核对：**哪个通了、哪个是半通、哪个还缺**。
> 每次出周报/月报时扫一眼这张表；修好一项就把状态改掉。

---

## 一、闭环链逐项核对

| # | 环节 | 机制 | 状态 | 证据 |
|---|---|---|---|---|
| 1 | 书籍/原始资料 → 蒸馏 → 判据页 | `sync_distilled.py`（--check/--git） | ✅ 通 | 2026-10-23 实测通过（1 个差异页：缠论108课蒸馏，目标已存在保留不覆盖） |
| 2 | 判据 → 策略卡 | 策略卡引用判据 ID（HOT-2/TOP-2/TOP-4/离场判据） | ✅ 通 | `strategies/S1~S3-*.md` 依据栏 |
| 3 | 策略 → 每日信号 | `strategy_engine.detect()` 扫 DB 自动登记 | ✅ 通 | `signals.csv`（112 条，含 source=manual 手工增补通道） |
| 4 | 信号 → 次日表现 | `fill_outcomes()` 用 K 线自动补算 | ✅ 通 | 胜/负/待验证三态，信号日=数据末沿时标待验证 |
| 5 | 表现 → **日报**（实战检验） | `sync_review.py render_report()` 每交易日一份 | ✅ 通 | `reports/YYYY-MM-DD.md`（8 节） |
| 6 | 表现 → **周报**（策略表现+修订建议） | `strategy_engine report-weekly` | ✅ 通（2026-10-23 建） | `reports/weekly/2026-W43.md` |
| 7 | 表现 → **月报**（判据仲裁+跨周趋势） | `strategy_engine report-monthly` | ✅ 通（2026-10-23 建） | `reports/monthly/2026-10.md` |
| 8 | 统计 → 策略卡自动刷新 | `update-cards` 注入 STATS 标记区 | ✅ 通（2026-10-23 建） | 策略卡「累计战绩」区自动刷新，硬编码数字已清除 |
| 9 | 修订建议 → claims 建页 | 周报/月报给建议，**用户拍板**后建页 | ⚠️ **半闭环** | 建议自动生成；拍板后「原判据页是否真的改了」无追踪记录 |
| 10 | 未决冲突 → 持续跟踪 | 周报「未决冲突」+ 月报「未决冲突清单」 | ✅ 通（2026-10-23 建） | SIZE-1（新闻/政策二分）已进两报跟踪 |
| 11 | 入口 → hot.md | 每次联动追加 | ✅ 通 | `wiki/hot.md` 尾部 |

**总结论：主链 11 环全部有机制，其中 8 环全自动；唯一半闭环是第 9 环（回写执行的追踪）。**

## 二、2026-10-23 本轮补掉的漏洞（对照历史）

| 漏洞 | 修补 |
|---|---|
| 只有周度**统计**、没有周报**报告** | 新建 `reports/weekly/`（市场回顾+逐策略解读+判据观察+修订建议） |
| 没有月度层 | 新建 `reports/monthly/`（跨周对比+判据仲裁 vs claims 门票） |
| 策略卡胜率硬编码，下周就过期 | `update-cards` 自动注入 + 日报「累计战绩速览」 |
| 判据观察没有周期性 surfaced | 周报第四节读 `_cache/checks.json` 自动汇总 ✅/❌ |
| 未决冲突（SIZE-1）会沉底 | 进周报/月报固定节，跨月跟踪 |
| 周日自动化只跑统计不写周报 | 自动化 prompt 已扩展（见下） |
| 月度自动化不存在 | 每月 1 日 20:00 自动生成上月月报 |

## 三、仍然存在的缺口（诚实登记）

| # | 缺口 | 影响 | 建议 |
|---|---|---|---|
| A | **回写执行无记录**：用户拍板后，原判据页是否真被修订、什么时候修订的，没有地方记 | 闭环最后一环可能「建议了但忘了做」 | 拍板时在 claims 页 + 台账各记一行（人工，5 秒钟） |
| B | **信号覆盖面只在涨停池内**：S1/S2/S3 全部以「当日涨停」为触发前提；回调买点、弱势股信号没有检测机制 | 策略库只能检验「打板系」方法 | 需要新数据源（自选股池+日线扫描），属扩展非闭环缺口 |
| C | **龙虎榜只有汇总净买额，没有席位明细** | TOP-5 只能验证「有没有游资」，不能验证「哪些游资、是不是同一批」 | akshare 接口暂无席位级数据；可考虑龙虎榜网页导表 |
| D | **盘前新闻未结构化**：SIZE-1 靠关键词启发式，两天「无法判定」 | 政策/新闻二分法无法机械判定 | 导表或截图进 `raw/market/`，人工标注后回流 |
| E | **日页与日报轻度重叠**（约六成内容相同） | 新人不知道看哪个 | 分工已写 README：日页=纯数据快照，日报=加解读；暂不合并（合并会丢增量更新的灵活性） |
| F | **两个统计口径并存**：周度统计.md 用滑动 5 日窗口，策略卡用全区间累计 | 同一个策略两个数字 | 卡片已标注口径；日报引用全区间速览 |

## 四、每周/每月自动跑什么（节奏表）

| 时间 | 命令 | 产出 |
|---|---|---|
| 每交易日盘后 | `python sync_review.py` | 日页 + 日报 + 信号登记 + `_cache/checks.json` + 台账/时序/manifest |
| 每周日 20:00（自动化） | `sync_review.py` → `strategy_engine report-weekly` → `update-cards` → git commit → 汇报 | `reports/weekly/YYYY-Www.md` + 策略卡战绩刷新 |
| 每月 1 日 20:00（自动化） | `strategy_engine report-monthly` → git commit → 汇报 | `reports/monthly/YYYY-MM.md` |
| 任意时候 | `strategy_engine weekly --from … --to …` | 不满一周也能统计；`signals.csv` 手工增补历史信号 |
