# market · 内容说明（使用者导读）

> 这个目录是**知识库与每日真实行情的联结点**：把书里编译出来的判据，放到每天的真实行情里检验。
> 本页是**使用导读**（怎么看、看什么）；维护规范与口径纪律见 [[market/_README]]。

## 一、这里有什么

| 页面 | 是什么 | 多久更新 |
|---|---|---|
| `2026-10-19.md` ~ `2026-10-23.md` | **数据日页**：单个交易日的纯数据快照（市场结构 + 题材矩阵 + 判据当日复核） | 每交易日 |
| `reports/2026-10-19.md` ~ `2026-10-23.md` | **日报·实战检验**：数据 + K 线结构 + 当日策略信号 + 转债视角 | 每交易日 |
| `reports/weekly/2026-W43.md` | **周报**：市场回顾 + 逐策略解读 + 判据观察 + 修订建议 | 每周（周日 20:00 自动） |
| `reports/monthly/2026-10.md` | **月报**：跨周趋势 + 判据仲裁 + 下月重点 | 每月（1 日 20:00 自动） |
| `strategies/S1-主线首板跟随.md` 等三张卡 | **策略卡**：依据 / 触发 / 胜定义 / 累计战绩 / 失效模式 | 战绩区自动刷新，正文手工 |
| `strategies/策略总览.md` | 策略索引 + 实盘五步检查顺序 | 卡片刷新时连带更新 |
| `strategies/周度统计.md` | 信号 → 次日表现全量统计 | 自动（每日刷新） |
| `判据实证台账.md` | 判据 × 日期 验证矩阵，哪条判据被观测支持/否证 | 每日重建 |
| `市场结构时序.md` | 跨交易日指标时间序列 + 阶段判读表 | 每日重建 |
| `闭环检查清单.md` | 11 个环节的闭环自检 + 仍存缺口 | 审计时 |

**数据从哪来**：`E:/股票/复盘数据/` 的每日行情 xlsx → `sync_review.py` → 本目录。
原始数据只索引不复制（`raw/market/.manifest.json` 记路径 + MD5）。

## 二、看盘时的入口顺序

1. **[[hot]]** → 最近一次复盘的结论
2. **[[market/strategies/策略总览]]** → 实盘五步固定检查顺序（阶段 → 题材 → 策略 → **强赎** → 离场）
3. **[[market/strategies/周度统计]]** → 各策略当前胜率与样本量
4. **[[market/判据实证台账]]** → 今天该听哪条判据、哪条已被观测否证
5. **[[market/市场结构时序]]** → 当前处于哪个阶段（冰点 / 修复 / 扩散 / 退潮）
6. 回判据页 → 具体怎么执行

**三份报告的分工**：日报 = 当日实战检验；周报 = 策略胜率统计；月报 = 跨周趋势与判据仲裁。

## 三、三条边界（先看这条再用数据）

1. ⛔ **不是荐股单**。个股只作为判据验证的**样本**出现，每页显式标注"非推荐"。
2. ⛔ **不是回测**。全部是【市场观测/历史事实统计】：没有对照组、未计交易成本与可成交性，胜率数字**不可外推**。
3. ⛔ **不自定阈值冒充原书**。凡原书未给量化界线的（如 TOP-2 的 30%、主线≥3 日），页面必须标 `自定义阈值`。

## 四、怎么重新生成

```bash
cd E:/股票/复盘数据
python sync_review.py                        # 增量：只处理未入库的新日期（日页+日报+信号）
python strategy_engine.py report-weekly      # 生成周报 → reports/weekly/
python strategy_engine.py report-monthly     # 生成月报 → reports/monthly/
python strategy_engine.py update-cards       # 刷新策略卡累计战绩
```

⚠️ 须**盘后**运行（akshare 盘中可能取到延迟数据）。
