# reports/ · 复盘报告层

> 每个交易日一份完整复盘报告。与根目录 `YYYY-MM-DD.md` 数据日页的关系：
> **日页是数据快照**（自动生成，纯数据），**本目录是复盘报告**（数据 + K 线结构 + 策略信号 + 分析）。

## 报告固定结构（`sync_review.py render_report()` 生成）

1. **市场结构**——涨停/跌停/涨跌停比/晋级率/真炸板率（判断阶段）
2. **题材主线**——持续性矩阵 + 主线 vs 非主线晋级率对比
3. **连板梯队**——含分歧标记（开板/换手/偏离 MA5）
4. **龙虎榜与游资**——TOP-5 判据验证（净买额集中度）
5. **K 线结构**——曹氏均线状态 + 缠论中枢位置 + 一字板扭曲检测
6. **策略信号**——当日 S1/S2/S3 触发清单（→ [[market/strategies/策略总览]]）
7. **上榜后表现**——龙虎榜历史事实统计（如有）
8. **数据性质与局限**——每份报告必须带的诚实声明

## 生成方式

```bash
cd E:/股票/复盘数据 && python sync_review.py
```

跑一次完成：xlsx 入库 → akshare 取数 → 日页 + 本目录报告 → 判据台账 → 时序页 → 索引。
