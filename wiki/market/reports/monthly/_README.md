# reports/monthly · 月报层

> **周报看策略表现，月报做判据仲裁。**

## 放什么

每个自然月一份 `YYYY-MM.md`，由 `strategy_engine.py report-monthly` 自动生成：

| 节 | 内容 | 回答什么 |
|---|---|---|
| 一、月度市场结构 | 涨停区间、涨跌停比极值日、主线变迁 | 这个月是什么市 |
| 二、策略月度表现 | 全月累计 + **分周对比**表 | 策略是变好还是变坏 |
| 三、判据仲裁 | 逐判据累计 ✅/❌ vs **claims 门票**核对 | 哪条判据该被修订了 |
| 四、本月新增与证伪 | 新信号策略、待验证数、证伪登记 | 这个月多了什么知识 |
| 五、下月观察重点 | 样本 <30 的补样本计划、数据缺口 | 下个月干什么 |
| 六、局限 | 固定警告 | 什么不能外推 |

## claims 门票（判据仲裁的核心规则）

> 某判据被 **≥10 个交易日**持续否证 → 达到建 `claims/` 页的门票 → **由用户拍板**是否修订原判据。

月报第三节自动核对每条判据的累计 ❌ 数，够了就明确写「已达门票，建议用户拍板」。
**market 目录不得自行产出新判据**（CLAUDE.md 4.7）。

## 怎么生成

```bash
cd E:/股票/复盘数据
python strategy_engine.py report-monthly                          # 默认全部登记簿
python strategy_engine.py report-monthly --from 20261019 --to 20261023   # 手动指定区间
```

## 自动化

每月 1 日 20:00 自动生成上月月报并提交知识库。

## 纪律

- 与周报同一套：历史事实统计、非回测、个股仅样本、阈值随数字引用
- 未决冲突（如 SIZE-1 新闻/政策二分）跨月跟踪，直至人工裁决
- 真龙例外必须显式登记——小样本统计抓不到「唯一的那一个」
