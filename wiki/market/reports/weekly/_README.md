# reports/weekly · 周报层

> **日报 = 单个交易日的实战检验；周报 = 一周策略表现与修订建议。**

## 放什么

每个自然周一份 `YYYY-Www.md`（ISO 周编号），由 `strategy_engine.py report-weekly` 自动生成：

| 节 | 内容 | 回答什么 |
|---|---|---|
| 一、本周市场回顾 | 每日涨停/跌停/涨跌停比/真炸板率/晋级率/主线 + 阶段判读 | 这周整体是什么环境 |
| 二、策略表现 | 与 [[../strategies/周度统计]] 同口径的汇总表 | 各策略这周赚没赚 |
| 三、逐策略解读 | 样本 <5 不下结论；≥55% 正期望；<40% 负期望 | 这周数字能不能信 |
| 四、判据观察 | 逐判据本周 ✅/❌ 次数 + **未决冲突清单** | 哪些判据在被持续支持/否证 |
| 五、修订建议 | 策略层怎么调、判据层是否够 claims 门票、数据层缺口 | **反哺**：统计→行动 |
| 六、样本量与局限 | 固定警告 | 什么不能外推 |

## 怎么生成

```bash
cd E:/股票/复盘数据
python strategy_engine.py report-weekly                          # 默认近5个交易日
python strategy_engine.py report-weekly --from 20261019 --to 20261023   # 手动指定区间
```

生成前会自动 `detect + fill_outcomes + weekly`（同区间刷新周度统计.md），
所以周报与 [[../strategies/周度统计]] 永远同口径。

## 自动化

每周日 20:00 的自动化任务会跑：`sync_review.py`（补数据）→ `report-weekly`（本页）
→ `update-cards`（刷新策略卡战绩）→ git 提交 → 向你汇报三策略胜率。

## 纪律

- 全部标注「历史事实统计，非回测」；未计成本与可成交性
- 个股只作样本；自定义阈值（主线≥3日、分歧 3次/25%/20%）必须随数字引用
- 修订建议只是**建议**：建 `claims/` 页、改判据，一律由用户拍板
- 不满一周也能出：`--from/--to` 手动指定任意区间
