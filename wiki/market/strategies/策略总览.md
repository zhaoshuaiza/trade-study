## 使用方式（实盘操作）

```
每日盘后：python sync_review.py                 → 日页+日报+信号登记，全自动
每周日：  python strategy_engine.py report-weekly   → 生成周报（策略表现+修订建议）
每月1日： python strategy_engine.py report-monthly  → 生成月报（判据仲裁+跨周趋势）
任意区间：python strategy_engine.py weekly --from 20261019 --to 20261023
```

**实盘时的固定检查顺序**（来自知识库叠加逻辑：方向→结构→确认→仓位）：

1. **市场阶段**（涨停/跌停比、晋级率、真炸板率）→ 决定今天适不适合出手
2. **题材持续性**（HOT-2，≥3日）→ 决定做哪条线
3. **策略匹配**（本目录 S1/S2/S3）→ S1 只在修复/扩散期有意义；S2 当前不参与；S3 信号=强制复核点
4. **强赎触发线**（转债，外生条款）→ **永远排第一**
5. **离场排序**（双阴→黄金线→缩量柱）→ 持仓者每日对照

## 报告分层（日报 / 周报 / 月报）

| 频率 | 位置 | 内容 | 生成命令 |
|---|---|---|---|
| 每交易日 | `market/reports/YYYY-MM-DD.md` | 实战检验：当日结构 + K线 + 信号 | `python sync_review.py` |
| 每周 | `market/reports/weekly/YYYY-Www.md` | 策略表现 + 判据观察 + **修订建议** | `python strategy_engine.py report-weekly` |
| 每月 | `market/reports/monthly/YYYY-MM.md` | 跨周趋势 + **判据仲裁**（claims 门票核对） | `python strategy_engine.py report-monthly` |

## 已知边界

- 样本集中在同一段主线周期内，**期间相关性极强，不可外推**；已验证 <30 的策略结论只作方向参考
- 所有自定义阈值（主线≥3日、分歧 3 次/25%/20%）均已在各策略卡标注
- 统计未考虑次日可成交性（一字板买不进）与交易成本
- 升级为正式判据需用户拍板（规则：market 目录不得产出新判据，→ [[market/_README]]）
