| [黄金柱](concepts/黄金柱.md) ⭐⭐ | **唯一可机械复核的买点**：三要素 + 三级别（接力柱涨 20%~30%）+ 三位置 + 测幅算式 |
| [量柱六元素](concepts/量柱六元素.md) | 高量/低量/平量/倍量/梯量/缩量柱的形态与操作判据 |
| [三日原则与量性](concepts/三日原则与量性.md) ⭐ | ⭐ **唯一能机械复核的定性判据**：形态再强，也要过后三日验证 |

**待编译** → [黄金三待编译](concepts/黄金三待编译.md)（第三章其余 5 个「黄金」层面：黄金梯/黄金劫/黄金线/黄金仓/黄金道）

**四条最好用的硬判据**：

```
1. 三日原则   → 后三日「价升量缩逐步走强」才升华；「阳后双阴」必退化
2. 低量柱     → 只看量柱就能找转折点（作者实测 13 根中 12 根后市回升）
3. 黄金柱     → 基柱合王牌柱 + 后三日均价 > 基柱实顶 + 价升量缩
4. 缩量柱     → 跌破第一量柱最低价即认错（原文称「最有价值的重大发现」）
```

> ⭐ **三日原则是全书最重要的一课**（原文自我警告）：
> 「离开了量性来单独看待量柱，**就有可能陷入形而上学的泥潭**」。
>
> **反例对照（D柱 vs E柱）**：
> 「**不明显的高量柱**」后三日走强 → **真黄金柱** → 一发冲天；
> 「**最明显的高量柱**」后三日双阴 → 次黄金柱 → **18天调整+ 一个多月调整**。
>
> **结论：形态越明显 ≠ 越可靠。别用「量越大越好」筛黄金柱。**

> 但同作者的《新手学炒股一本就够》说放量可能是**对倒伪造**的。
