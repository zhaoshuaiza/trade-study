## 五、学习路径建议

### 顺脉演进（想看懂走势）
```
道氏（什么是趋势）→ 波浪（结构如何细化）→ 缠论（如何让结构可判定）
```

### 风险优先（想活得久）
```
海龟优先 → 纪律是通用的
```

### ⚠️ 不建议从缠论开始
186MB 体量最大，且它明确批评波浪的主观性。
**没理解前两套在学什么之前，缠论会变成记术语。**

### 如果只学一套
**海龟。** 唯一完全机械化，核心收获（仓位+止损）跨体系通用。
