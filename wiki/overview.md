# 知识库全景

## 这是什么

一个基于 LLM Wiki 架构的个人知识库。原始资料放入 `.raw/`，由 Agent 编译成互相链接的结构化页面，查询时走索引渐进加载而非全量检索。

## 架构

```
.raw/  原始资料（只读，永不修改）
   ↓ 编译
wiki/  结构化知识（AI 写，人审核）
   ↑ 约束
CLAUDE.md  schema 层规则
```

## 三条核心工作流

1. **编译** — 资料进 `.raw/`，Agent 提取概念/实体/来源/观点，更新索引与日志
2. **查询** — 先查 `index.md`，按需下钻，回答须引用具体页面
3. **治理** — 定期 lint，查孤立页、死链、索引漂移、矛盾

## 与 RAG 的关系

不互斥。本方案是**编译时**产物——在构建阶段把散落材料固化为完整语义单元；
当页面量增长到几百篇后，查询阶段仍需补充**运行时**的本地检索（BM25 + 向量重排）。

## 原则

- 原始资料不可变，编译产物可重建
- 不确定的信息标注 `status: uncertain`，不编造
- 知识库中没有的内容，如实说没有，不用训练数据补
- 人守住两个环节：**信息筛选** 与 **编译审核**
