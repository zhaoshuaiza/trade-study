## 一、🛡️ 第 0 层：钱该不该进股市（每月检查一次）

> 依据：[[concepts/资金管理优先于仓位管理]]、[[concepts/资金管理的减震器作用]]

### 月度检查

- [ ] **本月我投入股市的钱 ÷ 总资产 = \_\_\_\_%**
  - [ ] ≤ 80%（牛市上限）
  - [ ] 超过 80% → **减到 80% 以下**
- [ ] **熊市检查**：当前大盘状态是？
  - [ ] 明显熊市（亏钱效应 + 下降趋势）→ 股票账户是否 ≤ **30%**？
  - [ ] 否 → 转入银行账户
- [ ] **是否留足一年家用现金？**（龙头体系第 2 条）
  - [ ] 是 → 通过
  - [ ] 否 → **优先补上，这是第一原则**
- [ ] **是否在用信用卡/借款炒股？**
  - [ ] 是 → ⛔ **立刻停止，这是第一原则**

### 三个"绝不"

- [ ] ⛔ 不贷款炒股
- [ ] ⛔ 不套信用卡炒股
- [ ] ⛔ 不满仓（保留余地）

## 二、📊 第 1 层：每笔下多少

> ⚠️ **你的约束：只能做股票单边行情**
> → 下面「海龟路线」和「傅海棠路线」**需改造使用**，已注明改法。

### 海龟路线（⚠️ 需改造：去掉做空机制）

- [ ] N 值 = **ATR(20)**，已计算
- [ ] 单位数 = **1% 净值 ÷ (N × 每点价值)**，向下取整
- [ ] 引用时确认用 **1%（实盘）** 不是 0.5%（费思测试口径）
- [ ] 加仓条件：**每盈利 0.5N 加 1 单位**，上限 4
- [ ] ⛔ 加仓**只在盈利方向**
- ⚠️ **单边市改造**：**趋势向下时只能空仓，不能做空**
  - [ ] 我已接受"空仓也是仓位"这一点

### 傅海棠路线（⛔ 不建议用于股票）

- [ ] ~~仓位依据 = 保证金占用~~ → ❌ **股票没有保证金机制，此路不通**
- ⭐ **但保留这条倒推法**（通用思想）：
  - [ ] 预判最低点位 ______，若跌到此价位我的仓位 ______（**未被强平=通过**）

> 📌 傅海棠的"**重仓的几乎都亏大钱**"这句**直接可用**，与市场无关。

### 通用（不分体系）

- [ ] 当前单一品种仓位 ≤ \_\_\_\_%
- [ ] **全市场总仓位** ≤ \_\_\_\_%
- [ ] 检查：我是不是因为"怕踏空"而超配？→ ⛔ 停手

## 三、🎯 第 2 层：什么时候买（按主线体系选一个）

> ⚠️ **只能选一个**，不要同时用两套

### A. 海龟路线（⚠️ 需改造：只做多）

- [ ] 入场：**收盘价突破 20 日 / 55 日**高点，次日开盘执行
- [ ] 出场：反破 **10 日 / 20 日** 极值
- [ ] 止损：**2N**，入场**同秒提交**
- [ ] ⛔ **止损绝不后移**（移动止损 = 认输）
- ⚠️ **单边市警告**：费思实测**唐奇安系统表现最差**（交易者效应），
  ⚠️ **不建议用唐奇安做题材股短线**，只在有明确趋势时用
  → 📌 见 [[concepts/止损的争议]]

### B. 缠论路线（⭐ A 股短线主选）

- [ ] 先画**分型 → 笔 → 线段**（结合律：≥1根独立K线成笔）
- [ ] 找**中枢**（≥3段次级别走势重叠）
- [ ] 判断买卖点类型（一买/二买/三买）
- [ ] ⭐ **初学者用机械束缚**：跌破 **5 日 / 5 周线** 一定走
  - [ ] 我当前是初学者 → 采用此条
  - [ ] 我已熟练 → 按走势分类判断，不设固定线

### C. 龙头价值赛道路线

- [ ] **正法模型四象限**检查：
  - [ ] 🟩 正法（有逻辑 + 在涨）→ **唯一允许动手**
  - [ ] 🟨 我执（有逻辑 + 没涨）→ ⛔ 普通人禁止
  - [ ] 🔴 妄动（没逻辑 + 在涨）→ ⛔ **管不住手就是灾难**
- [ ] **供求关系检查**：需求端↑？供给端受限？
- [ ] **弹性价值检查**：这个票的**变化还在吗**？（财报出来后弹性会消失）
- [ ] **龙头宪法九条**：今天买的是龙头还是杂毛？

### D. 价值投资路线

- [ ] 内在价值 = **10 年每股平均收益 × 10**
- [ ] 市价 ≤ 内在价值 × **0.6**（6 折，5 折更安全）？
- [ ] 三好：好业务（盈利长期保持）/ 好管理（从股东利益出发）/ 好价格
- [ ] 质量 9 项清单，重点看第⑤项**定价权**
- [ ] ⛔ **"烟蒂股"逻辑已过时**（「烟蒂理论正逐渐走向衰落」）

## 四、🛑 第 3 层：什么时候离场

## 四、🛑 第 3 层：什么时候离场

> ⚠️ **这是九套体系唯一真正互斥的层面** —— 见 [[claims/五套体系的仓位与风控对照]]
> ⚠️ **只能选一个**。且股票单边行情下，**离场后不能反手做空**（只有"错过"这个风险）。

### 海龟（⚠️ 需改造：只做多）

- [ ] 触及 **2N** → **无条件平仓**
- [ ] ⛔ 不后移、不加仓摊平
- [ ] 退出信号：**反破 10 日 / 20 日**极值，不设目标价
- ⚠️ **单边市注意**：离场后行情继续涨，**你无法反手**（这是股票与期货最大差别）

### 缠论（⭐ A 股短线主选）

- [ ] 离场依据 = **走势是否还能操作**，不是亏损多少
- [ ] 检查：中枢结构是否被破坏？有无背驰？
- [ ] ⛔ **禁止**按亏损比例止损（「按亏损多少就要止损的，最终都不可能大成功」）
- 📌 **初学者可用机械束缚**：跌破 **5 日 / 5 周线**一定走

### 龙头（⭐ A 股短线主选）

- [ ] 中枢震荡中**只做向下离开段**，不做向上离开段的追高
- [ ] 熊市：**休息，不是换方法**（换方法在熊市亏得更快）
- ⭐ 熊市降低仓位到**≤ 30%**

### 价值投资（⭐ 长线主选）

- [ ] ⭐ **几乎不设止损** —— 「**难的是在持有后不轻易卖出**」
- [ ] 只在**逻辑破坏**时离场（企业永久性亏损，不是价格下跌）
- [ ] 熊市：**熊市一跌就拿不住是典型错误**

### ⚠️ 单边行情的额外风险（股票独有）

- [ ] 我是否因为"怕错过"而**该走没走**？
  - [ ] 是 → 提醒：**不能做空，所以"走了就没了"是常态**
- [ ] 我持有的票**是否经常涨跌停**？
  - [ ] 是 → ⚠️ **跌停时可能卖不出去**，这是股票特有的风险

## 五、🧠 每日自检（开盘前 5 分钟）

> 依据：[[concepts/正法模型与龙头九则]]、[[concepts/表象规律与本质规律]]

- [ ] **今天我打算做哪一笔？** 逻辑是什么？（说不清 → ⛔ 不做）
- [ ] **这笔的止损位在哪？**（说不清 → ⛔ 不做）
- [ ] **这笔的仓位是多少？**（说不清 → ⛔ 不做）
- [ ] 我是不是因为**分时图异动**而心痒？
  - [ ] 是 → 检查：这个异动**有逻辑吗**？→ 无逻辑 = **妄动**
- [ ] 我是不是想把**短做变长做**？→ 提醒自己「**必须尽快回到原来的持仓上**」

## 六、📓 交易日志（每笔必记，⭐ 这是最重要的一页）

> 依据：全部九套体系都强调"记录自己错在哪"

| 字段 | 填什么 |
|---|---|
| 日期 / 品种 | |
| **买入理由（逻辑）** | ⭐ **必填，写不出来就别买** |
| **止损位** | ⭐ **必填** |
| 仓位 | |
| **出场理由** | ⭐ **是止损触发？还是结构破坏？还是冲动？** |
| **是否守纪律** | ⭐ ✅ / ❌ |
| **错在哪** | 事后填：逻辑错 / 时机错 / 仓位错 / **纪律错** |

### 每周复盘三个问题

- [ ] 本周有几笔**因为纪律问题**而不是判断问题亏的钱？
  - [ ] 有 → **纪律问题占多数 = 方法没问题，执行有问题**
- [ ] 我是不是**频繁换方法**？（金融帝国：熊市换方法亏得更快）
- [ ] 我的逻辑是不是**"表象规律"**？
  - [ ] 问：这条逻辑**知道的人多了会怎样**？（→ 见 [[concepts/权威的泥潭效应]]）

## 七、⚠️ 三个高频陷阱自检（每周问一次）

### 陷阱1：**高胜率陷阱**

- [ ] 我的胜率是多少？
  - [ ] **> 70%** → ⚠️ 检查赔率！见 [[concepts/正确率与赔率的互损原则]]
  - [ ] 计算 EV = 胜率×平均盈利 − (1−胜率)×平均亏损 = \_\_

### 陷阱2：**盈利时兴奋 = 未成熟**

> 傅海棠：「**如果你还能够为盈利而感到兴奋，那么我肯定你还没有成熟**。」

- [ ] 本周我有没有因为一次盈利而情绪波动？
  - [ ] 有 → ⚠️ **仓位太大或系统不匹配我**

### 陷阱3：**把奇迹当规律**

- [ ] 我最近在"复制"某个牛股的成功模式？
  - [ ] 是 → ⚠️ **问：它当年有什么"特殊性"？** 那些条件还能凑齐吗？
  - [ ] 参见 [[concepts/权威的泥潭效应]]（五个独立来源）

## 九、⭐ 30 天验证计划

| 周 | 做什么 | 检验什么 |
|---|---|---|
| **第 1 周** | 只用**一笔**极小仓位，按主线体系执行 | 我的执行是否可行？心理是否扛得住？ |
| **第 2 周** | 同上 + 完整记录交易日志 | 纪律问题占比多少？ |
| **第 3 周** | 同上 + 每周复盘三问 | 逻辑是不是表象规律？ |
| **第 4 周** | 汇总：算 EV、统计纪律问题占比 | ⭐ **决定是否扩大仓位** |

> ⭐ **第 4 周的关键判断**：
> - 纪律问题 < 50% → **方法可用**，可考虑加仓
> - 纪律问题 > 50% → **先修执行**，不要加仓
