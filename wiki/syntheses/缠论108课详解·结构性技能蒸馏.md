## 一、思维逻辑链（这是全书最值钱的部分）

很多学员学缠论失败，不是记不住定义，而是**没有装填思维链条**。以下是原书（经扫地僧注解强化）的完整推理路径：

```
第1步：市场是博弈，不可预测，但可分类
   └─ 阴卍语（扫地僧注：合阴惨理论思维）→ 无庄家，只有赢家和输家
   └─ 结论：放弃"预测未来"，转向"识别当下结构"（第1、2、6课）

第2步：走势必须能被无损分解 → 引入递归
   └─ 最低级别（1分钟）不可再分，那就从1分钟图入手
   └─ 有了1分钟中枢 → 可定义1分钟走势类型 → 再用递归得到5/30分钟、日/周/月
   └─ 【扫地僧关键洞见】"不同级别的图，只是同一客观走势在不同显微镜下的成像；级别与走势一一对应"（第63课书页367）

第3步：分解的最小构件是分型 → 笔 → 线段
   └─ 包含关系处理（向上取两K最高点、向下取最低点）→ 结合律 → 笔 → 至少三笔成线段（第62课书页362-364）

第4步：有了线段，才能定义中枢
   └─ 中枢 = 某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分（第18课书页082）
   └─ 盘整 = 只含一个中枢；趋势 = 至少含两个依次同向的中枢，且中枢之间不重叠（第18课）

第5步：中枢有两种演化方向 → 收益来源被穷尽
   └─ 中枢震荡（利润最短）：对应一二类买卖点
   └─ 中枢上移（利润最长）：对应三类买卖点
   └─ 扫地僧补刀："任何市场的获利机会，在这两种模式下逃脱不了"（第73课书页420）

第6步：走势终完美 → 如何提前知道转折
   └─ 背驰定理：某级别背驰必然导致该走势类型终止 → 引发更大级别盘整或反向走势（第29课书页161）
   └─ 反向定理：转折必然由背驰引发（第43课书页238）
   └─ 注意级别对应：1分钟顶背驰 ≠ 年级大调整，小级别背驰逐步累加才可能引发大级别转折

第7步：几何结构有了，还要有"力度"判断 → MACD
   └─ 盘整背驰 = 力度有限、回到中枢；趋势背驰 = 力度大、离开中枢形成第三类买卖点（第27课书页145）
   └─ 【扫地僧重要修正】"因为级别太小，MACD 黄白线没有回拉 0 轴"（第64课书页374）——小级别背驰必须靠结构+黄白线位置双验证

第8步：结构完整了，操作如何落地 → 三类买点的不完备性
   └─ 三类买卖点都是理论 100% 安全，但"抓买卖点"这个动作是个人主观行为，不可能 100%（第21课书页101）
   └─ 结论：不要追求"百分百"，只能无限接近（第21课）
   └─ 【防狼术】任何 MACD 黄白线在 0 轴之下的市场或股票都必须回避（第103课书页563）

第9步：级别放大后的操作选择（第40课书页227）
   └─ 小级别进场的代价：精确度要求更高、资金容纳度低
   └─ 升级为大级别操作基础上部分保留小级别操作（推荐）

第10步（心态层）：赚钱靠"不回本"而非"不回亏"（第80课）
   └─ 核心技术对繁、破坏性思维脑占 → 越修哲学横空 → 天妒英才留遗憾（第84课书页486）
   └─ 远离聪明（第105课）、学屠龙术前先学好防狼术（第103课）——全是心态课
```

**逻辑链的三个公理（记住这三句就够）**：

1. **走势必完美** —— 任何已完成走势都是自同构结构，可以被无损递归分解。
2. **分类不重叠** —— 中枢要么震荡要么移动，收益模式只有两种（第73课）。
3. **转折有必然性** —— 背驰与转折一一对应，但级别决定幅度（第29、43课）。

## 二、结构性可执行技能（从理论到动作）

### 技能 1：分型 → 笔 → 线段（三层递归的地基）

**这是全书最实操、也最容易做错的部分，标准精确到可执行。**（第62课书页362-364）

| 构件         | 判定标准                                     | 关键约束                  |
| ---------- | ---------------------------------------- | --------------------- |
| **顶分型**    | 第二根K线高点 = 相邻三K线高点中最高                     | 中间那根K线高点              |
| **底分型**    | 第二根K线低点 = 相邻三K线低点中最低                     | 中间那根K线低点              |
| 简称         | 顶分型的顶 / 底分型的底                            | "顶"指分型最高点，"底"指分型最低点   |
| **包含处理**   | 向上时取两K的**最高点**为高点、较高低点为低点；向下反之           | 【扫地僧】处理顺序从左向右依次，别跳步   |
| **结合律**    | 顶底之间**至少有一根独立K线**（不属于顶或底分型）              | 共用K线违反结合律，不算一笔        |
| **笔**      | 两个相邻的顶和底之间构成一笔                           | **必须是相邻的顶和底**，隔了几个就不是 |
| **笔的简明定义** | 底/顶分型 + 上升/下降K线 + 顶/底分型，**三者必须完全独立不可共用** | 上升K线不必3根，1/2根也可，只要不违反 |
| **线段**     | 至少由三笔组成                                  |                       |

⚠️ **扫地僧的诚实提醒**（第62课书页362）：

> "本 ID 理论本质上是一套几何理论……有严谨的几何定义就可以做到对走势的 100% 把握，这个理解是不对的。因为这个定义的基础也是 K 线，而最小级别的 K 线是 1 分钟的，那么这个 1 分钟以内的走势实际上已经被忽略了，因此这个严谨的几何定义是建立在忽略了部分走势波动的前提下的严谨。"

**实操口诀**：先处理包含关系（从左到右）→ 找顶底分型 → 顶底之间必须有独立K线才能成笔 → 至少三笔成线段。级别越小，图形越简单但判断越难（第64课书页370："连最复杂的图形上都能配套了"）。

### 技能 2：中枢的三种分类与判定

**中枢的严格定义**（第18课书页082 原文）：

> 某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分。

数学表示：次级别连续三个走势类型 A、B、C，高低点分别为 a1a2、b1b2、c1c2，则中枢区间 = (max(a2,b2,c2), min(a1,b1,c1))。

**扫地僧的实用性修正**（第18课书页082）：

> "实际上用目测就可以，不用这么复杂……所以，后面讲的笔和段无非是从数学上做到严格，而真正的操作中，看多了用目测即可，没必要陷入到笔和段里。"

| 中枢类型 | 含义      | 走势归属 |
| ---- | ------- | ---- |
| 上涨中枢 | 依次高于前一个 | 趋势   |
| 下跌中枢 | 依次低于前一个 | 趋势   |
| 盘整中枢 | 无方向     | 盘整   |

**盘整 vs 趋势的严格区分**（第18课书页082，扫地僧特别强调"这和以前对趋势的定义就不同了"）：

- **盘整**：任何级别的任何走势中，某完成的走势类型**只包含一个**中枢 → 该级别的盘整
- **趋势**：任何级别的任何走势中，某完成的走势类型**至少包含两个以上依次同向**的中枢 → 该级别的趋势。向上为上涨，向下为下跌
- **铁律**：趋势中的中枢之间**必须绝对不存在重叠**

### 技能 3：背驰—转折定理（第29、43课）

**核心定理**（第29课书页161 原文）：

> **缠中说禅背驰—转折定理**：某级别趋势的背驰将导致该趋势最后一个中枢的级别扩展、该级别更大级别的盘整或该级别以上级别的反走势。

**操作含义的三条推论**：

1. 转折必然由背驰引发，**背驰是唯一可提前观测的转折信号**（第43课书页238）
2. **级别对应关系不可越级**：1分钟顶背驰意味着至少1分钟盘整或下跌，不等于年级大调整。极端情况下，1分钟顶背驰后形成下跌逐步级别扩张，最后才慢慢形成年级大调整——"如果市场看到1分钟顶背驰就误要形成年级级别大调整，那就是脑子有问题"
3. 小级别背驰逐步累加，才可能导致大级别转折。**这是小级别操作的最大理论风险来源**

**盘整背驰 vs 趋势背驰**（第27课书页145）：

| 类型   | 力度 | 出现位置      | 后续                           |
| ---- | -- | --------- | ---------------------------- |
| 盘整背驰 | 有限 | 中枢内/类中枢   | **回到中枢**（三买后向上回中枢，或三卖后向下回中枢） |
| 趋势背驰 | 强  | 第二、三个中枢之后 | 可能形成第三个中枢                    |

**关键统计（可直接用）**：

- 第二个中枢后就产生背驰的情况，**占绝大多数**（日线以上级别几乎达到 90% 以上）
- 小级别（如1分钟）要四五个中枢后才出现背驰，但也是占大多数
- 第一个中枢就出现背驰的，不算真正意义的背驰，只能算盘整背驰

**扫地僧的实用提醒**（第27课书页145）：

> "小级别的盘整背驰，意义都不太大，而且必须结合其位置，如果是高位，那风险就更大了，往往是刀口舔血的活计。"  
> 多数第二、三类买点其实都是由盘整背驰构成的，第一类买点多数由趋势背驰构成。

### 技能 4：三类买卖点（第53、21、73课）

| 类型        | 定义                     | 对应结构         | 风险        |
| --------- | ---------------------- | ------------ | --------- |
| **第一类买点** | 某级别下跌趋势的背驰点            | 趋势背驰         | 级别最低、精度最难 |
| **第二类买点** | 第一类买点后次级别回调的低点，不破一买    | 盘整背驰         | 最常用       |
| **第三类买点** | 中枢上移后，次级别回调**不跌破中枢ZG** | 趋势背驰（力度离开中枢） | 最需确认      |
| **卖点**    | 镜像：三类卖点                | —            | —         |

**第三类买卖点的完整判定**（第64课书页373-374，原文图4表述）：

- 前提：某级别走势的**最后一个中枢**级别扩展 + 该级别更大级别的盘整（或该级别以上级别的反走势）
- 第一次回抽：向下跌破 → 三类买点形成 → 后面两种变化之一：
  1. **三卖后盘背**：向回到原来的中枢内
  2. **走向下走势，形成新的中枢**（构成两个类中枢的下跌走势）
- 判定要点：针对第二个奔走势的微型中枢前后两段，**MACD 两个红箭头对应的绿柱子的比较一目了然**
- 扫地僧强提示：不要问"这时候为什么不看黄白线之类的问题"——因为级别太小，MACD 黄白线没有回拉 0 轴

**关于"100% 安全"的重要澄清**（第21课书页101）：

> "这三类买卖点，都是被理论所保证的，100% 安全的买卖点……**但这个 100% 安全是指理论上的 100% 安全**，但在涉及当下动态的走势时，由于市场是动态的，抓买卖点这个动作是个人的，那么抓买卖点这个动作是做不到 100% 的，因为当下操作的买卖点是个人主观上认为的买卖点，未必一定是客观走势的买卖点……如果对这三类买卖点的绝对安全性没有充分的理解，就绝对不可能也绝对没有对缠中说禅技术分析理论有一个充分的理解。"

**抓不到买点不是理论失效**——很多人说自己"按本ID理论做短线买不回来"，扫地僧的回答是：如果你连中枢都没分清楚、级别也没搞懂、中枢上移与中枢震荡也分不清楚，第三类买点当然抓不住。**根本原因是分析链条前段失效，不是买点不出现。**

### 技能 5：获利机会的绝对分类（第73课书页420）

这是全书**最实用的商业逻辑**，直接回答"钱从哪来"：

| 模式       | 对应买点   | 利润特征 | 持续性                                        |
| -------- | ------ | ---- | ------------------------------------------ |
| **中枢震荡** | 一、二类买点 | 利润最短 | 在离开该中枢前，都在（来回）减仓                           |
| **中枢上移** | 三类买点   | 利润最长 | 中枢上移结束进入新中枢形成与震荡前，"唯一需要一定技术要求的就是对第三类买点的判断" |

**扫地僧对"中枢上移"的严格界定**（第73课书页420）——两个隐藏信息：

1. 它包含"中枢的向上离开段"
2. 它包含"买点区域"：通俗点说是"一个次级别走势离开中枢，并且在该次级别走势结束的位置变掉"，后面要么回到中枢继续震荡，要么形成三类买点

> "很多人，经常说自己按本 ID 的理论做短线买不回来，这也没什么奇怪。如果你连中枢都没分清楚、级别也没搞懂，中枢上移与中枢震荡也分不清楚……"

### 技能 6：一个具体走势的完整分析流程（第54课书页307）

**这是把理论落成操作的标准动作序列，务必背下来。**

作者以 18.5 元（设为 g0）为起点走了一遍完整流程：

```
步骤0【前置条件检查】图1有条件 d1=g2、d2=g4。
   有这些条件会增加分析难度，但没有也能分析。
   ↓
步骤1【选级别】以某级别分析图形时，先假设次级别是线段。
   【扫地僧补丁】此时其实还没有"笔和段"的概念，
   所以这里的"线段"并非后面大家所熟悉的线段——
   这也说明，并非只有严格按后面所讲的笔、段来划分走势才能分析和操作，
   没有后面的笔和段，也一样可以分析操作。
   ↓
步骤2【找分型起点】从 g0 开始进入图形。
   ↓
步骤3【数段】图1里除最后一个，其余每一个 dngn、gdn+1 都是 1 分钟以下级别，
   所以都可以看成没有内部结构的线段。
   ↓
步骤4【判中枢个数】显然当下走到 g1 时，由于只有两段，
   所以不形成任何中枢。
   ↓
步骤5【判一/二类买点】如果你是分笔操作者，那么 g1 就构成一个第二类买点。
   ↓
步骤6【中枢形成】当走势发展到 d2 时，一个 1 分钟级别的中枢就形成了，区间是 [d1, d2]…
   （此处作者继续演示到 g4 之后的走势结构，共10步）
   ↓
结论："走势组合变化多，买卖点一波波，精通理论每一个，遇到机会不后缩。"
```

**扫地僧的心态提醒（书页307原文）**：

> "看下面分析之前，不能太饿也不能太饱，不能太兴奋也不能太兴奋……否则一看完肯定晕。由于一般的图都没有这么复杂，所以看完完之后千万别信心受到打击，而是应该信心百倍。"

### 技能 7：级别选择的实操建议（第40课书页227、第63课书页366-367）

**问题**：小级别进场结果出现大级别上涨，怎么办？

| 方案                      | 代价              | 建议             |
| ----------------------- | --------------- | -------------- |
| ① 继续按小级别操作              | 精确度要求更高、资金容纳程度低 | 小资金可行          |
| ② 升级为大级别操作，基础上部分保留小级别操作 | —               | **推荐，对小资金也建议** |

**理由**：等成长为大资金时依然适用，而且由于级别大一点，对锻炼耐心也很有帮助。

**扫地僧的关键洞见（第63课书页367）**：

> "如果你选择 5 分钟或 30 分钟为最基本的图，那么和 1 分钟的看法一样，只不过你的显微镜倍数比较小，看起来比较粗糙而已。**这个哲学基本对应着几分钟 K 线图，完全可以用叫 N1 级别、N2 级别、N3 级别、N0 这个最小级别是什么？**"  
> "在显微镜中看到的图像，只是客观真实的走势在这个倍数的显微镜下的成像而已，**并非走势本身**。"  
> 举例：你对太多的柱子进行利加，可以用放大级别的 MACD 描绘一目了然。日线图的 MACD 看不见，其实要在 1 分钟图上也可以看得出来，只不过需要把所有对应对比段的 MACD 都加起来进行处理。

**这就是"显微镜比喻"**：级别不是走势本身，只是同一客观走势在不同精度下的成像。因此不要迷信级别，宁可小级别也要精确。

**级别递归的灵活运用（第53课书页302）**：

> "如果你决定用 30 分钟操作，那么其实就先假定把所有完成的 5 分钟走势都看成线段了。"  
> 【扫地僧强调】这段话一定要反复读，直到理解为止。太多了的人总是问这一类的问题：30 分钟的一笔不是对应 5 分钟的一段吗？为什么？

**答**：因为当你用 1 分钟级别重新组合时，其实就**先把分笔上的级别都看成没有结构的线段**了。就像研究猴子的行为时如果还考虑每个细胞里包含的分子里原子的电子走势问题，那猴子就不是猴子了。**这是必须明确的原则。**

### 技能 8：防狼术——最实用的风控（第103课书页563）

**这是扫地僧全书最落地的一课，建议作为操作的第一道关卡。**

| 步骤  | 动作                                                         |

| 第0步 | **别急着研究中枢、级别。先学防狼术。**（学屠龙术前先学好防狼术）                         |
| 第1步 | 设定你最熟悉的**最低时间周期**（如60分钟图、30分钟图），**不要用1分钟图**（1分钟经常在0轴下又上又下） |

### 技能 9：底部的精确定义（第108课书页576）

**扫地僧给出的"底部"定义**（解决"何谓底部"的经典问题）：

> 底部都是分级别的。如果站在精确走势类型的角度，那么第一类买点出现后一直到该买点所引发的中枢第一次走出第三类卖点前，都可以看成是底部构造的过程。

**推论链**：

1. 从一买到三卖之间都是筑底过程，**包括第二买点和中枢震荡延伸**
2. 为什么不建议散户参与筑底过程？——**因为期间比较磨人，而且在中枢震荡延伸期间，各种奇怪的走势经常出现，功力不深的很难把握**
3. **如果是第三类买点先出现，就意味着底部构造失败了**；反之，第三类买点意味着底部构造的最终完成并展开新的行情
4. 顶部反过来定义：顶部最好在疯狂走势的末期，一般是**小级别的第一类买点**时卖出，没必要参与筑顶（很多股票最疯狂时就是最高点，后面大概率走小转大）

**分型角度的粗略版本**（第108课书页576）：

> 站在分型的角度，底部就是构成底分型的那个区间，而跌破分型最低点意味着底部构造失败；反之，有效站住分型区间上边沿，就意味着底部构造成功并至少展开一笔上行行情。

⚠️ **注意方向**：不是"在底部区间上买"，而是反过来——**"在区间下探失败时买"**。

> "有了这个定义，就一定要搞明白，不是在底部的区间上买，而是相反，应该和中枢震荡的操作一样，**在区间下探失败时买**，这才是最好的买点。"

### 技能 10：三种能力层级（第84课书页486）

**为什么传统技术分析对缠论"自相似结构"免疫**：

> "自同构结构，在前面不太精确地用了自相似结构之类的词语，这很容易和数学里的分形以及利用这种先验性理论构造的理论中的一些术语相混淆，**所以以后都统一为自同构结构**。"  
> 【扫地僧补充】分形这种先验数学理论是指当学了这种数学理论后，可以精确计算出任意部分的形态，而股票走势的自相似性则不同，只是知道未来必然会走势完美，**但如何完美是无法提前预知的，这就是其中最大的差别**。

**三种能力**：

1. **任何有效的技术分析，本质上都是本ID理论的分支**——本ID还没看过任何有效的股票操作程序，是不属于本ID理论的
2. **要找出所有技术分析及操作程序是否属于本ID理论**——这是最高要求
3. 扫地僧建议：除了看本ID理论，一定要多看别人的书，这样才会有比较。**本ID理论不仅集所有技术分析理论之大成，更重要的是，本ID理论完全构建在不同的思维框架下**——如同中国的古代几何都很牛，但真正逻辑化、推理化、系统化、理论化的是欧几里得的，这**是完全不同的数学路线**

⚠️ 扫地僧的学习态度警示（第103课书页563）：

> "100 多课，估计里面任何一课都没真正弄懂，就嫌课程太慢？如果你真正弄懂其中任何一课，也不至于在实际操作中灰头土脸了。贪多嚼不烂，大部分人是没有深入学习和深入研究的耐性。"

## 七、一页纸速记卡（打印版）

```
【三公理】走势必完美 · 分类不重叠 · 转折有必然性
【三级构件】分型 →(结合律：至少1根独立K线)→ 笔 →(至少3笔)→ 线段
【中枢】至少三个连续次级别走势类型的重叠部分；盘整=1个中枢，趋势=≥2个同向不重叠中枢
【背驰】趋势背驰→力度离开中枢(三买)；盘整背驰→力度有限回中枢
【转折】背驰必然导致转折；级别对应不可越级
【买点】一买=趋势背驰点 二买=次级别回调不破一买 三买=中枢上移后次级别回调不破ZG
【钱从哪来】中枢震荡(利润最短,一二类买) / 中枢上移(利润最长,三类买)
【防狼术】你最熟悉周期的MACD黄白线在0轴下方 → 永不碰
【操作10步】选级别→定分型起点→数段→判中枢→判一/二买→中枢形成→…
【底部】一买后到三买前=筑底过程；三买先出现=筑底失败
【心法】不回本>不回亏 · 远离聪明 · 学屠龙术前先学好防狼术
```
