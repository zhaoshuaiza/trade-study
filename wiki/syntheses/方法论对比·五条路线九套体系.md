# 方法论对比：五条路线，九套体系

> **本页回答一个问题：这些体系在「怎么找信号」上到底差在哪？**
>
> 📌 **不排名、不选边站**（CLAUDE.md 4.3）——
> 只把差异摆清楚，**最终由你按交易品种与周期选**。

---

## 一、⭐ 一张表看懂全部差异

| 体系 | 输入 | 信号从哪来 | 是否需历史数据 | 主观成分 |
|---|---|---|---|---|
| **道氏** | **价格** | 两个指数**相互确认** | ✅ 需历史指数 | 低 |
| **波浪** | **价格** | 数浪（形态） | ✅ | ⭐⭐⭐ **高** |
| **缠论** | **价格** | 中枢 + 走势类型 | ✅ 需多级别 | 中 |
| ⭐ **海龟** | **价格 + ATR** | 唐奇安通道**突破** | ✅✅ **必须有** | ⭐ **最低** |
| ⭐ **量柱（黑马王子）** | ⭐ **成交量**（+价格） | **单根量柱的形态** | ⭐ **单根即可** | 低 |
| 龙头/赛道 | 题材 + 资金 | **主线识别** | — | 中 |
| 高胜算 | 胜率/赔率 | **概率优势** | ✅ 需统计 | 低 |
| 傅海棠 | 供求 | 库存/产能 | 需行业数据 | 低 |
| 巴菲特 | 财务 | **内在价值** | ✅ 需多年 | 低 |

> ⭐⭐ **最关键的一列是「输入」**：
> **只有量柱体系把「成交量」当作一等公民**——
> 其余八套都主要看价格。

## 二、⭐⭐ 五条方法论路线

### 路线 1：**确认派**（道氏）

```
核心：两个指数必须相互确认
判据：一个指数的信号不够，必须两个都指向同一方向
```
> ⭐ **这是「消除单点误判」的最早尝试。**
> 📌 继承者：缠论的「走势分类不重叠」也有确认色彩。

### 路线 2：**数形态派**（波浪）

```
核心：数出五浪/三浪结构
判据：形态完整 + 比例（斐波那契）
```
> ⚠️ **主观成分最高** —— 数浪可以数出多种答案。
> 📌 这也是波浪理论的**原罪**：无法机械执行。

### 路线 3：**结构递归派**（缠论）

```
核心：把走势唯一分解成「走势类型」
判据：中枢（≥3段次级别重叠）+ 分类不重叠
```
> ⭐ **与波浪的差别**：
> 波浪数「几浪」，缠论数「几段重叠」——**缠论要求分解唯一**。
>
> ⭐⭐ **缠师本人对此有明确表述**（原文已核实）：
> > 「完全分类……**具备某种等价关系**」→ 所以能机械化。
> 📌 详见 [[syntheses/缠师原文核查·说话人结案]]

### 路线 4：**机械突破派**（海龟）⭐ 判据最硬

```
核心：不预测，只设规则
判据：N 日突破 ± 2N 止损 + 加仓金字塔
```
> ⭐⭐ **海龟的独特之处：它是唯一「不预测方向」的体系。**
> 它不说会涨，只说「突破就买、破2N 就走」。
>
> 📌 原文点透：「**波动大 → N 大 → 手数变小 → 每笔亏损恒定 2%**」
> → **这是纯数学，不含任何对市场的判断。**

### 路线 5：**量价形态派**（量柱/黑马王子）⭐ 最快

```
核心：单根量柱的形态就能判断
判据：黄金柱三要素 / 低量柱 / 缩量柱
```
> ⭐⭐ **它不需要等结构走出来** ——
> 判据全落在**单根 K 线**上，所以比前三派快一个量级。
>
> ⚠️ **代价**：作者自称数据**无第三方审计**。

## 三、⭐⭐ 海龟 vs 缠论：两个最容易被混淆的对比

| | **海龟** | **缠论** |
|---|---|---|
| 止损 | **2N（固定比例）** | **结构破坏** |
| 依据 | **波动率** | ⭐ **走势结构** |
| 加仓 | 每赚 0.5N 加 1 单位 | **不主动加仓**（三买才是加仓点）|
| 预测 | ⛔ **不预测** | 预测「走势类型完成」|
| 能否量化 | ✅ 原书即量化 | ⭐ **缠师本人主张量化**（已用原著核实）|

> ⭐⭐ **关键澄清（库内已结案）**：
> 常见说法「缠论不可量化」→ ⛔ **原著中「艺术是不可能量化的」0 命中**；
> 那是**评注者扫地僧**的话。
> **缠师本人说「本ID的理论完全是数量化的，因此就是精确化的」**，
> 并在第 38 课给出**可编码的程式**。
> 📌 详见 [[claims/缠论能否量化]] 与 [[syntheses/缠师原文核查·说话人结案]]

### ⭐ 止损哲学互斥（库内已登记，不选边站）

```
浮亏达 2N 但结构未破：
  → 海龟：立刻走
  → 缠论：结构没坏，继续拿
两者直接矛盾，不能同时遵守。
```
> 📌 详见 [[claims/三种止损方法的适用边界]]。
> ⚠️ 本库**不选边站**，由你拍板。

## 四、⭐⭐ 「主观 vs 客观」的判据硬度排序

这是选体系时**最实用的一个维度**（按取点能否机械复核）：

| 体系 | 判据硬度 | 判据是什么 |
|---|---|---|
| ⭐⭐ **海龟** | **最高** | 极值点 + ATR，**全是数字** |
| ⭐ **量柱（双阴出货）** | 高 | 两根 K 线的收盘价关系 |
| ⭐ **量柱（精准线）** | 高 | 同向同价位重合（**容差 1 分钱**）|
| 缠论 | 中 | 分型/笔/线段，**需反复确认** |
| 道氏 | 中 | 两个指数确认 |
| **波浪** | ⭐ **低** | 数浪，**一浪可数出多种答案** |
| **黄金道（三维通道）** | ⭐ **最低** | 「三个最低点趋向一致」—— **库内标draft** |

> 📌 **一句话结论**：
> **要最机械 → 海龟；要最快 → 量柱；要最完整 → 缠论。**
> ⚠️ **没有哪套是全维度最优** —— 这正是 [[claims/五套体系的仓位与风控对照]] 存在的原因。

## 五、⭐⭐ 跨体系共振（同源而不冲突）

**本库最重要的发现之一**：几套看似不同的体系，**底层在做同一件事**。

| 体系 | 共同点 |
|---|---|
| ⭐ **缠论 + 量柱** | **都在量化庄家行为** —— 缠论量化庄家操盘（原文：「更适合庄家的洗盘减成本操作」），量柱量化散户与庄的角力（庄在散先）|
| ⭐ **海龟 + 缠论** | **都主张机械化**（缠师本人已证实）|
| ⭐ **道氏 + 波浪 + 缠论** | **同一条脉络的三个阶段**（趋势 → 结构 → 判据化）|
| ⭐ **道氏 + 通道线** | 都在拒绝「预测时间与幅度」—— 道氏、量线通道线都这么说 |

> 📌 **为什么同源能叠加不冲突**：
> 它们**观察同一对象的不同侧面** —— 价格结构 / 成交量 / 波动率。
> 三套数据源互不重叠，**同时指向时可信度最高**。
> 📌 具体用法见 [[concepts/量柱六元素]] 与实体页的「三体系叠加」。

## 六、⭐ 五套体系都主动承认自己错（⭐ 本库最重要的观察）

| 体系 | 原文承认的错误 |
|---|---|
| **道氏** | 1926 年汉密尔顿**把牛市回调误判为熊市** |
| **缠论** | 2007-02-27「最强单边走势」实为**骗线** |
| **缠论** | 评注者**反对量化**（⚠️ 非缠师本人）|
| **量柱** | 巢东股份 B 仓预测失败后**上调目标**（本库判定为事后解释）|

> ⭐⭐ **这些都是原文原话，不是 AI 加的评语。**
> 📌 **愿意写下自己错在哪 —— 这是最值得学的东西。**

## 七、选体系的四个维度（决策用，不替你选）

| 问题 | 指向 |
|---|---|
| 你做**期货**吗？ | 是 → 只海龟能用（双向+ATR 仓位）；否 → 其他八套 |
| 你做**可转债**吗？ | 是 → ⭐ 强赎排第一（见 [[syntheses/离场判据总纲]]）|
| 你要**最快信号**吗？ | 是 → 量柱（单根 K 线）；否 → 缠论/海龟 |
| 你要**能机械执行**吗？ | 是 → 海龟；否则 → 任何 |

> ⚠️ **本库不替你选**。理由：涉及你的资金、品种、周期与风险偏好。
