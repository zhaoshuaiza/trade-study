# 五套体系的共识与分歧

> 跨五套体系交叉得出的结论。**单本书的复述不在这里。**
> 本页的价值在于：**找出它们都同意的（可跨体系复用）**，
> 和**它们各不相同的（必须按场景选）**。

---

## 一、五套体系的共识（跨体系通用）

> 这些是**五套体系都同意**的部分。
> **正因为通用，它们是最值得先学的部分。**

### 1. 趋势是可观测的，不是可预测的

| 体系 | 表述方式 |
|---|---|
| 道氏 | 只承诺「已确认的趋势会延续」，不承诺何时出现 |
| 波浪 | 价值在于排除不可能的数法，不是预测下一浪 |
| 缠论 | 不预测方向，只定义走势完成的判据 |
| 海龟 | 触价即入，不等收盘确认 |
| 黑马王子 | 量价异动是**已发生**的事实，不是预期 |

> 📌 **这一条是全部技术分析的地基**。
> 任何声称能预测趋势转折的说法，都与五套体系的核心立场冲突。

### 2. 止损是硬约束，不是可选项

- 道氏/波浪/缠论：走势失效即离场（判据形式）
- 海龟：**2N 硬止损，入场同秒提交，绝不后移**（数字形式）
- 黑马王子：短线止损更关键（波动更大）

> 📌 **形式不同，实质相同**：错了就走，不找理由。
> 海龟只是把这条纪律量化成了 2N。

### 3. 仓位先于买点

- **海龟**把它列为头号死因：先定买点后算仓位，一次判断错误就重伤
- 其他四套虽未明确公式，但都隐含「不确定时轻仓」

> 📌 **反直觉但正确**：大多数人是先研究买什么，
> 最后才想起算仓位。顺序搞反了，一次错误就致命。

### 4. 人性是最大的失败来源

- 海龟：费思破坏规则后破产（**实证**）
- 道氏/波浪：数浪会随行情自我说服
- 缠论：级别判断会随持仓时间改变
- 黑马王子：涨停板最容易诱发追高冲动

> 📌 五套体系都有一个共同前提：**执行比分析难**。
> 知道规则是一回事，按规则做是另一回事。

## 二、五套体系的根本分歧

### 分歧 1：主观画线 vs 机械判据

这是**最大的方法论分野**：

```
主观画线派：道氏、波浪
  「我觉得这是第 3 浪」
  → 事后都能解释 → 无法机械执行 → 依赖主观判断

判据化派：缠论、海龟
  「中枢已形成且走势完成」/ 「突破 20 日最高价」
  → 可预先定义 → 可机械执行 → 依赖客观规则
```

> **缠论是对波浪的批判性改进**：
> 波浪的级别没有严格定义，导致数浪主观。
> 缠论用「中枢 + 级别」给出了可机械判定的替代方案。
>
> 海龟则更彻底——**根本不画线**，用通道突破替代。

### 分歧 2：预测的对象不同

| 体系 | 试图回答 |
|---|---|
| 道氏 | 趋势处于什么阶段 |
| 波浪 | 趋势内部由什么构成 |
| 缠论 | 走势是否已完成 |
| 海龟 | 怎么让风险可控 |
| 黑马王子 | 哪里会出现短线爆发 |

> 📌 **五个问题不冲突，但也不能互相替代**。
> 用缠论的中枢判断去做海龟的仓位管理，是方法论错配。

### 分歧 3：持仓周期的巨大差异

```
日内 ~ 3日     黑马王子
3日 ~ 2周      缠论（分钟级别操作）
2周 ~ 数月     波浪、海龟
数月 ~ 数年    道氏主要趋势
```

> 📌 **离场方式跟着周期走**，这是五条里最容易踩的坑。
> 用长周期方法做短周期标的，或反过来，都是找死。

## 三、尚未解决的问题

- [ ] 黑马王子的止损与仓位方式（待编译确认）
- [ ] 缠论三类买点的精确判定条件
- [ ] 各体系的**实证胜率与盈亏比**（必须标明回测/模拟/实盘）
- [ ] 五套体系在 **A 股实际市场**的表现差异（很多理论源自美股期货）
- [ ] 「判据化」能否完全消除主观性？海龟依赖 ATR 参数，参数选择本身是否主观？

> 最后一个问题值得深想：海龟把判断编码成规则，
> 但**「用 20 日还是 55 日通道」这个选择本身仍然是人为决定的**。
> 彻底消除主观性是做不到的，只能把它**限制在少数几个参数上**。
