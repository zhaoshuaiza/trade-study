## 一、为什么必须做样本外验证

[[syntheses/量柱体系在可转债上的适用性]] 已把量柱判据分成
「✅可用 / ⚠️需改造 / ⛔不可用」三档，但那**全是推演**。

### 三条最需要验证的假设

| # | 假设 | 来源 | 为什么可疑 |
|---|---|---|---|
| **H1** | 低量柱在转债上仍是**转折信号** | [[concepts/量柱六元素]] | 原文是**股票**数据（沪市2009），转债参与者结构不同 |
| **H2** | 「跌多而量不动 = 洗盘」在转债成立 | [[concepts/黄金劫与凹口淘金]] | 转债波动更大，**放量下跌的阈值可能不同** |
| **H3** | 1.382 / 1.618 / ×2 测幅在转债可用 | [[concepts/黄金仓]] | 转债受 **±20% 日限**，空间比股票小 |

> 📌 **H3 风险最高**：股票日限 10%，转债 20%，
> 但转债波动幅度也更大 —— **乘数是否要重标定，完全未知**。

## 二、⭐ 记录格式（每笔必记，这是本页的核心）

> 📌 **不做记录 = 永远无法验证。**
> 每笔转债交易后补一行，两三个字段即可。

### 必记字段

| 字段 | 填什么 | 对应假设 |
|---|---|---|
| 日期 / 代码 | — | — |
| **买入依据** | ⭐ **必填**：低量柱？精准线？平衡线？黄金柱？写不出来就别买 | H1/H2 |
| **转债价格** | 买入价 | H3 |
| **正股价格** | 同期正股价 | 算溢价率 |
| **转股溢价率** | 买入时的溢价率 | 验证「>30% 风险」 |
| **强赎距离** | ⭐ 正股价距离触发线 **x%** | 强赎判据 |
| **成交额** | 单日成交量 | H1 的「量」口径 |
| **离场依据** | ⭐ 强赎/溢价率压缩/双阴/黄金线/缩量柱（**选一个并勾选**）| H2 |
| **实际持有天数** | — | H3 验证窗口 |

### ⭐⭐ 关键：转债的「量」必须同票内比较

> **转债成交量受发行规模影响，不同转债之间不可横向比较。**
> 📌 所以「低量柱」的定义必须写成：
> ```
> 本券近 N 日成交额的低分位（如 20 日内最低的 20%）
> 而非「与别的转债比成交量」
> ```

## 三、⭐ 验证路径（三步，逐步收窄）

### 第一步：先只验一条（推荐）

**只验 H1：低量柱是否预示转折**

```
做法：记录每次「本券 20 日成交额处于最低 20%」的日期
     → 看其后 5 / 10 日转债涨跌幅
     → 若多数上涨 → H1 初步成立
```

> ⭐ **一条一条验，不要同时验三个** ——
> 否则数据混在一起，出问题时无法定位。

### 第二步：验 H2（洗盘识别）

```
做法：记录每次「跌幅 > 5% 但成交额未放大」的日期
     → 看其后 3 / 5 日是否继续跌
     → 若快速修复 → H2 成立（是洗盘）
     → 若继续跌→ H2 不成立（是出货）
```

### 第三步：验 H3（测幅乘数）

```
做法：记录每次「触发离场」时的**最高价**
     → 算 (最高价 − 买入价) / 买入价
     → 看这个涨幅的分布，是集中在 38%/62%/100% 附近，还是分散
     → 集中 → 乘数可重标定；分散 → 乘数不适用
```

> 📌 **第三步最可能得出否定结论** ——
> 我预判转债的波动会让涨幅分布**比股票更分散**。

## 五、⚠️ 三个已知的干扰因素（会影响验证结果）

| 干扰 | 说明 | 处理 |
|---|---|---|
| ⭐ **强赎** | 会在毫无量价信号时强制离场 | **必须单独标记**，不能计入任何技术判据的成败 |
| ⭐ **T+0 回转** | 日内多次买卖会污染「成交量」的解读 | 记录时**区分日内与隔夜** |
| ⚠️ **正股联动** | 转债涨跌 70%+ 来自正股 | 需记录正股同期表现，**才能剥离出转债自身的影响** |

> 📌 **正股联动是最难剥离的因素** ——
> 严格说，验证的是「量柱对**转债**的预测力」，
> 而转债的价格主要由正股决定。
> → **折中做法**：只验「转债相对正股的**超额**表现」。
