# 第一部分：为什么会冲突（根因）

## 根因1 ⭐⭐⭐：**九套体系在回答的不是同一个问题**

**这是所有冲突的总根源。** 表面上在争"谁对"，实际是**问的题目不同**。

| 体系 | 它真正回答的问题 | 它的"正确"范围 |
|---|---|---|
| [[entities/道氏理论]] | **趋势存在吗？** | 描述层 |
| [[entities/波浪理论]] | **趋势走到哪了？** | 描述层 |
| [[entities/缠论]] | **这段走势完成了没？** | **结构层** |
| [[entities/海龟法则]] | **怎么活到赚的那天？** | **风险层** |
| [[entities/黑马王子]] | **A 股短线怎么打？** | **战术层（A 股制度）** |
| [[entities/龙头价值赛道]] | **什么票值得追？** | **选股层（短线）** |
| [[entities/金融帝国·走出幻觉]] | **我会不会出局？** | **风险层** |
| [[entities/傅海棠·一个农民的亿万传奇]] | **供求怎么变成行情？** | **基本面层（期货）** |
| [[entities/传奇投资人的智慧]] | **买什么？** | **估值层（长线）** |

📌 **关键结论**：
> **九套体系有六层，没有两层在同一个层里竞争。**
> 所谓"冲突"，大部分是**跨层借用导致的伪冲突**——
> 比如用傅海棠的基本面方法去做缠论的结构判断，
> 或用缠论的买点去执行海龟的仓位算法。

---

## 根因2 ⭐⭐⭐：**方法诞生于不同的市场与年代**

**这是"谁对谁错"问题的物理基础。**

| 体系 | 市场 | 年代 | 当时的制度条件 |
|---|---|---|---|
| 道氏 | 美股 | 1900s-1931 | 做市商时代 |
| 波浪 | 美股 | 1930s | 同上 |
| 海龟 | **期货** | 1983 | 期货市场早期 |
| 缠论 | **A 股** | 2005起 | 股权分置改革 |
| 黑马王子 | **A 股** | 2000s | 涨停板制度 |
| 龙头价值赛道 | **A 股** | 2020s | 注册制 |
| 傅海棠 | **中国期货** | 1991-2013 | 保证金制度 |
| 金融帝国 | **中国期货** | 2005-2009 | 同上 |
| 价值投资 | **美股** | 1930s-2020s | 长期牛市 |

⚠️ **重点观察**：
- **A 股体系**（黑马/缠论/龙头）**强依赖涨跌停+无做空**
  → 换到美股/期货，**打板逻辑直接失效**
- **期货体系**（海龟/傅海棠/金融帝国）**依赖杠杆+保证金**
  → 换到股票，**仓位逻辑完全不一样**
- **价值投资**在 A 股的有效性是另一个问题（散户为主、换手率高）

📌 **所以"哪个体系更好"这个问题本身可能问错了** ——
> 正确的问法是：**「在我的市场上、我的周期上，哪套的假设成立？」**

---

## 根因3 ⭐⭐：**对"什么是风险"的理解不同**

**这是最隐蔽、也最容易造成实际损失的一层分歧。**

| 体系 | 它认为风险是什么 | 它的应对 |
|---|---|---|
| **缠论** | **判断错误**（走势不能操作了） | 结构止损 |
| **海龟** | **价格反转**（2N 被触发） | 硬止损 |
| **傅海棠** | **极端波动**（微观尾部风险） | 保证金占用 + 小仓位 |
| **金融帝国** | **破产**（被扫地出门） | 三段链 + 保守下注 |
| **巴菲特** | **永久性资本损失** | 分散 + 拿住 + 低价买入 |

**⚠️ 这五个"风险"不是同一个东西**：
```
傅海棠的风险 = 一次交易的极端波动
金融帝国的风险 = 账户归零（概率× 幅度）
缠论的风险   = 对结构判断错误
海龟的风险   = 趋势反转（必然会发生， 只是幅度未知）
巴菲特的风险 = 企业永久亏损
```

📌 **一个隐含结论**：
> **如果你不知道自己在防哪种风险，你的风控措施就必然对不上号。**
> 📌 这是本页最实用的一条。

---

## 根因4 ⭐：**对"预测"的态度不同**

| | 观点 | 代表 |
|---|---|---|
| **怀疑派** | 「没有人能 100% 预测」 | 缠论（理论 100% 客观但操作做不到）、金融帝国（「止损≠预测」）、海龟（只做系统不做预测） |
| **供求派** | 「供求关系是可调研的，可以提高胜率」 | 傅海棠、龙头、巴菲特 |
| **结构派** | 「走势有自同构结构，可递归分解」 | 缠论、道氏、波浪 |

> 📌 **这不是对错之争，是"确定性来源"之争**：
> 怀疑派认为确定性不存在，所以建**认错机制**；
> 供求派认为部分领域有确定性（供求、成本），所以建**调研流程**；
> 结构派认为结构有确定性，所以建**分类体系**。
>
> **三者都在解决同一个问题：如何在不确定中行动。** 只是路径不同。

# 第二部分：在哪里冲突（层面定位）

## ⭐⭐⭐ 关键发现：冲突高度集中在两个层面

### ⭐⭐ 三组跨体系强共识（至少三个独立来源，2026-10-10 从"六套横向对比"并入）

> 📌 **为什么单列在这里**：下面四个根因解释"为什么冲突"，
> 但**"它们在什么上一致"是另一个问题**——这三条共识是可直接复用的结论。
> 原 [[syntheses/六套体系横向对比·共识与冲突]] 停滞在"六套"时代，本节为并入内容。

#### 共识 1：「方法被广泛使用就失效」—— ⭐ 五个独立来源，同一机制

| 来源 | 年代 | 表述 |
|---|---|---|
| 邓普顿 | 1954 起 | 「**连续 5 年同方法成功 → 下一个 5 年该换**」 |
| 金融帝国 | 2009 | **权威的泥潭效应**：唐奇安因海龟披露而衰竭 |
| 费思（海龟实测） | 2007 | **交易者效应**：唐奇安系统表现最差 |
| 费思（参数纪律） | 2003 | **不要优化参数**（过拟合 = 拟合噪声） |
| 彭道富（龙头） | 2020 | 把"奇迹"当规律 |

📌 详见 → [[concepts/权威的泥潭效应]]
📌 ⭐ **作者的反向推论**（金融帝国）：**形态理论已被深入人心，反过来用比直接用更有价值**。

#### 共识 2：「供求关系是底层逻辑」

| 来源 | 表述 |
|---|---|
| **傅海棠**（2013，期货） | 「决定价格方向性运动的，**只有"供求关系"**」 |
| **彭道富**（2026，A股） | 「**供求关系是西方经济学最基础的词汇**……同样也是做股票最基本的同时也是最重要的逻辑」 |
| **巴菲特/芒格** | 「内在价值由**盈利能力**决定」—— 本质是现金流 |

📌 **相隔 13 年、不同市场、身份差距最大的两人独立同源。**
📌 巴菲特体系在"内在价值"层面与供求关系**同构** —— 长期价格由盈利（供求结果）决定。

#### 共识 3：「风控比技术更重要」

| 来源 | 表述 |
|---|---|
| **海龟** | 「**90% 是风险控制，赚钱是副产品**」 |
| **傅海棠** | 「和仓位大小关系也不大……**那些亏大钱的几乎都是重仓**」 |
| **金融帝国** | 「**稳定性 > 期望收益**」；三段式关系链 |
| **龙头价值赛道** | 「**资金管理比仓位管理重要一百倍**」 |

📌 **四套体系、两套期货出身的独立断言。**

#### ⚠️ 但这三条共识**都不是"越多越好"

| 共识 | ⚠️ 局限 |
|---|---|
| 方法会失效 | ⚠️ 没说"什么方法**不会**失效" |
| 供求是底层 | ⛔ **无法证明自己那条是"本质"而非"表象"**（见下文"我答不了的问题"）|
| 风控优先 | ⛔ **没说风控的边界在哪**（傅海棠的"重仓必亏"本身是经验值） |

---

### 五套体系风控的三层结构

```
┌──────────────────────────────────────────────────────────┐
│ 第 0 层【钱要不要进股市】                    ← 无冲突     │
│   金融帝国、龙头：总资产比例、熊市降档                      │
│   ⚠️ 两者都认为"比仓位管理更重要"，方向一致                 │
└──────────────────────────────────────────────────────────┘
                    ↓ 钱已在股市
┌──────────────────────────────────────────────────────────┐
│ 第 1 层【每笔下多少】                       ← 弱冲突      │
│   海龟：1% ÷ (N × 每点价值)                           │
│   傅海棠：保证金占用（反例：棉花 ATR 小但亏损最大）       │
│   龙头：≤ 30%/80%                                        │
│   ⚠️ 分歧在于"波动率能不能代表风险"，而非要不要控制       │
└──────────────────────────────────────────────────────────┘
                    ↓ 仓位已定
┌──────────────────────────────────────────────────────────┐
│ 第 2 层【什么时候离场】                     ← ⭐ 真冲突   │
│   缠论：走势不能操作了就走（可能盈利离场）               │
│   海龟：触及 2N 就走（必然亏损离场）                     │
│   龙头：正法模型判定 / 熊市休息                          │
│   巴菲特：几乎不走（除非逻辑破坏）                        │
│   ⚠️⚠️ 这里四个体系给出互斥的操作，不可调和               │
└──────────────────────────────────────────────────────────┘
```

### 六组冲突的层面定位

| # | 冲突 | 层面 | 强度 |
|---|---|---|---|
| 1 | **止损：金额触发 vs 逻辑触发** | 第2层 | ⭐⭐⭐ 不可调和 |
| 2 | **熊市：减仓/空仓 vs 拿住** | 第0-2层 | ⭐⭐⭐ 不可调和 |
| 3 | 仓位：ATR vs 保证金占用 | 第1层 | ⭐⭐ 需实证 |
| 4 | 重仓 vs 轻仓 | 第1层 | ⭐⭐ 立场对立 |
| 5 | 分散 vs 集中 | 第1层 | ⭐⭐ 可按场景选 |
| 6 | 能不能量化 | 方法层 | ⭐ **已核实有答案** |

# 第三部分：各自的优劣（核心）

## 3.1 缠论 —— 最精细的结构分析，但有前提

### 优势
| | 说明 |
|---|---|
| ⭐ **判据化程度最高** | 趋势/盘整的区分从"视觉感觉"变成"**可数的中枢个数**" |
| ⭐ **自带递归体系** | 中枢→走势类型→级别，**循环定义被级别打破** |
| ⭐ **买卖点明确** | 一买/二买/三买各有**结构依据**，不是靠感觉 |
| **不预测** | 明确说「不预测方向，只定义走势完成的判据」 |

### 劣势
| | 说明 |
|---|---|
|⛔ **"100%客观"只在结构层成立** | 作者自己承认：规则建立在"**忽略1分钟以下波动**"的前提上 |
| ⛔ **操作层面做不到 100%** | 原文：「抓买卖点这个动作是做不到 100% 的」 |
| ⚠️ **反对量化** | 「艺术是不可能量化的」—— 但 ⚠️ **已核实这是评注者扫地僧说的**，缠师本人说"理论完全是数量化的"（见 [[claims/缠论能否量化]]） |
| ⚠️ **本级别要选对** | 级别选错全盘皆输；原文："不知道是级别选小了还是结构没走出来" |

### ⭐ 最适合
**个股、有明确结构、愿意花时间画图的人。**
📌 **不适合**：追求全自动、无法忍受"画错可能"的场景。

---

## 3.2 海龟 —— 最完整的系统化，但假设趋势存在

### 优势
| | 说明 |
|---|---|
| ⭐ **唯一完全机械化** | 所有参数可计算、执行可重复 |
| ⭐ **风控优先** | 仓位、止损、加仓、组合热度，**六层逻辑链完整** |
| ⭐ **参数有纪律** | 明确「**不要优化参数**」，且费思用两章讲曲线拟合陷阱 |
| **有反例记录** | Curtis Faith 后来破产，承认「**是我违背了规则，不是规则失效**」 |

### 劣势
| | 说明 |
|---|---|
| ⛔ **假设趋势跟踪有效** | 在无趋势市场（长期震荡）会持续磨损 |
| ⛔ **加止损降低绩效** | ⚠️ 费思实测发现：**趋势跟踪系统加止损会降低所有指标**（见 [[concepts/止损的争议]]） |
| ⚠️ **本身已被证伪一部分** | 费思实测**唐奇安系统表现最差**，归因「交易者效应」 |
| ⚠️ **失效原因的悖论** | [[concepts/权威的泥潭效应]]：**正因为它被广泛使用，所以失效了** |

### ⭐ 最适合
**期货/大品种趋势跟踪、能严格执行纪律、接受"频繁小亏偶尔大赚"的人。**
📌 **不适合**：做 A 股短线题材（2N 会频繁被扫）。

---

## 3.3 龙头价值赛道 —— 最贴近A股实战，但主观性强

### 优势
| | 说明 |
|---|---|
| ⭐ **供求关系讲得最透** | 「需求↑+ 供给受限 = 既让马儿跑，又不让马儿吃草」 |
| ⭐ **弹性价值解释力强** | 一举解释「为什么好公司不涨」「为什么财报出来后反而不涨」 |
| ⭐ **有可直接执行的纪律** | 龙头宪法九条 + 正法模型四象限 |
| ⭐ **风控层级最高** | 资金管理比仓位管理重要一百倍（含具体比例） |
| | **有明确止损哲学**：止损 = 反复认错机制，不是预测 |

### 劣势
| | 说明 |
|---|---|
| ⛔ **"主要矛盾"无法量化** | 「当前时代最大的主要矛盾是什么」—— 不同的人有不同的答案 |
| ⛔ **宪法第9条与缠论冲突** | 「市场选出的 > 自己选的」vs 缠论"主动定位买点" |
| ⚠️ **强依赖 A 股制度** | 涨跌停 + 无做空 + 题材生态 |
| ⚠️ **"我执"象限的例外无标准** | 作者说"超级大佬可以在此象限动手"，但**没给验证方法** |

### ⭐ 最适合
**A 股短线题材、愿意做调研、能忍受主观判断的人。**
📌 **不适合**：追求客观机械化。

---

## 3.4 傅海棠 —— 唯一一手实盘，但样本单一

### 优势
| | 说明 |
|---|---|
| ⭐ **唯一一手实盘记录** | 5万→1.2亿的**逐年实录**，含全部错误示范 |
| ⭐ **七条规律可直接落地** | 尤其规律 6：**农产品看供应，工业品看需求** |
| ⭐ **十二个亏钱原因 + 五个拿不住利润原因** | 极实用，且是**自我总结** |
| ⭐ **成本视角独特** | 「价格长时间低于成本 → 必然会减产」是硬判据 |
| | **大行情窗口的时机判断**：**收获季节**（预期差最大） |

### 劣势
| | 说明 |
|---|---|
| ⛔ **明确反对技术分析** | 「技术分析对大部分投资者是一个误导」—— **与缠论/海龟正面冲突** |
| ⛔ **只有期货经验** | A 股/美股是否适用**未验证** |
| ⚠️ **样本量小** | 主战场只有大蒜和棉花两个品种 |
| ⚠️ **"七条规律"未给统计支撑** | 全是经验判断 |

### ⭐ 最适合
**大宗商品基本面交易、愿意实地调研的人。**
📌 **不适合**：做技术图形的人（他会直接否定你的方法）。

---

## 3.5 金融帝国 —— 最扎实的风控哲学，但不给信号

### 优势
| | 说明 |
|---|---|
| ⭐ **资金管理讲得最透** | 三段链：收益率 ∝ 下注比例 ∝ 回撤 ∝ 出局概率 |
| ⭐ **"稳定性 > 期望收益"** | 多数人搞反了 |
| ⭐ **保守性原则** | 用理论最优的一半（作者自述做法） |
| ⭐ **"权威的泥潭效应"** | 解释了为什么**方法会失效** |
| ⭐ **博弈论视角** | 「研发部和商家并不是朋友，**是博弈关系**」 |

### 劣势
| | 说明 |
|---|---|
| ⛔ **不提供任何信号系统** | 「我数学水平不高，无法计算出具体的理论数值」 |
| ⛔ **分散论证有前提** | 数学推导假设**相关性=0**，作者自己承认现实中做不到 |
| ⚠️ **仓位算法与海龟冲突** | 用**保证金占用**而非 ATR，**只给了棉花一个反例** |
| ⚠️ **成书于 2008 前后** | 部分市场情况已变 |

### ⭐ 最适合
**任何体系的使用者**——它是**风控层**，可以套在别的体系外面。
📌 **不适合**：想找买卖信号的人（它没有）。

---

## 3.6 巴菲特/芒格/邓普顿 —— 最经受时间考验，但不适合短线

### 优势
| | 说明 |
|---|---|
| ⭐ **时间跨度最长** | 伯克希尔 57 年 36,000 倍，有 1964-2021 完整数据 |
| ⭐ **可执行估值法** | 10 年每股平均收益 ×10；**安全边际 6 折** |
| ⭐ **芒格的方法论层次最高** | 先博（多学科思维模型）→ 后专 → 心不乱 |
| ⭐ **质量原则 9 项清单** | 含「**定价权**」这一核心 |
| ⭐ **巴菲特自己放弃了烟蒂股** | 「**烟蒂理论正逐渐走向衰落**」—— 自我修正 |

### 劣势
| | 说明 |
|---|---|
| ⛔ **不做时机** | 「**难的是在持有后不轻易卖出**」 |
| ⛔ **与止损体系完全对立** | 价值投资**几乎不设止损** |
| ⛔ **集中 vs 傅海棠的轻仓** | 立场直接对立 |
| ⚠️ **"内在价值"自认模糊** | 巴菲特：「即使我们两个人观察同一家公司，判断也会存在差异」 |
| ⚠️ **A 股适用性未验证** | 巴菲特早期买中石油/比亚迪都是在特定制度下 |

### ⭐ 最适合
**长线持股、不看盘、能忍受长期回撤的人。**
📌 **不适合**：任何需要频繁进出的策略。

## 3.7 道氏/波浪 —— 地基与结构化，但主观性强

| | 优势 | 劣势 |
|---|---|---|
| **道氏** | 趋势是可观测的；**不预测时间和幅度** | 趋势的"定义"仍有主观成分 |
| **波浪** | **价值是排除不可能的数法**（不是预测） | 数浪高度主观；**浪型会变形** |

📌 **两者是缠论的前身**，本库保留它们是因为它们定义了"趋势"这个基础概念。

## 3.8 黑马王子 —— 最贴近 A股制度，但依赖量价

| 优势 | 劣势 |
|---|---|
| ⭐ **唯一深度依赖 A 股制度**（涨停板+量价）| ⛔ **换市场完全失效**（无涨跌停就无涨停逻辑） |
| 周期最短，信号明确 | ⚠️ 强势股与"跟风股"难区分 |

📌 **与龙头价值赛道的对比最有价值**：
> **黑马看量价，龙头看逻辑** —— 同赛道不同哲学。

# 第四部分：⭐ 冲突的最终归纳

## 4.1 有解的冲突（可以按维度选）

| 冲突 | 解法 |
|---|---|
| **技术分析有没有用** | **分层**：选股层用供求（傅海棠/龙头），时机层用技术（缠论/海龟）。⚠️ 傅海棠是全盘否定，但他的否定只在"选什么"这个层面成立 |
| **能不能量化** | ⭐ **已核实**：缠师本人说「理论**完全是数量化的**」，「艺术不可量化」是**评注者扫地僧**的话。见 [[claims/缠论能否量化]] |
| **分散还是集中** | **按市场阶段**：熊市分散、牛市集中（邓普顿 + 龙头体系都提到） |
| **重仓还是轻仓** | **按胜率**：期望值为正且已验证 → 可重仓；未验证 → 轻仓。见 [[concepts/正确率与赔率的互损原则]] |

## 4.2 无解的冲突（必须选边）

| 冲突 | 为什么无解 |
|---|---|
| ⭐⭐⭐ **止损：金额触发 vs 逻辑触发** | **两种触发可能同时发生，且给出相反操作**。一只票浮亏 2N 但结构完好——海龟说走，缠论说留。**不可能同时执行** |
| ⭐⭐⭐ **熊市：减仓 vs 拿住** | **三条互斥**：减到 30%（龙头）/ 继续跟踪（海龟）/ 熊市拿住（价值投资）。**同账户无法同时执行** |

📌 **这两个冲突是本库无法替你解决的** ——它们不是信息不足，而是**逻辑互斥**。

## 4.3 ⭐⭐⭐ 但冲突本身是好事（你的判断，我同意）

**为什么冲突是好事**：

| 理由 | 说明 |
|---|---|
| **1. 它们不在同一层** | 六个层次，没有两层在争同一个问题（见根因1） |
| **2. 每套都记录了自己的失败** | ⭐ **这是最值得学的地方**：缠论记录 2007 骗线、海龟记录 Curtis Faith 破产、龙头记录恒立实业五特殊性、道氏记录创始人误判 |
| **3. 冲突处正是需要你判断的地方** | 信息可以查到，**判断不能** |
| **4. 强制你说明适用边界** | 说不出"我为什么选这套"，就说明你还没想清楚 |

📌 **本库最大的价值不是给答案，而是把问题问准。**

# 第五部分：我的判断（供参考，不是建议）

📌 **如果让我说一句**：

> **六套体系真正不冲突的部分是「别乱动」；真正冲突的部分是「什么时候该动」，
> 而这恰恰是最难的部分。**

**具体来说**：
1. **风控层可以统一**（金融帝国 + 海龟 + 龙头都同意）→ 但"止损 vs 拿住"没解决
2. **选股层可以统一**（供求/价值/弹性都在说"找有东西的票"）
3. **时机层无法统一** —— 因为这是各体系最核心的差异所在

**⚠️ 但这个"统一"有个前提**：
> 你得先想清楚**自己在防哪种风险**——
> 傅海棠防的是极端波动，金融帝国防的是破产，缠论防的是判断错，海龟防的是趋势反转。
> 📌 **不知道防什么，风控就必然对不上号。**
