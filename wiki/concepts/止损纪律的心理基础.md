# 止损纪律的心理基础

> 止损不是技术问题，是心理问题。知道在哪止损和能执行止损之间，隔着贪婪和恐惧。
> 来源：[[sources/止损 如何克服贪婪和恐惧]]（吉姆·保罗，2016）

## 核心判据

### 1. 进场前必须设好止损（不可后补）

**动作**：开仓单和止损单同时提交。如果进场后才设止损、或开始下调止损位以包容更多亏损，说明心理已经扭曲。

**为什么**：仓位一旦建立，你的判断就会被仓位方向扭曲。进场前你是客观的，进场后你是带情绪的。

**反面模式**：
- 进场后才想"亏多少我能接受"
- 跌破止损位后下调止损（"再等等"）
- 改变进场时的基本面理由来合理化持仓

### 2. 内化亏损五阶段（对照自查）

当亏损仓位让你进入以下状态时，说明已经被情绪接管：

| 阶段 | 表现 |
|---|---|
| 否认 | "这套方法是对的，只是还没涨" |
| 迁怒 | 对经纪人生气、骂市场、怨天尤人 |
| 讨价还价 | "只要回本我就马上卖" |
| 抑郁 | 对亏损仓位感到沮丧，逃避看盘 |
| 认命 | 终于割肉，或被保证金催缴强平 |

**执行规则**：进入第2阶段就该无条件平仓，不要等到第5阶段。

### 3. 违反规则的回报陷阱

如果你违反止损规则后**侥幸赚钱**，你学到的是"做错事也有回报"，下次会故技重施。问题是你分不清这次违反规则是安全还是危险——直到一次赔光。

**执行规则**：止损触发就执行，不允许"这次例外"。

### 4. 五种活动分类（你在做什么？）

| 活动 | 目的 | 判断标准 |
|---|---|---|
| 投资 | 本金安全+适当报酬（股利/利息） | 你在收租 |
| 交易 | 买卖价差 | 你在赚波动 |
| 投机 | 买进为了转售 | 你在赌方向 |
| 投注 | 证明自己对 | 你在面子 |
| 赌博 | 寻求刺激 | 你在找爽感 |

**关键**：买股票不等于投资，期货不等于交易。看你怎么做，不是看你做什么。

## 原文引用

> "市场亏损应该是外部而客观的损失，一旦你把个人情绪带进去，它才会变成主观损失。"

> "参与市场不是为了证明自我，不是要找娱乐。参与市场是为了赚钱，需要制订计划来执行决策。"
