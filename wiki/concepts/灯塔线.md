# 灯塔线

> **作者自认「研发时三个月不识肉味」的得意之作。**
> 它是《量柱擒涨停》[[黄金道]]的**前身**——
> 灯塔线用**量柱取点**，黄金道改用「三个最低点」取点。
> ⭐ **两者取点规则的差别，正是 [[concepts/黄金道]] 被标 draft 的原因。**

---

## 一、出身（重要：本库的取法分歧源头）

> 原文：「'股市灯塔线'是王子根据**西山大师的'佛光线'改编而成**的。
> 它继承和发扬了周易八卦的**阴阳转换规律**……」

> ⚠️ **注意**：灯塔线并非作者独创，而是**改编自西山大师的「佛光线」**。
> 原文明确致谢并称是「独家授权」。
> 📌 引用时不宜把它当作黑马王子原创。

### ⭐ 灯塔线 vs 黄金道（同一工具的两个版本）

| | **灯塔线**（本体系） | [[concepts/黄金道]]（改进版） |
|---|---|---|
| 出处 | 改编自西山大师「佛光线」 | 《量柱擒涨停》第 18 讲 |
| 取点 | ⭐ **用「最高量柱/最低量柱」所在日定** | **「与地线趋向一致的三个最低点」** |
| 可机械复核？ | ✅ **基本可以**（找量柱最高/最低的那天）| ⚠️ 「趋向基本一致」**需目测** |
| 作用 | 测顶量底 | 观顶/察底/识人气 |
| 画法难度 | 相对可控 | 原文自承「三个月不识肉味」|

> 📌 **这是本页对库内最重要的贡献**：
> 灯塔线的取点规则是**量柱驱动**的（客观），
> 黄金道改成了「三个最低点」（主观）→
> **所以本库把黄金道标 draft，而灯塔线可以相对放心用。**

---

## 二、三维测顶量底（灯塔线的原始用法）

原文把灯塔线与其他技术合成「三维综合技术」：

| 组成 | 作用 |
|---|---|
| **灯塔线** | 测顶、量底 |
| [[concepts/黄金道]] 黄金道 | 趋势通道 |
| [[concepts/黄金线]] 平衡线 | 个股买点 |

> 原文的描述：
> 「上证指数的**每一个重要高点和重要低点都在灯塔线和黄金道的规范之中**」。

### 大盘上的原始用法（原文两个案例）

```
测顶：以 2 月 16 日的量柱为标准，什么时候达到或超过该量柱即为顶部
测底：以 4 月 28 日的量柱为标准，什么时候达到或低于该量柱即为底部
```

> 📌 **这是「以量柱定顶底」的原始版本**：
> **用量柱的高度作为阈值**，而不是价格。

## 三、⭐⭐ 「四区四决」—— 灯塔线的操作核心

原文称这是「灯塔线的独特操作秘」，并说「我们现在看不懂不要紧，总有一天会懂的」。

> ⚠️ **诚实提示**：原文对「四区四决」的**系统阐述不足**，
> 只在案例中零散出现（A 区、B 区、「穿过」「咬住」「回踩」「站稳」）。
> 下列判据是**从案例中提炼的**，**原文未给出完整定义**。

### 从案例提炼的五个动作

| 动作 | 原文描述 |
|---|---|
| **回踩** | 「大盘回踩 B 线，浮力强劲，站稳 A 区」 |
| **咬住** | 「大盘'咬住 B 线'，起在 B 线，试探 A 区」 |
| **穿过** | 「大盘'穿过 B 线'，几乎平顶，进入 A 区」 |
| **站稳**（三日确认）| 「根据'**三日确认原则**」，大盘已站稳 A 区」 |
| **发火** | 「今日大盘最低点刚好触及 B 线（身居 A 区）就**发疯似的往上**」 |

### ⭐ 三日确认原则（原文明确）

```
第1 天：回踩 B 线 → 浮力强劲，站稳 A 区
第 2 天：咬住 B 线，起在 B 线，试探 A 区
第 3 天：穿过 B 线，几乎平顶，进入 A 区
→ 三日确认 → A 区成立
```

> 📌 **这与 [[concepts/黄金柱]] 的「后三日验证」是同一个方法论**——
> 都不信单日，要求连续多日确认。
> **这是量柱体系一贯的风格**，比任何单日信号都可靠。

## 四、⭐ 与「平衡线」的关系（易混，须区分）

原文提到「H、J、K 平衡线」，且第 20/21 讲专门讲
「把平衡线移植到分时图中」。

| | 灯塔线 | **平衡线** |
|---|---|---|
| 来源 | 灯塔线体系 | 量柱/量线的**等值线** |
| 取点 | 量柱最高/最低日 | **等量柱**的位置 |
| 作用 | 测顶量底 | ⭐ **突破/跌破即确认** |

原文实例（大盘）：
```
K 平衡线 2962 点 → 原文预测冲到 2971 点，
「误差高达 9 个点」
```

> 📌 **实战用法**：平衡线是**突破确认线**——
> 「站稳 2132，可能上探 2166；站不稳的话，就要考验 2108。」

## 五、⭐⭐ 原文的一条极重要的方法论警告（价值极高）

原文用一位**著名股评家**的通道线做了对比，结论极锋利：

> 「他取的这几个点**都没有生根**，都**没有可靠的量柱作基础**，
> 所以我便以'虚线'来显示疑问。」

> 「过去的'传统画线'方法**已被主力高度利用**，
> 只有现在的'**量柱量线**'才能识破其手法。」

### ⭐⭐ 这句话是本库「量柱体系」的存在理由

```
传统画线（主观画趋势线）
   → 主力可以「故意画出通道线」让散户相信
   → 原文举例：某股评家画了通道线，
     结果「股价骑在此线欲上不能，必然回落」
     而实际走势是「本来是十字阳线」——**实强示弱**

量柱画线（客观取点）
   → 取点必须有「量柱作基础」（生根）
   → 主力难以针对性伪造
```

> ⭐ **这是全库最值得记住的对比**：
> **「取点是否有量柱作基础」= 判别画线可信度的标准。**
>
> 📌 这也解释了为什么[[concepts/谷底线]]强调
> **「尽量寻找与之能形成'精准线'的最低点」**——
> 同样是在找「生根」的点。

> ⚠️ **原文同时展示了「实强示弱」手法**：
> 「14 日的这个骑线'十字阴线'之所以诡异，
> 就在于它本来是一根'**十字阳线**'，而且是骑着'通道线'的'十字阳线'」
> → 与 [[concepts/黄金劫与凹口淘金]] 的「假阴真阳」**完全同源**。
