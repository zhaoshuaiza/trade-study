# 黄金劫与凹口淘金

> **本库认为这是全书最实操的一讲。**
> 因为它讲的**不是找买点，而是识别「主力在洗你」**——
> 这是散户最容易交出筹码、也是最容易验证的时刻。
>
> 原文断言：「凹口淘金，**十拿九稳**」。

---

## 一、黄金劫是什么（原文定义）

> 「'打劫'是一个**围棋**术语……会打劫的庄家，
> 可以在打劫途中把对手的筹码悉数揽入自己的囊中。」

> 「什么是'打劫'？说穿了，就是'**先做笼子**'，然后'**请君入瓮**'。」

**打劫的本质**（原文第二节）：

> 「任何股票的涨跌都是主力（或者庄家）**诱导散户跟风**所造成的。」

原文的推理很干净：
- 散户**没有能力**拉升（除非瞎猫碰上死耗子）
- 散户**也不会**主动打压自己的股票（除非急等用钱）
- 所以：**主力拉升必须有散户跟进，主力打压必须有散户抛售**
- → **「判断主力的成本区间就非常重要」**

### 成本区间的标尺

> 「不同的阶段有不同的黄金线，如果股票在黄金线上方**连续大跌**，
> 或者**突然跌破黄金线**，我们就要注意了，这里可能就是依托黄金线的一场**黄金劫**。」

---

## 二、⭐ 打劫的三个特点（可验证）

这是本页最硬的判据 —— **不打这三个特征，就不是打劫**。

| # | 特点 | 原文标准 | 验证方法 |
|---|---|---|---|
| **1** | **有稳固的「行为中枢」** | 以**黄金线**为轴心，上下任意运行；**即使打穿第一黄金线，也有第二黄金线支撑** | 数一数有几道黄金线层层递进 |
| **2** | **有足够的「行为空间」** | 一般**先拉后打**：拉是为了探索空间，打是为了挤压筹码。「**拉升得越高，打压得越低**」 | 量出从A 到 C 的涨幅 vs 从 C 到 D 的跌幅 |
| **3** | **有可靠的「行为约束」** | **没有出现「大量出逃」** —— 股价跌 50%~70% 而**量柱几乎没动静** | ⭐ 跌得多 + 量不放大 = 庄家没跑 |

> 📌 **特点三 是最易验证的一条**，也是「洗盘」与「出货」的分界：
> **出货必然放量，洗盘必然缩量。**
> 这一条与 [[entities/黑马王子]] 中「缩量远比放量可靠」完全一致。

### 实证（哈高科 600095，2007年4–8 月）

原文称此为「打劫高手」，在 **3 个多月**内做出两次 50%+ 打压和60%+ 拉升：

| 阶段 | 幅度 |
|---|---|
| A → C 拉升 | +50% |
| C → D 打压 | **−50%**（连四个跌停，无量下坠） |
| D → E 拉升 | +45% |
| E → B 打压 | **−70%** |
| B → F 拉升 | **+69%**（连拉四个涨停） |

> ⭐ 原文的层次感：「A 柱和 B 柱**上下呼应，层层递进**，
> 给人制造'**地狱下面还有地狱**'的感觉」——
> 且指出左侧还有一个黄金柱 B₁，解释了「为什么 C 跌到 D 这么深」。

## 三、⭐⭐ 凹口淘金五法则（实战密码）

原文：「是不是所有的凹口都能淘到金子呢？**不是！**」

### 术语约定

| 名词 | 原文定义 |
|---|---|
| **银谷** | 下跌后**横盘整理**形成的凹陷，「装满了大家的银子，戏称为**装银子的仓库**」 |
| **金坑** | **突破凹口后的再次打压**形成的较小凹陷；「**主力赚钱全靠这个'凹口'**」，「一箭三雕」 |
| **凹口基本线** | 主力开始打压之处，即**成本线** |
| **凹口平衡线** | 突破凹口后的关键防线 |

> ⚠️ **金坑不能演变成银谷**：否则会「蜕变成一轮比一轮低的'**粪坑**'，那是千万碰不得的」。

### 五条法则

| # | 法则 | 原文标准 |
|---|---|---|
| **1** | **凹口要突然凹陷** | 是「**异动股**」——比大盘提前下跌（哈高科提前 5 天，银基发展提前 1 天）|
| **2** | **凹陷首日要凶狠** | 要能体现主力的「**故意**」，「跌得你想慌不择路地出逃」 |
| **3** | **凹陷部分成交量很少** | 「持股者不愿卖，持币者不敢买，**敢买的就是'始作俑者'的庄家**」 |
| **4** | **右侧有逐步放大的成交量** | 有的是**巨量或天量**（银基发展谷底拉升连续两天巨量；哈高科金坑右侧连续三天天量）|
| **5** | **凹口平衡线附近必有一根中阳或大阳柱** | 且拉升非常突然，「**几乎让人来不及发现它就上去了**」——是主力为摆脱坐轿者故意为之 |

### ⭐ 实盘金句

> 「只要有'**金坑**'的个股，**十有八九会迅速拉升**。」

**实证**：
- **哈高科**（600095）：2008-02-04 预报金坑当日 → 连涨六天含一个涨停，
  6.40 元 → 8.95 元，**六天 +39.70%**（原文称在熊市中难能可贵）
- **银基发展**（000511）：2007-12-26 预报 → 累计 **+45.66%**

## 四、⭐⭐ 洗盘的识别（与「打压」同等重要）

黄金劫的实战价值，一半在于**识别洗盘而不出局**。原文给了三个判据：

### 1. 「假阴真阳」—— 高开低走但守住前涨停板

> 「第十天的这根巨阴巨量柱，原来是**高开低走的假阴线**，
> 最低价依然收在前一交易日涨停板的价位之上，**其实质是巨阳巨量**。」

```
判据：最低价 > 前一交易日涨停板价→ 假阴真阳（实为巨阳）
      最低价 < 前涨停板价   → 真阴，出货
```

> 📌 **只看收盘涨跌会看错**。必须看**最低价与前涨停板的关系**。

### 2. 缩量洗盘 vs 放量出货

| 现象 | 原文判断 |
|---|---|
| **缩量一倍**的下跌，未破柱底 | 「可能在进行'**休克试验**'」→ **不必出场** |
| 连续大阴但**量柱逐步缩小** | 「主力以此**打压吸筹**」 |
| 跌破黄金柱对应价柱最低价 | 谨慎者**出货** |

### 3. 量柱的大小决定能否涨停（原文答疑）

网友问：巢东股份与粤传媒「一字之差」，前者涨停后者没封，量柱前者更长，为何？

> 「**量柱大，说明抛盘大，主力只能'被动吸筹'，所以不能涨停**；
> 而**量柱小，说明抛盘小，主力是'主动吸筹'，就能涨停**！」

> ⭐ **这是全库最反直觉、也最实用的一条量柱判据**：
> **量柱不是越大越好。** 大量柱 = 抛压重 = 拉不动。
> 这与 [[concepts/黄金柱]] 的「**柱不在高，含金则灵**」、
> [[entities/黑马王子]] 的「**缩量远比放量可靠**」完全同源。

## 五、原作者的金言（可直接背）

> 「**凡是牛市中的打压，就是建仓的机会；
> 凡是熊市中的拉升，就是出货的良机；
> 凡是逼近黄金线的打压，就是介入的机会；
> 凡是远离黄金线的拉升，就是出货的良机。**」

配套的「远离」判定用**数学**而非感觉：
见 [[黄金仓]] 的三级测幅（1.382 / 1.618 / ×2）。

## 六、实战检查清单

**识别打劫**
- [ ] 有几道黄金线层层递进（行为中枢）？
- [ ] 拉升幅度与打压幅度是否匹配（行为空间）？
- [ ] ⭐ **跌了 50%+ 而量柱几乎没动**？（行为约束 → 是洗盘不是出货）

**识别凹口**
- [ ] 凹口是否**突然**形成、比大盘提前？（法则 1）
- [ ] 首日是否**凶狠**？（法则 2）
- [ ] 凹陷处**成交量很少**？（法则 3）
- [ ] 右侧是否**逐步放量**？（法则 4）
- [ ] 平衡线附近是否有**中阳/大阳柱**？（法则 5）
- [ ] 是**金坑**还是已恶化为「粪坑」？

**洗盘期持仓**
- [ ] 是否守住前涨停板价（假阴真阳）？
- [ ] 量柱是**缩小**还是放大？缩 → 持有；放 → 出货
- [ ] 是否跌破黄金线连续 3 日以上？

- [ ] 「凹口淘金十拿九稳」是**作者自述**，无统计样本
- [ ] 「量柱大则不能涨停」的机制（主动/被动吸筹）**逻辑自洽但无法直接观测**
