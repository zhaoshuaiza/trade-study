## 一、⭐ 三大经典策略对比

| | **双低策略** | **高 YTM 策略** | **下修博弈** |
|---|---|---|---|
| **核心** | 低价格 + 低溢价率 | YTM > 3% | 预判发行人下修 |
| **赚什么** | ⭐ **股性 + 债性双击** | ⭐ **利息 + 到期保本** | ⭐ **条款套利** |
| **适合市场** | 震荡市 / 结构性 | ⭐ **熊市 / 低风险偏好** | 事件驱动 |
| **风险等级** | 中 | ⭐ **最低** | ⭐ **最高** |

## 二、策略一：双低策略（⭐ 平衡安全与弹性）

### 定义
> 筛选「**低价格（<120元）+ 低溢价率（<20%）**」的可转债

### 操作步骤

**① 初筛条件**
```
价格区间：100-120 元        （避免高价股性风险）
转股溢价率：< 20%            （确保股性跟随能力）
剩余规模：< 15 亿元          （提升资金关注度）
```

**② 二次筛选**
```
正股基本面：营收/净利润增速 > 10%   （规避衰退行业）
发行人意愿：大股东配售比例 > 30%     （促转股动力强）
```

**③ 动态调仓（止盈止损）**
```
止盈：价格 > 130 元  或  溢价率 > 30%
止损：价格跌破债底 5%  或  正股暴雷
```

### 原文回测数据（⚠️ 未独立核实）

| 策略 | 年化收益 | 最大回撤 | 胜率 |
|---|---|---|---|
| **双低策略** | **18.5%** | **−12%** | **65%** |
| 沪深300 | 6.2% | −35% | 45% |

> 📌 **注意**：胜率 65% + 回撤 12% —— 这印证了本库
> [[concepts/正确率与赔率的互损原则]] **不是越高越好**：
> ⭐ 双低策略的胜率（65%）远高于沪深300（45%），
> ⭐ **但回撤只有 1/3** —— **胜率和回撤要一起看**。

### 案例（⚠️ 已失效）
>孚日转债（128087）：2023 年价格 115 元、溢价率 15%，
> 正股上涨 30% 后转债涨至 145 元。

## 三、策略二：高 YTM 策略（⭐ 债性保护为核心）

### 定义
> 专注**到期收益率（YTM）> 3%** 的可转债，以**利息和到期保本**为主要收益来源

### 操作步骤

**① 筛选标准**
```
YTM > 3%              （高于同期国债收益率）
信用评级 ≥ AA          （规避违约风险）
剩余期限 > 2 年        （避免短期流动性冲击）
```

**② 组合构建**
```
行业分散：银行、公用事业、消费等低波动行业
单券仓位 ≤ 10%          （防范个体风险）
```

**③ 持有策略**
```
止盈：持有至到期，或价格反弹至**债底以上 10%-15%**
止损：发行人下调评级 或 正股 ST → 立即止损
```

### 案例数据（⚠️ 历史）

| 标的 | YTM(2024) | 信用评级 | 价格 |
|---|---|---|---|
| 浦发转债 | 3.8% | AAA | 98 |
| 中信转债 | 3.5% | AAA | 101 |

### ⚠️ 风险警示（原文给的真实失败案例）
> **青农转债（128129）**：2022 年因正股暴跌，YTM 升至 5%，
> 但**信用评级降至 AA−，价格跌至 85 元**。

⭐ **这条极重要**：它说明——
> **YTM 高不等于安全。**
> ⚠️ **如果发行人信用恶化，债底会被击穿。**
> 📌 这正好印证 [[concepts/可转债复合资产特性]] 里的
> "债底**不是保本**"——**青农转债就是活案例**。

## 四、策略三：下修博弈（⚠️ 风险最高）

### 定义
> 预判发行人主动下修转股价，通过"**转股价值提升→ 转债价格上涨**"获利

### 筛选条件

**① 下修动力强**
```
剩余期限 < 2 年          （促转股压力大）
未转股比例 > 70%          （避免到期偿债压力）
发行人财务费用率高（如 > 5%）
```

**② 下修能力足**
```
PB（市净率）> 1            （下修后转股价不低于每股净资产）
大股东持股集中             （股东大会通过概率高）
```

### 操作流程

**① 潜伏期**
```
价格 < 110 元时建仓       （博弈失败时仍有债底保护）
分散持仓 3-5 只下修预期标的   （⭐ 降低单只失败风险）
```

**② 事件催化**
```
跟踪董事会公告（下修议案提出 → 股东大会表决）
股东大会前 5 日加仓        （通过概率 > 70% 时）
```

**③ 退出时机**
```
止盈：下修成功后溢价率压缩至 < 15% 时
止损：下修失败 或 正股破位下跌时
```

### 案例（⚠️ 已失效）
> **洪涛转债（128013）**：2021 年剩余期限 1.5 年、未转股比例 90%、PB=1.2；
> 董事会提议下修 30%，转债价格从 98 元涨至 118 元。

## 五、⭐⭐ 三个策略的选择判据

```
问自己三个问题：
① 我能承受多大回撤？   → 不能 → 高YTM（回撤最低）
② 市场震荡还是趋势？   → 震荡 → 双低；趋势 → 下修博弈
③ 我有没有信息优势？   → 没有 → 别做下修博弈
```

| 市场状态 | ⭐ 建议 |
|---|---|
| **熊市 / 下跌** | ⭐ **高 YTM**（债性保护） |
| **震荡市** | ⭐ **双低**（股性未充分定价） |
| **结构性行情 / 政策预期** | ⭐ **下修博弈**（但风险最高） |

> 📌 **双低策略的适用面最广**（震荡 + 结构性），原文也这么说。

## 六、⚠️ 风控（原文 6.2 提炼）

> 完整风控清单见 `raw/academic/可转债每日掘金/62风险管理与常见陷阱风控措施.md`

### 原文的止盈止损参数汇总

| 策略 | 止盈 | 止损 |
|---|---|---|
| 双低 | 价格 > 130 元 或溢价率 > 30% | 跌破**债底 5%** 或正股暴雷 |
| 高 YTM | 债底以上 **10-15%** | 评级下调 / 正股 ST |
| 下修博弈 | 溢价率压缩至 < 15% | 下修失败 / 正股破位 |

### ⭐ 单券仓位上限
> 高 YTM 策略：**单券仓位 ≤ 10%**

> ⚠️ 可转债的债底特性使它**天然适合分散**：
> 单只下跌有债底保护，但**系统性下跌时债底也会被击穿**（青农案例）
> → 📌 **仍需分散**，不能因为"有债底"就重仓单只

## 七、可执行判据（可勾选）

### 每次买入前
- [ ] **策略类型**：双低 / 高 YTM / 下修博弈（**只选一种，不要混用**）
- [ ] **价格区间**：双低 ≤ 120 元｜高 YTM 按 YTM 筛｜下修 < 110 元
- [ ] **溢价率**：双低 < 20%｜下修博弈 < 10%
- [ ] **剩余规模**：< 15 亿元（提升资金关注度）
- [ ] **信用评级**：≥ AA（高 YTM 策略**必须**）
- [ ] **剩余期限**：> 2 年（高 YTM）
- [ ] **强赎状态**：⚠️ **必查**（见 [[concepts/可转债复合资产特性]]）
- [ ] **单券仓位**：≤ 10%

### 持有中
- [ ] 止盈条件是否触发？
- [ ] **评级是否被下调？**（高 YTM 策略的红线）
- [ ] 正股是否 ST？
- [ ] 每周查一次**异常波动公告**（严重时可能被停牌）

## 十一、⚠️ 税负对策略的影响（本页新增）

| 策略 | 税负敏感度 | 说明 |
|---|---|---|
| **双低/高YTM（持有到期）** | 🔴 **高** | 票息本身很薄，**20% 利息税**显著；须算**税后 YTM** |
| **下修博弈（短期持有）** | 🟢 **低** | 二级市场买卖差价**暂免个税** |
| **强赎前止盈（波段）** | 🟢 **低** | 同上；但 ⚠️ 强赎兑付时利息扣 20% |

📌 **实操要点**：转股后卖股票要交印花税，**通常直接卖转债更划算**。
详见 → [[concepts/可转债交易成本与税负]]
