## 一、市场以「大多数个人投资者是失败者」为前提运作（原书 §1.1）

> [!warning] 题面与原文口径差异
> 本任务题面称「九成个人投资者亏损」，但原书第1章仅以「大多数个人投资者都是失败者 / 大多数个人投资者不会盈利」表述，**未给出具体百分比**。依库规质量红线，本页以原书口径「大多数」为准；「90%」具体数值 **status: uncertain**，不臆造。

### 1.1 杠杆收益率与散户失败（原书口径照录）

[原] 书中用「杠杆收益率」（信用交易中用小额担保金从券商借入股票或资金买卖的潜在损益指标）作为判断个人投资者盈亏的标准之一。计算口径：证券交易所**每周三**发布统计数据，主要网络券商自行公布整体客户数据；与外国投资者、机构投资者相比，个人投资者更倾向「**融资买入**」（借资金做多）而非对冲 / 卖空。

[!important] 原书关键结论（§1.1）
> 「任何交易市场都是以『大多数个人投资者都是失败者』为前提在运作的。」
> 「大多数个人投资者不会盈利」是行情延续的前提——「大多数个人投资者都盈利的话，行情的上升走势便会终止」。

具体数字（[原] 原书照录，日股信用交易口径，**不可直接迁移 A 股**，见 §五）：
- 当杠杆收益率低于 **-20%** 时，融资买入的个人投资者就面临巨大亏损，可能被券商要求**追加担保金**；可用资金有限者被迫抛售，引发连锁「抛售高潮」（接近下跌探底值）。
- 收益率接近零时，「行情就该走向最高点」（图1-1 印证）。

### 1.2 失败不是技术不行，是「失败者心理」在作祟

[原] 第1.1节列出 **12 条「失败者模式」**（书中称之为「失败者心理」），作者断言：之所以采取「无计划、损失大、收益小」的交易方式，归根结底是因为大多数失败者都明显抱有「导致失败的心理」。

| # | 失败者模式（原书照录） | 可执行识别判据（动词 + 触发条件） |
|---|---|---|
| 1 | 认为知道秘诀就能简单盈利 | 当看到《×年后你将成亿万富翁》类书名就心动、想买小道消息时 → 立刻记录「我是否在做模式1」 |
| 2 | 没真正想过要成功 | 当被问「为何不坚持学」答「多麻烦啊，不知能否赚钱」时 → 标记为「伪赢家动机」 |
| 3 | 努力方向错了（只啃二手公开信息） | 当把日经 / 四季报 / 电视财经当主要优势来源时 → 自检「这信息是否已体现在行情里」 |
| 4 | 缺少领路人或指导者 | 当周围只有不懂装懂的熟人建议、无人能指出错误方向时 → 寻找可验证的导师 / 体系 |
| 5 | 对金钱持负面情绪 | 当潜意识认为「赚钱是罪恶 / 不义之财」并因此过早斩仓时 → 写下自己金钱观的根源 |
| 6 | 被眼前股价摆布、无法纵观全局 | 当把亏损归咎「次贷 / 地震 / 日元升值」等外部事件时 → 强制写「我自己的决策哪里错了」 |
| 7 | 凭本能面对盈亏（损失规避） | 当盈利就急着套利、亏损就死扛不肯割肉时 → 对照「损小利大」反查（见 §三） |
| 8 | 凭直觉交易（赌徒的荒谬） | 当交易理由是「报纸说热卖 / 朋友说外汇快」而无计划时 → 禁止下单，先写交易日志 |
| 9 | 仅凭少量经验下判断（少数定律） | 当某法连亏5次就断言「行不通」放弃时 → 先算该法的连续失败概率（见 §三） |
| 10 | 善于把行为正当化 | 当连续失败却说「方法行不通、被骗了」回退老方法时 → 记录「我是否在自我正当化」 |
| 11 | 为获胜率所左右 | 当被「获胜率9成」吸引、忽视损益比率时 → 改算「损益比率」而非胜率（见 §三） |
| 12 | 被消极信念束缚 | 当「股票该回调时买」等信念反向时拒不接受缺陷时 → 列出自己持有的信念清单 |

> [!important] 原书关键结论（§1.1 末）
> 「即使意识到了『自己也有失败者心理』，但要转换为『谋求成功的心理』『赢家心理』并改变行动却非易事——因为迄今培养起来的行为方式和思维框架都已根深蒂固。」

## 二、NLP 是什么，为何能训练交易心理（原书 §1.2 为何选用NLP / 建模）

### 2.1 NLP 的定义与起源（原书照录）

[原] NLP = **神经语言程序学（neuro-linguistic programming）**，被称为「模式化科学」「大脑的使用说明书」。核心命题：脑是让「心」（情感）运转的机器；懂得操控大脑，就有可能创造并改变情感。

[原] 起源（**1970年代，美国加州大学**）：理查德·班德勒与约翰·葛瑞德模仿三位心理治疗师并系统化其共通点——
- 米尔顿·艾瑞克森（催眠疗法，针对个人）
- 弗雷德里克·皮尔斯（格式塔疗法，针对工作组）
- 维琴尼亚·萨提亚（家庭疗法，针对家庭）

NLP 现为吸收语言学 / 心理学 / 人类工程学 / 精神生理学的「应用性学科」，广泛用于教育、商业、体育（原书例：克林顿演讲用「迎合对方视 / 听 / 感」、罗宾斯指导阿加西重返网球世界第一）。

### 2.2 建模（modeling）：把赢家「彻底模仿」成自己的东西

[原] 建模 = 「将成功模式完全吸收，并进而转化为自己的东西」。日本「道」文化即此：从「守」（彻底模仿师傅的眼神 / 语言 / 动作）到「破」（发挥个性）到「离」（自创）。

建模需分析原型人物的三种感觉（[原] 原书照录）：
- **视觉**：交易赢家持有什么信念？以什么视点 / 焦点看问题？
- **听觉**：吸收什么信息？与自己进行什么对话？
- **身体感觉**：如何使用身体？如何控制情感？

> [!important] 原书关键结论（建模段）
> 为「变身理想的交易赢家」，应采用 **输入（现状）→ 输出（理想）→ 测试 → 操作** 的 TOTE 循环。

### 2.3 TOTE 模式（test-operate-test-exit，原书照录）

[原] 以「可用资金 **100万日元** 的工薪族、目标以交易谋生」为例：
- **输入（现状）**：视觉=账户余额100万日元；听觉=妻子抱怨「这个月开销怎么办」；身体=加班疲劳累积。
- **输出（理想）**：视觉=账户超 **1亿日元**、每月旅行；听觉=妻儿感谢「爸爸好厉害」；身体=美食 / 健身 / 按摩舒畅。
- **测试**：对比输入输出差距（「哪里不同、还缺什么」）。
- **操作**：针对领悟采取行动；不顺利则成为下次测试信息，循环往复。

可执行入口（动词 + 触发条件）：
- **当设定年度交易目标时** → 先按「视觉 / 听觉 / 身体感觉」三栏各写一句「现状」与「理想」，三栏不写清不下目标。
- **当现状与理想差距模糊时** → 用「测试」三问（哪里不同 / 还缺什么 / 我要改变哪点）逼出可行动项。
- **当一次操作失败时** → 不归咎市场，把失败改写为「下一次测试的输入信息」，进入下一轮 TOTE。

## 三、杠杆收益、损益比率与「损小利大」（原书数字照录）

### 3.1 损失规避与前景理论（原书 §(7)）

[原] **1979年**卡尼曼（普林斯顿）与特沃斯基（斯坦福）通过实证研究提出「损失规避」：面对等量收益与损失，人们对损失的敏感大于收益；该「前景理论」使卡尼曼获 **2002 年诺贝尔经济学奖**（特沃斯基于1996年去世）。

[原] 原书用100万日元买股示例刻画「损大利小」陷阱：涨到110万即急满足而套利（A处）；跌回100万「都损失10万了」痛苦骤升；跌到90万（C处）愤怒后悔不肯抛；跌到70万（D处）麻木破罐破摔，最终「被套牢」。

> [!important] 原书关键结论（§(7)）
> 「盈利时只获得少量利润，而亏损时则是损失大部分资金，这种悲惨的情况正是『损大利小』。相反，只要结果是『损小利大』，就是赢家。」

可执行判据（动词 + 触发条件）：
- **当头寸浮盈达到原计划了结点** → 按规则了结，禁止因「还想多赚」而取消（对抗 A 处过早套利的反面失控）。
- **当头寸浮亏触及止损** → 无条件执行，禁止进入「麻木死扛」（D处）状态；若发现自己用「总有一天涨回」自我安慰 → 立即平仓。

### 3.2 获胜率 vs 损益比率（原书 §(11)，数字原样保留）

[原] 原书以「获胜率9成」为例：10次9次盈利每次赚 **1万日元**、仅1次赔 **10万日元** → **总计仍赔 1万日元**。故「获胜率只代表盈利次数，不代表利润」。

[原] 损益比率运算（原书原值，不改动）：
- 损益比率 **1:1**（盈1万 / 亏1万）→ 1次亏与1次盈对抵为0，**胜率超过 5成（>50%）即盈利**。
- 损益比率 **1:2**（盈2万 / 亏1万）→ 与2次亏损对抵，1次盈利即打平，**胜率超过 33% 即盈利**。

> [!important] 原书关键结论（§(11)）
> 「比起获胜率，我更想要关注的是股票的『风险收益率』（损益比率）。即使5成获胜率，只要收益大于亏损就能盈利。」

可执行判据（动词 + 触发条件）：
- **当评估任一交易方法时** → 先算其损益比率，再反推「需要多少胜率才不亏」，不以「高胜率」为采纳理由。
- **当某法连续亏损想放弃时** → 按 §3.3 连续失败概率判断是否属于正常波动，而非方法失效。

### 3.3 少数定律 vs 大数法则（原书 §(9)，数字原样保留）

[原] 获胜率 **60%** 时连续失败概率（原书图1-3）：**10连败概率 0.1%**，**5连败概率 2.6%**（即千分之二十六）。原书强调：交易赢家重视「大数法则」而非「少数定律」（仅凭少量经验妄下判断）。

[原] 概数定律（大数定律）示例：抛硬币正面概率50%，抛10次可能9次正面；抛1000次正面可能为 **600 / 400 / 524 / 476**，**几乎不会是 900 或 100 次**——实验次数越多越接近概率。系统型交易即「等待概率重现」的模式，交易次数越多越易再现概率。

可执行判据（动词 + 触发条件）：
- **当某交易法连亏5次想放弃** → 先查该方法历史胜率；若期望胜率60%，则5连败概率2.6%属正常，禁止据此判「方法行不通」。
- **当回测样本极少（如 <30 次）** → 标注「偶然性大，非结论」，不据此定论（并入库规 4.4 / 4.7 数据性质标注）。

## 四、「变身交易赢家的 5 步法」总览 + 为何单纯技术派不够（原书 §1.2）

### 4.1 五步法总览（把赢家心理当成功典范去模仿）

[原] 本书把「赢家心理」当作**成功典范 / 成功哲学**去模仿（建模对象）。NLP 交易训练由以下 **5 个步骤**构成，分章展开；本页只给总览与入口动作。

> [!important] 原书关键结论（§1.2 三位一体）
> 撒普博士（范·K.撒普）将「交易者成功要素」归纳为三，缺一不可：**心理要素（个人心理）+ 自我管理要素（资金管理）+ 决策要素（交易方法）**。只有培养赢家心理与精神调节能力，达到「心技一体」的三位一体，才能「久赚不赔」。

五步与 TOTE / 三位一体的映射（[原] 原书结构）：

| 步骤 | 对应章 | TOTE环节 | 核心动作（动词 + 触发条件） |
|---|---|---|---|
| ① 自我认识 | 第2章 | 输入 | **当开始训练前** → 客观重识「真实内心」（含幼时经验 / 信念 / 环境），列出当前金钱观与交易信念清单，再定策略 |
| ② 目标设定 | 第3章 | 输出 | **当设定目标时** → 按「与性格 / 环境 / 情感相符」的现实目标，写清「交易成功后的理想生活」（视觉 / 听觉 / 身体感觉三栏） |
| ③ 问题解决与策略 | 第4章 | 测试 | **当现状与理想有差距时** → 先学资金管理（头寸调整 / 可承受风险），列「问题清单」逐条找解法，溯源到自身信念 |
| ④ 改善心理的技巧 | 第5章 | 操作 | **当执行受阻时** → 用具体心理改善技巧（书第5章专讲「如何改善」，而非空喊「控制心态」） |
| ⑤ 事业计划 | （终章） | 维持 | **当方案确定后** → 制订 business plan，维持 TOTE 循环与三位一体，养成习惯 |

可执行总入口（动词 + 触发条件）：
- **当读完本页决定启动训练** → 按 ①→⑤ 顺序建档，每步留书面产物（信念清单 / 理想三栏 / 问题清单 / 技巧记录 / 事业计划）。
- **当某步卡住** → 不跳步；回到上一步的 TOTE 环节补输入 / 输出 / 测试。
- **当市场环境或个人资金 / 家庭环境变化** → 重做 ③（问题清单）与 ⑤（事业计划）；原书例：若「月收益10%目标」因工作需要无法顺利实施，则须改变目标或环境。

### 4.2 书中关于「为何单纯技术派不够、必须做心理训练」的核心论点

[原] 原书论点梳理（来自 §1.1 失败者模式 + §1.2 三位一体）：
1. **技术易学，心理训练需耐力与持续练习**：原书指出「即使交易经验非常丰富的人，也大都有过『不知为何没割肉导致重亏』『无法按原则下单』『不知不觉改了止损点』『不顺就孤注一掷』的失败」——问题在心理层面而非技术。
2. **三位一体缺一不可**：无论经验多丰富、手段多高，若达不到「无意识的感情」境界交易，成功只是暂时的；不改善精神境界会陷入不安 / 压力导致无效率交易。
3. **多数亏损可溯源到心理**：失败者12模式几乎全是心理 / 认知偏差（秘诀幻想、伪动机、损失规避、直觉、少数定律、自我正当化、胜率迷思、消极信念），而非「不知道买卖点」。
4. **系统型交易也需个人心理**：原书虽建议初学者从系统型交易起步（预设所有买卖 / 退出、可由回测预估风险、不易陷心理陷阱），但明确指出「即使表面排除主观性的系统型交易，也需交易者在实践中树立坚定的个人心理状态」，且存在过度拟合风险。

> [!important] 原书关键结论（§1.2 交易方法段）
> 「无论一个交易者技术如何优秀，如果心理素质根本不过关，就不可能使得技术和心理因素相辅相成，并灵活运用。只有培养赢家心理和精神调节能力，真正做到心技一体……才能在交易中保持久赚不赔。」

可执行判据（动词 + 触发条件）：
- **当自认「技术已够但仍稳定亏损」** → 不自责技术，改做 ①自我认识（挖无意识动机 / 金钱观），见 [[自我认识与无意识动机]]。
- **当系统信号发出却下不了单 / 改了止损** → 判定为心理缺口，进入 ④心理改善，见 [[NLP心理改善技巧·感元次感元与状态管理]]。

## 五、边界与坑

1. **心理训练不替代风控 / 资金管理**：原书把「自我管理要素（资金管理）」列为三位一体之一，且 §1.1 模式3 / 11 直指「不懂头寸与可承受风险就无法成功」；先修资金管理再谈心态（承接 [[三位一体交易策略与资金管理·风险管理是生存关键]]）。
2. **NLP 训练不替代风控系统**：建模改变的是「情感与行为模式」，不是止损单；仓位 / 止损仍须按规则机械执行（库规 4.5 不替代风控）。
3. **日股 / 信用交易语境参数不可直接迁移 A 股**：-20% 杠杆收益率、每周三统计、融资买入偏好、1亿日元目标等均为原书日语境；A 股无同等「杠杆收益率」统计口径，仅借鉴机制（亏损放大 → 被迫平仓 → 连锁下跌）。
4. **损益比率 / 连续失败概率数字是原书教学示例，非 A 股参数**：1:1 需 >50%、1:2 需 >33%、60% 胜率下 5连败 2.6% / 10连败 0.1% 是书中数字，落地须用自己系统的真实回测值替换（库规 4.1 参数原样保留、不擅自优化，但也不可当作普适真理外推）。
5. **「获胜率9成」等书内反例不可当方法**：那是原书用来批判「被胜率左右」的负面案例，不是推荐策略。
6. **不给投资建议**（库规 4.5）：本页不含任何标的、买卖点、收益承诺；书中案例（日元金额、肯用「百分比」谈外汇）仅作方法论示例。
7. **建模有「守破离」顺序**：先彻底模仿赢家（守），再发挥个性（破 / 离）；禁止未模仿就自创「独门秘籍」。
8. **系统型交易有过度拟合风险**：原书明示「为在回测得精确结果而强关联历史数据」即过度拟合，此类数值不能屡胜；警惕用历史数据调优参数（库规 4.1）。
9. **「九成亏损」未在本书第1章给出具体百分比**（见 §一 warning）：本页以原书「大多数」为准，90% 标 **status: uncertain**。
