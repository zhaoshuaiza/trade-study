# 价值投资实战手册·唐朝体系

> [!info] 本页性质
> **本批 6 本书里唯一一本「以 A 股上市公司财报为素材、把估值落成可计算公式」的书。**
> 核心贡献只有一句：**三大前提 + 市盈率**。
> 其余 90% 篇幅是**财报诊断动作库**——几乎每一条都是「打开财报第 X 页，比对两个数字」的可机械复核操作。
> 但：**几乎所有对比表格在素材抽取中丢失**，因此本书的量化结论大量无法复核（见「素材缺失」）。

## 一、覆盖范围

### 1.1 讲了什么

| 章 | 内容 | 判据密度 |
|---|---|---|
| **第一章 正确面对股价波动** | 投资的定义、股票本质（股模式 vs 票模式）、睡前/睡后收入、股票长期回报、收益三大来源、远离杠杆 | ⭐ 低（理念层） |
| **第二章 如何估算内在价值** | 格雷厄姆两条路径的分野、**三大前提 + PE 的估值公式**、高杠杆企业打七折 | ⭐⭐⭐ **全书最高（唯一公式）** |
| **第三章 企业分析案例** | 15 个 A 股案例（雅戈尔、老板电器、利亚德、长安汽车、茅台×4 篇、洋河×4 篇、五粮液、泸州老窖、古井贡、腾讯×2 篇、海康威视、分众传媒、招商/民生银行、宋城演艺、信立泰） | ⭐⭐⭐ **判据密度最高** |

**第三章的 15 个案例不是案例分析，是判据库**——几乎每篇结尾都是「投资决策：投还是不投」，且排除理由高度模板化。

### 1.2 不讲什么

| 不讲 | 说明 |
|---|---|
| ❌ 择时 / 技术分析 / 趋势 | 全书 0 处均线、0 处 K 线、0 处仓位择时法 |
| ❌ 做空 / 衍生品 / 期货 | 全书 0 处；作者 A 股单边 + 只买 A/H/B 股 |
| ❌ **可转债** | 转股溢价、强赎、下修、回售、债底、YTM、评级 **全部 0 命中** |
| ❌ 宏观预测 | 反复说「不懂、不知道」，拒绝预测房地产、政策、货币政策 |
| ❌ 分散化配置理论 | 无马科维茨、无资产配置、无再平衡 |
| ❌ 卖出判据的独立成文 | 只有「估值区间上下沿」隐含卖出，**没有独立卖出清单** |
| ❌ 组合层面的风控 | 无回撤控制、无最大持仓比例规则（只有「不懂不投」） |

## 二、Z 层：【可直接落成动作】

> [!important] Z 层的三条边界
> 1. **Z-01~Z-08（估值公式）可直接代入数字，是全批唯一的公式。**
> 2. **Z-09~Z-40（财报诊断）动作可机械执行，但结论常需回到已丢失的表格才能定量。**
> 3. **Z-41~Z-46（排除与决策）是「动词 + 可验证触发条件」形式。**

### 2.1 估值核心（8 条，全批唯一公式）

| ID | 判据 | 原文要点 |
|---|---|---|
| **Z-01** | **股权投资的定义** | 「投资的定义是**在未来获取更多的购买力**」；买股票 = 买企业所有权的一部分，不是买价格 |
| **Z-02** | ⭐ **估值的三大前提**（使用 PE 前必须逐条回答） | ① **净利润数据是否为真？** ② **未来能否持续？** ③ **持续是否需要依赖加大资本投入？** 原文：「估值的核心数据就是市盈率」「我的估值系统很简单，就是三大前提 + 市盈率」「确定盈利为真 + 未来大概率可以持续 + 盈利的持续不依赖增加资本投入」 |
| **Z-03** | ⭐ **PE 是投资回报率的倒数** | 「市盈率是投资回报率的倒数，看市盈率事实上就是看投资回报率」 |
| **Z-04** | ⭐ **无风险回报对应 20 倍 PE** | 「如果**无风险回报在 20 倍市盈率**（一般参照五年期国债，即**五年期国债利率 5%**）」——⚠️ 5% 是 2016—2018 年语境，见「时间烙印」 |
| **Z-05** | ⭐ **三年一倍法（低估买入位）** | 早期表述：「**三年后 15 倍 PE 卖出能赚一倍的价格，就可以买入**」；后期放宽为「三年后若以 **15~25 倍市盈率**之间卖出能获得满意回报（**我对满意的私人定义是翻倍**）的位置，就是很难亏钱、值得下手的低估位置」 |
| **Z-06** | ⭐ **高杠杆企业打七折** | 「**高杠杆企业打七折**」；算例：长安汽车为达成 8% 销量目标须新增固定投资 56 亿 + 股权投资 9 亿 = 65 亿，「65 亿元中的大部分就成了为了维持现有盈利能力而必须投下去的资金，**它不是自由现金流**」「它是利润，但只是可望而不可及的『**泡沫利润**』」「在不确定性增大的时候，表面上看上去低的 **7 倍市盈率，就不那么夸张了**」 |
| **Z-07** | **估值区间的上下沿操作** | 茅台：「**440~480 元之间，我可能会逐步降低对茅台的持仓**」；「**已经做好在 650~400 元之间『坐电梯』的心理准备，做好了 400 元之下开始加仓的准备**（400 元对应 **20 倍市盈率**）」；「当前约 **30 倍市盈率**，是老唐心中的茅台合理估值」；海康：「目前市盈率 **30 倍**……这是我心中合理估值的上限」「**2017 年内可以接受 1600 亿~1800 亿元市值之间的买入**」 |
| **Z-08** | **PE 只在同股同权与同一商业逻辑下横比** | 存款/债券可比（「还本付息的确定性差异小到可以忽略」）；跨行业不可比：「21 倍的洋河股份和 7 倍的长安汽车，谁更有投资价值？这个问题的难度就比较大了」。⚠️ 但作者本人随后对洋河给 25 倍、对长安福特给 3 倍 PB——见 C-05 |

### 2.2 财报读数：收入与利润（8 条）

| ID | 判据 | 原文要点 |
|---|---|---|
| **Z-09** | ⭐ **销售收现 vs 营收（含税口径对齐）** | 洋河 2017 一季报被误读为造假：「销售商品收到的现金为 67.4 亿元，远低于 75.9 亿元营业收入……含税加总数据大幅低于不含税的营业收入，这不是涉嫌财报数据造假吗？」修正法：**「如果以半年为一个时段，将前一年四季度和当年一季度数据之和做个同比，就一目了然」**（2016-10 至 2017-03：收现 128.4 亿 + 应收增加 1.3 亿 vs 营收 101 亿） |
| **Z-10** | ⭐ **预收款余额变动方向诊断** | 「预收款余额从 2016 年四季度初的 **13.4 亿元**，增加到四季度末的 **38.5 亿元**，再减少为 2017 年一季度末的 **13.6 亿元**」；茅台 2015：年终预收 82.6 亿 vs 年初 14.8 亿 → 「当年有高达 **67.8 亿元（含税）**新增销售收入，并未在 2015 年财报确认」 |
| **Z-11** | ⭐ **还原预收款后的真实增速** | 茅台 2016：报表营收 389 亿 + 净增预收 92.8 亿 = **468 亿**；2016 前三季度实际 345 亿 vs 2017 前三季度 424 亿 = **同比 22.9%**（而非报表 60%）；「真实市场增长大约在 **23%~33%** 之间，60% 高增长数据仅仅是因为上一年有意做低财报数据的原因」 |
| **Z-12** | ⭐ **经营现金流净额 vs 应付增加额** | 利亚德：财报 293 页经营现金流净额 7.78 亿，「但就在这个数据的上一行，有另一个数据『**应付增加 8.46 亿元**』」「利亚德是靠多拖了上游供应商 **8.46 亿元货款**，才得以获取 7.78 亿元经营现金流净额。**弦绷得还是比较紧的**」 |
| **Z-13** | **经营现金流净额 vs 净利润（长期趋势）** | 银行/民生案例的标准动作：「往年同期，经营活动现金流净额都是高于净利润的，证明公司实打实地赚到了真金白银」；民生 2017「经营现金流净额**暴降至 11.7 亿元**，不足报表净利润（27.4 亿元）的一半」 |
| **Z-14** | **单季环比 vs 同比的口径选择** | 分众：「三季度净利润同比增幅约 **1%~8.4%**，对比上半年高达 32% 的增速」；茅台：「2017 前三季度及第三季度的真实销售，并没有财报显示的那么高的增长。在公司收款发货节奏基本稳定的前提下，**财报事实上使用了预收款进行数据调节**」 |
| **Z-15** | **三费/费用增速拆解** | 茅台 2013：「三项费用增加额由 6 亿多元广告宣传及市场拓展费用和 6 亿多元管理费用构成」，且「员工总数从年初的 **13717 人**增加到年末的 **16800 人**，新增人员中 **78% 为生产一线员工**……吸纳大学本科及以上学历的员工整整 **800 名**」 |
| **Z-16** | **报表利润的「去泡沫化」** | 利亚德：「2017 年公司税前利润 12.1 亿元，但所得税费用仅 **45 万元**……当期直接少计入 **2.82 亿元**的所得税费用」「对于保守的投资者，老唐建议将公司净利润 **12 亿元看成约 9 亿元**」 |

### 2.3 财报读数：资产、负债与现金（8 条）

| ID | 判据 | 原文要点 |
|---|---|---|
| **Z-17** | ⭐ **货币资金异常的交叉验证** | 老板电器：「公司的现金持有量高得不正常，而且不是一年如此，是**年年如此**」；「一家身处中国金融业最发达的区域浙江省杭州市的制造业企业，在没有大额投资需求的情况下，保留大量闲置资金，不进行投资，不购买理财产品，仅仅满足于获取三年定期存款的收益水平，**这大概率不正常**」；量化思路：「高达 34 亿元的现金，将收益率提高 1 个百分点，就可以增加近 **3000 万元**税后净利润」 |
| **Z-18** | ⭐ **应收与应付配平检验** | 海康：「别人欠公司约 **120 亿元**，公司也欠别人约 **120 亿元**……**总体平衡**」「在产业链上……**基本属于产业链上的相对强势者**」 |
| **Z-19** | ⭐ **票据占比 = 渠道控制力代理指标** | 2015 年营收中所收汇票占比：**洋河 14.4%、茅台 26.4%、五粮液 45.8%、老窖 37.3%、汾酒 48.8%**「这组数据同样可以看出**洋河对现金付款要求最高，对渠道的控制力在几大酒企中遥遥领先**」；⚠️ 脚注提示「汾酒所收票据中，居然有部分**未获银行承兑的商业汇票**——通俗理解，就是买酒企业打的**白条**」 |
| **Z-20** | **类现金资产的严格界定** | 腾讯：「现金及等价物、受限制现金、定期存款、预付款等几个科目归入类现金资产」；「该负债与 1821 亿元类现金资产，可以看作**跨时间、跨空间的套利行为**，差额 **434 亿元为净现金**」 |
| **Z-21** | ⭐ **有息负债为零是加分项** | 洋河：「**有息负债近于零**」「有息负债**几近为零**——财报简单透明」；银行则相反，负债结构是核心（见 Z-30） |
| **Z-22** | **短期借款异常的抵押物追查** | 利亚德：「短期借款有 **19 亿元**，其中一笔是用 **10.1 亿元的存单抵押**借贷，其他大部分是**董事长李军**用自己持有的利亚德股票来做抵押或者担保的」 |
| **Z-23** | **存货结构推测** | 茅台系列酒：「系列酒成本减少 4%，远低于销量减少的比例，推测滞销的系列酒，主要是**成本最低的迎宾酒**」 |
| **Z-24** | **商誉与业绩承诺的绑定** | 宋城六间房：2015 年斥资 26 亿收购，「2015—2018 年的业绩承诺分别为 **1.51 亿元、2.11 亿元、2.75 亿元和 3.57 亿元**，期间承诺利润总和接近 10 亿元」→ 商誉 **23.7 亿元**；「如果未来六间房持续盈利，这部分商誉就始终在报表上；反之……这部分商誉就要做减值」 |

### 2.4 财报读数：同行对比与利益相关（10 条）

| ID | 判据 | 原文要点 |
|---|---|---|
| **Z-25** | ⭐ **坏账/存货计提比例同行横比** | 利亚德：「计提坏账比例**与同行相比偏低**」；「对于其他应收款和存货的计提比例，利亚德同样存在和同行相比计提比例偏低的问题」 |
| **Z-26** | ⭐ **同行业同科目不良率的合理性检验** | 银行：「一般来说，同一行业的大数据覆盖下，不同银行在该行业的不良率通常差距不大（总额较小，受个案影响的除外）。**或许因为公司管理优秀**，某些行业会略好，但**如果一家普通的银行比业内公认的优秀者不良率还低很多，那就很可能在不良认定上尺度过松**」；实例：采矿业招行不良率 **10.68%** vs 民生 **1.72%**；批发零售 **4.13%** vs **3.17%**；制造业 **6.53%** vs **3.7%** |
| **Z-27** | ⭐ **拨备计提比例的注水阈值** | 「就本期计提而言，民生本期计提拨备 **342 亿元**，占贷款余额的 **1.22%**。一般来说，**计提低于 1.5%，可以视为利润注水的特征之一**。招行本期计提占贷款余额的比例为 **1.81%**」 |
| **Z-28** | **「不良/逾期 90 天以上贷款」比值** | 「招行的数值是 **126%**，可以理解为不仅所有逾期 90 天以上的贷款均已归为不良贷款，而且还有约 **120 亿元**的逾期 90 天以内甚至没逾期的贷款也被认定为不良贷款」；「老唐计算（民生的）该数值是 **73.6%**，可以理解为**有大量已经逾期 90 天以上不还的贷款，依然还假装是正常贷款对待**」 |
| **Z-29** | ⭐ **员工人数与薪酬变动方向** | 民生 2017 员工「减少了 **903 人**，主要裁撤的是市场人员和技术人员，这两类合计裁撤 **1113 人**。而这是民生**连续第三年裁人**」；招行「从 70461 人增加至 72530 人，净增 **2069 人**」「员工薪酬总额也增加 **67 亿元**」；「2017 年增加的归母净利 **19.7 亿元**，完全是通过『**龟息辟谷**』大法，尽可能减少活动省出来的」 |
| **Z-30** | ⭐ **负债结构决定成本（银行拆解链）** | 「招行借的钱有 **72.2% 是储户存款**，平均成本只有 **1.27%**，而民生吸引的储户存款只占负债总额的 **54.7%**，且平均成本 **1.76%**」；民生「有高达 **45.3%** 的款项是这样借来的，给的利率 **3.75%**」→ 「民生负债成本 **2.66%**，比招行的 **1.77%** 高出 **0.89%**」；核心机制：「招行吸引的存款有约 **24% 是最低利率的个人活期**，而民生该项数据仅有 **6%**……个人活期存款平均成本仅 **0.37%**，相比到市场借钱的成本 **3.07%**，**仅此一项就节省超过 260 亿元**」 |
| **Z-31** | **贷款结构差异定位** | 招行贷款占比 **58.8%** vs 民生 **46.8%**；「民生在贷款以外的其他领域，收益率都是高于招行的。然而**战术的勤奋不能掩盖战略的遗憾**，在低收益的资产上配置了过重的资源，再怎么努力，结果也不理想。更关键的是，**民生十年来首次在贷款收益率上也输了**」 |
| **Z-32** | **会计口径不一致导致的假毛利率差** | 洋河毛利率 65% vs 五粮液 75%：「洋河是把**消费税计入营业成本**，而五粮液则将消费税单列。2016 年，洋河的营业成本里面包含有 **15.74 亿元消费税**……如果按照五粮液的口径，则洋河营业成本应为 **41.34 亿元**（57.08-15.74），**毛利率同样高达 75%**」；返利口径：「洋河有『经销商尚未结算的折扣 **27.14 亿元**』……按照行业规则给经销商的销售返点，**不计入营业收入**，直接计为欠经销商的债务」，五粮液/老窖/古井贡则「按照全价计入营业收入，然后再将给经销商的返点计入销售费用」 |

> [!warning] 唯一可能造成伤害的一条
> **Z-02 三大前提 + Z-05 三年一倍法，如果被直接套用到转债价格上，是错误的。**
> 原因（结合本库既有纪律）：
> 1. 转债没有 EPS，**PE 无定义**，Z-03「PE 是投资回报率的倒数」在转债上不成立
> 2. 转债的下行保护来自**债底 + 发行人信用**，不是「三年后有人以更高 PE 接手」
> 3. 转债的「三年后卖出」必须先判断届时是**股性、债性还是平衡**，以及**强赎/下修/回售**三条路径
> 4. 「高杠杆企业打七折」（Z-06）在转债上有对应物——**发行人信用资质折扣**，但**折扣基准不是 PE 而是非投机级/投机级评级与担保方式**

**可迁移的只有两条，且都在「发行人信用层」**：
| 用法 | 对应条目 | 说明 |
|---|---|---|
| 三大前提第①条「净利润数据是否为真」 | Z-02 + Z-25 + Z-26 + Z-27 | 筛**发行人**：应收/存货/其他应收计提比例是否同行偏低、是否存在大额其他应收款 |
| 三大前提第③条「是否依赖加大资本投入」 | Z-06 + Z-17 | 筛**发行人**：货币资金异常高但收益率极低、是否依赖持续再融资维持运营 |

**明确不可迁移**：Z-03/Z-04/Z-05/Z-07/Z-08（全部 PE 相关）、Z-32（收入确认口径）、Z-39（PB 仅适用金融企业 —— ⚠️ **对转债发行人反而是最相关的估值工具之一**，但本书给出的是银行专用流程，不可直接套）。
