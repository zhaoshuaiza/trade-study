# 概念：筹码分布（CYQ）

> 把"一只股票在各价位上有多少持仓"画成图，就是筹码分布。
> 核心思想：**价格只是表象，成本才是本质**——看谁赚、谁亏、谁被套，比看 K 线形态更能判断方向。

## 一、这是什么

- **CYQ（筹码分布）**：估算单只股票在所有价位上的**持股量**，用横向条形显示"哪个价位筹码最厚"。
- **成本均线**：以"成本"为权重的均线（区别于普通价格均线），1996 年由陈浩、杨新宇发明。
- 配套工具：博弈 K 线（把"价格涨跌"折算成"筹码盈亏"）、活筹指数、短线盈亏。

## 二、⭐ 核心判据（可落成看盘动作）

| 形态 | 含义 | 动作指向 |
|---|---|---|
| **低位单峰密集** | 成本在低位高度集中，散户割肉、主力接走 | 关注吸筹尾声，等"无量上穿"确认 |
| **高位单峰密集** | 成本在高位集中，散户追高接盘 | 警惕派发，不追 |
| **筹码发散** | 各价位都有筹码，成本涣散 | 方向未定 / 震荡，不轻易判趋势 |
| **低位锁定** | 低位筹码不随上涨而松动 | 主力锁仓、看好后市 |
| **低位无量上穿密集区** | 价格穿越筹码峰却没放量 | 抛压轻、控盘强 → 突破有效 |
| **高位 / 次高位横盘** | 高位筹码峰不降、价格横走 | 派发 / 诱多，准备离场 |

## 三、最实用的三类识别

1. **吸筹完成**：低位单峰密集 + 筹码锁定 + 成本均线向上发散
2. **高控盘庄股**：上述 + 低位高控盘形态（陈浩第11章专述）
3. **受伤庄股**：前期中高控盘 → 受大盘暴跌错杀被套 → 大盘企稳后主力有自救动力（陈浩第9章）

## 四、⚠️ 适用边界与坑

- **时代局限（最重要）**：本书基于 **2000 年前后 A 股庄股时代**。当前机构化、量化化后，
  "纯庄股高控盘"信号**显著弱化**，CYQ 仍可用但权重应降低。
- **不能单独用**：筹码分布告诉你"成本在哪"，不告诉你"何时动"。
  需配合量价（[[sources/量柱擒涨停]]）、趋势（缠论/海龟）使用。
- **可转债慎用**：转债有债底、转股、强赎等自身结构，纯筹码分布视角容易误判（见 [[syntheses/量柱体系在可转债上的适用性]]）。
- **参数时效**：CYQ/成本均线为陈浩自研指标，原书给的是**形态原理**非可调参数；
  现代行情软件自带"筹码分布"，算法细节未必与原书一致。
