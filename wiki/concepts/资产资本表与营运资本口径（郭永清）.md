# 资产资本表与营运资本口径（郭永清）

> ⚠️ **本页最核心的一条：本书的「营运资本」不是通用教材的「营运资本」。**
> 原书原话（第 8 章 8.1.2）：
> 「**在此需要强调一下，本书中的营运资本定义与一般教材中的营运资本定义之间存在差异。**」
> 本页把两套口径并列写出，并给出替代流动比率的新指标。**参数一律原样保留，不改数值。**

## 一、⭐ 营运资本：两套口径并列

| | 通用教材 / 百度百科口径 | **本书口径（郭永清，第 8 章）** |
|---|---|---|
| 广义 | 总营运资本 = 投放在**流动资产**上的资金 | — |
| 狭义 | 营运资金 = **流动资产 − 流动负债**（某时点） | — |
| **本书定义** | — | ⭐ **营运循环中的营运资产 − 营运负债**（净额） |
| 剔除什么 | 不区分是否与经营活动有关 | ⭐ 剔除**未投入循环的金融资产**（交易性金融资产、长期未使用的银行存款）、剔除**与营运活动无关的短期债务**（短期借款、交易性金融负债） |
| 原书批评 | — | 「上述定义未对流动资产和流动负债是否与经营活动有关进行区分……为了更准确地反映公司经营活动情况，我们对营运资本进行了重新定义和界定」 |

> 📌 **本口径来自本书第 8 章 8.1.2，与通用教材不同。**
> 落到动作上：**算营运资本时不要用「流动资产合计 − 流动负债合计」**，而要手工取（存货 + 应收票据 + 应收账款 + 预付款项…）−（应付票据 + 应付账款 + 预收款项 + 应付税费…）。

## 二、⭐ 资产资本表：资产负债表的重构

### 2.1 为什么要重构（原书列的标准表缺陷，8.1.1）

标准表按**流动性**分类的四大缺陷：

1. **资产分类武断主观**：会计准则用「预计」「目的」判断，导致**变现能力更好的股票/债券投资被归入非流动资产，而卖不掉的存货被归入流动资产**。原书评价：「**大谬也！**」
2. **资产分类无法与现金流量表建立清晰联系**：「除了财务会计人员可以自娱自乐外，一般企业管理人员无法理解财务报表」。
3. **负债分类忽略经济活动逻辑**：应付账款（经营活动形成）与短期借款（筹资活动形成）被混在一起，但两者来自不同部门、决策逻辑完全不同。
4. **负债分类忽略是否需要资金成本**：营运负债基本不承担资金成本（且对强势公司「**反而越多越好**」），短期借款/长期借款/应付债券才承担资金成本。

### 2.2 重构后的两张表结构

| 侧 | 科目（本书分类） |
|---|---|
| **资产**（按**带来经济利益的方式**分） | ① **金融资产**（广义：银行存款、其他货币资金、交易性金融资产、持有至到期投资、可供出售金融资产、投资性房地产等，视同「现金蓄水池」）<br>② **长期股权投资**（联营/合营，战略目的）<br>③ **经营资产** = **长期经营资产**（固定资产、无形资产、商誉等）+ **营运资本** |
| **资本**（按**来源和期限**分） | ① **短期债务**（→ 短期资本）<br>② **长期债务**（→ 长期资本）<br>③ **股东权益**（→ 长期资本） |

**等式**：`资产 = 资本`（取代「资产 = 负债 + 股东权益」）

**轻资产 / 重资产的操作性定义（8.2.1，本书自定义）**：
> 「如果在经营资产中，**营运资本需求投入为主且占比较高，则为轻资产公司**；**长期经营资产投入为主且占比较高，则为重资产公司**。」

推论（原书）：重资产公司固定成本高、经营杠杆系数高，**对销售规模增长要求非常高；销售规模略有下滑，将引起净利润更大幅度下滑**。

## 三、⭐ 流动性：弃用流动比率，改用三个新指标

### 3.1 被弃用的两个指标（原值保留，8.4.1）

```
流动比率 = 流动资产 / 流动负债
速动比率 =（现金 + 应收账款）/ 流动负债
```
原书记载的传统理想值：**流动比率至少应大于 1，理想值为 2；速动比率的理想值为 1**。

**本书的否定理由（原话）**：
- 「流动和速动本身是**动态**的概念，但是我们却用**静态的时点数据**来计算。」
- 「如果流动比率和速动比率提高，流动性就提高，那么我们为什么不鼓励顾客尽可能晚地付款……为什么不尽可能多地持有存货？……**上述做法不仅没有提高流动性，而且违背了公司管理的常识和创造价值的目标。**」
- 「**流动**二字的含义，不在于存量的多少，而在于是否能够**流转运动起来**。」
- 前言补刀：「在**工业 4.0 时代**，传统的流动比率和速动比率已经**不能说明任何问题**。」

> ⚔️ **与本库已有冲突的关系**：本库已有 [[claims/流动比率阈值的两种相反主张]]（祖鲁「2.00 或更高彰显实力」vs《一本书读懂财报》「破产前一年恰巧达到 2」）。
> **本书是第三个立场，且不参与阈值之争**——它认为指标本身失效，直接换指标。**三种立场并列，本页不裁决。**

### 3.2 ⭐ 替代指标一：营运资本长期化率（8.5）

```
营运资本长期化率 =（长期资本 − 长期经营资产 − 长期股权投资）/ 营运资本
```

- **分子**：长期资本在满足长期经营资产和长期股权投资后，剩余可用于营运资本的部分。
- **含义**：「营运资本中的长期资本比重越大，公司的流动能力就越强；营运资本『动』得越快，投入越少，公司的流动能力就越强。」
- **改善流动性的三条路（原书）**：① 增加长期资本（长期贷款 / 发行新股 / 减少股利增留存收益）；② 提升长期资产产能与使用效率、减少闲置；③ 提升营运效率、压缩营运资本。
- **⚠️ 指标自身的缺陷（原书明说）**：**营运资本为负数的公司无法用该指标评价**（「我们无法用该指标来分析沃尔玛」）。

> **原书验证案例（文字层可得的结论，无表格数据）**：
> - **万华化学 2011-2015**：营运资本长期化率一路下滑到**为负** → 出现「短融长投」，流动性风险大；同期流动比率/速动比率也一路下降 → 两指标结论一致，本书承认「未能体现营运资本长期化率指标的有效性」。
> - **金风科技 2011-2015**：传统营运资本、流动比率、速动比率**均下降**（结论：流动性变差），但营运资本长期化率从 **127.46% 上升到 293.24%**（结论：流动性改善）；同期应收账款与存货周转次数提升、应付账款周转次数下降 → **营运资本长期化率与周转效率指标结论一致，而传统指标与之矛盾**。这是本书用来证明新指标更有效的核心案例。

### 3.3 ⭐ 替代指标二 / 三：长期融资净值 与 短期融资净值（8.4.4）

```
长期融资净值 = 长期融资 − 长期资产
             = 长期借款 + 股东权益 − 长期经营资产 − 长期股权投资 − 长期营运资本

短期融资净值 = 短期资本 − 金融资产 − 短期波动性营运资本需求
```

| 长期融资净值 | 判定 | 资产资本结构类型 |
|---|---|---|
| **< 0** | 存在短期资本被用于资产长期资金需求 = **「短融长投」** | **激进型** —— 「非常容易陷入财务困境」 |
| ≈ 0 | 匹配 | **匹配型** |
| **> 0** | 长期资本溢出，可覆盖部分短期波动需求 | **稳健型** |

| 短期融资净值 | 判定 |
|---|---|
| **< 0** | 金融资产超过短期资本，现金储备充足 → **稳健型** |
| ≈ 0 | **匹配型** |
| **> 0** | **激进型** |

### 3.4 ⭐ 营运资本是「长期资金需求」，不是短期（本书的关键判断，8.4.4）

原书论证：「多数营运资产和营运负债需要**不断更新、持续循环发生**，具有**长期周转性特征**……只要公司存在，营运资本就存在……**营运资本从资产的变现周期角度看是短期资产，但是从其资金投入需求角度看则是长期资金需求。**」

配套的现实论证（原话）：「很多公司用流动资金贷款满足营运资本需求，流动资金贷款到期后怎么办？**续贷！**续贷再到期怎么办？**再续贷！**……流动资金贷款表面是短期的，其实质是**持续长期贷款**。」

**近似处理规则（原书）**：营运资本可拆为稳定的长期营运资本与波动性短期营运资本；「由于大多数公司的长期营运资本占营运资本总额的绝大部分，因此我们**近似地将所有营运资本视同为长期营运资本**。」

### 3.5 营运资本的三个决定因素（8.4.4）

1. **行业特征** —— 同销售额下，机械制造比百货连锁需要更多营运资本；沃尔玛型为负。
2. **营运效率** —— 效率越高，存货/应收越低，营运资本越少；**效率高到一定程度可为负**（占用上下游资金）。
3. **销售增长水平** —— 「即使效率不变，销售增长也会引起营运资本需求的增长……**初步估计可以认为营运资本需求增长幅度与销售额一样**」。→ 原书警告「**意想不到的销售增长会导致流动性问题**」。

## 四、⭐ 可落成的动作（按 `CLAUDE.md` 4.2）

| # | 动作 | 可验证触发条件 |
|---|---|---|
| **J-01** | **重算营运资本**：取（存货 + 应收票据 + 应收账款 + 预付款项）−（应付票据 + 应付账款 + 预收款项 + 应付税费），**不要用流动资产减流动负债** | 每次分析财报时执行一次；两者差异大 → 说明公司有交易性金融资产或短期借款，通用口径失真 |
| **J-02** | **判产业链地位**：营运资本为负 → 先查长期融资净值是否也为负 | 营运资本为负 **且** 长期融资净值为正 → 产业链强势（优势）；营运资本为负 **且** 长期融资净值为负 → 资产资本结构错配（支付危机，乐视网型） |
| **J-03** | **用营运资本长期化率替代流动比率看流动性** | 营运资本 > 0 时计算；连续 3 年下滑且转负 → 流动性风险上升信号 |
| **J-04** | **查「短融长投」**：算长期融资净值 | 长期融资净值连续为负且绝对值扩大 → 激进型结构，流动性风险累积 |
| **J-05** | **判轻/重资产**：算长期经营资产 ÷ 经营资产 | 占比高 → 重资产；随后**重点盯销售规模**：重资产公司销售略降 → 净利润更大幅度下滑 |
| **J-06** | **查财务杠杆倍数上限** | `财务杠杆倍数 = 资产总额 ÷ 股东权益`；**> 2 倍**触发警示（原书：「对投资者而言，公司的财务杠杆倍数最好控制在 2 倍以内」） |
| **J-07** | **查金融资产占比**：非金融公司金融资产占总资产比例 | 占比过高 → 拉低资产收益率，原书建议动作是**加大现金分红或股票回购** |
| **J-08** | **算有息债务率替代资产负债率** | 本书用 `股权资本比率 = 股权资本 ÷ 资本总额 × 100%`；理由：预收款项、应付账款等经营负债在正常经营下「**越多越好**」，不该计入分母的「负债」 |

## 五、⚠️ 待复核与适用边界

> [!warning] 待复核（2017 年口径）
> - 本书基于 **2015 年年报**与**当时有效的《企业会计准则第 30 号——财务报表列报》**。「可供出售金融资产」「持有至到期投资」等科目在新金融工具准则下**已不存在**；新租赁准则、新收入准则也改变了营运负债与收入的确认。**做重分类时须按当期准则重新映射科目，不能直接照抄本书的科目清单。**
> - 营运资本长期化率的两个验证案例（万华化学 2011-2015、金风科技 2011-2015）为**十年前数据**，仅用于说明指标逻辑，**不代表当前状态**。

- **指标不适用的场景（原书明说）**：营运资本为负的行业/公司**无法用营运资本长期化率**评价流动性。
- **不能做的事**：本页只提供**质地与风险判据**，**不给买卖点、不给仓位、不给任何标的指向**。
- **与 A 股/可转债的关系**：用户对 A 股单边选股，本页的 J-01/J-02/J-03/J-04 可直接用于**个股与转债正股的质地排雷**；其中「营运资本长期化率转负 + 短融长投」对**转债正股的信用风险**尤其直接（转债的债底保护依赖正股不出现流动性危机）。
