# 投资至简·确定性与弹性定仓位

> **一句话**：仓位不是「看好的程度」，是**确定性 × 弹性**的函数。
> 确定性优先于弹性——**弹性再大，确定性有瑕疵 → 不投，或只给小仓位**。

---

## 一、两个变量各自的定义

| 变量 | 含义 | 怎么估 |
|---|---|---|
| **确定性** | 你能**大把握判断公司 5~10 年未来**的程度 | 商业模式 / 发展前景 / 护城河 / 管理质量 四项的清晰度 |
| **弹性** | **预期收益空间** = 业绩增长空间 + 估值折价幅度 | 未来现金流折现值 vs 现价的差距 |

### ⚠️ 术语冲突警告（必须先声明）

> 本书的「**弹性**」= **预期收益空间**，用于**定仓位**。
> 彭道富 [[concepts/弹性价值]] 的「弹性」= **股价对「变化」的反应**，用于**判断会不会涨**。
> **两者同名不同义，跨页引用时必须标明是哪一家的定义。**

---

## 二、优先级：确定性 > 弹性

> 出处：第一章第三节·五。原书主张「确定性优先于弹性」：
> **弹性大但确定性有瑕疵 → 要么不投，要么小仓位。**

### 四象限决策表（由原书原则整理，可直接用）

|  | **确定性高** | **确定性有瑕疵** |
|---|---|---|
| **弹性大** | ✅ **重仓**（这是唯一配得上重仓的格子） | ⚠️ **不投，或极小仓位试探** |
| **弹性小** | ✅ **可持有，但不重仓** | ❌ **不投** |

> 📌 「弹性大 + 确定性有瑕疵」是最诱人的陷阱格子：
> 看起来空间巨大，但你没把握 → 原书给的答案是**小仓位**，不是「重仓搏一把」。

## 三、集中度：三个数字，原样保留

原书在不同位置给了三个略不同的表述，**均照录不改**（这是原作者口径，不做统一）：

| 出处 | 表述 |
|---|---|
| 第一章第三节·八·4 | 「我们的主要持仓标的在 **10 只左右**，且有相对侧重」 |
| 第一章第三节·五 | 「选择 **5~10 家**具有长期竞争力而且价格合适的公司」 |
| 第一章第二节·六（容错机制第 6 条） | 「如果拥有 **5~10 只**，每只股票都看错的概率就会大幅度减小」 |

> **动作**：把 **5~10 只**当作区间，**10 只左右**当作常态；超过 10 只不是分散，是**研究精力不够分**。

## 四、凯利公式的思想来源（不是原书公式，是原书引用的逻辑）

原书用「确定性 × 弹性」表达仓位，其思想对应**凯利公式**：

```
f = (b·p − q) / b
    p = 胜率（≈ 确定性）
    q = 1 − p
    b = 赔率（≈ 弹性 / 赔率倍数）
```

- **p 高、b 高 → f 大 → 重仓**
- **p 低 → 无论 b 多高，f 都很小甚至 ≤ 0（不该投）**

> 📌 这正是「确定性优先」的数学表达：**p 在分母之外，但 p < 0.5 时 f 必为负**。
> 本库另一处使用凯利的是 [[concepts/超额收益·组合构建与仓位规则]]（刘哲也给出 `f=(bp−cq)/bc`），
> **两处公式形式一致，可交叉验证**。

## 五、能力圈：「懂」的可操作定义

| 原书定义 | 出处 |
|---|---|
| 「懂」= **有大把握判断公司 5~10 年的未来** | 第一章第三节·六 |
| 判断的是**未来「经济特征」**，**不是懂产品** | 同上 |
| **不以行业划分能力圈**——「落脚点还是放在能否看懂一家企业的商业模式、发展前景、护城河、管理质量……企业处在什么行业并不重要」 | 同上 |
| 研究要**抓大放小**——「研究茅台，需要对白酒发酵的微生物机理研究很深吗？……把商业模式、发展前景、护城河、管理质量等几个大的问题弄明白就完全足够了」 | 同上 |

→ **动作**：判断自己「懂不懂」只问一句——**我能不能说清它 5~10 年后还怎么赚钱**。
说不清 → 确定性打低分 → 仓位自动降下来。

## 六、风险控制要在买入之前：容错机制七条

> 原书：「**胜而后求战**，而不是战而后求胜。」（第一章第二节·六）

| # | 层级 | 内容 |
|---|---|---|
| ① | 世界观 | 必然性 / 偶然性 / 多重性 |
| ② | 投资观 | 资产形态转化（股权思维） |
| ③ | 纪律 | 只买**能力圈内** |
| ④ | 公司 | 买**确定性高**的好公司 |
| ⑤ | 价格 | 足够**安全边际** |
| ⑥ | 组合 | **适度分散**（5~10 只） |
| ⑦ | 行为 | **不加任何幅度的杠杆、不做空** |

### 原书对「净值止损」的批评（值得单列）

> 点名批评私募「净值跌破 **70%** 的清盘线」式止损：
> 「**连续止损 10 次，本金还剩下多少？**」
> （按 30% 单次损失计算：0.7¹⁰ ≈ **2.8%**）

→ 含义：**机械止损在多次触发后会摧毁本金**；截断风险应该发生在**买入前**（③④⑤⑥⑦），
而不是靠卖出时的止损线兜底。

### 回撤五分类（先分类，再决定动不动）

| 类型 | 是否可避免 | 动作 |
|---|---|---|
| ① 股价随机游走 | **不可避免** | 不动 |
| ② 个股短期情绪回落 | **不可避免** | 不动 |
| ③ 公司业绩回落 | 分长期/短期 | 长期恶化 → 触发卖出标准② |
| ④ 黑天鹅 | 事前不可知 | 事后持续评估 |
| ⑤ **牛市崩塌** | **可能可避免** | **应提前准备**（唯一需要主动防的一类） |

## 七、可执行清单

```
建仓前：
[ ] 给标的的「确定性」打 1~5 分（依据：能否说清 5~10 年怎么赚钱）
[ ] 给标的的「弹性」打 1~5 分（依据：DCF 现值 vs 现价的差距）
[ ] 填入四象限表，确认落在哪个格子
[ ] 若落在「弹性大 + 确定性瑕疵」→ 仓位上限：试探仓（不超过单只上限的 1/4）
[ ] 检查容错七条是否全部满足（尤其 ⑦ 无杠杆、无做空）
[ ] 确认总持仓只数在 5~10 之间

持有中：
[ ] 回撤发生时先分类（五类中的哪一类）
[ ] 只有第 ⑤ 类（牛市崩塌）需要主动应对，其余按兵不动
```
