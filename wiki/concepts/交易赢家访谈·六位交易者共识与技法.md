# 交易赢家访谈·六位交易者共识与技法

> **一句话**：6位风格迥异的赢家，一旦入场就自动切换成「交易者模式」——勤奋(成长)、热情(自由)、严格风控(安稳)、坚持自我(重要感)是跨流派共识；差异集中在系统vs主观、止损逻辑与头寸节奏，本页把6篇访谈蒸馏成可复用的技法与判据。

> [!note] 素材等级
> 《交易心理学》（村居孝美）第7章「交易赢家访谈」6位交易者访谈全文蒸馏。所有「关键结论」均原书照录，人名/方法/数字/引文原样保留并标 [原]；业绩与规模数据依库规 §4.4 标注性质为 **「书中访谈陈述，非独立验证」**。原书引文见 [[sources/交易心理学（村居孝美·NLP交易训练）]]。

## 二、共识一：系统交易 vs 主观/自由裁量判断

六位在「用不用系统」上分成明显三档，但**没有任何一位否认纪律与规则的价值**。

| 流派 | 代表 | 书中原述要点 |
|---|---|---|
| **100%系统型** | 克里斯托弗·斯坦顿 | 「以前以自由裁量为主……现在完全转换成系统型交易，系统型在**自我规范的层面上有其优势**」[原] |
| **系统为主+主观否决** | 肯·雅各扎克、拉里·威廉斯 | 肯：「交易策略还包含一定自由裁量，基本面不好即使系统发买入信号也不交易」[原]；拉里：「虽然我有交易系统，但不会仅依靠交易系统吃饭」[原] |
| **100%自由裁量** | 斯科特·拉姆齐、马克·休赖斯 | 拉姆齐：「全部以我30年交易经验为根据的自由裁量型交易」[原]；休赖斯以套利/刷单的人工经验判断为核心 |

> [!important] 原书关键结论（第7章小结 7.7）
> **「一旦他们开始交易就完全颠覆了平时欲望的优先顺序，都自动转换成『交易者模式』。」** 成功者的重要原因是「明白使用适合自己的方法，苦心钻研，熟知如何下意识地安排这些需求的顺序」——即**方法要适配自己，而不是照搬他人的系统**。

可执行判据（落成动作）：
- **动词+触发**：当准备采用某套系统/方法时 → 先回答「这是否符合我的时间框架、资金规模、个性」三问；若任一项不匹配 → 不照搬，按自身条件改造后再上。
- **动词+触发**：当系统发出信号但宏观/基本面明显不利时 → 类比肯·雅各扎克规则：基本面否决信号则**放弃该笔交易**，不硬做。

## 三、共识二：止损怎么定（各流派原文照录）

这是差异最大、也最有操作价值的一环。逐条原样保留：

### 3.1 拉里·威廉斯——看行情结构，不看价格高低
> [原] 「我认为观察行情应该主要观察当时行情的结构本身，而不是价格的高低。行市结构会告诉我何时退出，也就是止损点的位置。」

- 配套：单场交易心理准备 **1000～1500美元**损失 [原]；每次交易损失控制在 **2%以下** [原]；时间单位以**一个月或两个月**计（小额日间交易不适合他）。
- 判据：**动词+触发**：当要判断止损位 → 先看当下行情结构（趋势/突破形态是否破坏），不把「买入价上方/下方X元」当作止损依据。

### 3.2 斯科特·拉姆齐——专业知识定初损，按基点(BPS)量化
> [原] 「最初的止损点是根据专业知识来决定的……基本上是每笔交易5个或10个基点。当我进行相对有风险的交易时，就采取以10为基点。」（1 BPS=0.1%，10基点=投入资金1%）

- 单笔交易**不承受1%以上**损失；收益多时承受2%~3%风险但会回到1% [原]。
- 判据：**动词+触发**：开仓前 → 用专业知识定初损，普通市况风险≤1%（10 BPS），高风险市况才放到10 BPS。

### 3.3 肯·雅各扎克——按波动性，分档插止损点
> [原] 「止损点位置是根据风险回报来决定的。起决定性作用的是波动性（时间、价格、波动）……这是一天的最高价和最低价的价差幅度统计值。」

- 价差幅度200 → 插**3个止损点**，幅度增大可至**7个**；下跌时在各止损点**逐渐减少头寸** [原]。
- 止损幅度设在平均每场交易额 **0.25%～0.7%**；达 **24～27基点(2.4%～2.7%)** 自动套利 [原]。

### 3.4 克里斯托弗·斯坦顿——系统定止损，头寸越大止损越窄
> [原] 「在系统型交易中，不论是哪个市场都不会允许一天超过1.5%的风险……止损点的位置变化都是由交易系统本身来决定的。」（多市场总计最大限额亦1.5%）

- 头寸大且预计交易次数多 → **相应缩小**止损幅度；反之扩大 [原]。
- 判据：**动词+触发**：当单笔头寸放大或计划连做多笔 → 自动收窄止损幅度，使当日合计风险不破1.5%上限。

### 3.5 马克·休赖斯——节奏止损，「回到原点」
> [原] 「一旦套利就退回到原来的每个月5张合约的交易……一旦开始亏损，觉得规律不对劲时，就迅速撤离。」（曾从200张减到5张）

- 判据：**动词+触发**：当连续亏损或「规律感觉不对」→ 立刻把头寸缩回基础规模（他的基准是5张合约），不扛、不摊平。

### 3.6 齐藤正章——按规则类型定止损，止损即放弃
> [原] 「如果是逆向的话在到期日（天数）时止损，如果是顺向的话，在股价趋势开始向相反方向变动时止损。」「一旦止损就放弃交易。只是，当系统再次发出交易信号时，我当然会听从信号马上下单。」

- 判据：**动词+触发**：当触发止损条件 → 平仓并**放弃该笔**，不手动回补；仅当系统重新发信号才再进场。

> [!important] 原书关键结论（跨访谈共性）
> 六位的止损**没有统一公式**，但全部「先定退出再定进入」：拉里「不仅要事先考虑在哪里开始交易，更加有必要事先想好在哪里结束」[原]。这与 [[三位一体交易策略与资金管理·风险管理是生存关键]] 的「先止损后入场」原则一致。

## 四、共识三：资金管理与单笔风险上限

| 交易者 | 单笔/单日风险上限（原述） | 头寸管理要点 |
|---|---|---|
| 拉里·威廉斯 | 每次交易损失 **<2%**；单场心理准备1000~1500美元 [原] | 不论什么交易**基本用相同张数**（年轻时2张vs50张、50张亏）[原] |
| 斯科特·拉姆齐 | 单笔 **≤1%**（10 BPS）；日终亏损通常控在 **5%以内**、可接受上限10% [原] | 计算风险定头寸；加仓**只加一半**不让风险加倍 |
| 肯·雅各扎克 | 风险回报 **3:1**（亏1%期望赚3%）；头寸/保证金比率 **4%~6%**、最多9%~11% [原] | 基本保证金管理；07年前后改按波动率减头寸 |
| 克里斯托弗·斯坦顿 | 单日风险 **≤1.5%**；可用资金最多损10%（实际5%~7%）[原] | 6类资产组合：农产品16%/货币18%/能源13%/股票19%/利息18%/贵金属16% |
| 马克·休赖斯 | 不预设百分比，强调「**稳健/安全第一**」[原] | 行情顺则扩头寸；亏损即退回5张基准 |
| 齐藤正章 | 单笔上限=固定资产 **1/18 或 100万日元较小值**；超20%年跌不可接受 [原] | 信号日成交总额≤0.5%、收盘单≤0.2%；**非动态资金管理** |

> [!important] 原书关键结论
> **拉里·威廉斯**：「要想在交易市场立足，**资金管理是最重要的**。对于交易者来说最好的书是关于资金管理的书。」[原] 肯·雅各扎克以「连贯性（稳定回报）」为终极目标，斯坦顿称「**最关键的是自我规范**」，齐藤正章把「风险管理」列为给正能量的头号积极词——**风控是六位共同的第一优先级**。

可执行判据（落成动作）：
- **动词+触发**：开户/建仓前 → 先算「这笔最多能亏多少」再反推头寸，禁止先定想赚多少再定仓位（齐藤「不要奢望高于系统的收益」[原]）。
- **动词+触发**：当一笔盈利后想加仓 → 仿拉姆齐「只加一半」：原1单位→加0.5单位，使总风险不翻倍。

## 五、共识四：心理训练与自我规范

| 交易者 | 心理/自律技法（原述） | 可执行判据 |
|---|---|---|
| 拉里·威廉斯 | 把心理学**系统脱敏法**用于交易：反复刺激克服恐惧；交易中当「悲观主义者」只对头寸 [原] | **动词+触发**：当对某头寸过度自信 → 主动设想「真的还要接着赌下去吗、放弃是否更好」，用悲观预设压住狂热 |
| 斯科特·拉姆齐 | 看重「**自我规范**和**风险管理**」；不公开高收益目标，只问「战略/风险管理正确吗、行情如预期吗」[原] | **动词+触发**：当想对外宣布高收益目标 → 改为只核查「策略对不对、风险可控否」两问 |
| 肯·雅各扎克 | 练冲绳空手道「锻炼忍耐跌幅的强劲体魄」；公开目标给员工家人反而无压 [原] | **动词+触发**：当陷入消极 → 用体能训练（运动/武术）恢复，不靠酒精 |
| 克里斯托弗·斯坦顿 | 亏损后**全盘重检系统**而非低落；每天健身房1小时；不公开收益目标免压 [原] | **动词+触发**：当单日亏损 → 不情绪化，按系统日志逐市场查盈亏归因 |
| 马克·休赖斯 | 「**稳健**」为交易最重要；亏损也保持积极（否则被他人压倒）；回家洗澡第二天照常 [原] | **动词+触发**：当大亏当天 → 做完动作（回家/洗澡/睡眠）切断反刍，次日重置 |
| 齐藤正章 | 「**绝对服从系统**」；挑战100公里马拉松保持精神健康；每年只修正一次系统 [原] | **动词+触发**：当想手动 override 系统信号 → 默念「平均下来服从规则更好」，除非到年度修正窗口否则不动 |

> [!important] 原书关键结论（第7章小结 7.7）
> 交易赢家的共性情感排序：**勤奋(成长)、充满热情(自由)、严格管理风险(安稳)，且最重要的是不在乎别人看法、坚持自己观点(个性=重要感)**。只求眼前利益者因知识技术不足而永远无此积极欲望。

## 六、各自最强调的一条（1-2个最高操作价值技法）

> 每条落成「动词+触发条件」可执行判据，便于看盘时直接调用。

1. **拉里·威廉斯**——止损看结构不看价位
   - **动词+触发**：当设止损 → 以行情结构（突破/趋势线/形态破坏）为退出依据，不以「买价±N元」机械定停。

2. **斯科特·拉姆齐**——加仓只加一半
   - **动词+触发**：当行情顺、与调查一致想加仓 → 原1单位加**0.5单位**；禁止「涨了就买2张使风险翻倍」。

3. **肯·雅各扎克**——风险回报3:1才出手
   - **动词+触发**：当评估一笔交易 → 预计亏损1%须有望赚≥3%才开仓；否则放弃。

4. **克里斯托弗·斯坦顿**——单日风险封顶1.5%+小单试错
   - **动词+触发**：当多市场同时持仓 → 合计当日风险≤1.5%；新策略/新市场从**1张合约**起步，验证后再递增加。

5. **马克·休赖斯**——回到原点(5张基准)+一天只抓3次机会
   - **动词+触发**：当连亏或节奏乱 → 头寸退回基础规模（他的5张），重新从原点积累；对个人投资者：**放弃刷单、瞄准3秒以上差价而非1秒**，更精准读图表。

6. **齐藤正章**——绝对服从系统+单笔1/18或100万日元较小值
   - **动词+触发**：当系统发信号 → 头寸=固定资产1/18与100万日元取小者；**每年仅一次系统修正窗口**，平时信号即纪律，不手动干预。

## 五、边界与坑

> 注：为避免与上方「共识章节」编号冲突，本节沿用模板的「五、边界与坑 / 六、关联」收尾结构；正文共识分章编号为二~六。

1. **访谈为个人经验，非普适法则**：六位风格迥异，方法高度依赖其资金规模、市场（商品/货币/国债/日股）、时代语境；直接照搬拉里·威廉斯的「相同张数」或斯坦顿的「1.5%单日上限」未必适配你的账户。
2. **日美/期货语境不可直接迁移 A 股**：书中市场为美股期货、CME/G7货币、CBOT谷物国债、日本个股；参数（BPS、保证金比率、合约张数）与 A 股（T+1、涨跌停、无保证金杠杆交易）机制不同，**只迁移「先定退出、按风险定头寸、系统服从」的方法论，不迁移具体数值**（库规 §4.1：参数原样保留仅作参考，不以「更适合A股」为由改值）。
3. **业绩数据不可当验证战绩**（§4.4）：18.12%、6000%、40%、5.5亿美元等均为访谈自述，未独立审计，引用须标注「书中访谈陈述」。
4. **系统≠万能**：肯·雅各扎克、齐藤正章都保留「基本面否决/年度修正」空间；纯系统交易者斯坦顿也强调「自我规范」是人的责任——**系统管信号，人管风险与状态**。
5. **不给投资建议**（库规 §4.5）：本页不含任何具体标的、买卖点、收益承诺；所有技法均为方法论层面的可执行判据。
6. **「适合自己」优先于「看起来厉害」**：原书小结明示成功源于「用适合自己的方法」——他人高收益系统若不匹配你的个性/资金/时间，强用反而有害。
