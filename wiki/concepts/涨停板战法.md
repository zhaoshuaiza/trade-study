# 概念：涨停板战法（黑马王子量学体系）

> A 股独有的 **±10% 涨跌停板**制度（转债 ±20%）催生了"涨停板战法"这一专门流派。
> 黑马王子（张得一）的"量学"是其中体系化最完整的一支：
> **从量柱形态发现涨停基因、从量级变化发现涨停前兆、从量性转化发现涨停先机**。

## 一、底层逻辑（四大定律 + 三原理）

**四大涨停定律**（原书第1章，明确表述）：
1. 凡是涨停板，必是**人为的**（非随机）
2. 凡是人为的，必然有**踪迹**
3. 凡有踪迹，必然有**规律**
4. 凡有规律，必然可**复制**

**三个基本原理**（"庄在散先、价在量先、卖在买先"）：
- 庄在散先：先看主力动作，再读散户反应
- 价在量先：价格变化领先于成交量信号
- 卖在买先：从"谁在卖"反推"为什么卖"

> 📌 这是"伏击涨停"而非"追涨停"——盘前预报、等待确认，而非盘中追高。

## 二、⭐ 可执行判据框架（PTALT 模型）

黑马王子构建了 **PTALT** 模型：以伏击涨停为核心理念，以**量柱、量线**为系统工具，
四大定律 + 十八种伏击技法（原书目录明确列举的战法名）：

| 战法（原书章节名） | 一句话动作指向 |
|---|---|
| **金线战法**（黄金柱 / 黄金线） | 找"黄金柱"→ 沿黄金线低吸，线破即走 |
| **黄金双线战法** | 设置两条关键线，双线收敛处为伏击点 |
| **黄金十字战法** | 量价交叉点作为启动信号 |
| **长阴短柱战法** | 长阴线 + 缩量 = 洗盘而非出货，关注次日 |
| **倍量伸缩战法** | 倍量柱伸缩处往往是启动前兆 |
| **大盘阴线战法** | 大盘出阴线时的个股逆势信号 |

> 上述具体形态的细节定义（假阴真阳、长阴短柱、长腿踩线、价升量缩、涨停基因等）

## 三、可落成动作的检查清单

1. 盘前扫描：找**黄金柱 / 倍量伸缩 / 长阴短柱**形态的候选股（非盘中追高）
2. 画线：标出**黄金线 / 双线**，只在其附近伏击
3. 确认：等"涨停基因"组合出现（价升量缩、假阴真阳等，详见关联页）
4. 离场：黄金线破位即走；达到预期涨停数后不再恋战

## 四、⚠️ 适用边界与坑

- **仅 A 股 / 可转债有效**：依赖涨跌停板制度，美股/港股/期货无此结构，**不能用**。
- **T+1 约束**：A 股当日买入不能当日卖，伏击次日才能离场 → 必须预设退出线（黄金线破位）。
- **转债差异**：转债 ±20% 且 T+0，涨停板战法在转债上节奏不同，需单独验证（见 [[syntheses/量柱体系在可转债上的适用性]]）。
- **游资风格 ≠ 价值投资**：这是**短线博弈**，与缠论/海龟的趋势持有逻辑冲突，
  用哪套见 [[syntheses/体系适用性矩阵·股票与期货]]。
- ⚠️ **监管风险**：原书提倡的"盘前预报涨停"若演变为公开荐股/群推送，触碰监管红线；
  本库仅作个人方法论研究，不给任何人荐股（CLAUDE.md 4.5）。
