# 拓扑 U 型

> U 型不是训练出来的缺陷，而是因果解码器 + 残差连接的**几何必��**。

## 核心主张

**U 型曲线在随机初始化时即已存在**——在任何训练或位置编码生效之前。
它是一个推理理论对因果解码器结构的必然结果。

这直接挑战了两个主流解释：

| 旧解释 | 问题 |
|---|---|
| 习得的 Softmax 工件（attention sink 类） | 若为习得，则应随训练改变 |
| 位置编码的距离衰减（RoPE 类） | **实验证明有无 RoPE 结果一致** |

## 数学推导链条

**第一步：多层因果注意力 = Cesàro 矩阵的迭代幂**

```
M[i,j] = 1/i   (对 j ≤ i)，否则 0
```

含义：token i 在初始化时对前 i 个 token 做**均匀平均**——
因为权重随机，注意力分数本质均匀。

**第二步：加入残差连接**

```
N = (1−α)I + αM        α ∈ [0,1]
```

`I` 是恒等矩阵，代表残差能让信号**完全跳过**注意力层。
这一步是关键的——见下文「理论演进」。

**第三步：推导影响密度闭式解**（连续极限下）

得出从早期位置 j 的信号如何影响 H 层网络末端输出。

## 三个关键结构

| 结构 | 名称 | 数学性质 | 物理含义 |
|---|---|---|---|
| 序列起始端 | **Primacy Tail**（首因尾部） | 梯度影响的**对数发散** | 早期 token 跨层累积，优势不断放大 |
| 序列末端 | **Recency Delta**（近因增量） | 孤立的 **O(1)** 锚点 | 最后一个 token 保留原始表示 |
| 两极之间 | **阶乘死区** | **O(1/(H−1)!)** | 中间 token 结构性劣势 |

**H 是网络深度。死区宽度随深度阶乘级扩张。**

## 为什么中间特别糟

中间 token 既没有首因的**累积优势**（每层都被反复处理），
也没有近因的**新鲜度优势**（直接残差通路）。
它们的信号路径被**混合稀释到阶乘级**。

用一句话概括：
> 早期 token 有「反复加工」的保护状态，最近的 token 有「新鲜度」优势，
> 中间的 token 两样都没有。

## 实验验证

| 验证项 | 结果 |
|---|---|
| 随机初始化的 **Qwen2** 与 **GPT-2** | **Step 0 即呈现 U 型** |
| 有无 **RoPE** | **完全一致** |
| 初始化 vs 预训练网络对比 | **标准训练未能克服拓扑谷** |

## 理论演进（三篇论文的接力）

**1. Xiao et al. 2023 —— Attention Sinks**
首次实证：早期 token 因位于自回归链根部而**不可避免地吸收大量概率质量**。
但只是现象描述，未给结构解释。

**2. Wu et al. 2025 —— 图论方法**
证明因果掩码创建**非对称有向无环图**，早期 token 位于
**指数级更多的计算路径**上，驱动随深度增强的首因偏置。

**其缺陷被诚实指出**：在纯注意力设定下（无残差），
其模型预测注意力**完全塌缩到第一个 token**——即纯首因，
**无法解释实测的 U 型**。该矛盾被原作者列为开放问题。

**3. Herasimchyk et al. 2026 —— 残差感知注意力 rollout**
证明因果掩码诱导首因、**残差连接诱导近因**，
预测的影响曲线与预训练模型达到 **Spearman 相关 0.88–0.98**。

**4. 本文献（Chowdhury, 2026）—— 精确闭式理论**
引入残差连接**挽救了近因锚点**，生成完整的拓扑 U 型。
与 Herasimchyk 的区别：后者需要训练后模型的参数，
本理论推导的是**随机权重下初始化时的闭式密度**，无需任何训练参数。

## 作者明确的边界

论文**不主张**：
- 该偏置不可逾越
- RoPE 修改之类的干预无用
- 雅可比范数直接度量检索准确率

论文**主张**的是：确立基线及其来源，
使后续克服它的努力可以**精准定位**。

## 对知识库既有内容的修正

**重要修正：上下文长度与偏置的关系需要更精确的表述。**

先前 [[中间遗忘]] 记录的是「上下文越长，退化越严重」（经验现象，
Liu et al.）。本理论提供解释但需注意区分两条路径：

- **阶乘死区**随网络深度 H 扩张——这是**静态的结构性质**
- **经验上**的「越长越差」还叠加了 RoPE 类外推衰减

理论证明的是**深度**带来的死区，**不是长度**直接导致退化。
两者常被混为一谈，但严格说：死区的绝对宽度由深度决定，
而位置在序列中的**相对位置**决定落在死区的哪一段。

**因此更准确的说法是**：不是「上下文越长越错」，
而是「无论多长，落在中间的那部分始终处于劣势；越长则中间段占比越大、
落入阶乘死区的 token 越多」。
