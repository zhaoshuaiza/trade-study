# 双阴出货

> **全库最简单、最直接、最可机械执行的离场技法。**
> 不需要黄金柱，不需要谷底线，**只看两根阴线的关系**。
>
> 原文自评：「非常简单、非常直观、非常有效的出货技法。」

---

## 一、定义（原文）

> 「所谓'双阴出货'就是'**在碰到连续两个阴线时出货**'。」

### ⭐ 判据（可机械复核）

```
① 出现连续两根阴线
② 第二根阴线「有效跌破」第一根阴线的收盘价（含持平时）
   → 立即盘中出货
```

**「中轴线」** = 前一交易日收盘价，
是判断「是否跌破」的基准线。

> 📌 **可执行判据**：
> ```
> 次日阴线收盘价 ≤ 前日收盘价（持平也算）
>   → 出货
> 次日阴线收盘价 > 前日收盘价
>   → 继续持有
> ```

---

## 二、⚠️ 关键细节：包含「低开高走的假阳线」

> 「注意，应**包括'低开高走的假阳线'**。」

这是最容易漏的一条。判定**不看K 线颜色，看实际走势**：

```
昨日阴线 → 今日低开高走（K 线可能是阳线/十字）
   但最高价未能与昨日收盘价持平
   → 一旦跌破中轴线 → 仍然算「双阴」→ 出货
```

| 情形 | 是否算双阴 |
|---|---|
| 两根真阴线，第二根跌破前收盘 | ✅ 算 |
| 昨日阴 + 今日**低开高走假阳**，跌破中轴线 | ✅ **也算** |
| 昨日阴 + 今日真阳且站上前收盘 | ❌ 不算 |

> ⭐ **这条实质是：只看「有没有跌破前收盘价」，不看颜色。**
> 与 [[concepts/黄金劫与凹口淘金]] 的「假阴真阳」是同一类思路 ——
> **K 线形态会骗人，价格位置不会。**

## 三、原文的四个实盘标记（指数实例）

作者给上证指数 2009-12-04 至 2010-06-18 全程标注「双阴出货线」，
声称「只要是符合条件的'双阴'，**闭着眼睛出货都是对的**」。

| 情形 | 盘面特征 | 原文判读 |
|---|---|---|
| **A 点**（2009-12-09） | 低开 38 点，**当天最高点也未能与前一日收盘位持平** | 一旦在最高位掉头跌破中轴线 → 出货 |
| **B 点**（2009-12-16） | 低开 19 点，上攻 3299 点但**回落至前收盘时保平无望** | 跌破中轴线 → 出货 |
| **C 点**（2010-01-07） | 平开，稍过前收盘即回落，**两波上攻均未突破中轴线** | 第二波上攻乏力时出货 |
| **D 点**（2010-01-26） | 稍高开即一路下滑，**始终没冲过前收盘位** | 三个高点**全在中轴线下方** → 出货 |

> ⭐ **提炼出一条更硬的辅助判据**：
> **全天所有高点都在中轴线（前收盘）下方** → 弱势确认 → 出货。
> 原文在D 点的分时图上明确写：**「逐波低于人线看跌」**。

## 四、⚠️ 与缠论止损的对照（哲学不同，不选边站）

| | 双阴出货 | [[claims/三种止损方法的适用边界]] 缠论结构止损 |
|---|---|---|
| 依据 | **两根阴线的价格关系** | **走势结构**被破坏 |
| 触发 | 第二根阴线跌破前收盘 | 走势类型完成/破坏 |
| 输入 | 只有 2 根K 线 | 至少三段次级别走势 |
| 可执行性 | ⭐ **极高**（一眼可判） | 需判断级别 |

> 📌 **这是本库中最「机械」的一个离场判据**，
> 与 [[claims/三种止损方法的适用边界]] 记录的「结构止损 vs 2N」互斥问题**不同层次**——
> 但两者**可能给出相反动作**：
> 双阴出货会叫你走，缠论结构未破可能还在持有。
>
> **取舍由用户拍板，本库不选边站。**

### 与量柱体系其他判据的关系

| 判据 | 用法 |
|---|---|
| [[黄金线]] 破位 | **防守线破了才走**（慢，会回补） |
| **双阴出货** | **两根阴线就走**（快，牺牲回补） |
| [[黄金劫与凹口淘金]] 洗盘识别 | 用来判断「该不该走」——**跌得多而量不动 = 别走** |

> ⭐ 三者的关系：
> **双阴出货负责「无条件走」，黄金劫负责「识别例外」。**
> **两者冲突时，以「是否缩量」为裁决键。**

## 五、实战检查清单

- [ ] 昨日是否为阴线（或低开高走的假阳）？
- [ ] 今日是否**跌破或持平于**昨日收盘价（中轴线）？
  - 跌破/持平 → **出货**
  - 站上→ 持有
- [ ] 今日**最高价**是否曾触及中轴线？
  - 全天未触及 → ⭐ **弱势确认，更应走**
- [ ] 是真阳线还是**低开高走的假阳**？（假阳也算数）
