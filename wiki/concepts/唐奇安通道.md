# 唐奇安通道

> 只捕捉趋势启动瞬间的机械触发信号。

## 一、是什么

以**过去 N 日最高价/最低价**作为通道，突破即入场。

```
上轨 = 过去 20 日最高价
下轨 = 过去 20 日最低价
收盘价突破上轨 → 次日开盘做多
收盘价跌破下轨 → 次日开盘做空
```

---

## 二、海龟体系里的两个系统（✅ 原文参数）

原文对比了**两个**唐奇安变体，注意区分：

| | **唐奇安趋势系统** | **定时退出唐奇安系统** |
|---|---|---|
| 入场 | 20 日突破 | 20 日突破（同） |
| 出场 | **10 日反向突破** | **持有 80 天后无条件退出** |
| 趋势过滤 | **350 日/25 日指数移动平均** | 同 |
| 止损 | **2N（2ATR）** | **无任何止损** |
| 定位 | 原版海龟的简化版 | 用来验证「退出策略有多重要」 |

**趋势过滤规则（可执行）**：
> 「交易者们严格遵守短期移动均线所指示的方向：
> **如果 25 日均线在 350 日均线之上，只能做多**；如果 25 日均线在 350 日均线之下，**只能做空**。」

> 📌 这是**硬性方向锁**——不满足条件时**不开仓**，而不是"少做"。
> 区别在于：方向锁让你在下跌趋势中连反弹都不参与。

**⚠️ 注意「2ATR 止损」与原版的关系**：
原文明确写「这个系统还规定了 2ATR 的止损退出点，
**这与原版海龟系统相同**」——即 **2N 止损来自原版海龟**，不是这个简化版自己加的。

## 三、⚠️ 费思的实测发现（重要，与直觉相反）

> 「请注意，**唐奇安系统的表现不如其他系统**。这说明，
> **突破法在海龟计划实施之后的岁月中已经丧失了一些优势**。」

作者的归因：
> 「我认为这在很大程度上是**交易者效应（trader effect）**造成的。」

**含义**：**大家都用同样的突破法，优势会被磨平。**

> 📌 这是本书最反直觉的发现之一，也解释了为什么海龟的规则不能简单照搬。

而「定时退出唐奇安」（同样是突破入场，只改了出场）**表现好于**突破退出：
> 「一个系统的赢利能力并不完全依赖于一个有优势的入市策略。」

详见 [[concepts/止损的争议]]。

## 四、原版海龟的完整突破规则（pending）

## 五、可执行判据

| 判据 | 动作 |
|---|---|
| 突破是否确认 | 原文用**收盘价**穿越，次日**开盘**执行 |
| 什么时候不做 | 25 日均线在 350 日均线下方 → **禁止做多**（反之亦然） |
| 出场 | 按采用的变体二选一：10 日反向突破 / 80 天定时（不可混用） |
| 单一指标优势 | 别假设「突破一定比均线好」——原文实测唐奇安系统**输给**简单均线系统 |
