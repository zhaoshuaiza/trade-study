## 放什么

**抽象名词**——任何体系里出现的概念、方法、结构、指标。

| 体系 | 概念举例 |
|---|---|
| 道氏 | 主要趋势、次要趋势、短期波动 |
| 波浪 | 推动浪、调整浪、浪的嵌套、失效规则 |
| 缠论 | **中枢**、走势类型、级别、背驰、三类买点 |
| 海龟 | **ATR与N值**、唐奇安通道、**仓位管理**、组合热度 |
| 黑马王子 | 量柱、量线、量价背离、涨停板战法 |

## 判断标准

> **能指着它说「它就是这个东西」吗？** 不能 → concepts

- 「中枢」→ 不能，它是抽象结构 → concepts ✅
- 「缠论」→ 能，它是一套体系 → entities

⚠️ 与 [`../entities/`](../entities/) 的区别就在这一问。

## 概念页怎么写

必备内容：定义、核心特征、为什么重要、关系。

**交易概念的特殊要求**：

按 `CLAUDE.md` 4.2，概念必须能落成动作：

| ❌ 无用 | ✅ 可执行 |
|---|---|
| 「严格止损」 | 「单笔亏损达净值 2% 时无条件平仓，止损单与开仓单同秒提交」 |
| 「顺势而为」 | 「收盘价站上 20 日最高价时进场，跌破 10 日最高价时离场」 |
| 「量价背离」 | 「成交量创新高但价格未创新高，视为顶背离，减仓一半」 |

> **沉淀标准：动词 + 可验证的触发条件。**

**参数原样保留**（见 4.1）：如果概念里含具体数值，标注出处，
不要用「更适合 A 股」当理由悄悄改。
