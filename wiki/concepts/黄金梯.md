# 黄金梯

> **[[黄金柱]] 的空间展开形式。**
> 有了它，[[concepts/黄金柱]] 的「以二测四」才有前提；
> 梯形的**疏密节奏**直接预告该股走强还是走弱。

---

## 一、是什么（原文定义）

> 「所谓'黄金梯'，就是**依托'黄金柱'的支撑，踏着'黄金线'的节律，
> 一级一级上台阶，逐步升级、逐步登高的阶梯**。」

```
黄金柱（支柱） + 黄金线（踏板） = 黄金梯
```

---

## 二、⭐ 三个特征（合格判据）

原文：「好的'黄金梯'**必须**具有三个特征」。

| # | 特征 | 硬标准 | 违反后果 |
|---|---|---|---|
| **1** | 至少**三根黄金柱**做支撑 | 低于 3 根「很难做好黄金梯」；**黄金柱越多，梯越好** | 结构不可靠 |
| **2** | 黄金线**不被有效击穿** | **收盘价低于黄金线的价柱不能连续三天以上** | 梯形断裂 |
| **3** | 每道黄金线左侧有**峰顶支撑** | 形成「一级高一级」的明显台阶，**台阶间隔以逐步加大为好** | 缺乏杠杆 |

> 📌 原文补充：黄金线**可以借助其他「将军柱」的力量形成合力**，
> 运用得当会有「一重天地一重景象」的效果。
> 即：不是每级台阶都必须是黄金柱，将军柱也能参与接力。

---

## 三、画法三步（原文给的初学者路径）

```
第一步  找各阶段的「将军柱」，用红箭头标记
        （一般是倍量柱、高量柱、平量柱、梯量柱）
第二步  从将军柱中筛出「黄金柱」，按 concepts/黄金线 的画法标出黄金线
第三步  在黄金柱下方画一条竖线，形成「⌐」形标记
```

> 原文：「一旦熟练之后，**仅用水平线就能看清黄金梯的走向和级别**。」

### ⭐ 这套阶梯包涵了主力操盘全过程

原文以浪潮软件（600756）7根量柱的阶梯为例，指出从左至右
**几乎包含主力操盘做市的全过程**：

```
试探 → 建仓 → 增仓 → 补仓 → 震仓 → 启动 → 拉升
```

> 📌 **可执行**：数一数梯级数，就知道主力走到哪一步。
> **最后一根量柱价涨量缩 → 次日必有涨停**（原文称从未失误）。

**实证**：浪潮软件 2009-04-07 预报，当日涨停后连拉 6 个涨停；
按 4/7 最高价 8.93 × 2 = 17.86 元，4/20 最高摸到 **17.88 元**。

## 四、⭐⭐ 三种梯形（核心判据）

**这是本页最有价值的部分** —— 梯形决定该股是黑马还是落后大盘。

| 梯形 | 特征 | 含义（原文判断） | 应对 |
|---|---|---|---|
| **前紧后松型**<br>（递减阶梯） | 阶梯间隔**逐步加大** | 「主力在前面炒作中**基础打得扎实，筹码准备充分**，往后拉升将令人膛目结舌」 | ⭐ **重点参与** |
| **前松后紧型**<br>（递减阶梯） | 阶梯间隔**逐步缩小** | 「主庄往往**前期猛打猛冲，到后期捉襟见肘**」 | ⚠️ **涨幅落后大盘，及时换掉** |
| **前后紊乱型** | 「松松垮垮，七扯八拉」 | 「庄家**没有实力、没有谋划**」；或新老庄家更替；**或庄家已撤离** | ⛔ **跟着迟早倒大霉** |

> 📌 原文比喻：「**看梯形就好比看庄稼，初期就有好苗子，后期定有好收成。**」

### 可执行判据

```
台阶间隔逐步放大 → 前紧后松 → 最强 → 持有
台阶间隔逐步缩小 → 前松后紧 → 走弱 → 换股
台阶无规律/杂乱    → 紊乱    → 无主力 → 离场
```

## 五、与[[黄金柱]]测幅的衔接

[[concepts/黄金柱]] 第四节给了测幅算式，但**明确写了前提**：

> 「从位置上看，**黄金梯上的黄金柱**，具有双倍测幅功能。」

**⚠️ 关键限制（此前未说清，本次补上）**：

```
① 只有在「黄金梯」上、且在梯级上的黄金柱才具备测幅功能
② 必须先有 ①②③④ 五个梯级（原文举例的实例是中茵股份）
③ 计算对象是「以第②级测第④级，以第③级测第③级，以第④级测第…」以此类推
```

**实证**：中茵股份第 ② 级底线（D 柱最高价）3.98 元 → 测第 ④ 级 = 7.96 元，
实际 M 柱收盘 **8.06 元**，误差 1%。

> 📌 **所以「黄金柱×2」不是万能公式**——
> **梯级结构不存在时，不要硬套。** 这是本页对 [[concepts/黄金柱]] 的关键补充。

## 六、实例拆解：长力股份（600507）

原文 2009-03-25 预报、03-26 介入的案例，完整演示了「洗盘识别」：

| 天 | 现象 | 原文解读 |
|---|---|---|
| 第1–2 天 | 连续调整，**股价未跌破倍量柱的 2/3**，量能呈**1/3 递减** | 「非常狡黠的庄家，明显是**洗盘**」 |
| 第3 天 | 量柱缩小，股价回到倍量柱 **1/2** 处 | 洗盘继续 |
| 第4 天 | 价涨量增，冲过倍量柱最高价 → 形成第二根倍量柱 | 拉升 |
| 第5–6 天 | **重演**第2–3 天洗盘，量柱逐步缩小 | 主力复制手法 |
| 第7 天 | 小涨，量柱明显缩小 → **构成黄金柱** | 「**双重黄金柱**」 |
| 第8 天 | **再次巨阴洗盘**，但量柱比前面都小 | 「有双重保险，**必然强力洗盘**」 |
| 第9 天 | **突然拉至涨停** | 「重要的启动信号」 |
| 第10 天 | **高开 6 个点**，涨到 8 个点回调收集浮筹 → **巨阴巨量** | ⭐ **假阴真阳**：最低价仍在前一日涨停板之上 |

**结果**：自 4/14 讲座点评起，4.20 元涨到 10.44 元，含 4 个涨停板，
达成第一目标 4.20×2 = 8.40 元（实际高出 0.09 元）。

> ⭐ **原文最值得学的一点**：
> 第 10 天的「巨阴巨量」被判定为**假阴真阳**——高开低走但最低价守在前涨停板之上。
> **只看收盘涨跌会看错，看「最低价 vs 前涨停板」才看得准。**

## 七、实战检查清单

- [ ] 数出梯级数 —— **≥3 级**才算合格黄金梯
- [ ] 每级黄金线是否都**未被连续 3 日收盘价击穿**？
- [ ] 每道黄金线左侧是否有**峰顶支撑**？
- [ ] **台阶间隔是逐步加大（强）还是逐步缩小（弱）？**
- [ ] 梯级是否杂乱无章（→ 离场）？
- [ ] 当前走到第几级（试探/建仓/增仓/补仓/震仓/启动/拉升）？
- [ ] 最后一根量柱是否**价涨量缩** → 次日涨停信号
- [ ] 要做测幅：**梯级结构存在吗**？不存在则不用 ×2
