> 编译自唐朝《手把手教你读财报.2，18节课看透银行业》（中国经济出版社，2017年1月第1版，ISBN 978-7-5136-4559-1）。
> 全书以工商银行（SH.601398）2015年报为贯穿案例，共十八课 + 序 + 阅读提示 + 前言 + 参考文献 + 后记，源文件 4922 行，**已 100% 通读**。

## 一、覆盖范围与诚实声明

**本书是本库中少见的"行业专属财报读法"教材**：不是通用财务报表教学，而是把通用财报方法论落到**银行业这一个行业**上，给出了该行业几乎全套可计算的监管指标公式。

**必须先说清楚的三件事：**

1. **本书不是交易方法论书。** 它教你的是**每年读财报时该看哪些数、怎么算、怎么交叉验证**。这属于"选股/持股跟踪"环节，**不是"看盘时用得上的动作"**。因此本书的内容绝大多数**不能直接进入本库的技术/择时层**，只能进入"基本面研究层"。本页据此做了严格的三层切分（见第二节）。
2. **所有指标都是年度/季度频率的。** 不存在任何日线/分钟级信号。任何试图把"拨备覆盖率""净息差"当日内择时指标的用法，都是对本书的误用。
3. **本书的监管参数有时间锚点，全部是 2016 年之前的版本。** 书中明确援引的《资本管理办法》（银监会2013年实施）、《商业银行风险监管核心指标（试行）》、MPA体系（2015年12月29日发布、2016年起考核）等，**截至本书写作时点（2016年）仍在过渡期**。多年后是否已修订，原文未给，本页不做推测。**实际使用前必须回到现行监管文件核对。**

**时间锚点：**
- 案例数据锚点：工商银行 2015 年度报告（2016年3月披露）
- 行业数据锚点：银监会年报截至 2015 年底
- 宏观数据锚点：2016年6月/2016年8月（第十六课估值演示案例"站在2016年8月底回看"）
- 作者完稿：2016年12月27日，成都

#### 2.1.1 拨备变动恒等式（原文原样保留）

```
期末减值准备余额 = 期初减值准备余额
                 + 本期减值损失
                 - 已减值贷款利息收入
                 - 本年核销
                 + 收回以前年度核销

其中：本期减值损失 = （本年新增 - 本年回拨）
本年划转不影响拨备总量、不影响资产负债表与利润表
```

**原文用工商银行 2015 年报完整演算了一遍（原值照抄，单位百万元）：**
- 2014：240959 + (193927 − 137660) − 2779 − 38364 + 1498 = 257581
- 2015：257581 + 86022 − 4156 + 414（收购子公司）− 60296 + 1089 = **280654**
- 用 280654 ÷ 贷款总额 119334.66 亿元 → **拨贷比 2.35%**
- 用 280654 ÷ 不良贷款总额 1795.18 亿元 → **拨备覆盖率 156.34%**
- **原文特别提醒**：分母用的是**贷款总额**，不是资产负债表上"客户贷款与垫款"净额 116528.12 亿元。

**四个名词的严格区分（原文反复强调，混淆即误判）：**

| 名词 | 对拨备总量 | 对利润表 | 对资产负债表 | 含义 |
|---|---|---|---|---|
| 本年新增 | 增加 | 减少当期利润 | 减少总资产、净资产 | 当年新计提（= 信用成本） |
| 本年回拨 / 转回 | 减少 | 增加当期利润 | 增加总资产、净资产 | 债权还在，只是评级/估值变好（含**贷款升级**） |
| 本年划转 | **不变** | **无影响** | **无影响** | 单项评估柜 ↔ 组合评估柜之间搬动。原文戏称"我们不生产拨备，我们只是拨备的搬运工" |
| 本年核销 / 转出 | 减少 | 无影响 | 减少贷款总额（净额不变） | 债权和拨备一起"烧掉"。核销**不影响利润表**，但影响不良率/拨备覆盖率/拨贷比 |
| 收回以前年度核销 | 增加 | 无影响 | 无影响 | 原来烧掉的拨备被还原 |

**这五个科目之间的勾稽关系，是本书最容易被机械复核的判据。** 拿到任何一份银行年报，用这五个数就能验出拨备是否被操纵。

#### 2.1.2 银行财报九步阅读流程（原文原样保留）

| 步骤 | 动作 | 关键内容 |
|---|---|---|
| 第一步 | 翻到审计意见，瞄一眼 | 须有"公允反映了×××"字样（仅年报） |
| 第二步 | 资产负债表百分化 | 每科目 ÷ 总资产，找变化最大的科目并追问原因 |
| 第三步 | 看存款结构和付息率 | 与同行对比：同环境下目标行增幅/降幅是大于还是小于同行 |
| 第四步 | 看净利息差、净利息收益率、生息资产规模 | 看息差在扩大还是缩小；同行是否同向 |
| 第五步 | **分析贷款质量（原文称"这一步是重心"）** | 必看指标清单：不良贷款率、拨备覆盖率、拨贷比、当年计提/贷款余额、拨备前利润、（逾期+重组）/贷款余额、当期新增逾期+重组、当期新增不良（报表新增不良+当期核销转出）、当期新增关注、90天以上逾期/不良贷款、公司贷个人贷占比变化、公司贷行业和地区分布 |
| 第六步 | 利润表百分表 | 分母=营业收入，重点四大项（见 A11） |
| 第七步 | 看"财务概要"里的监管指标 | 重点：总资产回报率、资本充足率、风险加权资产占总资产比率 |
| 第八步 | 拷问思考结果 | 读"董事长致辞""行长致辞""讨论与分析"，与自己的判断对照；想不通谁对谁错就**记录下来，用未来现实验证** |
| 第九步 | 估值 | 持有者：判断是否发生重大不利变化；未持有者：估算价值空间 |

**前置成本（原文自述）：**
- 原文称全书"没有什么全新的创造，只是将现有知识按照投资者阅读和理解银行业和银行财报的需要，分门别类整理"

| 指标 | 公式 | 监管要求 |
|---|---|---|

```

```
- X值＜0（生息资产日均＞付息负债日均）→ 净利差＜净息差
- X值＝0 → 净利差＝净息差

### 4.4 样本与锚点局限

## 五、用户约束适配

**用户实际场景：A股单边 + 可转债，不做期货。**

### 5.1 可以落地的部分

- **本书全部内容与用户场景兼容**（A股单边、银行股是A股、财报数据公开可得、无杠杆要求），**不存在期货/衍生品障碍**。
- 银行股本身可作为 A 股单边账户的一个**低波动底仓**，与转债的高弹性仓位形成互补。第十五课原话（虽是感慨但反映监管现状）："对于银行业这样一个天天过手天量财富，只要足够保守就可以躺着吃差价的行业而言，没有什么比拥有一个苛刻的'婆婆'更让人放心的了"
- **九步阅读流程 + 拨备五科目勾稽**可作为银行持仓的**年度复核清单**，这是本书对用户最实用的部分。

### 5.2 必须做的替换与限制

1. **不要把银行财报方法与可转债方法混用。** 转债的判据是债性/弹性/强赎条款/转股溢价/信用评级，与银行的拨备、资本充足率、净息差**没有任何共同变量**。本库已有 [[可转债三大经典策略]]、[[可转债定价模型]]、[[可转债债性指标]]，两套体系必须分开执行。
2. **注意银行股与转债的下游联动**：银行是转债发行人的重要资金方，也是转债市场的重要持有人之一。若用户持有大量银行股，同时持有大量银行转债，两者在"银行信用风险"这一维度上是**同一风险源的两次押注**，构成隐性集中。**本页不给出仓位建议，仅提示这一重叠事实由用户自行裁决。**
3. **用户不做期货 → 本书内容中"衍生金融负债""信用违约互换""利率衍生品"等章节（第五、六课）可以直接跳过**，不影响其余章节的可用性。这与 [[五套体系的适用市场]] 中按市场类型筛选体系的做法一致。
4. **数据获取成本**：本书假定读者能下载并逐页翻阅数百页的银行年报。**A股年报全部公开可取，无付费门槛**；唯一成本是时间（一本300页+的年报，从头到尾精读需数小时至数十小时）。
5. **时效性必须自行核对**：如 4.2 所述，全部监管参数为2013–2016年锚点。**用户若按本页参数做判断，须先回到银保监会/金融监管总局现行文件核对**。

### 5.3 与用户约束无关、本页不提供的内容

本页不提供任何银行股买卖建议、不提供当前银行股估值判断、不预测银行股价格方向。原文中的银行推荐与估值演算均已在 2.3 中标注为不可入库内容。
