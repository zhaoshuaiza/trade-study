#### 2.1.1 三方独立排雷流程（L13 的完整原样保留）

```
1. 在全国选择 3 个不同的城市，每个地方请一个人，帮"我"看要买入公司的财务报表
2. 这 3 个人相互不认识、互不联系
3. "我"本人认真阅读企业前 3 年的财务数据
4. 大家研究过财报后，"我"同他们交谈（通常三人结论不一样）
5. 首先通过财务指标给企业挑毛病（先排雷），然后综合他们的意见
6. 让他们看的不仅是目标公司，还包括同类型上市公司：
   - 买五粮液 → 同时看贵州茅台
   - 买招商银行 → 同时看民生银行
   - 买上海机场 → 同时看深圳机场
7. 最后让"我"的老师再在财务数据上把关
```

**这是本书中最接近"可机械执行"的方法论的一条**：三人独立、互不通气、必须看同行对照。**但它不是看盘动作，是尽调流程。**

#### 2.1.2 牛熊仓位布阵（原文林园个人仓位法，L16）

**牛市初期：**
- 龙头股：**60%~70%**
- 小盘股：**15%**
- 低PE高分红（派息率**10%以上**，林园认为熊市中一定被低估）：约25%

**牛市中后期：**
- 把"中间这块仓位（低PE高分红）"的比例**缩小，甚至缩小到0%**
- **加大**小盘股的投入
- 林园原话："我们的判断就是小盘股最能涨，牛市一定是小盘股涨得最多"
- 林园给出的历史业绩陈述："指数涨130%，我的组合就能增长5倍。用我最笨的办法就行……它至少能跟上指数，你不会落后于指数"

- **林园的方法建立在极少数持仓上。** 前言列出的长期持仓：贵州茅台、五粮液、招商银行、云南白药等**三四只股**。原话："随着调研的深入，重心转移到贵州茅台、五粮液、招商银行等三四只股票"。**n=3~4 的样本，无法支撑"不败"这一表述的方法论普适性**

## 五、用户约束适配

**用户实际场景：A股单边 + 可转债，不做期货。**

### 5.1 兼容的部分

- **完全兼容，无障碍。** 林园体系是A股单边的选股体系，标的是A股上市公司，年报数据全部公开可取。
- **ROE<10% 排除、利润总额<1亿 排除这类"一票否决式粗筛"，成本极低**（用免费行情软件即可批量跑），适合作为用户研究流程的第一道过滤器。
- **三方独立排雷流程**（L13）在信息不对称环境下有实际价值。

### 5.2 必须做的限制与替换

1. **本体系不能提供任何转债判据。** 用户的主要战场是可转债，而**可转债没有"净资产收益率"和"利润总额"这类年度指标，也没有年报式的利润表**。转债的核心变量是债底、到期收益率、转股溢价率、强赎条款、评级、下修条款——与林园六大指标**没有任何共同变量**。必须用 [[可转债三大经典策略]]、[[可转债债性指标]]、[[可转债定价模型]] 单独执行。**严禁把 ROE 套到转债发行人身上**（很多转债发行人是小市值公司，ROE 波动极大）。
2. **可转债的"低价"与林园的"低估"是两个完全不同的概念。** 转债的低价来自债底（信用+利率），林园的低估来自"未来业绩增长15%以上"。**把"转债价格低于净资产"当成低估，是把 [[可转债价格区间与风险等级]] 的债性思维与 [[可转债复合资产特性]] 的股性思维混淆**——转债的债底保护在正股基本面恶化时可能同时失效。
3. **不做期货 → 本书完全无关，无需删减。** 这与 [[五套体系的适用市场]] 按市场类型筛选体系的做法一致：林园体系只适用A股现货基本面。
4. **数据获取成本**：本章判据全部基于年报（公开免费），但**逐年对比需要自建表格**；三大交易所与巨潮资讯网均可免费获取，成本是时间。
5. **时效性必须自行核对**：见 4.3。ROE/派息率阈值来自2006年前后判断，成书2022年未更新。

### 5.3 本页不提供的内容

本页不提供任何个股推荐、不预测股价、不给出当前市场是否符合林园标准的判断。原书中的全部个股操作记录与盈利预测均已在 2.3 中标注为不可入库内容。
