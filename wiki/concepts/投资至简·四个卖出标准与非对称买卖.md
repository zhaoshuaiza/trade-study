# 投资至简·四个卖出标准与非对称买卖

> **一句话**：卖出只有四种合法情形，**没有一种叫「跌了」**；
> 而「持有」既不是买入也不是卖出——把三件事混成两件，是绝大多数决策错误的源头。

---

## 一、四个卖出标准（原书第一章第三节·三）

| # | 标准 | 原书给出的尺度 | 判据 / 动作 |
|---|---|---|---|
| **①** | **发现当初看错了** | — | 「价值投资者没有『止损』一说，但应该坚决**『止错』**」。看错即卖，**不需要价格条件** |
| **②** | 企业基本面发生**长期的**恶化 | 强调「**长期的**」，不是短期 | 短期业绩下滑不构成卖出；要看**长期竞争地位**是否受损 |
| **③** | 企业价值被「**极度高估**」 | 强调「**极度**」，不是「一般」高估 | 一般高估 → **不卖**。只有显著超出估值区间上沿才卖 |
| **④** | 发现「**明显更好**」的机会 | ⭐ **好上 100%、200% 才值得换股；好 20%~30% 无法判断，不必换** | 换股的比较基准是**预期收益率**，不是「这家涨得快」 |

### ⭐ 第 ④ 条是全库最具体的换股阈值

> **好 20%~30% → 不换**（差异在估算误差内，无法判断）
> **好 100% → 值得换**
> **好 200% → 明显该换**

→ 动作：想换股时先算两个标的的**预期年化收益率**。
算出来只差 20~30 个百分点（甚至只是 20~30%），**说明你其实判断不了，别动**。

## 二、买入 / 持有 / 卖出 三区（第一章第三节·四）

原书举例：设某公司估值区间为 **100 亿~200 亿元**

```
   <100 亿（最好 50 亿）       100 亿 ~ 200 亿            >200 亿（显著）
        │                          │                         │
      【买入区】                 【持有区】                【卖出区】
   低于下沿才买              不买也不卖                 显著高于上沿才卖
```

| 区域 | 动作 | 常见错误 |
|---|---|---|
| 买入区（< 下沿，最好打对折） | 买 | 在区间中部就急着建仓 |
| **持有区（区间内）** | **什么都不做** | 把「持有」当成「可以继续买」 |
| 卖出区（显著 > 上沿） | 卖 | 一般高估就卖飞（见 [[concepts/合理价格与持有不等于买入]] 的五次卖错） |

## 三、为什么「持有」不等于「买入」——逻辑同一律（本页最硬的一条）

原书对「持有 = 买入」这个流行说法的拆解：

> **持有 = 卖出 + 买入**（两个动作的组合）
> 而「买入」是单一动作。
> **一个组合动作与一个单一动作，在逻辑上不可比较**（违反**逻辑同一律**）。

推论：
- 「我还拿着它」→ 只能推出「我**没有卖**」，推不出「我**愿意在这个价位买**」
- 因此**持有区里的正确动作是「不动」**，不是「加仓」

> 📌 这与 [[concepts/合理价格与持有不等于买入]] 里巴菲特的表述**完全一致**（1999 年信：
> 「并不急着增加持股」，但「也没有相应地降低投资部位」）。
> **两位作者从不同路径得出同一结论**——一条走逻辑学，一条走实证。

## 四、与「止损」的根本分歧

原书**取消「止损」这个维度**，只承认「止错」：

> 推论四（第一章第二节·二）：「**止损、止盈等任何基于买入成本价做出的交易决策都是逻辑错误的。**」
> 建议把成本价改成 **0 元**并忘掉它。

**理由**：买入成本是**历史信息**，与「这笔资产未来能产生多少现金流」无关。
以成本价为锚做决策 = 让过去决定未来。

### ⚠️ 但这条不能无条件推广（本页的边界声明）

| 适用 | 不适用 |
|---|---|
| 以 DCF 定价、**无杠杆**、3~5 年以上周期的股权持有 | 趋势跟踪、题材波段、**带杠杆**的品种、**有期限/强赎约束**的品种 |

**对可转债的特别提示**：
转债有 **强赎** 这一**外生离场信号**（与走势无关的条款触发）。
强赎不是「止损」，也不是「止错」，而是**第四类离场**——**规则强制**。
→ 转债持仓必须**独立于本页的四标准**，单独执行强赎检查（优先级最高）。

参见 [[concepts/止损的争议]]、[[claims/三种止损方法的适用边界]]、[[syntheses/体系适用性矩阵·股票与期货]]。

## 五、可执行清单（打印版）

```
卖出前，只允许勾选以下之一：
[ ] ① 我看错了（写出错在哪：哪条判据失效）
[ ] ② 基本面长期恶化（写出证据：连续几年、哪个指标）
[ ] ③ 极度高估（写出估值区间上沿，与现价比）
[ ] ④ 明显更好（写出两标的预期年化，确认差距 ≥100%）
[ ] ⑤ 【转债专用】强赎条款触发（规则强制，独立判断）

未勾选任何一项 → 不卖。
勾选「跌了 / 怕了 / 赚够了 / 涨太多」→ 无效理由，不卖。
```

**持有区自查**：
```
我现在的动作是「持有」还是「加仓」？
若是加仓 → 必须重新走一遍买入标准（价格是否进入买入区）
价格在持有区 → 只能「不动」
```
