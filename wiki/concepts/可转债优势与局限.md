# 可转债的优势与局限（含"低利率失效"盲点）

> **这一页回答"转债到底值不值得做"。**
> ⭐⭐ 最有价值的是**第四节「关键局限」里的低利率风险**——
> 这是前面所有转债页面都没提到的**盲点**：所有"债底保护"的说法都隐含一个前提，
> 而这个前提在利率上行时会失效。

---

## 一、四大核心优势

### 1. ⭐ 下跌有底（债性保护）

- **保本属性**：价格接近纯债价值（YTM>3%）时，下跌空间被锁定
- 📌 **案例**：2022 年熊市中证转债指数最大回撤 **−15%**，同期沪深 300 回撤 **−35%**
  → **跌幅只有股票的 43%**

📌 见 [[concepts/可转债价格区间与风险等级]]（不对称的具体数字）

### 2. 上涨无限（股性弹性）

- 低溢价率（<20%）转债紧密跟随正股，**涨幅可能超过正股**
- 📌 案例：2021 年恩捷转债（128095）正股涨 120%，**转债涨 180%**
  （溢价率从 30% 压缩至 5%）

⭐ **注意这个案例的机制**：涨幅超过正股不是因为正股涨得多，
而是因为**溢价率被压缩**（30%→5%）——**转债的额外涨幅来自溢价率收敛，不是杠杆**。

### 3. 条款博弈（规则套利）

通过预判发行人行为（下修/回售/强赎）获取波动收益。

📌 案例：洪涛转债（128013）下修转股价 30%，**单日上涨 18%**。

### 4. 灵活配置（适配全周期）

| 市况 | 策略 |
|---|---|
| 熊市 | 高 YTM 转债提供防御 |
| 牛市 | 低溢价转债放大收益 |
| 震荡市 | 条款博弈创造 Alpha |

📌 详见 → [[concepts/可转债三市适用策略]]

## 二、⭐⭐⭐ 关键局限（这一节最值钱）

### 局限 1：收益天花板 —— 强赎机制压制长期空间

- 一旦触发强赎，转债价格迅速向赎回价（通常 103 元）靠拢，**限制长期持有收益**
- 📌 **宁建转债（113036）**：强赎后 **180 → 120 元，涨幅归零**

> 📌 **这与"长期持有价值投资"直接冲突** ——
> 详见 [[concepts/可转债复合资产特性]] 的强赎条款分析。

### 局限 2：条款博弈的不确定性

- **下修需股东大会通过**，且大股东可能反对（原股东股权稀释顾虑）
- 📌 案例：某国企转债因原股东反对，**下修议案被否，价格下跌 10%**

⚠️ **注意这是资料里唯一一个"匿名案例"** —— 说明这个失败模式不罕见但难以统计。

### 局限 3：信用与流动性风险

| 风险 | 说明 |
|---|---|
| **违约隐患** | 低评级（AA− 以下）可能本金损失（辉丰转债） |
| **流动性陷阱** | 小盘转债（<5 亿）**买卖价差大，难以及时成交** |

📌 见 [[concepts/可转债三大误区]]（凯发转债价差 5%、辉丰停牌半年）

### ⭐⭐ 局限 4：低利率环境失效（**前面所有页面都漏了这条**）

> **若债市利率大幅上升，债底价值下移，削弱保护。**

⭐ **这一条极其重要，因为它揭示了"债底保护"的隐含前提**：

```
债底 ≈ 未来现金流按当前利率折现
     ↓
若无风险利率上行
     ↓
同样的现金流折现出来更低
     ↓
债底下移 → 保护减弱
```

📌 **也就是说：**

| | 利率下行 / 平稳 | **利率上行** |
|---|---|---|
| 债底 | 高，防守强 | ⛔ **下移，防守削弱** |
| 债性策略（高YTM） | ✅ 有效 | ⚠️ **失效** |
| 低价转债 | 有安全垫 | ⚠️ **安全垫变薄** |

⭐ **这不是"转债不好"，而是"所有说转债有债底的说法都有一个前提"**。
**债底不是绝对的，它跟着利率走。**

> 📌 这条对"熊市就买债性转债防守"的策略是一记警告：
> 如果熊市的原因是**利率上行**，那么债性转债的债底也会下移，防守效果会打折。

### 局限 5：正股长期低迷

- 若发行人**无下修意愿**，低价转债可能**长期滞涨**
- 📌 这意味着"低价 + 高 YTM"不等于"会涨"，可能一年都不动

---

## 三、⭐ 优势与局限对照（速查）

| 优势 | 对应的局限 |
|---|---|
| 下跌有底 | ⛔ **低利率失效**会削弱债底；低评级可能直接违约 |
| 上涨无限 | ⛔ **强赎天花板**封住长期空间；溢价率压缩完后跟正股同步 |
| 条款博弈 | ⛔ **下修可能失败**（股东反对） |
| 灵活配置 | ⛔ **正股长期低迷**时转债也滞涨 |

⭐ **结论：转债不是"稳赢工具"，是用四个优势换一个对应局限。**

---

## 四、⚠️ 资料自己的两条警告（值得单独抄下来）

> **不可盲目信仰"保本"**：低评级转债可能违约，高价转债强赎风险不可忽视。
>
> **不可过度依赖历史回测**：市场结构变化（机构化、监管改革）将重塑策略有效性。

📌 第二条印证了本库的 [[concepts/权威的泥潭效应]]——
**回测里的有效策略，市场结构一变就可能失效。**

## 五、未来展望（原文观点，仅供参考）

### 市场趋势
- **供给收缩**：注册制下发行门槛提高，优质标的稀缺
- **机构化加速**：保险、年金等长线资金增配，**推动估值体系重构**
- **创新条款**：绿色转债、浮动利率转债

### 投资者应对
- **精细化条款博弈**：用 AI 模型预测下修概率
- **ESG 整合**：碳中和、社会责任主题
- **全球化配置**：通过 QFII 参与境外可转债（港股、美股 CB）

### ⚠️ 对"机构化"这一条的判断

📌 **这条对个人投资者最重要**：
> 机构资金增配 → **估值体系重构** → **现有的历史估值区间可能失效**。

⚠️ 如果这条成立，那么"价格 100-120 元""溢价率 <20%"这类阈值
**在未来可能需要重新校准**。

## 六、可执行判据

### 判断转债是否值得做

- [ ] 我能接受强赎强制下车吗？（不能 → 转债不适合长线）
- [ ] **当前利率环境是上行还是下行/平稳？**
  - [ ] ⛔ **利率上行期 → 债性策略打折，谨慎用"债底"做防守理由**
- [ ] 我能接受"正股长期低迷转债长期滞涨"吗？

### 用优势前先看局限

| 我想用 | 必须先确认 |
|---|---|
| 债底防守 | 评级 ≥AA？利率不是上行？正股没 ST？ |
| 追高弹性 | ⭐ **强赎预警线设了吗？**（正股 ≥转股价×120% → 减仓） |
| 条款博弈 | 能接受下修失败吗？（原股东可能反对） |
| 低价滞涨 | ⭐ **发行人有下修意愿吗？**（可能一年不动） |
