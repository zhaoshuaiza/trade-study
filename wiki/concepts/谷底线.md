# 谷底线

> **《量柱擒涨停》里没有的第7 个「线」。**
> 它比 [[黄金线]] 更简单——**就是画水平线**，但判据更硬：
> **只画能形成「精准线」的那个最低点。**
>
> 与 [[黄金道]]（标记 draft）不同，
> 谷底线的取点规则是**可机械复核的**。

---

## 一、是什么（原文定义）

> 「画水平线，就是'**谷底线**'。」

**与黄金线的分工**：

| | [[黄金线]] | **谷底线** |
|---|---|---|
| 取点来源 | 黄金柱的「量价平衡点」 | **各阶段的最低点** |
| 依据 | 量柱（有无黄金柱） | **价格结构**（纯K 线低点）|
| 数量 | 与黄金柱一一对应 | 每一阶段都有一条 |
| 画法 | 四分法取点 | **画水平线即可** |

> 📌 **谷底线更基础**：它不需要先找出黄金柱。
> 顺序是：先有谷底线 → 才有黄金柱的支撑线 → 才谈得上黄金柱测幅。

---

## 二、⭐ 画法（关键在「精准线」）

**取点规则**（原文）：

```
一般以「最低点」取点
  ↓
根据股性可调整为：
  · 最低点（默认）
  · 实体低点（收盘价）
  · 参照点（左侧低点）
```

### ⭐ 取点窍门（这是本页最实操的一条）

> 「谷底线的画法有一个窍门，就是**尽量寻找与之能形成'精准线'的'最低点'**——
> 千万不要主观臆断。」

**「精准线」的含义**：该最低点与其**左侧的某个重要点位恰好重合**
（可能是巨阴最低点、阳十字最低点，或若干价柱的重要点位）。

> 📌 **可执行流程**：
> ```
> ① 找出各阶段最低点 A、B、C、D…
> ② 逐个检查：该低点左侧是否有重要点位与之重合？
> ③ 有 → 画线（精准线，支撑力强）
> ④ 无 → 画线但标记为「非精准」（支撑力弱）
> ⑤ 若最近两个低点基本持平 → 只画一条
> ```

## 三、⭐ 三大功能（可直接判断后续走势）

| 功能 | 原文说明 | 后续走势判据 |
|---|---|---|
| **① 支撑线** | 「谷底线是主力测试某阶段下方撑力的支撑线，往往采用**休克手法**……若这个**低量柱被确认**，就会出现上升行情」 | 谷底线 + 低量柱 → 支撑成立 |
| **② 抬升线** | 若某阶段谷底线**高于**左侧谷底线 → 谷底**逐步抬高** → 说明持股成本逐步抬高 | **抬高 → 后期上涨** |
| **③ 阻力线** | 若某阶段谷底线**低于**左侧谷底线 → 谷底**逐步降低** → 套牢盘逐步增多 | **降低 → 后期下跌** |

> ⭐ **这是本页最好用的一条**：
> **谷底线逐步抬高 → 看涨；逐步降低 → 看跌。**
> 与 [[concepts/黄金梯]] 的「三梯形强弱判据」是同一思路，
> 但**谷底线只看方向（抬高/降低），不看间隔（渐大/渐小）**，
> **判据更简单也更硬**。

### 原文的对照实证

| |四川路桥（600039） | 中国建筑（601668） |
|---|---|---|
| 谷底线形态 | 多为**精准线** | **不是精准线** |
| 对应量柱 | 都是**低量柱**（有爆发力） | **有高有低**（无爆发力） |
| 节奏 | 节奏鲜明，步步为营 | 松散 |
| 后续 | 多次触线即升 | **每次反弹都在谷底线附近受阻回落** |

> 📌 **判别主力的两条硬标准**：
> ```
> 谷底线是否精准 → 主力的「计划性」与「控盘力」强
> 谷底线对应的量柱是否低量 → 是否有「爆发力」
> 多根精准线构成 → ⭐ 主力计划性极强，重点关注
> ```

## 四、⭐⭐ 谷底线捉涨停的四大要素

原文提问：「每只股票都有其谷底线，但**并非有谷底线的股票都能出现涨停**。」

| # | 要素 | 原文标准 | 本质 |
|---|---|---|---|
| **1** | 谷底线之前有**「长阴短柱」** | 「主力借势强力洗盘的'**假跌**'……**其'假跌'的特征就是缩量**，主力不出货」| ⭐ **假跌必然对应真涨** |
| **2** | 谷底线之底现**「百日低量」** | 「一方面显示**主力不出货**，一方面显示**当前市场不愿出货**」| **休克疗法的试探结果** |
| **3** | 谷底线之后应**「触底即升」** | **3~5 天内**突破第一阻力位，再 **3~5 天内**突破第二阻力位| ⚠️ **重在时效** |
| **4** | 阻力线之前应**「蓄势突破」** | 「一天触线，一天过线，步步为营，逐级突破」| **主力控盘实力的体现** |

### ⭐ 反面对照（原文给出失败案例）

中国建筑 C 线后第 5 天突然拉升，一口气冲过两个阻力位：
> 「**元气大伤**，让附近的套牢盘迅速解套，增加了主力拉升的负担，
> 结果是连续 **10 天受制于**第二阻力线，上攻乏力，无功而返，
> 只好再次暴跌回到起点。」

> 📌 **要素 4 的反面教材极有价值**：
> **一次性冲过多个阻力位 = 帮套牢盘解套 = 自毁前程。**

## 五、实战检查清单

- [ ] 找出各阶段最低点，**逐个检查左侧是否有「精准线」**
- [ ] 谷底线是**逐步抬高**（→看涨）还是**逐步降低**（→看跌）？
- [ ] 谷底线对应量柱是否为**低量柱**？（决定有无爆发力）
- [ ] 勾涨停四要素：
  - [ ] 1. 前有「长阴短柱」（缩量假跌）
  - [ ] 2. 谷底出现「百日低量」
  - [ ] 3. 触底后 **3~5 天**突破第一阻力位
  - [ ] 4. 阻力位前**蓄势**（一天触线一天过线）
- [ ] ⚠️ 若一次性冲过多个阻力位 → **警惕**，参考中国建筑案例
