# 涨停基因

> **三个「基因」的组合 —— 用来在涨停前判断「这只票会不会涨停」。**
> ⭐ **本库认为这是手记体系里最可操作的一页**，
> 因为它把「会不会涨停」拆成了**三个可独立检查的条件**。
>
> ⚠️ 注意命名有误导性：**「涨停基因」可用在转债上**，
> 它检查的是**量价结构**，不依赖涨停板本身。

---

## 一、三个基因（原文口径）

> 「科学研究发现，人体的'基因'决定人体的素质……
> 我们研究发现，**股票的'基因'决定股票的素质**。」

### ⭐ 基因一：「长阴短柱」

> **口诀：「长阴压短柱，攻势猛如虎。」**

**定义**：
```
长阴 = 长长的阴价柱（股价大跌）
短柱 = 短短的量柱（量能缩小）
```

**市场机制**（原文解释，⭐ 这是本页最有价值的部分）：

| | 一般下跌 | **长阴短柱** |
|---|---|---|
| 价 | 大跌 | 大跌 |
| 量 | **量价同步**（放量）| ⭐ **极度缩小** |
| 说明 | ⭐ **主力和散户同时出货** | **主力打压股价，散户没出货** |

> 📌 **所以「长阴短柱」是洗盘，不是出货** —— 这与
> [[concepts/黄金劫与凹口淘金]] 的「跌得多而量不动 = 洗盘」**完全同源**。

**原文的极限位置**：洗盘的「打压极限」往往在
**回踩精准线 / 回踩黄金线 / 回踩峰谷线 / 回踩峰顶线**。

### ⭐ 基因二：「精准线」

> **口诀：「回踩精准线，涨停在眼前。」**

**实证**（新潮实业 600777）：
```
5月10日最低点 5.18 元
其左侧谷底     5.17 元
再往左 9月3日开盘价 5.17 元
→ 三点一线，仅仅相差 0.01 元的 N 型精准线
```

> 📌 **这与 [[concepts/谷底线]] 的「精准线」是同一判据**，
> 谷底线页强调的「**尽量寻找能与左侧形成精准线的最低点**」，
> 源头就在这里。

### ⭐ 基因三：「阻力位」

> **口诀：「第三阻力位，往往有腾飞」。**

| 阻力位 | 原文定义 |
|---|---|
| 第一阻力位 | 谷底线反攻的第一压力 |
| **第二阻力位** | 5/12 **倍量**触及 → 有望冲击第三 |
| ⭐ **第三阻力位** | **「往往有腾飞」** |

> 📌 判据：按[[concepts/谷底线]]反攻计算的阻力位，
> **倍量触及第二阻力位 → 冲击第三阻力位**。

---

## 二、⭐⭐ 组合逻辑（原文明确）

> 「**这三个基因的组合**，加上**倍量垫底的'基因'**，
> 我们就敢于大胆预报并介入了。」

```
基因一 长阴短柱     → 洗盘不是出货
     +
基因二 回踩精准线   → 打压到位（找到支点）
     +
基因三 倍量触及阻力位 → 进攻启动
     ↓
⭐ 三者同时具备 → 涨停概率大幅提升
```

> 📌 **注意「倍量」的两次出现**：
> 「**倍量垫底**」与「**倍量触及第二阻力位**」——
> **倍量柱是关键信号**。

---

## 三、⭐ 原文对「为何不早盘涨停」的解释（人性洞察）

新潮实业当天**下午才封死涨停**，原文解释：

> 「如果早盘封于涨停，持股者的出货率肯定要低，
> **主力吃不到廉价筹码**。
> 所以他**故意示弱**，不封涨停而让持股者逢高出出，他们就能轻易得手了。」

> 📌 **这是「实强示弱」的又一实例**——
> 与 [[concepts/太极线]] 记录的「骑线十字阴线」、
> [[concepts/黄金劫与凹口淘金]] 的「假阴真阳」
> **是同一个手法的三种表现**。

> ⭐ **可执行推论**：
> **看到「本该涨停却不涨停」，不要急着判它坏了** ——
> 先查是否同时具备基因二（回踩精准线）与基因三（倍量触及阻力位）。

## 四、⭐⭐⭐ 在可转债上的适用性（重要）

> **「涨停基因」这个名字有误导性 —— 它其实可以用在转债上。**

### 可直接迁移的部分

| 基因 | 转债可用性 | 说明 |
|---|---|---|
| ⭐ **基因一 长阴短柱** | ✅ **完全可用** | 纯量价关系，**与涨跌停板无关** |
| ⭐ **基因二 精准线** | ✅ **完全可用** | 纯价格几何，**与板无关** |
| ⭐ **基因三 阻力位** | ⚠️ **需改口径** | 转债**无涨停板**，阻力位须按 [[concepts/平衡线]] 的「过线/触线」重新划 |

> 📌 **理由（与 [[syntheses/量柱体系在可转债上的适用性]] 一致）**：
> 这三个基因检查的是**量价结构与价格几何**，
> **不依赖涨停板制度**。
> → 真正作废的只是「涨停」这个**结果**，不是**成因**。

### 转债版的判据写法

```
① 长阴短柱   → 阴价柱 + 短量柱（缩量洗盘）
② 回踩精准线 → 三点一线（价格几何，转债同样成立）
③ 触及阻力位 → 按平衡线「过线看涨、触线看跌」判
④ 失效判据   → ⛔ 强赎公告优先（与量价无关，见转债适配页）
```

## 五、实战检查清单

- [ ] **基因一**：最近是否有「长阴短柱」？
      （阴线明显长，量柱明显短）
- [ ] **基因二**：是否回踩了**精准线**？（三点一线，相差很小）
- [ ] **基因三**：是否**倍量**触及第二阻力位？
- [ ] 三者是否**同时**具备？
- [ ] 「本该涨停却不涨停」时：先查基因二、三是否还在 → 别急着判坏
- [ ] 若在转债上：再加 ⛔ **强赎状态** + ⚠️ **溢价率**（见转债适配页）

### ⚠️⚠️⭐ 「基因之三」在原书中排印缺失（重要发现，已二次核对）

本库核查过程：

```
① 全文检索「涨停基因之三」→ 0 命中
② 查原始 OCR 分片 shards_量线捉涨停/p0011-0020.txt → 同样 0 命中
   ⭐ 说明不是 OCR 丢字，是【原书排印缺失】
③ 目录第三章「伏击七则」编号连续（1~8+），无第3则缺号
   → 缺失只发生在【序言的基因清单】，不在正文
```

> ⭐⭐ **本库结论**：
> **「之三」不是本库漏编译，是原书序言本身就没有列出第 3 条。**
> 序号从「之二」直接跳到「之四」，中间是空的。
>
> ⚠️ **不能推测填补**（按 CLAUDE.md：库里没有就说没有，不用训练数据补）。
> 📌 **如需确认，可核对纸质原书序言第 001~002 页**——
> 序言署名「方正（《人民日报》经济快讯记者）」，2010-05-01 于清华园。

> 📌 **术语线索（仅供参考，非结论）**：

> 其结构与「长阴压短柱」「回踩黄金线」完全同构（都是 4+4 字口诀）。
> ⚠️ 但**原文未把它标为「基因之三」**，故本库不作认定。

### ⭐⭐⭐ 本库对源书七条基因体系的结构性判断

把六条可核基因按**判据类型**归类（本库提炼）：

| 判据类型 | 基因 | 数据来源 | 本库页 |
|---|---|---|---|
| ⭐ **量能位置** | 一（百日低量群）、五（长阴短柱）| **单根量柱 + 同柱比较** | [[concepts/百日低量与百日低量群]]、本页基因一 |
| ⭐ **量能突破** | 二（倍量过左峰）| 量柱 + 峰线 |
| ⭐ **线的关系** | 四（回踩黄金线）、六（复合精准线）| **多条线的重合/踩线** |
| ⚠️ **缺口** | 三 | **原书缺失** |

> ⭐⭐ **本库发现的一条体系规律**：
> 六条基因里**四条（②④⑤⑥）都以「量线」为载体**，
> 只有一条（① 百日低量群）纯用量柱。
> → 这与本库既有结论**一致**：
> 「量柱是庄家意图载体」+「所有量线本质上都是平衡线」（第 8 讲）。
> **基因 = 量柱（意图） × 量线（位置）** 的组合。

### ⚠️ 关于「基因」这个词的营销属性（诚实登记）

序言有明显的宣传包装，原文自述：

> 「称得上是我国**第一部揭示'涨停基因'之基础理论和涨停规律的原创作品**」
>
> 「作者在全国图书博览会上的演讲，**揭示了部分奥秘**」
>
> 「对于'涨停基因'的研讨，黑马王子**应该是股市第一人**」

⚠️ 且《量柱擒涨停》修订版前言提到：
> 「将中国人民大学、清华大学实战操盘特训班的精华编成
> 《**伏击涨停**》和《**涨停基因**》**两本配套教材**」

> ⚠️⭐ **本库判断**：
> **「涨停基因」既是方法论术语，也是一本教材的书名。**
> 「七条基因」出自**演讲摘录**（序言转述），而**不是书中的系统章节**。
> → 因此：
> - ⛔ **不能把它当作七章结构**来学
> - ⛔ **不能认为学完六条就掌握了《量线捉涨停》**
> - ✅ 六条各自都有**正文专章/专节**支撑，可分别深学

## 七、⚠️ 局限（诚实登记）

| 项 | 状态 |
|---|---|
| ⚠️ **「精准」无量化标准** | 「相差 0.01 元」是原文举例，**多少算精准未定义** |
| ⚠️ **「长阴」「短柱」无量化标准** | 多长算长阴？多短算短柱？**原文未给** |
| ⚠️ **「阻力位」依赖谷底线先画出来** | 谷底线画不准 → 阻力位不准 |
| ⚠️ **「涨停」口径** | 原文语境是 A 股涨停板，**转债无此机制**（成因可用，结果不可用）|
| ⚠️ 案例数量 | 原文举三木集团、新潮实业两例，**样本极小** |
| ⚠️ **「基因之三」原书缺失** | ⛔ 已二次核对（全文+分片），**原书序言排印缺号**，非本库漏编 |
| ⚠️ **七条清单出自演讲摘录** | 序言转述「全国图书博览会上的演讲，**揭示了部分奥秘**」→ ⚠️ **不是书中系统章节** |
| ⚠️ **「基因」是双义词** | 既是方法论术语，**也是一本教材的书名**（《伏击涨停》《涨停基因》）|
| ✅ **基因①已编译** | ⭐ 2026-10-14 已建 [[concepts/百日低量与百日低量群]]（含四要点上下文）|

> 📌 **诚实结论**：
> 三个基因作为**定性框架**很有价值，
> 但**每一项都缺少量化阈值** →
> 本库定位为「**检查清单**」，不是「**自动信号**」。
