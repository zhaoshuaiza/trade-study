# 平衡线

> **全库使用频次最高的工具（五本合计 646 次）。**
> 一句话概括它的用法：
> > **「过线看涨，触线看跌。」** —— 原文原话
>
> ⭐ 取点**不用量柱、不用目测**，只用「最大阴线的实体顶部」——
> 所以它是手记体系里**判据最硬**的一条线。

---

## 一、是什么（两种来源，必须分清）

原文明确区分了两类，这是本页最关键的辨析：

| | ⭐ **自然平衡线** | **人工生成的平衡线** |
|---|---|---|
| 取点 | **以下降途中最大阴线的实体顶部**取点 | 取「跳空缺口的中间值」 |
| 依据 | **下跌动能的终点** | **上下平衡原理** |
| 数量 | 天然生成 | 需人工推导 |
| 可靠性 | ⭐ 更高（**主力自己用它做攻防线**）| 较低 |

**实证观察**（原文反复提到的一个现象）：

```
为什么 A 与 A1 完全重合？
为什么 B 与 B1 完全重合？
为什么 C 与 C1 完全重合？
```

> 「这就是主力操盘的精妙之处，
> **他们以平衡线为天然攻防线**，
> 该上就上（如 B1 处），该下就下（如 A1 处），
> 定点启动（如 C1 处），触线回落（如 D1 处）。」

> 📌 **这句话解释了平衡线为什么有效**：
> 不是画得准，而是**主力自己就在用它操作**——
> 你画的就是主力画的。

## 二、⭐⭐ 三大规律（可直接落成动作）

### 规律一：「咬住平衡线」的**阴阳律**

> **凡是咬住平衡线的时候，只要「阴多阳少」，往往暗示回调；
> 如果「阳多阴少」，往往暗示向上。**

原文实例（天润发展 002113）：主力连续三日「咬住平衡线」，
原文读作「红肥绿瘦」「阳盛阴衰」→ **判断节后有冲关动作**。

### ⭐ 规律二：「咬住平衡线」的**节奏起伏律**

```
A1 处 → 该下就下
B1 处 → 该上就上（倍量起柱）
C1 处 → 定点启动
D1 处 → 触线回落
```

| 位置 | 动作 | 应对（原文）|
|---|---|---|
| **B1（过线 + 倍量柱）** | ⭐ **最好的介入机会** | 盘中过A1线即介入；**B1 次日也是介入良机** |
| **D1（触线）** | 回落 | **最高点一般不出货，次高点可出货** |
| **C1（跌破）** | ⛔ 跌破 | **有效跌破C1 就是出货良机**，等再冲过C1 才介入 |
| **E 线（压力位）** | ⚠️ 左侧集中 12 根高度一致的价柱 | **触及E线出货；有效突破E线才是最佳介入时机** |

### ⭐ 规律三：「突破平衡线」的**时机爆发律**

> 「要真正找到介入和退出的时机，就得从**量波**的角度来进行判断。」

**原文的三个实操判据**：

| 位置 | 形态 | 原文判读 |
|---|---|---|
| **A 点** | 跳过第一阻力位、**倍量起柱** | 「A柱的任何一处介入都是正确的」 |
| **B 点** | **长阴短柱**，最低点未跌破第一阻力线 | 「根据'过线看涨'，更是**介入良机**」→ 次日放量涨停 |
| **C 点** | **放量假阴柱**，最低点在第二阻力位上方 + **向上跳空缺口支撑** | 继续看涨 |

## 三、⭐⭐ 核心口诀：过线 vs 触线

> **「过线看涨，触线看跌」** —— 原文原话

| 动作 | 含义 | 应对 |
|---|---|---|
| ⭐ **过线** | 突破平衡线（**收盘/最高价越过**） | **看涨 → 介入** |
| ⭐ **触线** | 触及即回落 | **看跌 → 出货** |
| ⛔ **有效跌破** | 跌破后无法收复 | **出货良机**；等再冲过才介入 |

> 📌 **注意区分「过线」与「触线」**——
> 这是同一根线的**两个方向**，不是两个指标。

### 关于「底部线」的取点（原文答疑）

网友问：「为什么不在 8.47 元画底部线？」

原文答：「'底部线'应该是**过夜价**」——
「该股在 8.47 元只是'点缀了一下'，所以其'底部线'应该是'**收盘价**'」。

> 📌 **这是一个容易错的取点细节**：
> **底部线用收盘价，不取盘中最低价。**

## 四、⭐ 与本库其他「线」的分工（全部对比）

| 线 | 取点依据 | 能否机械复核 | 主要用途 |
|---|---|---|---|
| ⭐ **平衡线** | **最大阴线实体顶部** | ✅ **能** | ⭐ **突破确认 / 进出时机** |
| [[concepts/谷底线]] | 各阶段最低点（须成「精准线」）| ✅ 能 | 支撑/阻力方向 |
| [[concepts/灯塔线]] | **量柱**最高/最低日 | ✅ 能 | 测顶量底 |
| [[concepts/太极线]] | 大阳/大阴实底 | ⚠️ 「大阳/大阴」无定义 | 行情中轴 |
| [[concepts/黄金线]] | 黄金柱的量价平衡点 | ✅ 能 | 防守线 |
| [[concepts/黄金道]] | 「三个最低点」「趋向一致」| ❌ **不能** | 趋势窗口（draft）|

> 📌 **平衡线是本库唯一一条「取点依据完全客观、且直接服务于进出时机」的线。**
> 在判据化程度上它优于太极线与黄金道。

## 五、实战检查清单

- [ ] 标出图中所有**最大阴线的实体顶部** → 自然平衡线
- [ ] 检查是否有**跳空缺口**，其**中间值**是人工平衡线
- [ ] 当前价相对最近平衡线：
  - [ ] **过线**（突破）→ ⭐ 看涨
  - [ ] **触线**（触及回落）→ 看跌
  - [ ] **有效跌破** → ⛔ 出货
- [ ] ⭐ 若正在「咬住平衡线」：
  - [ ] **阴多阳少** → ⚠️ 暗示回调
  - [ ] **阳多阴少** → ⭐ 暗示向上
- [ ] 左侧是否堆积**大量高度一致的价柱**？
  - [ ] 是 → ⚠️ 该线是**压力位**，触及出货
  - [ ] 有效突破 → ⭐ 最佳介入时机
- [ ] 配合量波判断：过线处是否**倍量起柱**？

## 六、⚠️ 局限（诚实登记）

| 项 | 状态 |
|---|---|
| ⚠️ **「最大阴线」无量化定义** | 多大幅度算「最大」？跨月比较还是区间内比较？**原文未给** |
| ⚠️ **「有效跌破」无量化定义** | 收盘跌破？跌破多少才算有效？**原文未给** |
| ⚠️ **「阴多阳少」需数 K 线** | ⭐ 相对可复核，但**几根比几根算多**未定义 |
| ⚠️ **理论出处在另一本书** | 原文注明「详见《量线捉涨停》第 5 讲」—— 该书已OCR 但**未编译** |
| ⚠️ 精度声明 | 「差 0.04 元回落」等均为**作者自述** |

> 📌 **对比 [[concepts/双阴出货]]**：
> 双阴出货**只用两根K 线**，判据极硬；
> 平衡线需要先判定「最大阴线」，**多一步主观判断**。
> → **若要最机械的判据，用双阴出货；平衡线更适合定「进出的位置」。**
