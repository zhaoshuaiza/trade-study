# 经营资产自由现金流与保全性资本支出（郭永清）

> ⭐ **本页记录了本书对自由现金流口径的一处实质性改写：只扣保全性资本支出、不扣扩张性资本支出。**
> 这一条会**直接改变成长期公司的估值结论**——按通用口径算出来是负自由现金流的公司，按本书口径可能是正数。
> ⚠️ 参数一律原样保留（`CLAUDE.md` 4.1），本页不给「建议改为 X」。

---

## 一、⭐ 口径分歧：三套自由现金流公式并列

| 提出者 | 公式（原样照录，第 15 章 15.2.1） |
|---|---|
| **科普兰（Tom Copeland, 1990）**<br>《本书称「当前教科书或者市场上运用比较普遍的是科普兰教授的定义和计算公式」》 | `自由现金流量 =（税后净营业利润 + 折旧及摊销）−（资本支出 + 营运资本增加）`<br>`= 息税前利润 ×（1 − 所得税率）+ 折旧及摊销 −（资本支出 + 营运资本增加）` |
| **康奈尔（Bradford Cornell, 1993）** | `自由现金流量 =（营业利润 + 股利收入 + 利息收入）×（1 − 所得税率）+ 递延所得税增加 + 折旧 − 资本支出 − 营运资本增加` |
| **达摩达兰（Aswath Damodaran, 1996）** | `自由现金流量 = 息税前利润 ×（1 − 所得税率）+ 折旧 − 资本支出 − 营运资本增加` |
| **汉克尔（K.S. Hackel, 1996）** | 经营活动现金净流量 − 资本支出 + 资本支出及其他支出中的**随意（discretionary）支出**部分 |
| ⭐ **本书（郭永清，15.2.2）** | `经营资产自由现金流 = 经营活动现金流量净额 − 保全性资本支出` |

## 二、⭐ 本书为什么改口径（三条批评 + 苹果树论证）

### 2.1 对科普兰公式的三条批评（15.2.2）

1. **只调整折旧及摊销不够全面**：「还有很多无须支付现金的项目，比如**资产减值准备、资产处置损失、递延所得税资产和递延所得税负债**等……还需要调整加回其他非现金成本费用。」
2. **息税前利润口径有问题**：「息税前利润包含**偶然的、一次性的利润**，比如出售子公司、长期投资股权及其他长期资产的利润。」
3. ⭐ **资本支出不该全额扣**：「资本支出包括两部分：一部分是**维持原有经营规模**的资本支出，另一部分是**扩张经营规模**的资本支出……在企业成长期或者扩张期，计算自由现金流的结果往往是错误的……**导致公司自由现金流为负数，得出公司价值为负数的错误判断，从而错杀很多实际上很有前途的公司**。」

### 2.2 ⭐「苹果树公司」论证（原书表 15-1，表格在文字层不可得，仅录正文结论）

设定：T0 有 2,000 棵苹果树（此前每年种 100 棵、树龄 20 年需更新）；每年创造价值 = 1/10 棵树的价值；T1-T8 每年新种 400 棵。

- **通用口径**：T1 自由现金流 = **−200 棵**（经营赚 200、资本支出 400）→ 结论「价值不大，没有什么前途」。
- **本书口径**：T1 只需替换 100 棵即维持规模不变，多出的 300 棵是扩张。真实可自由支配的现金 = 经营活动现金流量净额 − 保全性资本支出。→ 结论「**是一家不断发展的好公司**」。

**第二个论证（原书文字，可复算）**：一家成长期公司初始股东投入 1,000 万，每年经营活动现金流量净额 200 万（含折旧摊销 50 万），连续 20 年全部再投入（净投入 3,000 万）。
- 按全部资本性支出口径：**20 年自由现金流全为 0**。
- 但股东权益账面价值：期初 1,000 万 → 20 年后 **4,000 万**。
- 原书结论：「**无法通过自由现金流体现出该公司的价值，这是非常荒谬的。**」

### 2.3 原口径 → 本书口径（显式列出）

```
[通用] 自由现金流量 =（税后净营业利润 + 折旧及摊销）−（资本支出 + 营运资本增加）
                    ↓ 本书改造
[本书] 经营资产自由现金流量 =（税后净营业利润 + 折旧及摊销）−（保全性资本支出 + 营运资本增加）
                          = 息税前利润 ×(1 − 所得税税率) + 折旧及摊销 + 其他非现金支出
                            −（保全性资本支出 + 营运资本增加）
                          = 经营活动现金流量净额 − 保全性资本支出
```

⭐ **保全性资本支出的取数规则（原书）**：
> 「**由于从财报中很难得到保全性资本支出的金额，我们通常用长期资产的折旧摊销来做近似替代。**」

⚠️ **例外提示（原书明说）**：机场类公司（上海机场、深圳机场、白云机场）「一旦建好机场，每年就计提很多折旧和摊销。但是这些折旧和摊销中的大部分**并不需要再次投入替换新资产**，而只需投入**远低于折旧摊销**的金额即可保全机场的经营规模和能力，在这种情况下，**需要对保全性资本支出进行计算调整**」。

### 2.4 股权口径

```
股权经营资产自由现金流 = 经营资产自由现金流 − 利息支出
```
万华化学算例：`289,636.00 − 107,545.53 = 182,090.47 万元`

**自由现金流的用途顺序（原书）**：先支付债务利息 → 再投内含报酬率符合预期的新项目（扩张性资本支出）→ 仍有剩余才给股东分红。

## 三、⭐ 完整算例（原样保留，可复算）

### 3.1 万华化学（2015 年，15.2.2）

```
经营资产自由现金流 = 经营活动产生的现金流量净额 460,239.37 万元
                   − 资产折旧 147,283.57 万元
                   − 资产摊销 7,317.79 万元
                   − 长期资产处置损失 16,002.01 万元
                   = 289,636.00 万元
```
✅ 复算通过：460,239.37 − 147,283.57 − 7,317.79 − 16,002.01 = **289,636.00**

### 3.2 中国石化（2015 年，15.3.5）

原文算式：
```
中国石化经营资产自由现金流 = 经营活动产生的现金流量净额 16,581,800.00 万元
                          − 资产折旧 8,706,900.00 万元
                          − 资产摊销 929,900.00 万元
                          − 长期资产处置损失 72,100.00 万元
                          = 6,945,000.00 万元
```
⚠️ **原文自身不一致（照录不修正）**：按所列四项计算应为 `16,581,800.00 − 8,706,900.00 − 929,900.00 − 72,100.00 = 6,872,900.00`，而原文给出 **6,945,000.00**（差额 72,100.00，恰等于未减的处置损失）。**后续估值（6,945,000 ÷ 7.42% = 93,598,382.75）用的是原文数字 6,945,000。本页两值均照录，不做修正。**

## 四、⭐ 从自由现金流到每股内在价值（完整闭环）

### 4.1 公司价值（15.1 / 15.4.1）

```
公司价值 = 资产价值 = 金融资产价值 + 长期股权投资价值 + 经营资产价值
         = 资本价值 = 股权价值 + 债务价值

公司价值 = 金融资产账面价值 + 长期股权投资价值 + 经营资产自由现金流现值
```

三类资产的取值规则（原书）：

| 资产 | 怎么取值 | 原书理由 |
|---|---|---|
| **金融资产** | 直接取财报金额 | 「以财报中的金额作为金融资产的价值……**就估值日来说，以财报金额作为金融资产的价值依然是最合理的选择**」 |
| **长期股权投资** | 按收益率打折扣/溢价：收益率 = 贴现率 → 账面值；低于贴现率甚至为负 → **打折**；远高于贴现率 → **溢价** | 「对于长期股权投资金额不大的公司……花费非常多的时间和精力对其价值进行估算，显然得不偿失」 |
| **经营资产** | ⭐ **唯一需要贴现的部分** | 「**经营资产价值的估算成为股票估值的重点和核心**」 |

### 4.2 股权价值（15.4.2）

```
股权价值 = 公司价值 − 公司债务          （债务取账面价值，不用市场价值）
上市公司股票价值 = 股权资本价值 − 少数股东权益价值
                = 股权资本价值 ×（1 − 少数股东权益比例）
```

⚠️ **简化扣减式的失效场景（原书明说）**：「在**子公司亏损甚至即将关闭**的情况下，这种计算有可能会**低估**上市公司股东股票价值……如果存在巨额亏损的子公司，上述简化计算应该**谨慎使用**。」

### 4.3 万华化学算例（原样保留）

```
公司价值 = 金融资产 208,636.18 + 长期股权投资 18,612.81 + 经营资产价值 21,346,317.06
         = 21,626,068.16 万元        ← 原文数字
公司债务 = 2,313,423.57 万元
股权价值 = 21,626,068.16 − 2,313,423.57 = 19,312,644.59 万元   ✅ 减法复算通过
```
⚠️ **原文加总不一致（照录不修正）**：`208,636.18 + 18,612.81 + 21,346,317.06 = 21,573,566.05`，与原文给出的 21,626,068.16 相差 **52,502.11**。

### 4.4 中国石化算例（原样保留）

```
公司价值 = 金融资产 7,888,300.00 + 长期股权投资 8,297,000.00 + 经营资产价值 93,598,382.75
         = 112,363,182.75 万元        ← 原文数字
```
⚠️ **原文加总不一致（照录不修正）**：三项相加 = **109,783,682.75**，与原文的 112,363,182.75 相差 **2,579,500.00**。

## 五、⭐ 贴现率：WACC 的本书口径

### 5.1 公式与参数

```
WACC = kd × [D / (D + E)] × (1 − t) + ke × [E / (D + E)]

D = 债务资本，E = 股权资本
kd = 税前债务成本率，t = 公司实际所得税税率，ke = 股权资本成本率
```

| 公司 | 原文算式（原样） | 结果 |
|---|---|---|
| 万华化学 | `4.52% × 50% × (1 − 22.72%) + 9% × 50%` | **6.16%** |
| 中国石化 | `3.24% × 24.56% × (1 − 19.95%) + 9% × 75.44%` | **7.42%** |

（万华：税前债务成本率 4.52%、实际所得税税率 22.72%；中国石化：税前债务成本率 3.24%、实际所得税税率 19.95%；股权资本成本率均取 **9%**。资本结构权重取账面价值口径。）

### 5.2 ⭐ 股权资本成本率：否定 CAPM，用简化法（15.3.4）

```
股权预期回报率（主流）= 无风险利率 + 贝塔系数 × 股权风险溢价      ← 本书不采用

本书简化法 = 我国 5 年期国债利率 + 4%~5% 风险溢价 → 股权资本成本率 8%~10%
            （按个人风险偏好在区间内取值；本书演示统一取 9%）
```

**本书否定 CAPM / β 的原话**：
- 「用一个反映过去价格波动的数字就能完全描述一种证券风险的想法**真是太荒谬了**。」
- 「贝塔系数仅仅考虑了市场上的价格，而**没有考虑到公司具体的基本面或者经济发展**。」
- 「过去的波动性是一个**糟糕的**衡量风险的指标。」
- 「在股票估值中，**所有公司的股权资本成本是相同的**，不同的是公司之间创造未来自由现金流的能力不同。」

> 📌 推荐序一已预先声明：「本书的一些内容如对**有效市场理论、资本资产定价模型**等的论述，与传统的经典理论并不一致。」

> [!warning] 待复核（2017 年口径）
> 本书锚定的是「**2016 年我国 5 年期国债的利率为 4.2% 左右**」。该利率现已变化，**8%~10% 的区间必须按当期 5 年期国债利率重算，不得直接沿用**。
> 另：书中万华化学「未来可能不再享受所得税税率优惠政策，因此未来需要按照 **25% 左右**的所得税税率来进行自由现金流的估算」；中国石化实际所得税税率约 **25%**。
> ⚠️ 企业所得税率、高新技术企业优惠税率（书中提到万华曾享优惠致历史最低实际税率 10.84%）**均按 2017 年前税制**，当前须复核。

### 5.3 ⭐ WACC 权重用账面价值，不用市场价值（本书与主流教材的显式分歧）

| | 主流（本书点名的对手） | **本书** |
|---|---|---|
| 代表 | 《股票估值实用指南》（加里·格雷等）、达摩达兰《估值》 | 郭永清 |
| 权重口径 | **市场价值** | ⭐ **账面价值** |
| 本书的三条反对理由 | — | ① 分子（经营资产自由现金流）按账面价值计量，「分母应当与分子的口径保持一致」；② 「不能对资产采用账面价值而对资本采用市场价值」；③ 市场价值每天变 → 「**每天的贴现率不一致，每天的股票内在价值不一致，股票估值也就失去了意义**」 |

> ⚔️ **冲突登记**：本书 vs [[concepts/达摩达兰·估值方法与模型参数]]（达摩达兰用股权市值/债务市值加权，算例 `资本成本 =（股权市值 × 股权成本 + 债务市值 × 税后债务成本）÷（股权市值 + 债务市值）`）。**本页只登记，不裁决。**

### 5.4 ⭐ 风险调整走分子，不走分母

本书主张：不要用高贴现率惩罚高风险公司，而是**在估算自由现金流时取保守值**。
> 「第二种方法更加接近价值投资的本质——基于公司基本面的分析来进行股票估值。公司的风险不是取决于公司价格相对于市场的波动性，而是取决于公司经济基本面的变化。」

### 5.5 利率敏感度（原书算例，14/15 章）

30 年期、面值 1 万元、到期一次付息的国库券：

| 贴现率 | 贴现因子 | 现值 | 相对上一档变动 |
|---|---|---|---|
| 8% | `1/(1.08)^30 = 0.0994` | **994 元** | — |
| 7% | `1/(1.07)^30 = 0.1314` | **1,134 元** | **+320 元 / +32%** |
| 6% | `1/(1.06)^30 = 0.1714` | **1,174 元** | **+427 元 / +33%** |

→ 动作含义：**利率下行对长久期资产（含高成长股、转债正股）的估值抬升是非线性的**；做敏感性分析时利率必须单列。

## 六、⭐ 四个模型与本书算例参数（15.3.5）

| 模型 | 本书给的适用对象 | 本书算例与参数 |
|---|---|---|
| **零增长模型** | 「成熟稳定、没有增长的公司……比如成熟稳定的**公用行业**上市公司」，类似永久年金 | 中国石化：`6,945,000.00 ÷ 7.42% = 93,598,382.75 万元` |
| **不变增长（固定增长）模型** | 「有一些成熟的公司，未来的自由现金流以非常缓慢的速度增长」 | 无算例 |
| **两阶段模型** | 成长型公司：第一阶段详细预测期（**通常 3~5 年**）给高增长，第二阶段给低永续增长 | 万华化学：`FCF0 = 289,836.00 万元，g1 = 15%，WACC = 6.16%，g2 = 4%，n = 5`<br>→ 经营资产自由现金流现值 **21,346,317.06 万元** |
| **三阶段模型** | 成长 → 过渡 → 稳定，增长率由高到低 | 无算例 |

**g 的约束（原书）**：
> 「一般情况下，投资者的预期回报 WACC 至少要高于总体的经济增长率，因此**不变增长率 g 通常小于 WACC**。如果 g 永远高于 WACC，潜在的含义是很长时间以后，公司的规模将超过总体经济规模，这显然不可能。」

⚠️ **两点照录提醒**：
1. 万华两阶段算例里 `FCF0 = 289,836.00`，而 15.2.2 计算结果为 `289,636.00`（差 200）。**原文自身不一致，两值均照录。**
2. 两阶段 / 三阶段的**公式在文字层为图片，无法原样转录**；本页只保留参数与结果，不猜测公式形式。

## 七、⭐ 可落成的动作

| # | 动作 | 可验证触发条件 |
|---|---|---|
| **J-01** | **算经营资产自由现金流时用「经营活动现金流量净额 − 折旧摊销（近似保全性资本支出）」**，不要直接扣全部购建长期资产支付的现金 | 每年年报出来算一次；**成长期/扩张期公司尤其要用本书口径**，否则会把扩张投入误判为价值毁灭 |
| **J-02** | **机场类等「折旧远大于实际维护投入」的公司，手工下调保全性资本支出** | 折旧摊销占经营活动现金流量净额比例畸高、且长期资产已建成多年 → 触发调整 |
| **J-03** | **拉长窗口看自由现金流的可持续性** | 原书警告：「有些公司的经营活动现金流量净额……是**短时期内非正常地大量占用了上游供应商和下游经销商的资金**导致的……**一定要把分析的时间窗口拉长到多个年份**」 |
| **J-04** | **交叉验证**：经营资产自由现金流长期远大于 0 | 原书：「比较好的迹象在于……经营资产现金流都远远大于零，说明公司在完成保全性资本支出后，每年为公司股东和债权人创造了价值」 |
| **J-05** | **WACC 用账面价值口径算资本权重**，并做利率敏感性 | 分别算 `kd×(D/(D+E))×(1−t)` 与 `ke×(E/(D+E))`；利率变动 1pp 时对结果的影响单独列一行 |
| **J-06** | **g 必须小于 WACC** | 给永续增长率时先检查 `g < WACC`，否则模型不成立 |
| **J-07** | **扣少数股东权益** | 上市公司股票价值 = 股权资本价值 ×（1 − 少数股东权益比例）；**若存在巨额亏损子公司，该简化式会低估，须单独处理** |
| **J-08** | **估值结果只当参考，不当精确值** | 原书：「股票估值是艺术，不是科学。虽然在估值计算的过程中，我们计算到小数点后面两位，貌似精确，但其实是不可能的」 |

## 八、⚠️ 本书的最大落地缺口

原书算完万华化学每股内在价值后，只写了一句：
> 「至于低估 50 元还是 40 元或者 30 元**并不是很重要**，只要**被低估的幅度足够大**，就为我们的投资提供了足够的**安全边际**，因此发出了明确的**买入信号**。」

⛔ **「足够大」没有量化阈值。** 本书在估值端给出了完整公式链，但在「低估多少才动手」这一步**退回到定性**，且**没有给止损、仓位、持有期、卖出条件**。
→ 落地上必须配合 [[concepts/资金管理优先于仓位管理]]（仓位）与 [[claims/估值与仓位·五本书六处冲突]]（冲突裁决），本书单独用不了。
