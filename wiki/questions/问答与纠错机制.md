# 问答与纠错机制

> **这是你学习和本库共同成长的接口。**
> 学习时遇到问题在这里问；发现哪里写错了，这里也改。

---

## 一、怎么提问（三种方式）

### 方式 A · 直接在对话里问（推荐）

```
按库里已有内容回答：<你的问题>
```

AI 会先检索 `wiki/`，回答时**必须引用具体页面**（格式 `（依据 [[页面名]]）`）。

**如果库里没有，它会说「知识库中没有相关内容」—— 这是特性，不是缺陷。**
它不会用训练数据糊弄你。

### 方式 B · 主动纠错

```
我认为 [[某页面]] 写错了，因为<你的理由/原文证据>，请核实并修正
```

流程：
1. AI 回到原始资料（OCR 全文 / PDF 对应页）**核实**，而不是直接改
2. 核实成立 → 修正页面 + 在 `log.md` 记一笔+ 标注原误
3. 核实不成立 → 说明原文依据，**保留你的疑问记录**

### 方式 C · 学习过程中记录疑问

学完任何一阶段，把没想通的点写进 [[wiki/questions]]。
**问题本身就是资产** —— 同一个坑踩两次才是真的浪费。

---

## 二、提问时AI 遵循的检索顺序

```
1. wiki/hot.md         近期上下文，先看这个
2. wiki/index.md       总索引
3. 对应子类索引
4. 具体页面            只读真正相关的
```

**绝不把整个 wiki 读进上下文。**

---

## 三、⚠️ 回答纪律（AI 侧硬约束）

| 规则 | 说明 |
|---|---|
| **必须引用页面** | 格式 `（依据 [[页面名]]）` |
| **库里没有就说没有** | 不用训练数据补 —— 补了就失去知识库的意义 |
| **参数原样保留** | 不擅自优化；改造须单列「原值→建议值 + 理由」 |
| **冲突不抹平** | 保留各自来源与适用对象，**取舍由你拍板** |
| **数据分级标注** | 回测 / 模拟盘 / 实盘必须区分 |
| **不给投资建议** | 只做方法论层面说明，不写标的推荐 |
| **不确定就说不确定** | 不用模糊措辞掩盖 |

## 四、问题分类与去向

| 问题类型 | 写到哪 |
|---|---|
| 学某个概念是什么 | 已有概念页不足 → 补 `concepts/` |
| A 和 B 有什么区别 | `comparisons/` |
| 这个说法对不对 | `claims/`（需证据） |
| 综合来看怎么回事 | `syntheses/`（需跨 2 套体系） |
| 学习过程中的疑问 | `questions/` |
| 页面写错了 | 直接改 + `log.md` 记录 + 页面标注 |
