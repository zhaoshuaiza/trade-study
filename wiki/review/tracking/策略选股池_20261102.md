## 七、字段口径

| 字段 | 口径 |
|---|---|
| 被选进统计 | 该股当日出现在涨停池（`zt_pool`），即被选进一次；同一天不重复计 |
| 被选进次数 | 跨交易日累计出现天数（连板每天各算一次） |
| 首次/最近入选 | 最早/最近一次进入涨停池的日期 |
| 二次跳起 | 相邻两次入选间隔≥1 个未涨停交易日 |
| T+1 收涨率 / 续板率 | 二次跳起次日涨跌幅>0 / ≥9.8%，样本量随日期增长 |
| 无涨停基因 | 从未进入涨停池 → 不入选股池 |
