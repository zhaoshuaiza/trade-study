# 龙头价值赛道（彭道富体系）

> **本库唯一以"供求关系 → 主要矛盾 → 龙头"为链条的短线体系。**
> 与缠论（结构分析）、海龟（系统化）最大的不同：
> **它认为技术分析是"术"，逻辑才是"道"** —— 且明确指出缠论式的东西**根本抓不住大牛股**。

**序言作者**：炒股养家（淘股吧顶级游资）
**出版**：2026-01-18（Z-Library 出品）

---

## 一、体系定位

| 项 | 值 |
|---|---|
| 所属流派 | **价值派**（作者自述"不属于六大门派中的任何一派"） |
| 主战场 | **A 股短线**，强依赖涨跌停板制度 |
| 核心链条 | 价值 → 供求关系 → 主要矛盾 → 赛道 → 对标 → 先手 → 龙头 |
| 心法层 | 破心中贼 / 破执 / 色即是空（占全书约 1/4） |
| 与现有体系关系 | 与 [[entities/黑马王子]] 同属「跟庄/短线」赛道，但**哲学不同**：黑马看量价，本体系看逻辑 |

>📌 **适用边界（重要）**：本体系**强依赖 A 股制度**（涨跌停 + 无做空 + 题材炒作生态）。
> 换到美股/期货会**部分失效**，原因见 [[concepts/五套体系的适用市场]]。

## 二、六大门派与作者的位置（第26 章原文）

作者把市面上的"龙头战法"归为六派，**明确表示自己不属于其中任何一派**：

| 流派 | 特征 | 作者态度 |
|---|---|---|
| 周期派 | 用周期+择时做龙头 | 排斥其"术" |
| 技术分析派 | 找技术形态，起个名字叫龙头 | 排斥 |
| 消息派 | 四处打探消息 | 排斥 |
| 打板派 | 涨停板敢死队 | 排斥 |
| 坐庄派 | 资金优势操纵（山东帮/温州帮） | **唯一明确不排斥的** |
| 量化派 | 用量化做龙头 | 排斥 |
| → **价值派（作者自己）** | **价值第一** | 核心衣钵 |

> **关键区分**：「龙头战法」这个词已被用烂，各派混称。
> 作者的重新定义：**龙头战法的内核是价值第一**，没有价值性的龙头战法是"无源之泉，无本之木"。

## 四、⭐ 四个最有价值的原创判据

### 4.1 价值来自四个源头（第2章）

作者的"广义价值"定义——**不是教科书那一套**：

| 来源 | 含义 | 股市对应 |
|---|---|---|
| **从"争"中来** | 越多人抢越有价值 | 越被追捧越涨；**越涨越有人争** |
| **从"有用"中来** | 使用价值 | 业绩好、前景好 |
| **从"权力"中来** | 权力背书 | **政策/牌照** → 王府井免税牌照暴涨 |
| **从"信"中来** | 信念价值 | 信则有，不信则无 |

> 📌 **「争」是本体系最独特的洞察**：
> 「价值因争而产生，是人类的共性，不因身份高低、不因学历和智商而存在差别」
> —— 基金经理和散户在这一点上**完全一样**。

### 4.2 ⭐ 弹性价值（边际价值）—— 解释"为什么好公司不涨"

**这是全书最能直接落成判据的一条。**

> 「股票，特别是短期爆炸性的股票，**不是对基本面的反应，不是对价值性简单的映射，
> 而是对弹性进行反应**。」

作者的判据：
- **工商银行**基本面极好，但**弹性价值 ≈ 0**（每天赚的钱差不多）→ 除非牛市跟涨，否则几乎无表现
- **口罩股**：医生用的东西突然全民用+ 每天都用 + 持续数月 → **弹性无限大**
- **方大炭素**（2017）vs **宝钢**：宝钢赚得更多，但方大炭素石墨电极**每时每刻都在释放弹性**

**由此得出的判据**：
> 「**股价是对预期的反应，而不是对基本面的反应，也不是对事实的反应。**」
> 「**价值的敏感点在于变化，没有变化的价值也许不一定是龙头股战法所需要的价值。**」

这正好回答了那个经典问题：**为什么很多股票等到真正出财报、业绩非常高了，反而股价不涨了？**
→ **因为弹性价值没有了。**财报出来后变化停止了。

> 📌 这条判据与缠论的「背驰」有异曲同工之处：
> 都在找"**变化还在不在**"。但缠论看**价格结构**的变化，本体系看**基本面弹性**的变化。

### 4.3 ⭐ 供求关系 + 主要矛盾（第7-8章）

**供求关系**（作者认为是最底层逻辑）：

> 「供求关系是西方经济学最基础的词汇，我认为它同样也是做股票最基本的同时也是最重要的逻辑。」

最理想的形态——**需求端无限增加 + 供给端有瓶颈**：
> 「既让马儿跑，又不让马儿吃草。」

作者的验证案例：马化腾当年答投资人"我坚信它能挣钱"的依据是"**每天用QQ的人很多，后台服务器根本应付不过来**"
—— **纯供求关系，不是商业模式**。

**主要矛盾**（作者的"道"）：

> 「**投资的最大的道并不是存在于股市理论中**，无论是波浪理论还是CAPM，无论是技术分析还是价值投资，
> 这都是次逻辑。**最主要的逻辑，是社会上的主要矛盾。**」

作者的论证：
- 战争时期主要矛盾是"打赢敌人" → 军工股
- 资源紧缺时期主要矛盾是"资源占用" → 有色
- 和平时期主要矛盾是"吃喝玩乐" → 消费股
- **2006年起 A 股主要矛盾是"人与房子"** → 地产/银行/家电长期走牛

> 📌 **作者对"术"的明确贬低**：
> 「不要天天沉迷于打板呀情绪呀MACD呀量柱呀这些东西……
> **有道无术，术尚可求。有术无道，止于术。**」

### 4.4 ⭐ 正法模型（两象限，第51 章）—— 最好的思维工具

把交易决策放进**两个维度**：**逻辑性**（客观符合逻辑 + 主观自己懂不懂）× **信号性**（股价是否**已经**真的在涨）：

| | **无信号（未涨）** | **有信号（已在涨）** |
|---|---|---|
| **有逻辑** | 🟨 **我执**（最危险） | 🟩 **正法**（最好） |
| **无逻辑** | ⚪ 风平浪静（理想但不现实） | 🔴 **妄动**（绝大多数人亏钱的原因） |

作者的判词：
- **正法**：「只买有逻辑的上涨，放弃一切没有逻辑或者没有信号的操作」
- **我执**（有逻辑但没信号）：「逻辑虽然重要，但**这个逻辑是市场的逻辑才好**」—— 自己的逻辑+功力不够 =套几年
  > 作者举例：四川长虹、海虹控股、乐视网、中芯国际、康希诺维
- **妄动**：「**第四象限是绝大多数人亏钱的主要原因**」—— 眼红分时图波动，管不住手

> 📌 **核心操作原则**：
> 「**如果信号没有验证逻辑，或者说没有信号仅仅依靠逻辑，就是我执；
> 如果逻辑得到信号的呼应，就是正法。**」
>
> ⚠️ 但作者留了例外：**超级大佬可以在"我执"象限动手**，因为他们的逻辑往往**就是市场的方向**。
> 「对于其他绝大多数人，99.99% 的人，**不可臆想自己是大佬**。」

## 五、⭐ 龙头宪法九条（第24 章原文，可直接执行）

> **愁的人不是没有赚到钱，而是没有在龙头上赚钱。**

```
1、自选股里应该只放龙头，谁给买点买谁。凡是非龙头，放备选栏。
2、早盘前30 分钟，只看几个龙头的走势。看非龙头也是为服务龙头。
3、强制自己只与龙头发生关系。
4、有总龙头，就不要做分龙头。
5、有连板的龙头，就不要做反包的龙头。
6、有主升的龙头，就不要做反抽的龙头。
7、有主线的龙头，就不要做支线的龙头。
8、有明牌的龙头，就不要去挖什么暗线的龙头。
9、有市场选出的龙头，就不要做自己选的龙头。
```

> 📌 第9 条最有争议也最实用：**市场选出的 > 自己选的**。
> 这与「靠研究选股」的主流直觉相反，作者的理由见最大公约数理论。

## 六、⭐ 资金管理五条（比仓位管理重要一百倍，第60 章）

作者开篇即言：**有一种东西比仓位管理还重要百倍**。

**先看一个反差**：
> 「别人总资产有 1000 万，放在股市 100 万，他的全仓跟你的全仓是一回事吗？」
> 「如果不把这些搞明白，所谓的轻仓重仓就是**自欺欺人**。」

**五条规则（原文）**：

| # | 规则 | 关键词 |
|---|---|---|
| 1 | **永远不要贷款炒股，不要套信用卡炒股** | 第一原则 |
| 2 | 资金分不同等分，**永远不要把 100% 放股市**，至少留**一年家用现金** | 黑天鹅 |
| 3 | 大盘走熊 → **大部分资金转出**，股票账户**保留 30% 以下** | 「隔离法」，源于**对人性不信任** |
| 4 | 投入股市的资金**分几个账户** | 一个账户黑天鹅，不会全部 |
| 5 | 即使牛市，**投入股市不超过总资产 80%** | 「请人吃饭都要提前卖股票」的股民结局一定悲惨 |

作者的定位：
> 「炒股必须有"道"，**资金管理就是"大道"**。」
> 「如果大家把以上 5 点做到……**即使仓位管理出问题，只要资金管理没出问题，依然可以在股市中翻身**。」

> 📌 **与海龟的对比很有意思**：
> 海龟按 ATR 算仓位（[[concepts/ATR与N值]]），
> 本体系**明确否定"仓位管理"这个层次**，认为资金管理层更根本。
> 两者不冲突——**海龟假设你已经是那1% 仓位的人**，本体系讲的是"该不该把那笔钱放进股市"。

## 七、⭐ 两个"清醒剂"章节（第26、64 章）

### 7.1 看天吃饭第一条（第26 章）

**市场不好时，所有战法都失效**：

> 「没有增量资金，市场还不断抽血，新股大面积发行，动辄减持当道，**皮之不存，毛将焉附**？」

作者的禁令：
> 「当市场不赚钱的时候，没有赚钱效应的时候，**应该休息，而不是换方法**。
> 因为**换方法，在熊市里会让你亏得更快**。」

以及一句值得记住的话：
> 「为什么你在熊市一定会成为赵老哥，而不是被消灭的人？」
> —— ⚠️ **这句话是反讽**，意思是：多数人高估了自己在熊市中的存活能力。

### 7.2 多少人把"奇迹"当规律（第64 章）

以 **2018 年恒立实业**（连续翻 3 倍多）为例，作者的五问：

```
特殊1：2018 一路走熊，资金憋久了需要发泄口
特殊2：有壳资源题材，恒立就是壳资源活口
特殊3：壳资源结束后汽车股暴涨续命
特殊4：即将死亡之际科创板题材又来了
特殊5：当时炒作模式还没高度一致
```
> 「这 5 个特殊性，**也许永远无法复制**。但很多人却把它当规律。」

作者的批评：
> 「炒股**不能看"像"呀，应该看逻辑**。如果逻辑不对，所谓的像，
> 也许是把奇迹当规律来看。」

**并预告了后續失败案例**：照着恒立去炒鲁商发展 → 没复制；再照鲁商去 YY 宝鼎科技 → **形态分时图都很像，还是不行**。

> 📌 这与本库反复记录的「**参数优化 = 拟合噪声**」是同一件事，
> 作者用的是 A 股语境：把**偶然的形态巧合**当规律。

## 八、可执行判据速查

| 场景 | 动作 |
|---|---|
| 判断一只票能不能做 | **三问**：① 供求关系变了吗？② 弹性价值还有吗？③ 信号出来了吗？ |
| 拿到一个"好公司" | 先查**弹性**——每天赚的钱和昨天差不多 → **弹性为0**，除非牛市否则放弃 |
| 什么时候该休息 | **熊市 + 亏钱效应明显 + 下降趋势** → 停止交易，**不要换方法** |
| 什么时候不能碰 | **没有增量资金**的市场（新发+减持抽血） |
| 选股范围 | 只在**龙头**上做，杂毛/过气龙头不做 |
| 资金投多少 | **≤ 总资产 80%**；熊市股票账户 **≤ 30%** |
| 逻辑对但没涨 | 只允许**超级大佬**这么做；普通人等信号 |

## 九、与本库其他体系的对照

| 议题 | 本体系 | 其他体系 |
|---|---|---|
| **技术分析的地位** | ❌ 只是"术"，不沉迷 | 缠论/海龟：本身就是核心 |
| **赚钱靠什么** | 逻辑（供求+主要矛盾） | 缠论：结构；海龟：纪律 |
| **择时** | 看天吃饭，没行情就休息 | 海龟：永远持仓 |
| **止损** | 本书未强调止损，**强调资金隔离** | 海龟 2N 硬止损 |
| **量化** | 未直接表态 |⚠️ **缠论明确反对量化** |
| **优势票能否用技术分析抓住** | ❌ **不能**（苹果期货案例） | 缠论：可 |

> ⚠️ **一个重要的跨体系冲突**：
> 本体系说「特别是那些**用技术分析的，根本就拿不住苹果合约**」
> （第9章原话）。而缠论、海龟都是技术分析体系。
> 作者的立场很明确：**技术分析在极端行情（连续涨停、逼空）中会失效**，
> 因为「技术分析的工具无法处理极端行情」。
> 这不是说技术分析无用，而是**它的适用边界被本书作者质疑**。
