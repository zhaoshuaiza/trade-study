# RAG 论文 2020

## 基本信息

| 项 | 值 |
|---|---|
| 标题 | Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks |
| 作者 | Patrick Lewis, Ethan Perez, Aleksandra Piktus, Fabio Petroni, Vladimir Karpukhin, Naman Goyal, Heinrich Küttler, Mike Lewis, Wen-tau Yih, Tim Rocktäschel, Sebastian Riedel, Douwe Kiela |
| 机构 | Facebook AI Research（现 Meta AI） |
| 时间 | 2020-05-22 首发，2021-04-12 v4 |
| 会议 | **NeurIPS 2020** |
| arXiv | [2005.11401](https://arxiv.org/abs/2005.11401) |

## 简介

RAG 概念的**原始提出**。首次把「参数化 + 非参数化双记忆」用于**生成式**任务，
并给出可端到端微调的训练配方。此前这类可微分记忆结构仅用于抽取式任务。

## 关键贡献

1. 提出通用的 RAG 微调配方，把预训练 seq2seq（参数化）与维基百科稠密向量索引
   （非参数化）组合
2. **区分 RAG-Sequence 与 RAG-Token** 两种形式化
3. 三个开放域QA 任务上当时 SOTA

## 两种变体

| 变体 | 检索粒度 | 段落选择 |
|---|---|---|
| RAG-Sequence | 整个生成序列共用同一批段落 | 全局决策 |
| RAG-Token | 每个 token 可用不同段落 | 逐 token 决策 |

RAG-Token 更灵活（不同句子可依赖不同来源），代价是检索更频繁。

## 结果

- 三个开放域问答任务 SOTA，超过参数化 seq2seq 与任务专用
  retrieve-and-extract 架构
- 生成任务上比当时最优纯参数化 seq2seq 基线产出**更具体、更多样、更符合事实**的语言
