# 2023 RAG 综述

## 基本信息

| 项 | 值 |
|---|---|
| 标题 | Retrieval-Augmented Generation for Large Language Models: A Survey |
| 作者 | Yunfan Gao, Yunxiang Zhou, Peng Li, Siqian Kong |
| 时间 | 2023-12 |
| arXiv | [2312.10997](https://arxiv.org/abs/2312.10997) |

## 简介

LLM 时代最系统的 RAG 综述。核心贡献是把 RAG 的演进归纳为
**Naive → Advanced → Modular** 三代范式，并按**检索器、生成器、增强方法**
三大组件 + 评估体系来组织全貌。

## 关键贡献

1. 提出 RAG 三代范式分类法（本文最常被引用的部分）
2. 系统梳理检索优化：预检索五手段 + 检索阶段 + 后检索重排/压缩
3. 提出 Modular RAG 的新组件：路由、记忆、预测
4. 归纳三种增强过程：迭代、递归、自适应检索
5. 整理评估指标与基准

## 提到的自适应检索代表

- **FLARE**——通过监控生成概率决定是否检索
- **Self-RAG**——生成「反思令牌」，让模型自主决定检索时机与是否停止

## 评估基准

Natural Questions、TriviaQA、HotpotQA（多跳）、ASQA（歧义问题）
