## 放什么

| 类型 | 举例 |
|---|---|
| **交易体系** | 道氏理论、波浪理论、缠论、海龟法则 |
| **书籍/资料** | 《海龟交易法则》、《缠论108课》 |

## 判断标准

> **能指着它说「它就是这个东西」吗？** 能 → entities

- 「道氏理论」→ 能 → entities ✅
- 「趋势」→ 不能，它是个概念 → concepts
- 「中枢」→ 不能，它是个结构 → concepts

## 怎么写一个 entity 页

必备内容：基本信息表、核心贡献/参数、关键洞察、与其他体系的关系、来源页链接。

**交易体系页必须包含**：
- 一句话本质（这个体系最核心的洞察）
- 核心参数（原样保留 + 标注出处）
- 适用市场与周期
- 反面教训（如果有）

> 📌 海龟页记录了费思最终破产的教训——
> **这类「体系创始人自己没做到」的事实是体系页最有价值的部分。**
