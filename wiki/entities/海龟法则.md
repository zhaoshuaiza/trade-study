# 海龟法则

> 五套体系中**唯一完全机械化**的一套。把趋势思想变成可执行的系统。

## 基本信息

| 项 | 值 |
|---|---|
| 类型 | 机械化系统交易 |
| 实验发起 | Richard Dennis & William Eckhardt |
| 规则作者 | Curtis M. Faith（第一批学员，19 岁入场） |
| 形成年份 | 1983（两年实验期1983-1984） |
| 战绩 | 第一代平均年化约 80%，群累计利润约 1.75 亿美元 |

## 核心哲学

> **把风险控制放在第一位，把赚钱交给趋势，把人性关在门外。**

```
先确定能亏多少（仓位）→ 再考虑怎么赚（信号）→ 最后保证活到赚的那天（组合规则）
```

**六层逻辑链**（跳层必亏）：

| 层 | 名称 | 得出 |
|---|---|---|
| 第 0 层 | 生存层 | 任何时刻不能让单笔亏损击穿账户 |
| 第 1 层 | 度量层 | 用 N（ATR）把波动标准化成一个数字 |
| 第 2 层 | 仓位层 | Unit = 1% 净值 ÷ (N × 每点价值) |
| 第 3 层 | 信号层 | 20/55 日唐奇安突破 |
| 第 4 层 | 错误层 | 2N 硬止损，绝不后移 |
| 第 5 层 | 放大层 | 每盈利 0.5N 加 1 单位，上限 4 |
| 第 6 层 | 系统层 | 组合热度 4/6/10/12 + 回撤降档 |

## 核心参数（原样保留，禁止优化）

| 参数 | 值 |
|---|---|
| 入场通道 | 20 / 55 日唐奇安突破 |
| N 值 | ATR(20) |
| 仓位 | 1 单位 = 净值 1% ÷ (N × 每点价值) |
| 止损 | 2N 硬止损，入场同秒提交 |
| 加仓 | 每盈利 0.5N 加 1 单位，上限 4，只在盈利方向 |
| 出场 | 反破 10 日 / 20 日极值，不设目标价 |
| 胜率 | ⚠️ **38.7%~59.1%**（原书实测，因系统而异；网上流传的"约40%"是下限） |
| 盈亏比 | 1:3 ~ 1:6（推算，原书未直接给统一值）|
| ⭐ **入场** | **双系统**：20日（**上次盈利则跳过**）+ 55日（**不过滤**） |
| ⭐ **N 计算** | **每日开盘前算一次，当日不变** |

> ⚠️ 费思用两章专门讲「不要优化参数」——
> 任何在历史数据上调优出来的参数，都是在拟合噪声。

## 反面教训（必须一起记）

Curtis Faith 后来多次创业失败、加大杠杆、重仓、不设止损，**最终申请个人破产**。

他的原话：**「是我违背了规则，不是规则失效了。」**

> 📌 **海龟真正的对手不是市场，是持有系统的人。**

## 五套体系中的位置

| 体系 | 共同点 | 根本差异 |
|---|---|---|
| 道氏/波浪/缠论 | 都基于趋势 | 那三套**主观画线**，海龟**机械触发** |
| 缠论 | 都强调客观判据 | 缠论判「结构完成」，海龟判「价格突破」 |
