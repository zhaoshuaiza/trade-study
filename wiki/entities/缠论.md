# 缠论

> 国产最完整的结构分析体系。**不是波浪的改良，是另一条路**。

## 与道氏/波浪的根本差异

| | 道氏 / 波浪 | **缠论** |
|---|---|---|
| 观察对象 | 趋势的**形态** | 走势的**结构完备性** |
| 核心问题 | 趋势走到哪了 | 这段走势**完成了没有** |
| 核心概念 | 浪、周期 | **中枢**、走势类型、级别 |
| 画线 | 主观 | **严格定义，可机械判定** |
| 操作时机 | 趋势确认后 | **走势完成的判据出现时** |

**关键洞察**：缠论不预测方向，而是定义「**走势完成的判据**」——
走势没完成就不操作，完成就按类型对应操作。

## 核心概念

| 概念 | 含义 |
|---|---|
| **中枢** | 某级别走势类型重叠的价格区间，核心结构单元 |
| **走势类型** | 上涨、下跌、盘整（必须三选一，不可模糊） |
| **级别** | 日线/30分/5分等，不同级别的走势嵌套 |
| **背驰** | 同级别走势力度衰减，关键转折信号 |
| **三类买点** | 一买（趋势反转）、二买（回抽不破）、三买（中枢突破后回抽） |

> 📌 编译时应重点提取：**中枢的严格定义**与**走势完成的判据**。
> 这是缠论与海龟在方法论上真正的连接点——都是「判据化」。
