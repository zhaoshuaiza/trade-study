# 决策规则速查 — 走出幻觉·走向成熟

| 能力 | 一句话规则 |
|---|---|
| 盈亏同源——把亏损当进货成本 | 亏损不是做错的证明，而是获取趋势利润必须垫付的进货成本——规避亏损必然同时规避利润。 |
| 亏损五境界——诊断你对亏损的认知层级 | 拒绝面对→规避→承认合理→盈亏同源→得失随缘；先定位自己在第几层，再决定下一步谈什么。 |
| 风险防范只有两点——保住位置与绝对止损 | 真正的风险防范只有两条：守住趋势中的位置，以及给每笔一个绝对止损点；分散和买好公司都不是。 |
| 优化与组合陷阱——不要折腾参数和叠加策略 | 参数两端等效、方法叠加会把劣势一起叠加；给跟踪尺度找个固定的家，别再把利润调没了。 |
| 昆虫系统——作者给出的可复刻趋势跟踪配方 | 跨品种充分分散＋趋势信号进出＋每份等额资金＋赢时冲输时缩，用笨办法取胜率—赔率结构。 |
| 超市原理——高胜率正是你亏钱的原因 | 赚钱舍不得走、亏了死扛——这个本能制造高胜率，同时把利润平分、把亏损集中。 |
| 学习效应（狗咬尾巴）——别再追着近期的成败改方法 | 用最近的盈亏来评价方法、据此改方法，就是追自己尾巴——市场等你适应后才打破它。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
