### 2. 本书的根本特殊性（阶段 0 已判定，必须主导全部判断）

`BOOK_OVERVIEW.md` 第三节 ★可证伪性判定：**局部形式可证伪、整体是事后拟合的画线叙事**。五处结构性漏洞：

1. **输入主观**：三角形三点可选前低点/后低点/波段低点、可「两个低点都比较测试」、可「多走几天少走几天」、可在日/周/月/季/年线切换——三点一变所有线全变，「线在哪」由作图者选（行 539-542、1672-1673）。
2. **循环定义**：「看连续几天打不破 → 这时基本可以判定该线就是阻力线」（行 3937-3943），先见结果再命名机制、再用它「预测」。
3. **失败被无限吸收**：「只是相对而言」「都不是绝对的」「结合其他技术」「经验起决定因素」「认识不深刻」「即使买卖错了，也没有关系」——任何亏损都归因为使用者而非体系（行 2640-2650、1071-1079、3521-3524）。
4. **选择性记账**：200+ 图例**零失败复盘**；「每次卖出都是正确的！不管它后面的涨幅有多少，都与你无关」（行 2123-2125）排除踏空；「已经提前避免了即将发生的事情」（行 2584-2585）把未发生损失记战绩。
5. **零统计验证**：胜率 / 失败率 / 样本 / 回测 / 准确率 / 基准 **全文 0 次**，封面却称「通过大量的实战案例得到有效的验证」（行 4041-4042）——**以图例代替统计**。

结论：全书 **不是可复现交易系统**，而是「一套形式化却整体不可证伪的画线叙事」这一**样本**。其价值不在「多一条有效判据」，而在「一个可被逐条解剖的认识论标本」。

### 3. 因此「actionable 价值」判据必须反转解释（三条具体做法）

**做法 A —— 把判据4 的符号反转：从「可生成买卖指令」改为「可生成审查动作」。**

- 常规：某条能落成「突破中位线 + 次日开盘价确认 → 买入」→ actionable → GO。
- 本书：**越像可实盘操作的规则越危险**，因为晋级为「操作指引」会直接误导用户按一套整体不可证伪、零统计、且在自己主做的可转债上结构性失效的体系去下单。
- 反转后：凡**只提供买卖触发、不提供失效条件**的条目，判据4 判 **NO**，降级 `status: reference`，绝不作买卖指令。

**做法 B —— f01 / p 系列「看似最 actionable」的处置：晋级为「可检验的形式结构 + 其失效条件」，不晋级为可执行动作。**

- `f01 两段式确认母版` **GO**，但晋级定位是 `sanjiao-confirmation-rule-form` 的**研究对象**：输出契约是「结构化形式母版（触发/确认/动作）+ 逐条失效条件清单 + 局部可证伪 ≠ 整体可证伪 说明」，**不是**「何时买、何时卖」。
- `p01–p05 / p08 / p10–p12` 等 12 条纯买卖/选股细则 **NO**（reference），折叠进 M2 的 A2 段作「母版被套用到各线的注脚」，不单独发现、不作操作指引。
- 每个模块 description 强制含「仅批判性研究，不得据此实盘」，`critical_only` + `no_trading_advice` 双字段。

**做法 C —— 晋级优先级整体反转：审查工具提到最高，画线规则压到最低。**

- **GO（最高价值）**：`f07` 五漏洞审查清单、`f06` 循环定义、`ce01–ce05` 五类漏洞取证卡、`p17–p21` 失败吸收 disclaimer、`cases` 的「零失败复盘」核查结论——这些是**可迁移到审查其他技术叙事（尤其 089《主力操盘手法揭秘》同构的「主力意图叙事」）的高价值框架**。
- **NO / 降级**：画线规则本身（f01 的操作面、p 系列买卖触发、g 私有术语、c 个股图例）——交易语境限定、2026 年 A 股/可转债下连平移都做不到。
- V3 跨域结论（见第二节）直接支撑这一反转：**审查工具的跨域迁移力显著高于画线规则本身**。

- **V3 结论**：**审查工具的跨域迁移力显著高于画线规则本身**，且画线规则在用户主做的可转债 T+0 上**结构性失效、连平移都不可能**。这为第〇节的「晋级优先级反转」提供了独立于阶段 0 的第二个支撑：**按「用最少入口覆盖最多高价值意图」（03b 目标函数），入口应全部投给审查工具。**

## 三、五判据晋级门（GO / CONDITIONAL / NO）

> 判据依 `03b-stage1.6-promotion-gate.md` 五条：**①独立意图 ②独立契约 ③独立运行（以上必须通过）④独立复用 ⑤独立评测（与④至少 1 条通过）**。
> 与 085 样板简化五判据的映射：样板「判据4 对交易者 actionable」在此**按第〇节反转**为「对研究者 actionable = 可生成审查动作」，并叠加为凌驾于五判据之上的**★反转门**（见 3.1）。
> **GO** = 五判据基本全过，作为 promoted 模块锚点/核心证据卡；**CONDITIONAL** = 有价值但须合并/仅作子卡/边界卡；**NO** = 不晋级独立 skill，降级 `status: reference` 能力卡（术语/案例/操作细则），保留在来源路由入口，**不失联、不进 `rejected/`**（03b 硬规则）。

### 3.1 ★ actionable 反转门（凌驾五判据，先过这道）
