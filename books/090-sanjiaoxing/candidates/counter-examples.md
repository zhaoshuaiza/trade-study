- id: ce01
  title: 【漏洞#1·反面教材】输入主观、不可复现——三点选点与周期可自由裁量
  type: counter-example
  source_chapter: 第一章 第一节 选点（印刷 p.25-26 / 行 539-542、551-552）；时间窗见行 1672-1673；周期见行 1797-1799
  source_quote: |
    选择哪个点作为低点，要根据股票的实际走势，一般情况下均选择前低点（图1一30），如果后面的低点接近前低点，最好对两个低点都进行比较测试，然后做出判断。有些在上涨过程中出现的波段低点，也可作为测量低点结合分析，但对于新手不建议采用这些低点。
  failure_mode: |
    把「线在哪」当作数据给定，实际上由作图者主观选择：同一段行情可选前低点 / 后低点 / 波段低点、可「对两个低点都进行比较测试」、可「多走几天或少走几天」、可在日/多日/周/月/季/年线间切换。三点一变，中位线、对角线、反对角线、所有分数平衡线全部改变，导致「判据」不可复现、无法回测。
  mechanism: |
    这是典型的「 researcher degrees of freedom（研究者自由度）」：结论（线是否给出支撑/阻力）对输入选点高度敏感，而选点规则本身留有多条合法路径且「根据实际走势」裁定。总能挑出一段让历史走势「刚好」在某条线受阻的三角形，于是任何历史 K 线都能被解释。全书无多人选点一致性检验、无选点敏感度分析、零统计验证。
  warning_signs:
    - 「根据实际走势」决定用哪个极值点 / 哪个周期
    - 同一段行情画出好几条不同的线再挑「有效」的那条
    - 判错后改选一个低点或改用周线，图形就「对」了
    - 无法把「选哪三个点」写成不含裁量的程序
  bound_to:
    - "f03 三点选点+多周期"
    - "f11 大小三角形嵌套"

- id: ce02
  title: 【漏洞#2·反面教材】循环定义——先画线、看股价停在哪、再命名那条线为阻力线
  type: counter-example
  source_chapter: 第五章 综合运用总则（印刷 p.195 / 行 3937-3943）；「画线即结论」见行 2297-2299；「意外发现」见行 3660-3668
  source_quote: |
    如何确定是最大阻力线或最强支撑线，一般要看连续几天（或几周、月、季、年）股价突破或刚好打到该线后，收盘价均在该线下方，或股价虽然突破，但均未脱离该线，或股价在该线上下波动，表明该线阻力很大……这时基本可以判定该线就是阻力线。
  failure_mode: |
    把「预测项」与「被预测项」由同一段已发生行情导出：先观察股价连续几天打不破 / 刚好停在某条线上，再「这时基本可以判定该线就是阻力线」，反过来用这条线声称「事前」预测了股价。配合「当你画上阻力线（或支撑线）后，你就知道该买还是该卖，清晰可见」（行 2298）与反对角线系「实战中意外发现……这是一个新的发现」（行 3660-3668），是事后拟合最直白的自证。
  mechanism: |
    循环论证：线的「有效性」由它已解释过的那段价格定义，再用该「有效性」去解释同一段价格，没有独立的事前判定标准。若线真能事前给出支撑阻力，就不该由「看股价在哪儿停」来事后判定，但作者恰如此定义。叠加 ce01（三点主观）、ce03（角色可翻）、ce05（经验吸收），对任意历史 K 线总能画出至少一条线「刚好」解释每个拐点，整体不可证伪。
  warning_signs:
    - 「连续几天打不破 → 基本可以判定它就是阻力线」
    - 先看到股价停住，才给那条线命名／才把它画出来
    - 「意外发现 / 新的发现」某条线也很有效
    - 「画上线后就知道该买还是该卖」，却说不清线为何事前置于此
    - 阻力/支撑角色可随走势互相转换（「有可能」）
  bound_to:
    - "f06 循环定义"
    - "f09 周天循环几何类比"
    - "f10 画线即结论"

- id: ce03
  title: 【漏洞#3·反面教材】失败被无限例外与「综合 / 经验」吸收
  type: counter-example
  source_chapter: 第四章 第一节（印刷 p.126-127 / 行 2640-2650）；同型见行 1854-1858、2238-2239、2838-2840、3165、3944-3945
  source_quote: |
    三角形对角线与三角形中位线一样，理论上说是属于最大阻力线（或最大支撑线），但这只是相对而言，在一定条件下，其他阻力线或支撑线也会成为最大阻力线或最强支撑线，针对不同情况要做不同的分析。
  failure_mode: |
    体系给每条线排了「最大阻力线 / 最强支撑线」的等级，又用「但这只是相对而言」「在一定条件下其他线也会成为」「但这些都不是绝对的」「还要根据实际走势来分析」「有时也要根据实际情况变化」把等级架空，并要求「结合其他操作技术」「经验起着决定因素」。任何一次亏损都可归因为「没画全 / 没综合 / 经验不足 / 理解不深」，而非体系失效。
  mechanism: |
    这是「免疫化策略（immunizing stratagem）」：把核心断言包裹在可随时追加的例外与裁量里，使其不可被反例击中。线族本身又是开放集合（ce10「还有 1/3、2/3 斜线……不再赘述」），因此永远可以补一条没画出来的线；「经验决定」与「严格按照操作原则」（行 1037-1039、1757-1758）自相矛盾，形式化规则被人为裁量架空。零统计验证，无失败率、无「结合其他技术」的操作化定义。
  warning_signs:
    - 「只是相对而言」「都不是绝对的」「要结合实际走势」
    - 判错后被告知「要综合运用 / 经验不够 / 认识不深刻」
    - 「理论上属于最大阻力线」与「其他线也会成为」并存
    - 规则之外总有一个「灵活运用」的口子
    - 宣称「严格按照操作原则」却又说「经验起决定因素」
  bound_to:
    - "f05 多线综合+经验裁量"
    - "f07 不可证伪五漏洞审查清单"
    - "f09 周天循环几何类比"
  tags: [counter-example, negative-textbook, falsifiability-hole-3, failure-absorption, hedge-wording, discretion-override, unfalsifiable, zero-validation, critical-only, no-trade-advice]

  title: 【漏洞#4·反面教材】选择性记账——排除踏空成本、把未发生损失记为战绩
  type: counter-example
  source_chapter: 第三章 第一节末（印刷 p.122 / 行 2584-2585）；第二章 第二节（印刷 p.102 / 行 2123-2125）
  source_quote: |
    操作原理，你还会去买这样的股票吗？虽然你无法判断后天的大阴棒，但你已经提前避免了即将发生的事情。
  failure_mode: |
    绩效口径被自我定义：只记「按原则卖出躲跌 / 按原则买入获利」，不记「按原则买入后亏损 / 卖出后踏空」；「最后你会发现你的每次卖出都是正确的！不管它后面的涨幅有多少，都与你无关」（行 2123-2125）主动把踏空成本排除在外，「已经提前避免了即将发生的事情」把未发生的损失当成战绩入账。全书 200+ 图例无一例「按原则买入后亏损」的完整复盘（见 cases.md 末尾核查）。
  mechanism: |
    幸存者偏差 + 后视镜偏误：图例与「观察点」全部标在已发生行情上，只挑选体系「看起来对」的片段；同时通过重新定义「什么算一次交易绩效」，把无仓位的「不介入」也算作成功、把踏空剔除。如此「每次卖出都是正确的」成为恒真命题，无法用净收益、基准（买入持有/随机入场）或失败率去检验。零统计验证，无交易成本/滑点核算。
  warning_signs:
    - 「不管它后面的涨幅有多少，都与你无关」
    - 「提前避免了即将发生的事情」被记成盈利
    - 只见躲跌图例，不见「按原则买入后亏损」的复盘
    - 绩效用「每次卖出都正确」而非净收益/胜率衡量
    - 「观察点」全标在已走完的 K 线上
  bound_to:
    - "f07 不可证伪五漏洞审查清单"
    - "f10 画线即结论"

  failure_mode: |

  title: 「理论与实际有差距」一律归因于使用者认识不深刻、买卖错了也没关系
  type: counter-example
  source_chapter: 第一章 第一节末（印刷 p.43 / 行 1071-1079）
  source_quote: |
    理论往往与实际给人一种差距，那是因为你对理论的认识不深刻，理解和掌握还不够，同样的操作技术，不同的人得到的结果却不一样，甚至相反。在实际操作中必须严格按照操作原则进行交易，即使买卖错了，也没有关系
  failure_mode: |
    自我豁免式归因：当体系预测与实际走势不符，不追问体系是否有效，而把差距归因于使用者「认识不深刻，理解和掌握还不够」，并安抚「即使买卖错了，也没有关系」；「要及时总结经验」也只导向「下次更严格按原则」，从不指向修正或放弃原则。
  mechanism: |

    - 「理论与实际有差距是因为你认识不深刻」
    - 「即使买卖错了，也没有关系」
    - 同一方法不同人结果不同，被当作免责而非缺陷
    - 复盘只总结「更严格执行」，从不检验规则本身
  bound_to:

  title: 单凭一条线「当天就会买入」——靠追加「其他阻力线」提前消解潜在误判
  type: counter-example
  source_chapter: 第五章 第一节 图5-8 东方市场（印刷 p.184 / 行 3726-3729）
  source_quote: |
    图5一8"东方市场"次日开盘价刚好开在平衡线上方，如果单凭反对角线与1/2平衡线来测量判断，当天就会买入，这里如果结合其他操作技术来综合测量分析，就会提前发现受到其他阻力线的压力，三角形操作技术是多种技术的结合运用
  failure_mode: |
    作者自认：仅按反对角线与 1/2 平衡线会发出买入信号（隐含会买错），但「结合其他操作技术」就能「提前发现受到其他阻力线的压力」而避开。单条线判错不构成体系失效，反被用来论证「必须多技术综合」。
  mechanism: |
    潜在反例被「追加一条没画出来的线」吸收：线族开放（ce10）使任意一次误判都能补一条阻力线解释；「如果……就会买入」是反事实假设而非实盘复盘，全书无「按原则买入后亏损」的完整案例（见 cases.md 核查）。配合 ce07，失误最终归为「没综合 / 熟练度不够」。
  warning_signs:
    - 「如果结合其他技术，就会发现还有另一条阻力线」
    - 用反事实假设代替真实亏损复盘
    - 每次判错都能补出一条先前没画的线
