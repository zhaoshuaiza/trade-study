  term: 中位线（封面作「中信线」）★核心
  type: term
  source_chapter: 第一章 第一节（印刷 p.15 / 行 353-357、361、738）；封面孤例见行 11
  author_definition: |
    "过去我们只认为从低点到高点（或从高点到低点）50%处是重要的阻力位，却忽略了任意三角形中位线也是重要的阻力位，前者实际上就是属于底边为直线的任意三角形中位线的一种"（行 353-357）；"从低点到高点的50%处即中位线"（行 738）；"中位线在三角形其他平衡线当中属于最大阻力线"（行 361），下跌三角形中为"最强支撑线"（行 1755）。
    封面行 11 作"中信线"：全书仅此 1 次，正文/目录/封底均作"中位线"（523 次），疑为封面异写或 OCR 形近误识（位→信），下游一律按「中位线」处理。
  key_distinction: |
    ★ 重点：作者把**经典的 50% 半分位 / 半分回撤位重新包装成自创术语**。他自己承认"过去我们只认为……50% 处是重要的阻力位"，即这个数值锚本来就是传统百分比回撤；他的"创新"只是把该 50% 位改称"三角形中位线"，并按底边斜率分出"直线 / 上斜线 / 下斜线"三型、声称斜线型"更具普遍性"。
    ≠ 数学「中位线」：数学中位线是连接三角形两边中点、平行于第三边的线段，与"低点到高点 50% 处的水平位"不是同一构造；作者借用了几何名词，实际指价格区间的半分位。
    ≠ 标准形态学的趋势线 / 颈线；它不是由两个极值点连出的趋势线，而是由两点价格差取 50% 得到的水平（或随底边倾斜的）分割线。
    = 有 50% 这一数值锚、定义相对清楚（定义清晰度：中），但属「旧概念换新名」；其"最大阻力线"地位又由事后走势指认（见 g06）。
  why_it_matters: |
    下游所有涉及买卖触发的 skill 都会出现此词。若沿用数学义，会误以为要「连接两边中点作平行线」，画出完全不同的线；若沿用「50% 回撤位」常识义，又可能把它当作已被验证的标准工具、替作者的"三角形"背书。正确用法是：明确它=价格区间 50% 分位（经典半分位的重新包装），标注「封面『中信线』孤例 / OCR 误识」「2015 年旧生态、未验证」，且不据此生成任何买卖点位。

  type: term
  source_chapter: 第二章 第一/二节（印刷 p.80、p.93 / 行 1854-1858、2076-2080、2118-2119）
  author_definition: |
    "经过长期研究和实战验证上涨三角形的1/4、3/4高点平衡线都是阻力线，与上涨三角形中位线相比，1/4、3/4高点平衡线的阻力相对要弱些，但高点平衡线比起1/4、3/4平衡线又要强些，但这只是相对而言"（行 1854-1858）；下跌三角形 1/4、3/4 低点平衡线"主要起支撑作用"（行 2088-2093）；"1/4阻力线主要是在股价反弹的最初几天里，就如同第一道关卡……如果股价反弹未能突破1/4平衡线，这是反弹无力的表现"（行 2076-2080）。
  key_distinction: |
    ≠ 斐波那契 / 黄金分割回撤位（38.2% / 61.8%）；作者用的是 1/4、3/4、1/2 等**简单分数**，并归因于"三角形一分为四 / 三角形分割"，而非浪型或黄金比例。

    = 近似「百分比回撤位」的直觉被重新包装为「三角形平衡线」；是 g01 半分位套路的横向扩展到 1/4、3/4 位（旧概念换新名的又一例）。
  why_it_matters: |
    下游若把「1/4、3/4 平衡线」当成独立、经验证的技术指标或斐波那契位，会与道氏/波浪资产错误互证（BOOK_OVERVIEW 第七节明确「不可互相印证」）。须标注：简单分数位 + 未验证 + 力度「只是相对而言」，且操作原则「与上涨三角形中位线同」（p16）只是母版换线位置。

  term: 上涨三角形 / 下跌三角形
  type: term
  source_chapter: 第一章 第一/二节 基本形态（印刷 p.10、p.44 / 行 250-257、1093-1107）
  author_definition: |
    "上涨三角形有三种基本形态。第一种形态是股价两个低点处于同一条直线上或基本处于同一条直线上……第二种情况是前一个低点低于后一个低点……第三种情况是前一个低点高于后一个低点……在实际操作中要根据股票的实际运行走势来确定这三种三角形的基本形态"（行 250-257）；上涨三角形 = 两个低点 + 一个高点（a 低点、c 低点、b 高点），下跌三角形 = 两个高点 + 一个低点，按底边/高边是「直线 / 上斜线 / 下斜线」分三型。
  key_distinction: |

    ≠ 有客观识别标准的形态：作者自承「要根据股票的实际运行走势来确定这三种三角形的基本形态」，三点选点主观（g01 / ce01）。
    = 全书本体论的基本单元：股价「低→高→低」一次循环的三点连线（对应 g08 周天循环）。
  why_it_matters: |
    库内 021 酒田 78 条及形态学资产中的「三角形」是标准整理形态；若下游不显式区分，会把两套同名异物互相印证、叠加结论，产生严重误用。任何引用须写明「作者自创的三点三角形，≠ 经典上升/下降三角形整理形态」。

- id: g08
  term: 周天循环理论
  type: term
  source_chapter: 前言（印刷 p.1 / 行 72-78）；第五章 第一节（印刷 p.182 / 行 3665-3668）
  author_definition: |
    "股票走势从低点到高点，又从高点回落到低点；或从高点到低点，从低点回到高点，就是一个循环，如同走了360°，如果把这三点连接起来就是一个三角形。股价的涨跌，每一个循环都是围绕这样的三角形来运行的，三角形越大说明这一波的行情越大"（行 72-78）；"它符合自然法则的运动规律一周天循环理论，与其他技术派相比，三角形测量技术更具操作性、实用性和有效性"（行 3665-3668）。
  key_distinction: |
    ★ 把几何 / 天文类比（三点连三角形、360° 循环、「五心四圆三点一线」、江恩「轮中之轮」）当作价格运行的**因果机制**，是未经论证的本体论跳跃（对应 f09）：数学结构美 ≠ 社会数据因果；未与随机漫步 / 有效市场 / 多重检验偏差对话。
    ≠ 可检验的周期理论：无周期长度的定义、无样本、无「三角形越大行情越大」的量化与检验。
