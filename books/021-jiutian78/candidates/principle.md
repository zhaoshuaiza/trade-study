# 阶段 1 候选 · 原则 / 清单 / 规则（principle）

> 来源：《日本蜡烛图技术详解：酒田78条战法解析》朱成万 2015
> 每条含：书中佐证位置 / 内容要点 / 可执行动作

---

## P1 · 止损只升不降（结构跟随式止损）

- **书中佐证位置**：第42页（line 1398-1401「当大阳线B出现后止损设B开盘价9.02；C出现设9.20；D出现设9.44…止损位只能不断提升，不能不断降低」）；第2页二星止损在大阳1/2（line 3447）；第106页倍量大阳止损上提（line 3593）；第281页跳空低开大阳开盘价为止损（line 9529-9530）
- **内容要点**：每个买入信号绑定止损，挂在「信号结构的关键点」（大阳线开盘价 / 颈线 / 下影线一半），且**只上调不下调**。不是固定百分比止损。
- **可执行动作**：建仓当日即定止损=信号大阳开盘价；每出现一根新的放量大阳，把止损提到其开盘价；绝不因浮亏而下调止损。

## P2 · 顶部宜速、底部宜缓（买卖速缓不对称的规则化）

- **书中佐证位置**：第47-48页（战法6 切入线，line 1654-1660「高位切入线收盘前20分钟即可卖出；低位切入线须等股价涨过其最高价才买」）；第21页（line 702-707「一见大阴线就卖，赢多输少；跳空大阴立即卖出不可抢反弹」）；第68页（line 2670 见顶强于见底）
- **内容要点**：见顶信号即时执行（当天收盘前 20 分钟可卖）；见底信号等确认（突破信号高点再买）。顶部侥幸心理强、底部抢筹多，故节奏相反。
- **可执行动作**：高位看跌组合→次日开盘附近减仓；低位看涨组合→只在收盘突破该组合最高价后才介入。

## P3 · 盘整期观望「不动如山」（形态坟场原则）

- **书中佐证位置**：第374页尾（line 12859「不动如山：行情走势不明时，退场观望」）；第23页（line 773「交错线后续发展无法预测，只能静观其变」）；第31页孕出线/十字星盘整期大多失效（阶段0 命题11）
- **内容要点**：盘整期交错线、孕出线、人首线、十字星大多失效，方向不明时唯一正确动作是观望。
- **可执行动作**：当价格陷入横盘、信号互相矛盾时，退出或空仓，不做方向押注；等突破盘整区间再加立场。

## P4 · 形态强度分级（信号家族与深入度排序）

- **书中佐证位置**：第23页（line 750-752「友淡反攻 < 乌云盖顶 < 倾盆大雨 < 穿头破脚，阴线收得越低卖力越大，依次渐强」）；第46页（line 1588「三个图形见底信号依次渐强」）
- **内容要点**：一阳一阴家族按阴线深入阳线实体的深度排序；二连阴+阳线家族（迫切线<入首线<插入线<逆袭线）按第3根阳线收盘深入度分级。越深入，信号越强。
- **可执行动作**：看到看跌家族形态，先判它在家族里的「强度档位」再决定动作力度——弱信号（友淡反攻）只减仓，强信号（穿头破脚/怀抱线）果断清仓。

## P5 · 有效跌破/突破颈线三项量化标准

- **书中佐证位置**：第350页（line 11895-11898「收盘价在颈线之下 + 保持3天（至少2天）+ 跌幅≥3%；下影线刺穿不算」）；第351页头肩顶（line 11990「击破颈线3天后不能收于上方，头肩顶才算成立」）
- **内容要点**：确认顶部/底部大形态成立的硬标准——收盘破位 + 时间≥2~3天 + 幅度≥3%，下影线刺穿无效。
- **可执行动作**：价格刺穿颈线当天不行动；等收盘确认+满足时间/幅度后才认定形态成立并清仓；仅下影线刺穿则继续持股观望。

## P6 · 成交量辨真伪判别树（洗盘 vs 出货 vs 真突破）

- **书中佐证位置**：第20页（line 685-688「高位放量大阴=主力出逃；下跌往往不需量，洗盘会爆巨量（对倒）」）；第14页（line 442-446 高位涨停大阳诱多出货）；第94-95页（line 3190-3229 洗盘黑三兵不破支撑 + 量可放大）
- **内容要点**：放量突破=真；天量+高位=诱多出货；缩量/对倒巨量+不破重要支撑=洗盘；无量下跌=真跌（向下突破不需要量）。
- **可执行动作**：出现看跌形态先查位置+量——高位天量大阳=诱多减仓；下跌中无量破位=真跌继续空；回调巨量但不破支撑=洗盘持股。

## P7 · 缺口四分法 + 普通缺口 90% 回补

- **书中佐证位置**：第70页（line 2351-2366「四类：普通/突破/测量/衰竭；90% 情况下普通缺口都会回补」）；第67页（line 2306「酒田认为1周不回补则有大行情，但统计发现对A股…」）
- **内容要点**：普通缺口（盘整中、易回补、短期意义近零）、突破缺口（脱离形态）、测量缺口（趋势中）、衰竭缺口（量大/末端）。A 股实证普通缺口 90% 回补。
- **可执行动作**：向上普通缺口上方相对高点抛、缺口封闭后买回做差价；不把普通跳空当趋势信号；1周不回补的缺口才可能是突破/测量缺口，顺着原趋势看。

## P8 · 形态度量最小目标位

- **书中佐证位置**：第350页（line 11899「突破颈线后跌幅≈头部到颈线跌幅」）；第351页（line 11990 回升高于颈线则形态不成立）；第54页红三兵目标（line 12484）
- **内容要点**：头肩顶/双顶/三川/双底突破后的最小涨跌幅 = 形态高度（头部/低点到颈线垂直距离），实际常超过。
- **可执行动作**：进场同时算最小目标位作为止盈参考；价格到达度量位前不轻易丢筹码，到达后可分批了结。

### 独有贡献 / 时效 / 语境（同 framework，原则层补充）
- **独有**：结构跟随止损（只升不降）、买卖速缓原则、盘整不动如山——均为本书把酒田战法「操作化」的原创提炼，尼森版停留在「识别形态」。
- **2015 边界**：P6 的「主力对倒巨量=洗盘」依赖庄股时代特征；量化主导后纯量价辨庄可靠性下降。
- **A股语境**：涨跌停制度使大阳实体上限 20%（line 321-322），止损与目标位的绝对点数需按 A 股涨跌停约束理解。
