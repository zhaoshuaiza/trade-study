## 1. 结构 (Structural)

### 类型

实操手册 / 模式识别型技术分析再解。不是原典翻译——《酒田战法》原书（纪念本间宗久，昭和二十四年首版图形版）只有条文式记载；本书是作者用「数学定理教学法」对 78 条逐条做的现代 A 股语境重构。

### 一句话主旨

**78 条战法不是 78 个独立信号，而是同一套方法论在 78 种 K 线形态上的应用——任何形态的多空含义都由「位置、成交量、后市确认、均线系统」四要素决定，脱离位置谈形态必错。**

### 骨架 (主要论点及其关系)

1. **形态层**：78 条按「单线（1–5）→ 双线（6–14）→ 三线（15–22）→ 组合（23–44）→ 星线（45–52）→ 反击线（53–57）→ 舍子线（58–59）→ 三法（60–61）→ 底部/顶部大形态（62–70）→ 简要八条（71–78）」由元素到组合排列 —— 层层递进
2. **位置层**：同一形态在不同波段含义相反甚至失效（「一模一样的大阴线，处在不同的波段、不同的位置上，对后市的指引作用也截然不同」）—— 全书的地基
3. **确认层**：任何单个信号都不能当机立断，须等确认线；且「见顶信号强于见底信号」，故卖出「宜速不宜缓」、买入「宜缓不宜速」—— 位置层的操作化
4. **辨伪层**：成交量是分辨主力洗盘与出货的标尺（放量突破=真、天量高位=诱多、缩量不破支撑=洗盘、无量下跌=真跌）—— 确认层的核心工具
5. **操作层**：每个信号配套止损位（前大阳线开盘价 / 颈线 / 关键低点，止损只升不降）与目标位（形态最小度量涨幅）—— 从信号到动作
6. **验证层**：全书用 2008–2012 年 A 股实例逐条验证，并诚实记录失败案例与统计心得 —— 经验主义立场

**论点之间的关系**: 递进 + 工具链。位置层是地基，确认层与辨伪层是操作化的工具，操作层落到止损/目标位，验证层是作者的立场声明。

### 作者要解决的核心问题

**原典条文太简略、时代太远，不能照搬于当代 A 股。** 作者要把「笼统的战法条文精细化」——每条给出可识别的形态特征、可复现的判断流程、可验证的 A 股案例，让读者「认得出、判得准、动得了手」。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 位置 | 形态所处的波段阶段（高位/低位/中位/盘整期），判断优先级高于形态本身 | 常识把「位置」当背景信息；本书把它当作**决定符号的一级变量**——高位大阳线与低位大阳线符号相反 |
| 四看策略 | 判断任何 K 线组合的四步：一看出现位置、二看成交量、三看后市走势、四看均线系统 | 不是作者原话压缩，是作者在大阴线战法中明确给出的决策框架，全书反复引用 |
| 确认线 | 信号出现后第 2/3 天（乃至三五天内）的 K 线，用来验证信号真伪 | 常识把 K 线信号当即时结论；本书所有信号都是「待确认假设」 |
| 骗线 / 洗盘 | 主力故意做出的、与真实意图相反的形态（高位大阳诱多、缩量黑三兵逼筹） | 常识的「洗盘」是模糊说法；本书给了可判据：缩量 + 不破重要支撑位 |
| 有效跌破颈线 | 收盘价在颈线之下 + 保持 3 天（至少 2 天）+ 跌幅 ≥3%；下影线刺穿不算 | 常识的「跌破」是目测；本书给出三项量化标准 |
| 缺口四分法 | 普通/突破/测量/衰竭四类，靠「是否脱离形态、是否伴随密集形态、成交量、回补速度」区分 | 与西方经典缺口理论一致，但本书强调 A 股实证：普通缺口 90% 回补、衰竭缺口判别最佳依据是成交量 |
| 止损位只升不降 | 每当新的放量大阳线出现，止损位提到其开盘价；只上调不下调 | 常识止损是固定百分比；本书是**结构跟随式止损** |
| 信号以后出为准 | 多个矛盾信号并存时，以最新出现的信号为准 | 反「信号叠加」直觉——不是越多信号越确定，而是时序优先 |

### 核心命题 (用自己的话)

1. **K 线形态没有固有含义，含义由位置赋予。** 同样的大阳线，在低位是见底、中位是加速、高位是诱多出货、下跌途中是反弹一日游。
2. **所有信号都是待确认假设。** 单根或单个组合出现时只能提高警觉，不能行动；底部信号比顶部信号需要更多辅佐确认（顶部形成容易、底部形成难）。
3. **见顶信号强于见底信号，市场结构不对称。** 因此操作节奏相反：见顶「宜速」（当天收盘前 20 分钟即可执行卖出），见底「宜缓」（等突破信号高点再买）。
4. **成交量是辨认真假的核心标尺。** 放量突破=真突破；天量+高位=拉高出货；缩量+不破支撑=洗盘；无量下跌=真跌（向下突破不需要量）。
5. **每个买入信号必须绑定止损位，且止损只升不降。** 止损挂在「信号结构的关键点」（大阳线开盘价/颈线/下影线一半），不是固定百分比。
6. **形态有家族与强度分级。** 一阳一阴家族：友淡反攻 < 乌云盖顶 < 倾盆大雨 < 穿头破脚（怀抱线）；二连阴+阳线家族：迫切线 < 入首线 < 插入线 < 逆袭线。按第 3 根阳线收盘深入阴线的深度分级。
7. **「跳三跳，气数尽」有适用条件。** 只适用于盘整期末端；大牛市/大熊市中三空之后还有十来个缺口，「对盘整期比较适用，但大牛市或大熊市则不适用」。
8. **主力行为是可解读的。** 拉高出货（高位大阳+天量+次日回落）、洗盘（缩量+不破支撑）、诱多（红三兵骗线、破前覆盖线假突破）构成全书叙事框架。
9. **形态给出最小目标位。** 头肩顶/双顶/三川/双底突破后的最小涨跌幅 = 形态高度（头部/低点到颈线的垂直距离），实际常常超过。
10. **统计验证但不神化。** 「大阳线后次日上涨概率约 70%」「高位十字夜明星后大跌概率 80% 以上」是作者的经验统计（无样本量披露）；同时作者明确记录反向证据（如「夜星>十字夜明星>长黑回补型信号渐强」被证伪，「股票市场有时是没有定论的」）。
11. **盘整期是形态的坟场。** 交错线、孕出线、人首线、十字星在盘整期大多失效；方向不明时唯一正确的动作是观望（尾页「不动如山」）。
12. **时间框架分层可信。** 月线信号 > 周线 > 日线；同一形态在大盘/大盘股/小盘股上的出现频率与含义不同（高位大阳线在小盘股常见、大盘股罕见）。

### 论证链

作者用「数学定理教学法」搭建全书：先给形态特征（定理是什么）→ 技术含义（证明）→ 变式研究（举一反三，把形态放回家族与位置中）→ 实战验证（A 股例题，含失败案例）→ 小结与统计心得（概括提炼）。78 条合起来论证的不是「这些图案 predictive」，而是「**K 线判读是一个四要素决策过程，图案只是其中一个输入**」。

## 3. 批判 (Critical) ★

### 作者的时代局限

- 2015 年出版，全部案例取自 2008–2012 年 A 股。那是 T+1、涨跌停、散户主导、庄股文化余晖的时代。2015 年后的量化交易、注册制、程序化报备使「主力控盘」的叙事基础部分失效（本书把一切异常量价归因于「主力意图」）。
- 书中统计（70%、80%、90%）来自作者个人样本，无样本量、无时间外推检验，属小数定律。

### 作者的立场盲点

- **主力本体论**：全书默认市场上存在一个可解读的、有意图的「主力」。这带来两个问题：①把随机性量价异常过度诠释为操纵；②散户视角的「识庄」框架在机构博弈/量化主导的市场里解释力下降。
- **形态中心主义**：78 条全部围绕 K 线组合，成交量与均线只是配角，本书**完全没有**资金管理（仓位、单笔风险 %、凯利/破产风险）、没有交易成本与滑点、没有多周期共振分析——单靠本书构成不了可执行的交易系统。

### 未被证明的假设

- 「位置」是全书的决定性变量，但作者判断位置时大量使用事后视角（「只有大阳线 D 出现后，我们才有理由认为 C 处的切入线是底部」）。**信号的实时可操作性存疑**：如果位置只能事后确认，信号的入场价值就被削弱——这是本书最强的内在张力。
- 「见顶信号强于见底信号」被当作公理反复使用，但只给了行为学解释（顶部侥幸心理、底部抢筹），无严格统计证据。

### 最强反对意见

**如果形态含义完全由位置决定，而位置只能事后确认，那么任何形态信号的实时胜率都不可知——本书提供的不是可执行信号，而是一套事后解释框架。** 作者用「止损只升不降 + 等确认线」部分回应了这一点（把信号降级为假设、把执行权交给确认线），但这恰恰说明：**真正可执行的不是 78 条图案，而是「位置四看 + 确认线 + 结构止损」这套元规则**。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**
