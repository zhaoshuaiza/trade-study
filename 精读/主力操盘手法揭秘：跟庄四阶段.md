# 主力操盘手法揭秘：跟庄四阶段

> 主力建仓我潜伏，主力拉升我坐轿，主力撤退我逃命。
> 来源：[[sources/主力操盘手法揭秘]]（蒋幸霖，清华大学出版社）

## 主力坐庄四阶段

### 1. 建仓
- 方式：横盘建仓 / 打压建仓 / 快速拉升建仓 / 中继平台式建仓 / 跌停式建仓
- 盘面特征：K线小阴小阳、底部放量、潜伏底形态
- **跟庄逻辑：主力建仓我潜伏**

### 2. 试盘
- 目的：试探上方抛压和散户跟风程度
- 手法：拉升试探、打压试探、单笔大单试盘

### 3. 洗盘
- 目的：洗掉不坚定筹码，抬高成本
- 常见：横盘震荡洗盘、挖坑洗盘、假破位洗盘
- **别被洗出去：缩量回调是健康洗盘**

### 4. 拉升与出货
- 拉升：缩量涨停、连续放量
- 出货：高位放量滞涨、巨量长阴、利好兑现出货
- **主力撤退我逃命**

## 主力五大特性

- 雄厚的资金
- 专业的分析团队
- 信息优势
- 控盘能力
- 反散户操作

## 看盘基础（识别主力动向）

### 内盘外盘
- **内盘（绿）**：主动性抛盘，内盘大 → 抛压重，可能下跌
- **外盘（红）**：主动性买盘，外盘大 → 买盘强，可能上涨
- ⚠️ **庄家可利用内外盘欺骗**，要结合股价位置和总量看

### 第一笔成交
- 第一笔成交量大的股票 → 资金热切关注
- 第一笔成交一般 → 主力未主动参与

## 散户亏损三大原因

1. 靠小道消息 → 上当
2. 靠技术分析 → 被主力骗线
3. 跟风买入 → 被套山顶
