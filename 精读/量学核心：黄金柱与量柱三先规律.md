# 量学核心：黄金柱与量柱三先规律

> 量柱是有形、有性、有级的实体。黄金柱是牛股与黑马的温度计。
> 来源：[[sources/量柱擒涨停]]（黑马王子）

## 核心判据

### 1. 三先规律（量学的底层逻辑）

| 规律 | 含义 |
|---|---|
| **卖方先于买方** | 没有卖就没有买，抛压先出现 |
| **价涨先于量涨** | 价格变动先于成交量变动 |
| **量柱先于价柱** | 量柱是因，价柱是果 |

**执行规则**：看盘先看量，再看价。量在价先。

### 2. 六种基本量柱

| 量柱类型 | 市场含义 | 操作启示 |
|---|---|---|
| 高量柱 | 多空分歧最大 | 警惕变盘 |
| 低量柱 | 抛压枯竭 | 接近底部 |
| 平量柱 | 多空平衡 | 等待方向 |
| 倍量柱 | 资金突然进场 | 关注突破 |
| 缩量柱 | 交投清淡 | 观望或洗盘 |
| 梯量柱 | 逐步放量 | 趋势形成 |

### 3. 黄金柱 = 牛股温度计

**黄金柱三要素**：
1. 倍量柱突然放量
2. 后续缩量不跌破该量柱实底
3. 价格逐步走高

**黄金线**：黄金柱的实底价就是支撑线（黄金线），回踩黄金线不破就是买点。

**执行规则**：
- 找到黄金柱 → 画黄金线 → 回踩黄金线买入
- 跌破黄金线止损

### 4. 凹口淘金战术

- 股价下跌后形成凹口（底部形态）
- 凹口出现黄金柱 = 主力开始吸筹
- 凹口淘金 = 在底部黄金柱出现时买入
