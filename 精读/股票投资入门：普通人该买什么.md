# 股票投资入门进阶与实战：普通人该买什么

> 选择优质股并坚持长期持有，获得的收益绝不逊于其他投资。
> 来源：[[sources/股票投资入门进阶与实战]]（朱孜、王俊龙）

## 为什么普通人该买股票

### 1. 比存款强

- 建行股持有十年（分红再投入）＞ 定期存款
- 招行2004年买10万，2019年变137万，年化18.4%

### 2. 比房产强

- 格力电器十年涨幅 ≈ 北京西城房价
- 房产难做短线所以拿得住，股票总想高抛低吸反而亏

### 3. 历史数据（西格尔《股市长线法宝》）

美国1802-2002两百年：
| 资产 | 年均真实收益率 |
|---|---|
| 股票组合 | 6.6%（十年翻一番） |
| 长期债券 | 3.6% |
| 短期债券 | 2.7% |
| 黄金 | 0.7% |
| 美元现金 | -1.4%（购买力每年下跌） |

## 风险警告：期货不适合普通人

- 2020年原油宝事件：WTI原油跌到-37.63美元/桶
- 抄底的人保证金赔完还要倒欠银行三倍
- 没有杠杆都能倾家荡产，何况期货自带杠杆

## 核心方法

1. **选优质股**（银行股、成长股都行）
2. **长期持有**（十年起）
3. **分红再投入**
4. **不要追涨杀跌**
