# 慢即是快：普通投资者的五大阶段

> 低估买入、耐心持有、高估卖出。
> 来源：[[sources/慢即是快]]（三年一倍，20年一线经验）

## 核心方法

### 低估买入、耐心持有、高估卖出

- 投资方法经过五次迭代后的总结
- 适合大部分普通投资者
- 大概率赚钱、胜率高、可复制

## 从0到N的五大阶段

### 阶段一：顿悟混沌（新手裸奔）

- 听别人说赚钱就急匆匆开户
- 追热点、高买低卖（作者亲历：2007年买波导股份站岗）
- **90%的散户最终都是亏损结局**

### 阶段二：技术投资

- 苦学K线、指标、均线
- 作者发现：纯技术仍然难逃贪婪恐惧
- 技术分析三大假设：市场涵盖一切 / 价格沿趋势移动 / 历史会重演（各有局限）

### 阶段三~五（逐步成熟）

- 认识市场：知己知彼
- 洞悉周期和均值回归
- 基本面规避陷阱 + 仓位控制 + 投资心理

## 股市人性（作者亲历总结）

- 涨了后悔买少，暴涨后想全押一夜暴富
- 顶部提醒风险 → 被骂挡发财
- 跌了后悔买早，底部提示机会 → 被骂害人精
- **"七亏二平一赚"的铁律永远循环**

## 两只产品的路径

- 股票：底层逻辑 + 三种找好股票方法 + 好买点好卖点
- 基金：指数基金六大策略 + 定投
