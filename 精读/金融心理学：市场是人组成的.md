# 金融心理学：市场是人组成的

> 股票市场波动印证的并不是事件本身，而是人们对事件的反应，是数百万人对这些事件将会如何影响他们未来的认识。最重要的是，股票市场是由人组成的。——巴鲁克
> 来源：[[sources/金融心理学]]（拉斯·特维德）

## 四项基本原理

### 1. 市场走在前面

- 所有投资者的看法总和，不是某个人能掌握的
- "其他人"可能知道我们不知道的事情
- 走在市场认识之前，是艰巨的任务

### 2. 市场是非理性的

- 市场反应快，但主观、感性、被狂想控制
- 价格随大众的疯狂和冷漠摇摆，不由证券价值决定
- **每个投资者都试图理性，实际上都表现出非理性**

### 3. 混沌支配

- 经济模型越好，结果越混沌
- 非线性系统只能预测非常短期的行为
- **无法做客观、定量的长期预测** → 只能求助于主观猜测

### 4. 技术图形自我实现

- 许多人画相同的线、用相同软件 → 效果自我强化
- 用的人多了，图形就"灵"了，无论实际含义是什么

## 凯恩斯的洞察

- 职业投资者最关心的不是预测收益，而是**比群众早一步预测市场陈规的改变**
- 最高明的投资 = 先发制人，智夺群众，把坏东西让给别人
- 凯恩斯投资成功的主因：把主要精力放在心理学而非经济学

## 趋势市/转势/崩盘的心理

### 趋势市
- 趋势开始形成：少数人先动 → 跟随者加入 → 大众接盘
- 庞氏先生：不断有新人加入，接盘链条

### 转势时的预警信号（节选）
- 利多不涨 / 利空不跌
- 成交量背离
- 大众一致看多（反而危险）

### 崩盘的心理
- 动物本性：恐慌传染
- 牛市顶部往往伴随过度自信和杠杆

## 对交易的启示

1. **别预测长期** —— 混沌支配，长期不可预测
2. **别相信"大家都理性"** —— 市场就是非理性的
3. **技术分析有效是因为用的人多** —— 自我实现
4. **盯住群体心理** —— 转势看大众情绪的极端
