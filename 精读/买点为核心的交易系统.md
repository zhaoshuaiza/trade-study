# 买点为核心的交易系统

> 以买点为交易系统的唯一核心，卖点用简单、机械的方式处理。进攻是最好的防守。
> 来源：[[sources/简简单单做股票]]（楚云风）

## 核心判据

### 1. 买点 > 卖点

| 阶段 | 误区 | 结果 |
|---|---|---|
| 早期 | 只追求好买点 | 常败 |
| 中期 | 只研究好卖点 | 常败 |
| 后期 | 两者同等重视 | 还是常败 |
| 顿悟 | **买点是核心，卖点是机械规则** | 稳定 |

**执行规则**：
- 深研买点，浅做卖点
- 买点决定了，卖点自然就确定了（人出同源）
- 好的买点会把人性中矛盾纠结的影响降到最低

### 2. 一次盈利的交易必然是从一开始就盈利

> 利弗莫尔："要想在投机中赚到钱，就得买卖一开始就表现出利润的商品。那些买进或卖出后就出现浮亏的东西说明你正在犯错。"

**执行规则**：
- 进场后如果三天内没有浮盈，说明买点错了，先出来
- 追求"一开始就盈利"的入场点
- 不盈利就先出来，再等时机，直到等来一个对的入场点

### 3. 买点的两个要求

1. **不是真正的好机会不介入**——宁可不做，也不做错
2. **绝不追高，尽量在临界点附近介入**——耐心等关键点

**执行规则**：这会训练你的耐心，让你避免随机交易、因小失大。

### 4. 初始止损 = 买点的保护网

- 止损不是进场后才想的，是和买点相伴而生的
- 好的买点天然止损幅度小（因为在临界点附近，错了就是错了）
- 小亏大赚，长此以往就能稳定获利
