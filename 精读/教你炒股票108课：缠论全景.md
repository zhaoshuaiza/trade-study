# 教你炒股票108课：缠论全景

> 走势终完美。没有趋势，没有背驰。
> 来源：[[sources/教你炒股票全3册]]（缠中说禅，108课全集）

## 核心体系总览

### 1. 走势必完美（最根本）

- 任何走势都由趋势（上涨/下跌）与盘整构成
- 走势终将完成，完成的标准由中枢定义

### 2. 中枢（走势的心脏）

- 连续三个次级别走势的重叠区间构成中枢
- 中枢级别扩张 → 走势级别升级
- 中枢是判断走势延续与转折的核心

### 3. 背驰（转折的信号）

- 没有趋势，没有背驰
- 趋势末端，力度衰竭 = 背驰
- MACD辅助判断：黄白线回抽0轴后再创新高/低，力度减弱

### 4. 三类买卖点（操作核心）

- **第一类**：背驰点（趋势末端，力度衰竭）
- **第二类**：第一类之后的次级别回抽（不破前低/前高）
- **第三类**：中枢震荡后离开中枢，回抽不进中枢

## 关键论断

- **"不戴套的操作不是好操作"**：每一笔操作都要有止损保护
- **"没有节奏，只有死"**：节奏错了，什么理论都没用
- **资金管理是最稳固的基础**：投资的艺术归根结底是资金管理的艺术
- **大牛不用套**：不要用老思路套新走势，市场永远超越一般人想象
