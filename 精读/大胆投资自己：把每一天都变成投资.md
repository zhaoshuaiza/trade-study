# 大胆投资自己：把每一天都变成投资

> 只要我们在做决定前能够思考一下"眼前的选择将会对自己的未来产生怎样的影响"，那么这些就都可以看作一种投资。
> 来源：[[sources/大胆投资自己]]（松浦弥太郎）

## 核心观点

### 1. 一切都是投资

- 吃什么、睡多久、怎么运动 → 对身体的投资
- 学习、阅读、获取信息 → 对头脑的投资
- 时间管理、碎片时间应用 → 对未来的投资

### 2. 放弃思考 = 浪费人生

- "只要享受眼前的快乐就够了" = 浪费时间和金钱
- 每天认真投资自己和忽视投资的人，几年后必有巨大区别

### 3. 习惯成就未来

- 把投资变成习惯，恒心才是关键
- 规则要写下来，认真遵守
- 例：松浦的规则 = 早起 + 跑步一小时 + 五点后不工作 + 晚饭后散步

### 4. 规则要每天修正

- 规则不是"固定答案"，只是"当前合乎时宜的选择"
- 世界在变，自己也在变，要持续怀疑、试错
- **每天改变一点点，积少成多**

## 对交易者的启示（本库视角）

- **交易日志 = 对自己的投资**：记录、复盘、修正规则
- **交易纪律 = 习惯**：止损、仓位都是习惯问题
- **规则要迭代**：和交易系统一样，规则不是一成不变
- **别指望暴富**：积少成多，每天进步一点点
