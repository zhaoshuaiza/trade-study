# 弹性价值：为什么好公司不涨

> 股价不是对基本面的反应，是对**变化（弹性）**的反应。没有变化的价值，股价就不涨。
> 来源：[[sources/龙头价值与赛道]]（彭道富，2020）

## 核心判据

### 1. 弹性价值 > 静态价值

| 类型 | 例子 | 股价表现 |
|---|---|---|
| 弹性大 | 口罩股（突然全民用、天天用、持续半年） | 爆炸性上涨 |
| 弹性大 | 方大炭素（石墨电极天天涨价） | 涨疯了 |
| 弹性为0 | 工商银行（每天赚的钱差不多，明天无惊喜） | 常年趴着 |
| 弹性为0 | 宝钢（利润大但稳定无变化） | 跑不赢小公司 |

**执行规则**：找股票不是找"最好的公司"，是找"正在发生巨大变化的公司"。

### 2. 为什么出财报利好反而不涨？

> "很多股票等到真正出财报了，业绩非常高了，反而股价不涨了——因为弹性价值没有了。"

- 财报前：产品价格天天变、业绩天天超预期 = 有弹性 = 涨
- 财报后：利好落地、预期兑现 = 弹性消失 = 不涨了

**执行规则**：**买在弹性释放的过程中，不要买在弹性兑现的那一刻。**

### 3. 龙头的六大流派（作者定位：价值派）

| 流派 | 方法 | 问题 |
|---|---|---|
| 周期派 | 用周期选时+情绪 | 容易变成择时赌博 |
| 技术派 | 找好形态叫龙头 | 本末倒置 |
| 消息派 | 四处打探消息 | 你听到的是别人想让你听的 |
| 打板派 | 涨停板敢死队 | 纯博弈，无价值支撑 |
| 坐庄派 | 资金优势操纵 | 违法+接盘风险 |
| 量化派 | 程序做龙头 | 没有灵魂 |
| **价值派** | **先找价值性，再找弹性** | **作者主张** |

### 4. 四种基本价值（龙头的价值基础）

1. **有用性价值**（母价值）：产品/服务真有用
2. **权力价值**：政府/政策认可、特许经营
3. **信仰价值**：品牌信仰、用户忠诚（茅台的核心）
4. **竞争价值**：大家抢着买、因争而贵

**执行规则**：四项价值占得越多，龙头根基越稳。一项都不占的是负价值。

## 原文金句

> "股票，特别是短期爆炸性的股票，不是对基本面的反应，不是对价值性简单的映射，而是对弹性进行反应。"

> "股价是对预期的反应，而不是对基本面的反应，也不是对事实的反应。"

> "没有价值性的龙头战法，终将成为无源之泉，无本之木。"
