# 量线八大元素：量学的画线系统

> 汝欲学炒股，功夫在股外。
> 来源：[[sources/量线捉涨停]]（黑马王子，2014）

## 量线八大基本元素

| 量线 | 定义 | 作用 |
|---|---|---|
| **峰顶线** | 连接两个峰顶的线 | 压力位 |
| **谷底线** | 连接两个谷底的线 | 支撑位 |
| **平衡线** | 横向水平线 | 多空平衡点 |
| **斜横线** | 倾斜的水平线 | 趋势线 |
| **峰谷线** | 峰顶和谷底连接 | 重要支撑/压力 |
| **精准线** | 多次精准触线的位置 | 高概率买卖点 |
| **灯塔线** | 像灯塔一样指示方向 | 主升浪方向标 |
| **通道线** | 上下两条线围成通道 | 趋势通道 |

## 核心操作逻辑

1. 找到关键量线（支撑/压力）
2. 看价格在量线附近的反应
3. 精准线 = 多次触线不破 = 高概率买点
