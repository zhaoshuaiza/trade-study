# 可转债10种交易策略（小白版）

> 耐得住寂寞，才能守得住繁华。
> 来源：[[sources/可转债投资小白躺赚指南]]（于佳蓉，2020）

## 10种常见策略

| 策略 | 操作 | 适合人群 |
|---|---|---|
| **1. 低价买入持有** | 买100元以下的债，拿着等涨 | 懒人 |
| **2. 低溢价率策略** | 找溢价率<10%的，跟正股做 | 有时间看盘的 |
| **3. 双低策略** | 价格+溢价率都低的，分散买10只以上 | 稳健型 |
| **4. 下有保底策略** | 买到期收益率>0的，拿着等到期 | 极度保守 |
| **5. 强赎博弈策略** | 快要强赎前买入，吃最后一段涨幅 | 短线 |
| **6. 回售套利策略** | 跌到回售价附近买入，等回售 | 保守套利 |
| **7. 转股套利策略** | 折价时买债转股马上卖 | 专业 |
| **8. 打新策略** | 可转债新股申购，中签就卖 | 人人可做 |
| **9. 摊薄成本策略** | 跌了加仓，拉低成本 | 有资金的 |
| **10. 轮动策略** | 定期换成双低的转债 | 主动型 |

## 最适合新手的两个

### 1. 双低策略（推荐）

- 选"价格低 + 溢价率低"的可转债
- 分散买10-20只
- 定期（每月/每季）轮动
- 历史年化15%+

### 2. 打新策略（零门槛）

- 新债发行就申购
- 中一签（10张）一般赚100-300元
- 中签率低，但几乎没风险

## 与本库其他体系的关系

## 注意事项

⚠️ 新手从打新和双低开始：
- 不要上来就做短线
- 不要买高溢价率的妖债
- 注意强赎风险，别拿着被强赎
