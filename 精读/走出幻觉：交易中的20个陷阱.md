# 走出幻觉：交易中的20个陷阱

> 我们在市场中看到的，往往不是市场本身，而是我们自己内心的幻觉。
> 来源：[[sources/走出幻觉走向成熟]]（国内交易经典）

## 核心陷阱（摘要）

### 认知类

| 原理 | 含义 |
|---|---|
| 冰山原理 | 你看到的只是冰山一角 |
| 树形原理 | 交易结果不可预测，只能概率应对 |
| 恐龙效应 | 过去成功的经验，未来可能害死你 |
| 高低错觉 | 你觉得高了/低了，市场不这么觉得 |
| 对错悖论 | 对的操作也可能亏钱，错的操作也可能赚钱 |

### 心理类

| 原理 | 含义 |
|---|---|
| 焦虑原理 | 越想赚钱，越容易亏钱 |
| 鸵鸟现象 | 亏钱了就装死，不看账户 |
| 绿草坪效应 | 总觉得别的股票/别的方法更好 |
| 依赖现象 | 依赖指标、依赖老师、依赖消息 |

### 系统类

| 原理 | 含义 |
|---|---|
| 复利悖论 | 长期复利几乎不可能 |
| 损耗原理 | 交易成本会慢慢吃掉你 |
| 圆木桶理论 | 系统的短板决定你的极限 |
| 点球原理 | 关键时刻你会失误 |

## 作者的结论

- 大师们的结局都不好（利弗摩尔自杀、江恩破产……）
- 技术分析和基本分析都有局限
- 最终要走向交易系统之路
- 先走出幻觉，才能走向成熟
