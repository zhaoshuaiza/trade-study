# 缠论核心框架：走势必完美

> 市场无须分析，只要看和干。不预测，只应对。
> 来源：[[sources/缠论108课详解]]（扫地僧解读版）

## 核心公理

### 1. 走势终完美

任何走势类型（上涨/下跌/盘整）都会完成。完成之后必然转化为另一种走势类型。

**推论**：没有永远的上涨，也没有永远的下跌。走势是有结构的，可以被拆解。

### 2. 走势的递归结构

```
分型 → 笔 → 线段 → 中枢 → 走势类型 → 更高级别走势
```

- 小级别走势组成大级别走势
- 级别越大，稳定性越高
- 操作只做自己级别内的买卖点

## 三类买卖点（缠论的核心操作）

| 买卖点 | 定义 | 含义 |
|---|---|---|
| **第一类买卖点** | 背驰点 | 趋势衰竭，反转信号 |
| **第二类买卖点** | 一买后的第一次回抽不创新低/高 | 确认反转成立 |
| **第三类买卖点** | 中枢离开后的第一次回抽不回中枢 | 新趋势确认 |

**执行规则**：
- 一买：左侧抄底/逃顶，风险高
- 二买：更安全的入场点
- 三买：趋势确认后追入

## 两个关键概念

### 1. 中枢

- 股价在某个区间内上下震荡，形成的价格密集区
- 中枢是多空平衡的产物
- 离开中枢后的回抽不回中枢 = 第三类买卖点

### 2. 背驰

- 价格创新高/新低，但力度（MACD、成交量）跟不上
- 顶背离 = 上涨动能衰竭，准备反转
- 底背离 = 下跌动能衰竭，准备反转

## 操作纪律（第94-96课精华）

1. **当机立断**：买卖点出现就执行，不要犹豫
2. **修炼自己**：技术只是工具，最终拼的是心态
3. **杜绝一根筋思维**：走势有多义性，不要死认一种数法
4. **远离聪明，机械操作**：不要自作聪明改系统
