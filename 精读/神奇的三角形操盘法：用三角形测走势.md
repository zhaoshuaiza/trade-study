# 神奇的三角形操盘法：用三角形测走势

> 股价的涨跌，每一个循环都是围绕三角形来运行的，三角形越大说明这一波的行情越大。
> 来源：[[sources/神奇的三角形操盘法]]（三角形理论技术派）

## 核心理论

### 股票三角形理论

- 股价从低点到高点、高点回落到低点 = 一个循环（360°）
- 把三点连接起来就是一个**三角形**
- 三角形越大 → 行情越大；三角形越小 → 行情越小
- 整个走势由大大小小的三角形构成

### 关键线：三角形内的支撑阻力

- **对角线、中位线** = 股价运行中的重要阻力线/支撑线
- 股价运行到这些线附近 → 受阻力（或支撑）
- **跌破或突破这些线 = 卖出或买入的最佳出击点**
- 还有反对角线、1/4、3/4高低点平衡线、1/3、2/3平衡线

## 操作原则（以中位线为例）

### 买入信号

1. 股价最高点打到中位线（或差一点、突破一点），当日收盘在中位线下方
2. **次日开盘价在中位线上方 → 买入**
3. 若次日开盘仍在下，股价突破中位线且收盘在上，第三天开盘在上 → 买入
4. 次日开盘高开在中位线上方 → 买入

### 卖出信号

1. **次日开盘价跌破中位线 → 卖出**
2. 收盘价跌破中位线 → 卖出
3. 当日收阴线 → 坚决卖出
4. 当日收盘留长上影线 → 先离场观望
5. 连续两天打到中位线未能突破，第三天开盘在该线下方 = 最后卖出机会

## 理论特点

- **纯技术派**：无需分析繁琐指标和信息
- 信息都会提前反映到K线图上，正确运用K线可提前预测走势
- 适用于期货（在股票熟练基础上），中长线短线都可用
