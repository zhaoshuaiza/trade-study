# 养家心法：赚钱效应与回撤控制

> 看看天气，如果觉得要下雨了，就早点回家，不要贪玩，天气好了再出来。
> 来源：[[sources/著名游资悟道心得]]（18位游资心法汇编）

## 核心判据

### 1. 控制回撤的本质

> "控制回撤，最重要的就是回避系统性崩溃风险，事实上绝大部分崩溃都有前兆。"

**执行规则**：
- 从赚钱效应/亏钱效应的演变推断大势
- 止损 = 不看好了就卖出，管它是不是止损
- 感觉要下雨就早点回家，不要贪玩

### 2. 赚钱效应的循环

```
短线选手赚钱 → 自信增加 → 投入下一个品种 → 群体效应 → 热点有持续性
    ↓
反过来：追涨接二连三失手 → 资金大幅回落 → 反思减少操作 → 强势股补跌
```

**执行规则**：踏准这个循环节奏，就能分辨机会大小，决定仓位。

### 3. 追涨vs超跌切换

| 市场状态 | 做什么 |
|---|---|
| 有赚钱效应 | 做热点（追涨） |
| 有恐慌效应 | 做超跌（抄底） |

**执行规则**：超跌品种稳住了，强势股机会才大；超跌继续创新低，强势股补跌在即。

### 4. 超跌出击的两个条件（同时满足）

1. **大盘角度**：连续下跌一段后，再出现大阴线，指数远离5日线
2. **板块角度**：超跌板块连续下跌后，再次出现集体性大幅杀跌

**执行规则**：两者结合才是超跌出击时刻。单独一个条件不做。

### 5. 龙头战法的核心

> "龙头战法的核心：第一时间发现市场的精神领袖，第一时间上了。"

- 龙头能延续龙头地位，获得领先的收益
- 不要等龙头走出来了再追——第一时间发现，第一时间上车
