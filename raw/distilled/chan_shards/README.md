# chan_shards/ · OCR 分片目录

> **AI 自动写入，你不用管。**
> 这是缠论 593 页 OCR 时的**临时分片**，合并后就没用了。

---

## 放什么

每 10 页一个 `.txt` 文件，文件名标明页码范围：

| 文件名 | 内容 |
|---|---|
| `p0001-0010.txt` | 第 1~10 页 OCR 结果 |
| `p0011-0020.txt` | 第 11~20 页 |
| … | … |
| `p0591-0593.txt` | 最后一批 |

文件开头用 `=== 第N页 ===` 分隔每页，页码可定位。

---

## 为什么分片

593 页一次性跑，中途失败就得从头开始。
分片后**断点续跑**：哪片失败只补那片，不用重跑全量。

---

## 特性

| 特性 | 说明 |
|---|---|
| **可以随时删** | 合并成完整文本后就没用了 |
| **不是知识层** | 不参与检索、不参与双链 |
| **不要手工编辑** | 会被下次合并覆盖 |

---

## 完整文本在哪

合并后生成：

```
.raw/distilled/缠论108课详解-OCR-简体.txt
```

由 `merge_chan.py` 生成（库根目录）。

> 📌 **你要读的是合并后的完整文本，不是分片。**
> 分片只是给 OCR 进程用的。
