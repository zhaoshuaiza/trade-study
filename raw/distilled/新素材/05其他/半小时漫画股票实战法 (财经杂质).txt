序三
“炒股”这个词已经不时髦了，经过十多年指数层面的熊市之后，
一部分老股民已经心灰意冷。新生代则相对佛系，对股市兴味索然。
在这样的氛围下，“财经杂质”出版一本股票交易实战作品，着实需
要勇气。拿到书稿后，我发现书中结集的技术分析理论和股票交易
“战法”相当全面，漫画形式妙趣横生，我一口气读完，十分过瘾，
想借此谈谈个人拙见。
股票交易已经延续300年，我们要断言技术分析和趋势理论业已
消亡，还为时尚早。股票被当作一串代码反复交易的这个习惯，经过
股票市场的洗礼，仍被大家保留了下来。这皆因人类基因中“代价最
小化存活”的原始设定。我们有理由相信，“以小博大”作为欲望的
一部分或许将永远存续下去。
技术分析的鼻祖们，个个深谙人性，他们把不可捉摸的供求关系，
转化成技术与趋势的指标传授给别人。人们又在此基础上盲目地“完
善”指标，于是他们距离“股票是经济资产的一部分”的原点也就越
来越远。很多股民一生中最好的投资时光都在这个迷局里耗散殆尽。
交易系统作为一个生态，也在持续地演进，弱肉强食的环境也越发极
/
===== p0008 =====
端。特别是近几年程序化交易的渗透，让按图索骥的技术派在交易时
捉襟见肘，而交易对手却仿佛洞察棋局，步步紧逼。
现在的形势对交易型的股票玩家十分不利，在我看来，至少在小
于6个月周期、小于50%涨幅的有限趋势中，人工交易创造超额收益
的时代已经过去了，短期的盈亏幻觉最终将被均值回归戳破。而在更
长周期、更完整的趋势中，技术和趋势仍可能洞察整体市场的合力，
帮助我们实现逆向投资。坦率讲，2007年人人追捧的“大蓝筹”，
2015年最热门的“中小创”，或者大多数富含共识的大牛股，在完整
趋势逆转后，通常是股民离场的最佳时机。在海外成熟市场也存在同
样的规律。单个股票短时间内暴涨暴跌时有发生，按图索骥的技术推
导和预测会完全失效，但是在整体市场长周期的完整趋势中，逆转的
意义仍然不容小觑。
长远来看，股票投资中的“术（技术和趋势）”，让位于价值投
资的“道”（股票的价值等于生意未来净现金流的折现）、价值评估
的“法”（折现值相对于其他投资选择的机会成本考量）的前景不可
逆转。股票交易为市场提供的流动性的工作，将逐步交给机器和程序。
万幸的是，在理性地衡量机会成本并以勇气做出合理的应对和决
策上，机器的能力还无法接近人类的能力。我们能提高自己的认知，
评估上市公司背后的生意和其对应的价值，并积累起认知的复利。当
自己能理解的生意因为某种原因导致投资者和交易程序的恐慌共振，
市场剧烈波动到一目了然的胜算时，你要勇敢入场投资。在市场志得
意满、暖风拂面、投资的股票内含收益率下降到接近现金选择权价值
的附近时，你要尽早离场，清空线性推导思维，耐心等待下一次大到
很难拒绝的机会。

半小时看懂常用指标
指标1:高成功率的指标之王
在很多人看来指标都是“马后炮”。这个很容易理解，因为指标

只要你赢的概率比输的概率大，闭着眼去做就行了！这在我们的日常

来，我们就开始逐一了解常用的指标及其应用吧！
我们先从被称为王的男人……不，从指标开始。

===== p0054 =====
一、什么是MACD?
首先，我们先来看看，MACD（异同移动平均线）指标的四大
“太监”。
这是一张MACD图。
/
===== p0055 =====
1.DIFF，也就是图中的黄线。DIFF是短期（常用12日）指数移
动平均线与长期（常用26日）指数移动平均线的差值。因为其变动
较为灵敏，又称快线。
2.DEA，也就是图中的红线。DEA是M日（常用9日）的平滑移动
平均线。因其变化稍慢，又称慢线。
3.MACD红绿柱线，是DIFF值与DEA差值的2倍数值，柱线的高
低直接反映多空能量的强弱。
/
===== p0056 =====
4.零轴线，也就是绿柱子与红柱子长出的地方。零轴线是MACD
的多空分界线，DIFF和DEA在零轴线之上为多头市场，在零轴线以
下是空头市场。
那么作为这么重要的元素，它们有什么用呢？它们可以合体，然
后变化出各种形态！
/
===== p0057 =====
形态一：金叉
DIFF线自下而上穿越DEA，MACD则由绿柱转为红柱。
代表股价由下跌开始转为上升，意味着多头市场的开始。按金叉
位置与零轴线关系的不同，可以分为零（轴）上金叉和零（轴）下金
叉。
/
===== p0058 =====
一般而言，DIFF和DEA都位于零轴线上方时是零上金叉。市场
整体处于多头市场，金叉锦上添花，往往意味着新一波大涨势的开始。
DIFF和DEA都位于零轴线下方时是零下金叉。往往只是空头市
场短暂的反弹，所以其稳定度和可靠性都较低，力度也不大。
/
===== p0059 =====
当DIFF和DEA在零轴线下方形成二次或多次金叉时，稳定度及
可靠性就会大大提高，力度也往往较大。
形态二：死叉
/
===== p0060 =====
DIFF自上而下穿越DEA，MACD柱线由红柱转变为绿柱，代表股
价由上升转为下跌，意味着空头市场的开始。
死叉同样可以分为零（轴）上死叉和零（轴）下死叉。
/
===== p0061 =====
一般而言，DIFF和DEA同在零轴线上方为零（轴）上死叉，往
往只是多头市场中的一个回调，可靠性不高，且调整幅度不会太大。
DIFF和DEA同处于零轴线以下为零（轴）下死叉，往往意味着
新一波下跌的开始，且可靠性极高，下跌幅度也较大。
/
===== p0062 =====
二、简单粗暴的三板斧
知道了它们的形态后，我们就来点简单明了的技术吧。
1.第一板斧——MACD抄底术
/
===== p0063 =====
1.经过一波下跌后反弹；
2.股价再次下跌创新低；
/
===== p0064 =====
3.MACD的DIFF线低点不创新低；
4.MACD金叉确认底背离即是买入信号。
操作要点：MACD金叉确认底背离即可买入。等等！什么是背离？
背离可以理解为“背道而驰”，本来指标应该是追随股价的，也就是
股价涨，指标也上升。
/
===== p0065 =====
但当股价在不断创新高（或新低）的过程中，指标并不跟随股价
发生相应变化，反而背道而驰，就称为背离。
在MACD中，背离是准确率非常高的一种形态！
2.第二板斧——MACD抓主升
/
===== p0066 =====
1.经过一波上涨后调整；
2.股价调整不破前低；
/
===== p0067 =====
3.MACD在略高于零轴线位置金叉；
4.出中阳K线即买入信号。
/
===== p0068 =====
操作要点：MACD在略高于零轴线位置金叉出中阳K线即可买
入。
3. 第三板斧——MACD逃顶术
/
===== p0069 =====
1.经过一波上涨后调整；
2.股价第二波上涨创新高；
/
===== p0070 =====
3.MACD的DIFF线高点未创新高；
4.MACD死叉确认顶背离即卖出信号。
操作要点：MACD死叉确认顶背离即可卖出。这几个是MACD的
常用技巧，准确率也很高。
/
===== p0071 =====
具体的实际情况还应当结合其他指标进行综合的分析。通过其他

===== p0072 =====
指标2:指标搭配运用才能无往不利
很久很久以前，人们为了帮助分析中短期的趋势，用技术指标K、
D和三J条线，组成了一个偶像组合——随机指标（KDJ）。
它能够比较迅速、快捷、直观地研判行情，是期货和股票市场上
最常用的技术分析工具。
（其真实样貌。）
/
===== p0073 =====
一般情况下，可以把K线与D线都作为J线的僚机来使用，K值和
D值的取值范围都是0—100，而J值的取值范围可以超过100和低于
0。
这三个小伙伴的性格也完全不同，相比速度而言，J最快，其次
是K，最慢的是D。
/
===== p0074 =====
但相比安全性而言，D最靠谱，其次是K，最不靠谱的是J。
总的来说，K、D、J这三条线数值在20以下为超卖区，关注伺机
买入。在80以上为超买区，关注伺机卖出，在20—80之间为徘徊
区，坐观全场就行了。
/

当K线从D线上方向下穿越D线，同时J线从K、D线的上方向下穿

/

===== p0079 =====
接下来是背离，也很耳熟吧？
首先是顶背离。当股价连续上涨并持续创新高但KDJ并没有同时
跟随创出新高时，就会形成KDJ顶背离，预示股价短期上涨乏力。股
价短期内极容易滞涨回落，为短期出局信号。
/
===== p0080 =====
其次是底背离。当股价连续下跌并持续创新低，而KDJ并没有同
时跟随创出新低时，形成KDJ底背离，预示股价短期下跌动能减弱。
股价短期内极容易止跌反弹，是短线抢反弹择机买进的信号。
/
===== p0081 =====
上面这些概念性基础知识在MACD那里已经讲过了。道理都一样，
只是图变了而已。下面来点新鲜的——
所谓钝化就是指股价在行情中大涨或暴跌，使指标数据出现粘
连，让指标失去指导作用，因为KDJ是一个非常敏感的指标，所以它
特别容易出现钝化。
一般钝化分两种：高位钝化和低位钝化。高位钝化，在股价走势
极强的单边上涨行情中，K值与D值均在80以上的超买区，J值大于
100。股价仍在急速上涨创新高，此时形成KDJ高位钝化。
遇到高位钝化时不要慌，虽然指标失灵，但也意味着个股的强势
/
===== p0082 =====
性。此时就可以参考其他指标进行操作。
/
===== p0083 =====
把高位钝化反过来就是低位钝化了。一般K值与D值同时在20以
下的超卖区，J值在0以下。
遇到低位钝化一般意味着股价可能要跌一段时间了。此时适合参
考其他指标来判断KDJ何时回归正常，回归后的KDJ金叉是抄底的最
好时机。
/
===== p0084 =====
二、僚机的实战
在股价的实际走势中KDJ买卖信号频繁，且错误虚假信号较多。
因为，我们可以看到每次出现顶背离和底背离的时候，KDJ都会出现
金叉和死叉。但KDJ每次出现金叉、死叉的时候却不意味着股价也出
现了顶背离和底背离，所以，我们要做的就是判断其金叉和死叉的准
确性。
怎么更好地判断它的准确性呢？这就要用到它的最佳组合——
1.MACD+KDJ双金叉选股
/
===== p0085 =====
我们讲过，MACD出现金叉买点时，绿柱消失是红柱出现的拐点，
仅此信号是买入点。
但大家都知道MACD具有延迟性，所以当KDJ出现金叉，并且都
处于较低的值的时候，MACD绿柱缩量也即将出现拐点，即可以此来
判断此次KDJ为有效指导。为保险起见可在KDJ出现金叉后1—2日买
入。
/
===== p0086 =====
买入也是一样的道理。两个指标同时指示买入，说明买入信号非
常可靠，果断买入。实盘验证，准确率高达90%。
/
===== p0087 =====
2.MACD黄白线位于零轴线上方
KDJ金叉出现时是买入机会。由于KDJ自身的灵敏度较高，影响
了指标的准确性，所以只做强势区域的KDJ金叉，准确性会大幅度提
升。以贵州茅台为例，该股之前长时间MACD位于零轴线上方，每次
KDJ金叉出现，均是阶段买入机会，且准确率极高。
/
===== p0088 =====
（可于金叉补仓，也可死叉卖出金叉买入）
在实战中，根据二者的交叉和趋势，来判断买卖点，非常可靠。
借助KDJ灵敏而MACD稳健的特点，一旦KDJ发出买入信号或者卖出
信号，只要等到MACD有要金叉的趋势就可以买卖，不用等到MACD

要注意的是，所有指标都有自己的优点及缺点，不要依赖单一指

===== p0090 =====
指标3:给你精准战法的交易线
下面我们来讲布林线。
一、BOLLBOLLBOLL（布林线指标）
布林线指标是怎样的呢？它由上、中、下三条轨线组成。
/
===== p0091 =====
BOLL指标通过这三条线之间的关系，再结合其他指标可成为研
判大盘趋势的有效工具。
布林线有四大作用：
（1）布林线可以指示支撑和压力位置，股价通道的上、下轨线
可以显示股价安全运行的最高价位和最低价位。
上、中轨线都可以对股价的运行起到压力作用，而中、下轨线有
时则会对股市的运行起到支撑作用。
/
===== p0092 =====
（2）布林线可以指示趋势，通道的中轨线之上为可操作趋势，
中轨线之下为不建议操作区域，强势股总在中、上轨线之间。
弱势股总运行在中轨线下。
/
===== p0093 =====
（3）布林线可以显示超买、超卖。股价冲出上轨线将有回调，
股价跌出下轨线将有反抽。
/
===== p0094 =====
（4）布林线可以选择方向，上下轨收口变窄隐藏着突变，开口
越大说明风险越大。
说到开口，大致分三类：
1.布林线开口向下
出现这个状态的时候马上离场，坐等低吸就可以了。
/
===== p0095 =====
2.布林线开口紧缩
上面也说了，当出现这个形态的时候会出现突变，马上就会有大
变化。至于上涨还是下跌可以根据行情和其他指标参考，如不放心可
等形势明了再参与。
3.布林线开口向上
/
===== p0096 =====
K线沿着布林线上轨在运行，应对的策略就是持股不动，让利润
奔跑。
二、布林线与K线
了解了布林线的几个基本形状后，我们再来讲讲它与K线的关系：
1.当K线从布林线的中轨线以下向上突破布林线中轨线时，预示
着股价的强势特征开始出现。股价将上涨，应以买入为主。
/
===== p0097 =====
2.当K线从布林线的中轨线以上向上突破布林线上轨线时，预示
着股价的强势特征已经确立。股价短期将可能大涨，应以持股待涨或
短期买入为主。
3.当K线向上突破布林线上轨线后，其运行方向继续向上时，如
果布林线的运行方向也同时向上，则预示着股市的强势特征依旧，股
价短期还将上涨，应坚决持股待涨。
/
===== p0098 =====
而当K线的运行方向开始有掉头向下的迹象时，就需密切注意行
情是否开始转势。
4.当K线在布林线上方运动了一段时间后，如果K线掉头向下并
突破布林线的上轨时，预示着股价短期的强势行情可能结束，股价短
期内将大跌。短线应及时卖出股票，特别是那些短期涨幅很大的股票。
/
===== p0099 =====

了解了布林线的形状之后，我们把之前讲的MACD和KDJ也联系
起来，顺便加上5日均线（MA5），可以大大提高判断的准确率。

所以只有在买入和卖出时我们才主要依据KDJ，而在持仓途中我

===== p0105 =====
说到布林线，我们就不得不说一下它的一个“大哥”——多空

它是由多空线指标与普通布林线指标组合而成的。

===== p0106 =====
BBI和BOLL单独使用的范围太小，而BBIBOLL系统较为完美地结

哥”还真是当得有模有样，而且还能独当一面。BBIBOLL也是由上轨
线、中轨线、下轨线组成的。但中轨线就是BBIBOLL中的“BBI”，也
就是多空线，它最大的作用就在于判断走势的时候，根据多空力量的
强弱做出取舍判断。
（样子和普通布林线很像。）
BBIBOLL的缩口和宽口出现得比BOLL频繁，基本就是一个缩口
连着一个宽口。同样缩口意味着突变的开始，所以BBIBOLL更为直观
地反映当前局势。
/
===== p0107 =====
BBIBOLL的基础用法和BOLL相同，也是当K线大部分集中在中轨
线上方，且中轨线向上运行时，可判定当前多头强势，应该持有或逢
低买入股票。
当K线大部分集中在中轨线下方，且中轨线向下运行时，可判定
当前空头强势，应该逢高卖出股票，保持空仓或者少量持股观望。
/
===== p0108 =====
该指标同样也有支撑和压力的作用，但BBIBOLL会比BOLL更精
确，因为BOLL时不时地就会破上轨线或下轨线，造成一些无效指
示。
但是要更有效地使用BBIBOLL，就要说到BBIBOLL精确打击战法
了。
/
===== p0109 =====
调用方法很简单：打开电脑软件，输入BBIBOLL指标就出来了。
法则一：在多空布林线系统中，行情缩口变张口，中轨线上方
有阳线，行情涨。
反之，当行情缩口变张口，中轨线下方有阴线，则行情要跌。
/
===== p0110 =====
很多时候出现这两种情况时，第二天都是有反应的，而且对大盘
和个股都很适用。
可以说第一规则不单单是精确，更能给我们一个明确的判断，解
决我们操作方向的盲目性。
法则二：行情上涨时，K线实体一旦突破甚至完全站在上轨线上
方，行情极大概率会回调，尤其是第二天会有调整，基本都是收阴，
可能开盘价就是最高价。
/
===== p0111 =====
反之，行情下跌时，K线实体一旦跌破甚至完全站在下轨线下方，
行情极大概率会反弹，第二天往往都是放阳，所以开盘价买入都是较
低价。
/
===== p0112 =====
举个例子，如果在第一阶段跌破下轨线的第二天买入，在冲破上
轨线的两天开盘卖出，可以吃光所有反弹利润。
第二阶段回档，此时你已经空仓观望了。
/
===== p0113 =====
其实法则二的作用，就是寻找高抛低吸、逃顶抄底的好机会，不

把握。但是一旦行情受到大空或者大多的影响，可能会走出连续破上
轨线或下轨线的走势，而这大多是因为前期横盘调整，突然拉升所致，
说白了就是多空布林线还没反应过来就涨上去了，虽然这种情况极
少，但也是存在的，毕竟指标只是大概率。想要更准确，还是需要其

总之，行情都要走在上下轨线之内，而一旦行情走到外面，就可
能被修复向中轨线方向的行情回归。
出现法则二就是这个道理。所以多空布林这个交易系统更适合短

指标6:捉超跌反弹利器——乖离率
天下都是如此，更别说股市了。涨久必跌，跌久必涨。天下的分
合靠英雄，看股市的涨跌方法就多了。接下来我们就来说说其中之一
——乖离率。
/
===== p0159 =====
乖离率就是收盘价与某条均线之间差距的百分比。
任何一条均线都可以。用最简单也比较常用的5日均线来说，股
价远高于5日均线时，就是“5日均线乖离率”很大，属于短线卖出
时机。
/
===== p0160 =====
因为5日均线能够快速反映股价的运动趋势，是强势行情生命线。
当股价向上突破后有支撑作用，当股价向下跌破后，有压力特性。
/
===== p0161 =====
K线在均线上方乖离率为正，反之为负。
这波操作的原理就是：
/
===== p0162 =====
正的乖离率越大，股民获利越多，越容易萌生赚钱走人的念头。
所以后续股价就会下跌，此时就是绝佳的卖出点。
负的乖离率越大，股民的损失越大，有心机的人就会抄底。
股价自然也就上涨，此时是较好的买入点。
/
===== p0163 =====
通常在暴跌或大涨之后指数都会离5日均线有一定距离，大盘股
票价格指数超过2%，小盘股票价格指数超过4%，就有大概率可能引
发超跌反弹。
/
===== p0164 =====
但这个标准仅仅适用于波动率不是很大的行情，在A股波动率比
较高的2015年—2016年，这个标准可能是5%。
这并不是一个死板的数字，动乱年代与和平年代的标准不一样。
总之，用乖离率来判断短线的超跌反弹和超涨回档是很靠谱的。配合

大家都知道，股价和成交量之间有时候紧密相随，有时候又背道

===== p0377 =====
盘口2:换手率
你有没有经常听人说起过：
在之前的文章中，我们也或多或少地提到过换手率这个东西。那
么什么是换手率呢？
其实很简单，比如说一只股票一天成交了500万股，而这只股票
的流通股为1亿股，那么这只股票的当日换手率就为5%。
/
===== p0378 =====
/
===== p0379 =====
所以换手率可以真实地反映出这只股票的流通性。为什么要选择
换手率高的个股呢？
第一，股票的换手率越高，意味着该只股票的交投越活跃，人们
购买该只股票的意愿越高，属于热门股。否则，就是冷门股。
/
===== p0380 =====
一般来说，大多股票每日换手率在1%—2.5%。70%的股票的换
手率基本在3%以下，所以3%就成为一个分界。
第二，换手率高一般意味着股票流通性好，进出市场比较容易。
/
===== p0381 =====
一般不会出现买不到或卖不掉的情况，具有较强的变现能力。
第三，将换手率与股价走势相结合，可以对未来的股价做出一定
的预测和判断。
/
===== p0382 =====
比如，这只股票之前的换手率是14.71%，成交量也处于缩量。
第二天换手率突然上升，成交量也是昨天的两倍之多。
这可能意味着有投资者在大量买进，股价可能会随之上扬。这只
股票持续上涨一段时期后，出现价涨量缩形成背离，可能就是一个上
涨阶段的顶部了。
/
===== p0383 =====
第二天换手率剧增，伴随成交量剧增，可能意味着一些获利者要
套现，股价将会下跌。
所以换手率配合量价，是个很好把握当前局势的组合。
/
===== p0384 =====
但值得注意的是，换手率较高的股票，往往也是短线资金追逐的
对象。
投机性较强，股价起伏较大，风险也相对较大。
/
===== p0385 =====
总的来说，换手率体现的是股票的活跃度，但江湖险恶，光看换
手率还是不行的！
想要更准确地判断趋势还是要结合其他指标！
/

盘口3:分时量
你是不是经常会碰到这种情况：
不要着急，下面就教你通过分时量来判断后市的涨跌。
一、大盘分时量与未来
看大盘的时候，想要预测接下来的涨跌，有一个比较简单的办法，
总结一下就是：涨缩量，跌放量，跌面大；涨放量，跌缩量，涨面大。
涨缩量，就是说大盘上涨的时候交易量减少，在大盘上看到的红
柱越来越短。
/
===== p0387 =====
有些分时量没有颜色，你可以设置出来，也可以看分时图上的红
绿柱。
/
===== p0388 =====
那么涨缩量就是这样。
千万别说这是MACD哦。当出现涨缩量这种情况的时候，说明
并不是因为成交量导致的价格上涨，极有可能是单笔高价交易导致
的。
这种上涨往往是虚涨。跌放量是说大盘下跌的时候交易量增加，
/
===== p0389 =====
在大盘分时图上看到的绿柱越来越长。
说明大家正在纷纷卖出手里的股票。
/
===== p0390 =====
这种下跌往往是实跌，如果涨缩量遇见跌放量——
也就是虚涨之后是实跌，尤其是两者还相差特别大的时候——
基本后市跌得方向都没有，如果你早盘就发现这个情况，你逃得
越快，损失就越小，还可以避开后面更大的跌幅。
/
===== p0391 =====
反之，涨放量就是大盘上涨的时候交易量增加，在大盘上看到红
柱越来越长。
/
===== p0392 =====
同理，交易量带来的价格上涨往往是实涨。跌缩量则是在大盘下
降的时候交易量减少，在大盘上看到绿柱越来越短，或许说明持有股
票的人没有因为价格下跌就卖出，而是继续持有或持观望态度。
当涨放量遇到了跌缩量，这种下跌往往是虚跌。也就是实涨之后
是虚跌，尤其是在两者差别较大的情况下，基本后市大涨的概率很高。
/
===== p0393 =====
如果早盘有看好的股票，可以择机杀入，当天吃肉的概率很高。
不过大盘的起起伏伏情况太多，也有不少消息面的爆发和跳水。
/
===== p0394 =====
二、个股分时与未来
涨缩量，跌放量，跌面大；涨放量，跌缩量，涨面大。这个方法
也同样适合个股。
个股分时量还可以用两句话来概括：反弹有量，会有更高价格；
反弹无量，后市会掉下来。也就是说，当某只股票价格反弹的时候，
如果交易量也配合上涨，那么这只股票后期仍然还有上涨空间。
/
===== p0395 =====
如果交易量没有配合上涨，那么这只股票很有可能要下跌。
举个例子，例如这只股票反弹起来的时候，量价配合良好，后面
放出来的分时量超过前面的3倍。
/
===== p0396 =====
说明资金在跟进去，在T+1（当日买入的股票，要到下一个交易
日才能卖出）情况下刚进去的资金当天无法直接出来，该卖的已经卖
掉了，没有更多的抛盘压力，后市还继续上涨，如果大盘又好，那么
涨得更厉害。
/
===== p0397 =====
再比如，这只股票反弹起来，成交量并没有带起来。
这是虚高，诱多行情，迟早会掉下来。后面最大成交量远小于前
面的最大成交量。结果下午就直接下来了。
/
===== p0398 =====
如果量价配合得好，股价上涨，成交量伴随放大，表现在盘面上
是分时量红柱越来越长，绿柱远小于红柱。
/
===== p0399 =====
如果出现很长的绿柱，后市不乐观。所以，不管是大盘还是个股，
记住：涨放量，跌缩量，后市大概率是涨；反之，后市大概率是跌！
还有，之前我们在讲成交量的时候也讲过顶量和底量，你还记得吗？
分时图也照样适用哦。
如果反弹时底量远远大于顶量，反弹的高度一般都会比前高度
高。
/
===== p0400 =====
最后提醒大家，如果天天只看分时图，也很容易陷入卖了涨、买
了跌的泥潭。所以要配合其他周期和其他的因素来看，毕竟炒股不是
那么容易的。

盘口4:挂单栏
你有时候是不是觉得股市比女人还难以捉摸，那是你还没有了解
它，其实它所有的心思都会通过盘口语言告诉你。盘口语言说白了就
是主力操盘留下的痕迹。
上次说了盘口的内外盘，这次那就说说委买委卖栏。
/
===== p0402 =====
/
===== p0403 =====
当某只股票的分时盘口上突然出现了连续的或断断续续的大单挂
单并开始成交，就表明有可能主力开始行动了。
那么问题来了，什么样才算大单？有的小伙伴，见到上10万股
的单子，就慌了……
但其实，单子的大小跟该股流通盘的大小有关。
/
===== p0404 =====
而且这个单子不见得是一个人挂的，可能是几个人甚至几十个人
挂的。
单子的大小也跟该股每天换手率的大小有关。
我们常见的真正的大单挂单可以分为四种：
/
===== p0405 =====
下面我们来逐一讲解一下。
1.压迫式挂单
递增压迫式挂单是出现三档以上的递增式大卖单。
后面的卖压越来越大。不趁早抛出，后面会越来越难卖。递减压
迫式挂单正好相反。
/
===== p0406 =====
主力一旦吃掉第一档大单，往往市场就会立刻出现跟风盘，后面
的挂单会在短时间内一扫而光。
2.拦截式挂单
委买栏出现明显的大买单，说明下方接盘巨大，可以放心买入。
/
===== p0407 =====
而当上方的卖单被吃掉后，盘口又会出现类似的大买单。其重心
会不断上移，反复多次，直至涨停。
/
===== p0408 =====
大盘股在1万手以上，中盘股在1000手以上，小盘股在100手以
上，出现一档明显的大接单，通常在被抛盘打掉以后，还能反复出现，
是一种长效语言暗示。这些挂单不一定出现在整数价位上，但会给人
一种“一夫当关，万夫莫开”的视觉冲击力。
要是出现三档以上且递增的大接单：
/
===== p0409 =====
则显示了主力雄厚的实力，号召市场与主力一起参战。
/
===== p0410 =====
3.夹板式挂单
“夹板式挂单”是分别在委买和委卖栏某一个价位挂出的大单。
/
===== p0411 =====
使买卖盘口上显示出一种上有“天花板”，下有“水泥板”的格

/
===== p0412 =====
使市场在某一段时间里的成交量始终在一个“夹板”限定的空间
内。
/
===== p0413 =====
“夹板”一旦撤离，或是被大单打掉，就是主力向涨停板或者跌

4.蜂窝式挂单
“蜂窝式挂单”是密集挂出连续委买和委卖的大单，透露出市场
参与者对筹码关注程度很高。买卖气氛十分热烈。
如果是大盘股，说明各路资金云集于此，多空双方分歧明显，欲
想攻击涨停，多头需付出极大的努力。
如果是中小盘，则透露出主力不想自己“干活”，欲借助市场力
/
===== p0414 =====
量去推进股价。
如果除了价位的连续性之外，挂出的大单还基本对称，比如买盘
是五档四位数，卖盘也是五档四位数。
/
===== p0415 =====
那么这种盘口的挂单通常是满负荷挂出，如同蜂窝一样一个连着
一个，给人一种难以参与的感觉。
/
===== p0416 =====
如果在委卖盘上出现蜂窝式挂单，在委买盘上则是自然接盘挂
单，说明卖盘力量极大。
/
===== p0417 =====
如果在委买盘上出现蜂窝式挂单，在委卖盘上是自然接盘挂单，
则说明买盘力量极大。
/
===== p0418 =====
经验证明：委卖栏上的蜂窝式挂单，一旦开始被吃掉，涨停的概
率远远高于委买式蜂窝挂单被吃掉的涨停概率。
因为前者是主力的对倒盘，属于主力资金主动性攻击行为。
而后者是主力资金诱导下的市场力量，上涨的力度自然不如前
者。
/
===== p0419 =====
提示一下，大单挂单的成交应该也是被大单吃掉。如果是小单去
吃掉这些大单，则该股的涨停概率会大大降低。因为不是主力行为，
没有连续上升的动力。这四种盘口挂单形式，基本就能反映主力的意
图。当然，有些主力也会利用盘口语言，忽悠韭菜进入，然后进行收
割。但各有各的手段，较难精准判断。
所以，我们看到有大资金对抗时，注意见好就收，切勿盲目追涨
杀跌。

===== p0420 =====
盘口5:内外盘
下面我们来讲一下盘口必须要看的东西——内盘和外盘。
在软件中表现是这样的，内盘是绿色，外盘是红色。
/
===== p0421 =====
简单点说，内盘就是里面的人想出去。
也就是成交明细里面的S（Sell）。
/
===== p0422 =====
外盘就是外面的人想进来。
/
===== p0423 =====
也就是成交明细里面的B（Buy）。
/
===== p0424 =====
这两个单词可厉害了，它说明买卖双方都认为对方是——
先从外盘开始说起吧。外盘就是以卖出价格成交的数量，也就是
以卖家期望的价格成交，比如，股价10元。
而这些买卖当然就体现在了委卖栏中。
/
===== p0425 =====
这个数量表现了买家急于买入的程度，外盘大说明这只股票主动
买入的多。
/
===== p0426 =====
外盘的大小影响股价的涨跌，但不能确定股价的方向。想要分析
股价交易状况，还要看内盘，内盘就是以买入价格成交的数量。也就
是以买家期望的价格成交，这个数量表现了买家急于卖出的程度，比
如股价10元。
所以，股票成交中的内盘表示的是主动性卖出。外盘，表示的是
主动性买入。通过外盘、内盘数量的大小和比例，可以看出是买盘多
还是抛盘多，甚至可以发现主力的动向。
/
===== p0427 =====
因为外盘内盘也不是所有时间都有效，比如主力资金吸筹时为了
迷惑小散搞对冲，让内盘大大大于外盘，让小散乖乖地交出筹码。
/
===== p0428 =====
主力资金要出货时让外盘大大大于内盘，让小散双手接盘。
所以你在看内外盘的时候不能单单只看内外盘大小，还要关注这
只股票的近期走势是否在低位。
那么，记住一个口诀吧。

战法8:压力支撑
这篇我们来说一个通过精准判断支撑位和压力位的方式进行买卖
的战法。在了解战法之前，我们先要知道支撑位和压力位是如何构成
的。首先，市场上的投资者基本分为两类：
有的人可能觉得自己不属于这两类，那是因为你的投资时间还不
够长。时间长了，你要么属于这两类，要么——
/
===== p0534 =====
基本面投资者基本都是长线投资者。他买入一只股票会一直持有
到投资目标的基本面发生变化才会卖出，典型的代表人物就是巴菲
特。
技术类投资者则基本都是短线投资者，技术面投资者会根据行情
的变化分析其内在的因素，在有利的时候买入，在不利的时候卖出，
做波段操作，典型的人物是索罗斯。
/
===== p0535 =====
那操作的类型和市场的走向有什么关系呢？假设，这个市场上一
共有100人。
有50个人认为在上升过程中，价格回落到10日均线附近是一个
不错的买点，那价格在10日均线附近时，这50个人就会去买。
/
===== p0536 =====
价格可能就会停留在这个位置，所以10日均线的价格就成了行

再比如2015上半年牛市的时候，很多人说等上证指数到5000点
就清仓，显然5000点会成为一个压力位。

===== p0537 =====
支撑位和压力位的行情是非常复杂的，参与的投资者越多，支撑
位和压力位就越难把握，因为每个人看法不一样，而手上有大量资金
和筹码的人就比较有话语权。
有很多种方式可以判断支撑位和压力位，比如均线技术，也就是
5日、10日、20日这类均线上下形成支撑位、压力位。一般来说，5
日均线是上涨途中最好的买入点，基本可以上涨至少3—5个K线周期。
/
===== p0538 =====
在上涨的时候要关注10日均线的支撑，一般都会有1—2次来测
试10日周期K线的支撑情况，所以之前有第一次下落10日周期K线是
一个买入点。
最后是一波上涨结束后的回调浪，我们可以看20日周期K线，这
个时候不跌破20日周期K线就都可以尝试。
当股价下跌时，这些均线又会转为压力线，不突破压力线是不会
有下一波行情的，所以突破压力线也可以作为买点的参考之一。
/
===== p0539 =====
还有一个简单的方法就是看布林线，我们之前讲过布林线和多空
布林线，这里就不多说了。它们的下轨线和中轨线可以作为支撑的依
据，上轨线作为压力的依据。

===== p0540 =====
值得注意的是，中轨线有时也会叛变，转而成为压力线。所以股

再就是整数点位的支撑和压力。理论上一般是对2000、3000等
整数关口，在下跌的过程中会起到一定的支撑作用，上涨过程中会起

是以大整数为预期。

当前股价的趋势，还能发现多空之间神秘的规律。

===== p0543 =====

一般是画两种线：斜线：趋势支撑线。
横线：多空转换线。
/
===== p0544 =====
一、斜线
我们先说说斜线，趋势支撑线，说白了就是把股票近期的止跌点
连接起来。
这条线就是这只股票的支撑线，一般情况下股价到了这个位置就
会回头，如果跌破，那就赶快跑人。
/
===== p0545 =====
对，理论上是这样，但有时你也会遇到这种问题：这只股，该怎
么画呢？
/
===== p0546 =====
不同人找出的低点各有不同，L1是从左侧最低点连接两个波谷
低点。
L2则是连接了四个波谷的低点。
若因为L1下破趋势支撑判断涨势结束，不久后反而重新大幅反
抽走高，并在后续反抽不过而继续回落。
/
===== p0547 =====
所以，L1判断的时间周期更长，之后回落的幅度较大，误差也
大，而L2则判断周期较短，幅度较小，相对比较滞后，但胜在有效
性更强。
不管你选择哪一条线，在实际运用中还需注意以下几点。
1.触碰波峰或者波谷的次数越多，有效性越强，至少三点以上。
/
===== p0548 =====
2.连接K线实柱比连接影线的效果更强，最好根据量能的变化去
测试。
3.画线时的低点，是上涨过程中的回踩低点。
/
===== p0549 =====
4.趋势线上为最佳补仓点，没回调到趋势线时也可小仓位补仓，
防止不到趋势线出现股价拉升，错过降低成本的机会。
5.如果是大阴线，高量，高换手，这样大K线触及趋势线不破，
更说明趋势线的支撑非常强。
/
===== p0550 =====
6. 一旦跌破趋势线一般很难立即重新站上。
7.要知道上涨趋势是否依然存在。
/
===== p0551 =====
二、横线
我们再来说说横线，也就是多空转换线。
当股票没有明显的大行情时，我们就需要用到这个，简单说就是
该股票高位时的支撑点，低位时的压力点。
/
===== p0552 =====
线上是多方市场，突破可以买买买，线下就是空方市场，观望即
可。道理其实和斜线差不多。
记住，多次下跌不破的位置才叫支撑，一跌就破的位置肯定不是
支撑。
同理，多次上涨不破的位置也才叫压力。
/
===== p0553 =====
也是接触的点越多，线越稳健。
多空线可以根据你的交易周期来画。
股价一旦跌破横线，短线要回调，触及但不跌破，短线有上涨。
/
===== p0554 =====
突破后站稳横线，是买入最佳时机。
那什么时候卖合适呢？
/
===== p0555 =====
画出它的小级别趋势线，跌破卖掉就好喽。
当然，也可以结合均线等指标。好了，我们再来回顾一下要点。
1.线要画在多次下跌不破的地方和上涨不前的地方。
/
===== p0556 =====
2.被触及且不破的次数越多，支撑、压力越强。
3.触及后当天立即反弹，支撑也强。反之，压力也很强。
4.股价跌破并在多空反转线下运行一段时间，后面再站上线，这
样进场更安全。
5.如果股价跌破，代表进入短线回调，短线就要注意风险了。
/
===== p0557 =====
总而言之，通过画线来判断支撑位和压力位还是比较精准的，基
本能很好地把握买卖点，套牢的也可以准确补仓，降低成本。刚开始
拿不准，可以多画几条，后面就会越来越准。快试试吧，看着自己画
的线，说不定也会有“大师”的成就感呢。
