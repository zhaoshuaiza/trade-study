## 收录标准

学术资料要收，但也要筛：

| ✅ 收 | ❌ 不收 |
|---|---|
| 有方法论价值的实证研究 | 只报告结果不给机制的 |
| 权威机构的正式文档 | 无出处的数据图表 |
| 有清晰结论的研究 | 观点性的评论文章 |

> 📌 **收学术资料时特别注意**：论文的结论通常有**适用范围和样本限制**。
> 编译时必须记录这些限定，不能把「某样本下成立」写成普适结论。

---

## 编译时怎么处理

1. 记录出处：作者、年份、期刊/会议、arXiv ID
2. 提取**方法与机制**，不只是结论
3. 记录**样本与适用边界**
4. 与库内已有观点冲突时 → 建 `claims/` 或 `comparisons/` 页，**不覆盖旧结论**
5. 无法确认的标 `status: uncertain`
