## 四个入口，按资料类型分

| 目录 | 放什么 | 怎么放|
|---|---|---|
| **`articles/`** | 网页文章、公众号、博客 | **用 Obsidian Web Clipper 一键存入** |
| **`clips/`** | 短片段：观点、数据、案例摘录 | 手动粘贴，注明出处 |
| **`academic/`** | 论文、学术报告、技术文档 | 从 `E:/笔记Obsidian/电子书/` 或各处下载后放这 |
| **`distilled/`** | 已编译的中间产物 | **AI 自动写入，你不用管** |

> 📌 **为什么要分类**：
> 网页文章最容易「读完就忘」，单独放`articles/` 能让你定期回看。
> `distilled/` 让AI 的中间产物有地方落，不污染 wiki 成品层。

## 一、网页文章怎么存（最常用）

### 用 Web Clipper 一键剪藏

1. 浏览器装 **Obsidian Web Clipper** 扩展
2. 打开任意网页 → 点扩展图标
3. **目标目录选 `raw/articles/`**
4. 勾选「保存原文链接与出处」

剪藏后的文件自带：
- 正文内容
- 原文链接
- 网页标题与作者
- 剪藏时间

> ⚠️ **务必确认目标目录是 `raw/articles/`**，
> 存错目录 AI 编译时会漏掉。

### 什么样的文章值得存

| ✅ 存 | ❌ 不存 |
|---|---|
| 有完整论证的深度长文 | 营销软文、无观点的资讯 |
| 讲清一个方法论的教程 | 标题党、碎片化观点 |
| 一手经验总结 | 纯转述的二手内容 |
| 有数据支撑的分析 | 没有论据的情绪化判断 |

> **宁缺勿滥。** 垃圾进必然垃圾出。
> 判断标准：半年后还会回来看这一页吗？

## 二、其他三类

### `clips/` · 短片段

刷到有价值的一句话、一个数据、一个案例，粘贴进来，格式：

```markdown
---
source_url: 
author: 
clipped_at: 2026-10-07
---

摘录内容...

## 我为什么觉得有用（可选，一两句）
```

> ⚠️ **你自己的推测不要放这里** ——
> 推测属于 `wiki/claims/`，不是素材层。

### `academic/` · 学术与技术资料

论文 PDF、技术报告、官方文档。

**注意**：交易类的书籍 PDF 不用放这，在 `E:/笔记Obsidian/电子书/` 统一管理，
本库只在 `wiki/sources/` 记录路径。

这里放的是**补充性学术资料**，比如：
- 关于市场微观结构的论文
- 行为金融学实证研究
- 量化交易方法的技术文档

### `distilled/` · 中间产物

**AI 自动写入，你不用管。**

编译过程中产生的：逐页提取片段、章节摘要、待核实的参数列表。
这里的内容**可以随时删除重建**，不是原始资料。

## 三、编译流程

```
① 存资料 → raw/articles/ 或 raw/academic/
② 说「读 CLAUDE.md，编译 raw/」
③ AI 处理：检索 → 提取 → 更新 wiki → 建双链 → 记 log
④ 有冲突或不确定 → AI 列出来等你拍板
```

## 四、素材层的铁律

依据 `CLAUDE.md`：

| 规则 | 理由 |
|---|---|
| **raw/ 里的内容不修改** | 它是事实来源，改了就无法溯源 |
| **不删除原始资料** | 蒸馏产物可重建，原始资料没了就没了 |
| **参数原样保留** | 引用的数值要能回溯到原文 |
| **不确定标「待核实」** | 不猜、不编 |
