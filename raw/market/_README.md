# raw/market/ · 复盘原始数据索引

> 每日复盘的**原始数据层**。⚠️ 本目录**只放索引，不复制数据文件**——
> xlsx 原件全部在 `E:/股票/复盘数据/`，由 `.manifest.json` 登记路径/MD5/行数。

## 为什么不在库里复制数据

1. **单一份源**：xlsx 改了（重新导出）只动一处，不会出现库内副本与原件不一致
2. **库保持轻量**：知识库是 markdown 仓库，塞二进制文件会让 git 历史膨胀
3. **MD5 校验**：导入时比对哈希，文件被改过立刻发现（口径漂移检测）

## 数据文件命名约定（E:/股票/复盘数据/）

| 文件 | 内容 | 来源 |
|---|---|---|
| `ztYYYYMMDD.xlsx` | 涨停池明细（东财口径：连板/封单比/开板/换手/流通值/几天几板） | 同花顺/东财客户端导出 |
| `ztTHSYYYYMMDD.xlsx` | 涨停池（同花顺口径：涨停形态/多标签题材/封单额/首封时间） | 同花顺客户端导出 |
| `YYYYMMDDRD.xlsx` | 热点归因（涨停原因/数量/热点分析） | 复盘软件导出 |
| `_ak_cache/YYYY-MM-DD.json` | akshare 网络数据缓存（涨停池/炸板池/跌停池/龙虎榜） | `ak_market.py` 自动 |
