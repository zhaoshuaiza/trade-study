# 日本蜡烛图技术详解·酒田78条战法判据（朱成万 2015）

> 蒸馏自《日本蜡烛图技术详解：酒田78条战法解析》（朱成万，地震出版社 2015，A股语境另解版）。

> ⚠️ **不构成投资建议**；案例全取 2008–2012 庄股时代，统计数字（70%/80%/90%）无样本量，仅作经验倾向。

## 零、定位与边界

| 项 | 内容 |
|---|---|
| 与尼森版关系 | 尼森《日本蜡烛图技术》按**形态分类**讲"这是什么图案"；本书用**数学定理教学法**把 78 条重构为「位置+量+确认+均线」四要素决策**过程** |
| 独有贡献 | ① 元规则框架（位置是一级变量）② 结构跟随止损（只升不降）③ 买卖速缓不对称 ④ 主力行为解读树 ⑤ A股实证+诚实记录反向证据 |
| 2015 时效边界 | 案例为 2008–2012（T+1/涨跌停/庄股余晖）；2015 后量化/注册制使「主力控盘」叙事部分失效 |
| A股/期货语境 | 涨跌停使大阳实体上限 20%；元规则对期货同样适用，唯杠杆/跳空规则需换算 |

## 一、元规则框架（比背 78 条更重要）

- **F1 四看策略**（第20页）：任何形态先查 ①位置 ②成交量 ③后市确认线 ④均线系统；**位置第一优先级**，后三者是确认工具。四步不全不行动。
- **F2 位置决定符号**（第17/11页）：同一大阳线，低位=见底、中位=加速、高位=诱多、下跌途中=反弹一日游。**形态无固有含义，含义由位置赋予**。
- **F3 信号以后出为准**（第142页）：矛盾信号并存时以**最新**信号为准，反「信号叠加越确定」直觉。
- **F4 元规则优先于图案**：78 条是同一方法论在 78 形态的应用，练成反射而非查表。
- **F5 周期分层**（第11页）：月线 > 周线 > 日线可信度递减；日线信号用周/月线过滤。
- **F6 见顶强于见底**（第68/47页）：顶部易成、底部难成 → 导出**见顶宜速、见底宜缓**。

## 二、八条可执行原则（信号 → 动作）

| # | 判据 | 可执行动作 |
|---|---|---|
| P1 | **止损只升不降**（结构跟随）第42页 | 建仓即定止损=信号大阳开盘价；每出新的放量大阳，止损提到其开盘价；**绝不下调** |
| P2 | **顶速底缓** 第47-48页 | 高位看跌组合→次日开盘减仓；低位看涨组合→**等收盘突破该组合最高价**才买 |
| P3 | **盘整不动如山** 第374/23页 | 横盘+信号矛盾→空仓观望，等突破区间再加立场 |
| P4 | **形态强度分级** 第23/46页 | 先判信号在家族强度档位（友淡反攻<乌云盖顶<倾盆大雨<穿头破脚）；弱信号只减仓，强信号清仓 |
| P5 | **有效跌破颈线三项** 第350页 | 收盘破+≥2~3天+≥3%幅才认定；仅下影刺穿→观望 |
| P6 | **量能辨真伪树** 第20/14/94页 | 高位天量大阳=诱多减仓；下跌无量破位=真跌；回调巨量不破支撑=洗盘持股 |
| P7 | **缺口四分+90%回补** 第70/67页 | 盘整跳空量不配→普通缺口做高抛低吸；1周不回补才看突破/测量 |
| P8 | **形态度量目标位** 第350页 | 进场同时算最小目标位（头部/低点到颈线距离）作止盈参考，到达前不轻易丢筹码 |

## 三、术语表（本书元语言，G1–G9）

| 术语 | 作者定义 | 与常识差异 |
|---|---|---|
| 位置 | 形态所处波段（高/低/中/盘整），优先级高于形态本身 | 常识当背景；本书当**决定符号的一级变量** |
| 四看策略 | 位置→量→后市→均线 四步 | 常识只「看形态」（第零步） |
| 确认线 | 信号后第2/3天的 K 线验证 | 常识当即时结论；本书所有信号都是**待确认假设** |
| 有效跌破颈线 | 收盘破+≥2~3天+≥3%幅，下影刺穿不算 | 常识目测刺穿即慌 |
| 缺口四分 | 普通/突破/测量/衰竭；A股普通缺口90%回补 | 同西方，但本书给 A 股量化实证 |
| 洗盘vs出货 | 洗盘=缩量/对倒巨量+**不破支撑**；出货=高位天量大阳诱多 | 常识「洗盘必缩量」被本书证伪 |
| 家族强度 | 按阴线深入阳线深度排序（越深越强） | 常识各形态等权；本书按深入度给力度 |
| 止损只升不降 | 挂结构关键点，随新放量大阳上提 | 常识固定百分比/价位 |
| 信号以后出为准 | 矛盾时最新信号优先 | 反「信号叠加越确定」 |

## 四、边界与警示（诚实记录的失败模式，X1–X7）

- **X1 洗盘黑三兵必缩量=以讹传讹**（第95页）：判洗盘先看**不破支撑**，量可放大。
- **X2 夜星渐强排序=纯逻辑无定论**（第263页）：不机械套强度排序，任何组合等确认线。
- **X3 盘整期形态大多失效**（形态坟场）：横盘信号降级为噪声，按 P3 不动如山。
- **X4 位置只能事后确认**（第48页，最强张力）：单次形态实时胜率不可知；用「确认线+止损」兜底，不依赖当下判位置。
- **X5 高位大阳=诱多骗线**（第14页）：高位涨停大阳+天量→不追、反向警惕。
- **X6 统计概率无样本量**（第15/70页）：70%/80%/90% 当倾向不当保证，实盘样本外自检。
- **X7 跳三跳气数尽仅后段成立**（第369页）：先判初段/后段，初段顺势、后段才看反转；第四次跳空反为警戒。
